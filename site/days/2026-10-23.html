php/php-src

GitHub Trending 1位★ +287CGitHub ↗

Web開発で広く使われるスクリプト言語PHPの公式処理系のソースコード

何ができるか

  • PHP の言語処理系（インタプリタ：ソースコードを読み込んでその場で実行するプログラム）本体をソースからビルドできます。
  • make test で実行できる大規模なテストスイートが同梱されており、並列実行や特定ディレクトリだけのテストもできます。
  • make install で、自分でビルドした PHP をシステムにインストールできます。
  • 多数の拡張機能（PHP に機能を追加するモジュール）が同梱され、追加の拡張は PIE（PHP Installer for Extensions）で導入できます。
  • Windows 向けには windows.php.net でビルド済みバイナリが配布されており、展開するだけで使えます。

なぜ注目されているか

PHP はブログから世界的な大規模サイトまでを支える汎用スクリプト言語であり、このリポジトリはその公式ソースコードです。リポジトリページでは4万を超えるスターを集めています。推測 新バージョンの開発や RFC（新機能の提案と投票の仕組み）による変更が継続的に進んでいるため、注目が集まりやすいと考えられます。

どんな人に役立つか

PHP の内部実装（言語処理系の仕組み）を学びたい人や、PHP 本体へのバグ修正・機能追加に貢献したい人に役立ちます。開発用に --enable-debug 付きでビルドして挙動を調べる使い方もできます。

技術的なポイント

  • 処理系は C 言語で書かれており、ライセンスは Modified BSD License（BSD-3-Clause）です。
  • ビルドには autoconf、bison（構文解析器の生成ツール）、re2c（字句解析器の生成ツール）が必要で、標準構成では libxml2 と libsqlite3 も使います。
  • ./buildconf で configure スクリプトを生成し、./configure と make で組み立てる、Autotools 方式のビルド手順を採っています。
  • 新機能の追加には RFC と開発者による承認が必要で、バグ修正は GitHub の issue 番号をコミットメッセージで参照する決まりになっています。

試し方

  1. Ubuntu などで、ビルドに必要なパッケージをインストールします。
  2. ./buildconf で configure スクリプトを生成します。
  3. 開発用なら ./configure --enable-debug で構成し、make -j4 でビルドします。
  4. make test でテストスイートを実行し、問題なければ make install でインストールします。
sudo apt install -y pkg-config build-essential autoconf bison re2c libxml2-dev libsqlite3-dev
./buildconf
./configure --enable-debug
make -j4
make TEST_PHP_ARGS=-j4 test
make install

luongnv89/claude-howto

GitHub Trending 8位★ +177PythonGitHub ↗

図解とコピペ用テンプレートでClaude Codeを基礎から上級まで学べるガイド

何ができるか

  • スラッシュコマンド、メモリ、チェックポイント、スキル、フック、MCP、サブエージェント、プラグインなど、Claude Code の機能を10のモジュールで順に学べます。
  • スラッシュコマンド、CLAUDE.md のテンプレート、フックのスクリプト、MCP の設定、サブエージェントの定義などを、自分のプロジェクトにそのままコピーして使えます。
  • Mermaid（テキストから図を描く記法）の図で、各機能が内部でどう動くかを説明しています。
  • Claude Code で /self-assessment や /lesson-quiz を実行すると、クイズで自分の理解度を確かめ、足りない部分を見つけられます。
  • 初心者から上級者までのレベル別の学習順序と所要時間（全体で11〜13時間）が示されています。
  • 英語のほか、ベトナム語、中国語、ウクライナ語、日本語の README があり、EPUB の電子書籍も生成できます。

なぜ注目されているか

公式ドキュメントが機能の説明中心なのに対し、機能を組み合わせて実際のワークフローを作る方法を、学習順序付きで教える点を打ち出しています。リポジトリページでは4万を超えるスターを集めており、README では Claude Code のリリースごとに内容を更新していると述べています。推測 Claude Code の利用者が増え、体系的に学べる教材の需要が高まっていることが注目の理由と考えられます。

どんな人に役立つか

Claude Code を入れたものの基本的な使い方にとどまっている人や、フックやサブエージェントを組み合わせてコードレビューやドキュメント生成を自動化したい開発者に向いています。チームの新人向けの学習教材としても使えます。

技術的なポイント

  • 各機能はフォルダ（01-slash-commands/ から 10-cli/ まで）に分かれ、説明とすぐ使えるサンプルファイルが入っています。
  • スラッシュコマンドやサブエージェントは Markdown ファイルとして .claude/commands/ や .claude/agents/ に置くだけで使える形式です。
  • フックはシェルスクリプトとして ~/.claude/hooks/ に置き、イベントに応じて自動実行させます。
  • EPUB の生成は uv run scripts/build_epub.py で行い、ライセンスは MIT です。

試し方

  1. ガイドのリポジトリをクローンします。
  2. 最初のスラッシュコマンドを自分のプロジェクトの .claude/commands/ にコピーし、Claude Code で /optimize と入力して試します。
  3. 続けてプロジェクトメモリ（CLAUDE.md）やスキルをコピーして導入します。
  4. 学習ロードマップに沿って各モジュールを進め、終わるたびに /lesson-quiz で理解度を確かめます。
git clone https://github.com/luongnv89/claude-howto.git
cd claude-howto
mkdir -p /path/to/your-project/.claude/commands
cp 01-slash-commands/optimize.md /path/to/your-project/.claude/commands/
cp 02-memory/project-CLAUDE.md /path/to/your-project/CLAUDE.md
cp -r 03-skills/code-review-specialist ~/.claude/skills/
uv run scripts/build_epub.py

peach-mitao/peach

Trendshift 1位PythonGitHub ↗

ローカルとクラウドの動画を1か所で管理・視聴できる個人用メディアシステム

何ができるか

  • ローカルのハードディスクと、マウントした115、PikPak、OneDrive などのクラウドストレージを1つのコレクションとしてまとめられます。
  • 全画面のカバー画像の壁から作品を選び、その場で再生できます。
  • 既存の NFO（作品情報を書いたメタデータファイル）やポスター画像を読み込み、足りない情報を複数のソースから補えます。
  • FANBOX、Patreon、Kemono など複数サイトのクリエイターの更新をまとめて追えます。
  • 番号の検索や磁力リンクから115や PikPak へのクラウドダウンロードを依頼し、完了後に自動で整理・登録できます。
  • 視聴記録やブラウザ履歴、ブックマークなどから好みを分析します。

なぜ注目されているか

README によると、18歳以上の利用者が自分の成人向けコンテンツのコレクションを管理するためのツールです。リポジトリページでは公開から短期間で8千を超えるスターを集めています。推測 ローカルファースト（データを自分のPCに保存する設計）で複数のストレージやサイトをまとめて扱える点が支持されていると考えられます。

どんな人に役立つか

18歳以上で、ローカルやクラウドに散らばった自分の動画コレクションを1か所で整理・視聴したい人向けです。同じ LAN 内のスマートフォンからも閲覧できます。

技術的なポイント

  • Python で書かれ、ソースから動かすには Git、uv（Python のパッケージ管理ツール）、Python 3.14 以上が必要です。
  • アプリはローカルで動き、ブラウザから閲覧・再生する構成で、データは本機の peach-data フォルダに保存されます。
  • クラウドストレージは CloudDrive2 などでローカルディレクトリとしてマウントして扱います。
  • Windows 用インストーラー、macOS 用の .app と DMG、VPS や NAS 向けの Docker で配布されます。
  • スキャンや更新取得は進捗を保存し、再起動後に未完了分から再開します。

試し方

  1. Windows では Releases から完全版インストーラーを入手してインストールします（管理者権限は不要です）。
  2. ブラウザで初回設定ページが開いたら、メディアのディレクトリとアクセス範囲を選びます。
  3. スキャンを開始し、ブラウザで閲覧・再生します。

seedds/nxnative

Trendshift 2位CGitHub ↗

手持ちのSwitchゲームをエミュレータなしでiPhoneやiPadでネイティブ実行する変換ツール

何ができるか

  • 自分の Nintendo Switch ゲームの NSP ファイル（ゲームのパッケージ）と prod.keys から、スクリプト1本で iPhone や iPad 用の IPA（iOS アプリのパッケージ）を作れます。
  • 作った IPA は AltStore や Sideloadly などのサイドロード（App Store を通さずにアプリを入れること）ツールで端末にインストールします。
  • スーパーマリオブラザーズ ワンダー、ゼルダの伝説 ブレス オブ ザ ワイルドなど多数のタイトルが iPhone で動作確認済みで、一部は更新データ適用時に60fpsで動きます。
  • 起動前の設定画面でフレームレート、描画解像度、据え置き・携帯モード、言語を選べ、タッチ操作の2D・3Dレイアウトやゲームコントローラーにも対応します。
  • Apple の開発者アカウントがあれば、IPA の代わりに Xcode プロジェクトを作って実機へ直接インストールすることもできます。

なぜ注目されているか

エミュレータ（別の機械の動作をソフトウェアで再現するもの）ではなく、ゲーム自身のコードを Apple のチップで直接動かし、グラフィックスを Metal で作り直すという方式を採っています。リポジトリページでは公開から短期間で2千を超えるスターを集めています。推測 人気タイトルが iPhone で、しかも元の Switch より高いフレームレートで動く例があることが注目の理由と考えられます。

どんな人に役立つか

Switch のゲームを自分で所有していて、iPhone 15 Pro 以降や M1 以降の iPad で遊びたい人に向いています。ゲーム機のバイナリ変換やグラフィックス API の変換の仕組みを学びたい人にも参考になります。

技術的なポイント

  • NSO（Switch の実行ファイル形式）を書き換えるリライター、Switch の OS である Horizon の代わりを務めるホスト、NVN（Switch のグラフィックス API）を Metal 上で動かす層で構成されています。
  • Ryujinx のシェーダー変換器でゲームの Maxwell 向けシェーダーを SPIR-V に変換し、SPIRV-Cross で Metal Shading Language に変換します。
  • ゲームのテクスチャは BC 圧縮形式のため、それを読める A17 Pro 以降の iPhone か M1 以降の iPad と、iOS/iPadOS 26 以降が必要です。
  • d2r-mobile が開発したネイティブ実行の手法をもとにしており、NSP の読み込みには LibHac を使っています。
  • リポジトリにはゲームのデータは一切含まれず、ライセンスは MIT です。

試し方

  1. Xcode と Homebrew の入った Mac にリポジトリを取得し、必要なツールをインストールします。
  2. 1本のゲームの NSP（本体、あれば更新データと DLC）を1つのフォルダに入れます。
  3. build_ipa_from_nsp.py にフォルダと prod.keys を指定して IPA を作ります（初回は30〜60分かかります）。
  4. できた IPA をサイドロードツールでインストールし、可能なら Increased Memory Limit の権限を付けて署名します。
git clone https://github.com/seedds/nxnative.git && cd nxnative
brew install xcodegen zstd spirv-cross glslang
brew install --cask dotnet-sdk
python3 -m pip install lz4 capstone fonttools "backports.zstd; python_version < '3.14'"
python3 scripts/build_ipa_from_nsp.py ~/Games/MarioWonder -k ~/keys/prod.keys

EthanArbuckle/fairplay-decrypt

Trendshift 7位CGitHub ↗

FairPlay暗号化されたiOSアプリ（IPA）をオフラインで復号するツール

何ができるか
