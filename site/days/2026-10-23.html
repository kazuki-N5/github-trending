どんな人に役立つか

  • 観看記録・ブックマーク・ブラウザ閲覧履歴を組み合わせた多次元のTaste分析エンジンを内蔵する。
  • クラウドダウンロードはAPI連携（115・PikPak）で行い、ダウンロード後に自動整理される。
  • エラー診断はSentryへのオプション送信で行い、データベースや視聴履歴は送信しない。

試し方

  2. ブラウザで初回設定ページを開き、メディアディレクトリとアクセス範囲を選択する。
  3. スキャンを開始して、ブラウザでコレクションを閲覧・再生する。

Renhuai123/ziwei-doushu

Trendshift 7位TypeScriptGitHub ↗

倪海厦『天纪』体系に基づく紫微斗数オープンソース排盤エンジンと大規模解読データセット

何ができるか

  • 完全な紫微斗数排盤アルゴリズムを実装し、四化システム・格局知識庫・古籍原文データを含む。
  • 公暦1950〜2026年の実在する全日付をカバーする約67.5万命盤×13次元の解読データセット（v4.0、解凍後56.6GB）を公開している。
  • 真太陽時補正・中国夏令時・農暦/公暦相互変換・十二神煞・運限コンテキストなど8つの補助モジュールを備える。
  • 5件の排盤回帰テストとCI（GitHub Actions）を整備しており、npm testで一括実行できる。
  • 倪師『天纪・紫微斗数』の原話1848条を第五集まで網羅し、各条が動画の再生時刻へリンクされている。

なぜ注目されているか

推測 CC BY 4.0で商用利用可能な大規模命盤解読データセットはほとんど存在せず、AI/LLMのファインチューニングや占いアプリ開発に使いやすい点が注目を集めている。断語の出典を倪師原話や古籍に逐一照合して校正した透明性の高さも研究用途で評価されている。

どんな人に役立つか

紫微斗数アプリ・占いサービスを開発したいエンジニア、またはAI学習用に大規模な命盤テキストデータが必要な研究者向け。中国伝統占星術を学ぶ人が排盤アルゴリズムのリファレンス実装として使うこともできる。

技術的なポイント

  • TypeScript（Next.js 16ベース）で実装され、排盤エンジンはフロントエンドから独立したモジュール群として設計されている。
  • データセットはzstd（長窓口27）で圧縮したJSONL形式で、年ごとに分割ダウンロードが可能。
  • 排盤は決定的生成（同一入力→同一出力）でAIを介さず、断語ライブラリとの組み合わせで全文を生成する。
  • 真太陽時補正は経度差と均時差の両方を考慮し、1986〜1991年の中国夏令時にも対応する。

試し方

  1. リポジトリをクローンして npm install を実行する。
  2. npm test でCIが通ることを確認する。
  3. データセットはReleasesページ（v4.0-13d）から年単位でダウンロードし、zstd -d --long=27 で解凍する。
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu && npm install
npm test
zstd -d --long=27 year-1990.jsonl.zst
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
