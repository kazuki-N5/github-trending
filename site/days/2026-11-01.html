vercel-labs/agent-desktop

Trendshift 2位RustGitHub ↗

AIエージェントがOSのアクセシビリティツリーでデスクトップアプリを安定操作できるCLI

何ができるか

  • デスクトップアプリのUI構造をOSのアクセシビリティツリー経由でJSONスナップショットとして取得できる
  • 各UI要素に参照（ref）を割り当て、ピクセル推測に頼らず安全に操作・再試行できる
  • macOS・Windows・Linux対応のCLIツールおよびCライブラリとして提供されている
  • npmでインストール可能で、観察・操作・キーボード・マウスなど約60種類のコマンドを提供する
  • C FFIライブラリ（libagent_desktop_ffi）により、他のプログラムからインプロセスで呼び出せる
  • エージェント向けに組み込みドキュメント（skills get desktop / platform）を内蔵している

なぜ注目されているか

推測 AIエージェントによるコンピュータ操作（Computer Use）の需要が高まる中、画面ピクセルを解釈する手法より信頼性の高いアクセシビリティツリーを活用した手法として注目されていると考えられる。推測 Vercel Labsが公開していることから、AIエージェントとデスクトップGUIの連携を標準化しようとする取り組みとして関心を集めているとみられる。

どんな人に役立つか

AIエージェントにデスクトップ自動化機能を組み込みたい開発者に向いている。コンピュータ操作を行うAIエージェントを構築・研究しているエンジニアや研究者にも活用できる。デスクトップアプリのテスト自動化やRPA（ロボティック・プロセス・オートメーション）に興味がある学生にも参考になる。

技術的なポイント

  • Rustで実装されており、パフォーマンスと安全性を確保しつつmacOS・Windows・Linuxのクロスプラットフォームに対応している
  • OSごとのアクセシビリティAPI（macOS: AX API、Windows: UI Automation、Linux: AT-SPI2）を通じてUI要素の実構造にアクセスする
  • スナップショットとrefの組み合わせにより、操作対象が古くなった場合はエラーを返して再スナップショットを促す安全な設計になっている
  • C FFI（Foreign Function Interface：異なるプログラミング言語間でCライブラリを共有する仕組み）によりRust以外の言語からも組み込み可能
  • レスポンスはJSONエンベロープ形式（okフィールド＋dataまたはerror）で統一されており、エージェントが扱いやすい設計になっている

試し方

  1. npmでグローバルインストールする
  2. ターミナルでスナップショットコマンドを実行し、アプリのUI構造（JSON）を確認する
  3. 取得したrefを指定して操作コマンドを実行し、再度スナップショットで結果を確認する
  4. 組み込みドキュメントコマンドでOS別の詳細な使い方を参照する
npm install -g agent-desktop
agent-desktop skills get desktop
agent-desktop skills get platform

heydamir/unslop

Trendshift 4位JavaScriptGitHub ↗

AIっぽいUIを本物のデザインへ変換するClaudeスキル

何ができるか

  • UIの「スロップ（AI特有の没個性な見た目）」を自動検出し、紫グラデーション・グロー・絵文字ラベル・不揃いな余白などを洗い出す。
  • プロダクトの内容に合わせたデザイン方向性を提案し、複数パスで段階的にUIを修正する。
  • Next.js・React・Vue・Svelte・Tailwind・プレーンHTML/CSSなど主要なスタックに対応している。
  • ダッシュボード・アプリ・ランディングページのほか、URLで渡したライブサイトにも対応している。
  • 確認を取ったうえで画像生成サービスを通じてヒービジュアルを生成できる。
  • Playwrightとffmpegがあれば、画面の短い正方形ストーリー動画を生成できる。

なぜ注目されているか

推測 AIコーディングツールで量産されるUIが特定のパターン（紫グラデーション・グロー・絵文字多用など）に偏りがちという問題が開発者コミュニティで広く認識され始めている。推測 Claude自身をデザインエージェントとして活用しUIを自動改善するというアプローチが新しく、デザイナー不在のチームでも手軽にUI品質を高められる点が注目を集めている可能性がある。

どんな人に役立つか

AIコーディングツールでプロトタイプを作成したがデザインが「AI感丸出し」になってしまった開発者に向いている。デザイナーが不在で見た目をなんとかしたいスタートアップやソロ開発者にも役立つ。/unslopコマンド一つでデザイン改善を試したい人に適している。

技術的なポイント

  • ClaudeのスキルシステムはSlashコマンド（/unslop）で呼び出せるプラグイン機構で、~/.claude/skills/または.claude/skills/ディレクトリに配置するだけで導入できる。
  • LLM（大規模言語モデル）が画面を「監査」してUI上の視覚的問題を検出し、複数パスで段階的に修正するアプローチを採用している。
  • Playwright（ブラウザ自動操作ライブラリ）でスクリーンショットを撮影し、ffmpeg（動画処理ツール）で短い動画を生成する。
  • 外部の画像生成サービスと連携してヒービジュアルを作成でき、有料APIの呼び出し前に必ず確認を求める設計になっている。

試し方

  1. skills/unslopフォルダを~/.claude/skills/（全プロジェクト共通）またはプロジェクトの.claude/skills/（プロジェクト固有）にコピーする。
  2. ClaudeのCLIで/unslopと入力してスキルを呼び出し、改善したい画面やURLを伝える。
cp -r skills/unslop ~/.claude/skills/

  • 内蔵ブラウザで閲覧中のページについてAIに質問できる
  • ユーザーの好みを記憶し、完了したタスクを再利用可能なスキルとして登録できる
  • スケジュール実行や条件付きタスク、タスクの中断・停止に対応する
  • arm64端末向けのLinuxサンドボックスでファイル操作やコードの実行ができる

なぜ注目されているか

推測 スマートフォン上でAIが人間の代わりにアプリを操作するというコンセプトが注目を集めている。サーバー不要でデータが端末外に出ないプライバシー設計と、APIなしで多くのアプリに対応できる汎用性が評価されている可能性がある。

どんな人に役立つか

Androidアプリの繰り返し操作を自動化したい人や、AIに作業を委任しながら自分は別の作業をしたいユーザーに適している。開発者にとってはCLI・MCP経由でPCから制御できる点も魅力になる。

技術的なポイント

  • KotlinでAndroidネイティブアプリとして実装されており、Android 11以降（アプリ操作はAndroid 12以降推奨）に対応する
  • 画面内容をAIが解析して操作対象を特定するアクセシビリティ技術を活用し、対象アプリのAPI不要で動作する
  • OpenAI互換・Anthropic・Geminiなど複数のモデルプロバイダーエンドポイントをカスタム設定できる
  • API鍵とメモリをデバイス上に暗号化保存し、データをMikaのサーバーに送らないプライバシー重視の設計を採用している
  • arm64端末ではLinuxサンドボックスを内蔵し、ファイル処理やコード実行もAIエージェントが担える

試し方

  1. GitHubのReleasesページからAPKファイルをダウンロードしてAndroid端末にインストールする
  2. アプリを起動してモデルプロバイダー（APIキーまたはアカウントログイン）を設定する
  3. アプリ操作機能を使う場合はワイヤレスデバッグのペアリングを行う

deepseek-ai/dsh-superagent-prototype

Trendshift 7位TypeScriptGitHub ↗

GitHubリポジトリ向けの自律型コーディングエージェント

何ができるか

  • GitHubのイシューやコメントを監視し、許可されたユーザーからのリクエストに応じて自動的に作業を開始する
  • 作業を独立したエージェントセッションとディレクトリで実行し、完了するとプルリクエストを作成して返答する
  • Feishu（Lark、企業向けチャットツール）との連携により、チャットからコーディング作業を依頼できる
  • チームが定義したポリシー（ルール）に基づき、エージェントが自律的に行動できる範囲を細かく制御できる
  • Webパネルで人間の確認が必要な作業アイテムを一覧表示し、作業状況をひと目で把握できる

なぜ注目されているか

推測 GitHubでの自動コーディングエージェントへの関心が高まる中、DeepSeekがその実装の仕組みを研究プロトタイプとして公開したことで注目を集めていると考えられる。「人間の注意を最小限に抑えつつ最大の価値を提供する」という設計思想と、実際に動作するプロトタイプが公開されている点が評価されているとみられる。

どんな人に役立つか

GitHubリポジトリを管理する開発チームで、イシュー対応や反復的なコーディング作業を自動化したいエンジニアに役立つ。DeepSeek Harness（DSH）を使ったマルチエージェントシステムの研究者や、エージェント型AIシステムの設計パターンを学びたい学生にも参考になる。

技術的なポイント

  • TypeScriptで実装されており、DeepSeek Harness（DSH）というエージェント実行基盤（ランタイム）上で動作する
  • Cordisプラグインシステム（依存性注入を使ったモジュール構成の仕組み）を採用し、GitHubやFeishuなどの外部サービスとの連携を拡張可能な設計にしている
  • tmux（ターミナルの多重化ツール）を使って独立したセッションでエージェントの作業を実行し、プロセスを分離する
  • GitHub CLI（gh）でGitHub APIの認証・操作を行い、プルリクエストの作成などを自動化する

試し方

  1. Node.js 22.19以上、pnpm、git 2.32以上、tmux、Python 3.8以上、GitHub CLI 2.48以上をインストールし、DSHのバージョンがpackage.jsonのengines.dsh範囲内であることを確認する
  2. SETUP.mdとdocs/000-philosophy.mdを読んでから作業を始める
  3. プローブコマンドを実行して必要なツールが揃っているか確認する
  4. エージェント用のGitHubアカウントを作成し、対象リポジトリへの招待を承認する
  5. docs/006-deployment.mdに従いインストール・マシン設定・起動停止の手順を実施する
node -v; pnpm -v; git --version; tmux -V; python3 --version; gh --version | head -1; dsh --version
gh api user --jq .login
pnpm check

patch-gg/pixelfx

Trendshift 9位JavaScriptGitHub ↗

244種類のピクセルアートエフェクトをコード1つずつで実装したライブラリ

何ができるか

  • 火・爆発・水・氷・雷・SF・近接・聖・影・天候・UI・アイテム・遷移・生き物など244種類のエフェクトを収録している
  • npmまたはsrcフォルダのコピーだけで依存関係なしにブラウザのcanvasで動作する
  • nodeツールでスプライトシートとAseprite形式のJSONを出力しGodot・Unity・Phaserなどのゲームエンジンに対応している
  • paletteオプションでコードを変更せずにエフェクトの色を自由に変更できる
  • Claude Codeのプラグインとして追加すれば、エフェクトの検索・使用・エクスポート・新規作成をAIに依頼できる
  • tools/new.mjs・render.mjs・check.mjs でエフェクトの雛形作成・プレビュー・品質チェックができる

なぜ注目されているか

推測 ゲーム開発でよく使われるピクセルアートのエフェクトをコード単位で再利用できる形にまとめた点が注目を集めている。さらにClaude Codeと連携してAIが新しいエフェクトを生成できる仕組みを提供しており、AIを活用したゲームアセット制作ワークフローへの関心と合致している。

どんな人に役立つか

ピクセルアートスタイルの2Dゲームを開発するインディーゲーム開発者やゲームジャム参加者に役立つ。GodotやUnity・Phaserなどのエンジンユーザーがスプライトシート出力機能を使ってすぐにアセットとして取り込める。Claude Codeを使って独自エフェクトを自動生成したいエンジニアにも適している。

技術的なポイント

  • エフェクトは時間値のみから各フレームを計算するピュアな関数として実装されており、シームレスなループを実現している（純粋関数: 同じ入力に対して常に同じ出力を返す関数）
  • パーティクル（粒子）をシミュレートするエフェクトは120Hzでステップ計算し、ランダム値はシード（再現可能な乱数の初期値）付きで生成される
  • 色情報とadditive light（加算ブレンド: 光の重ね合わせ表現）を別バッファで管理することで発光表現を実現している
  • グレーのダミーキャラクターはフラットトーンとインクラインで描画された3Dスケルトンをレンダリングしている
  • node tools/render.mjs でAseprite形式のJSONとスプライトシートを出力しエンジン向けエクスポートに対応している

試し方

  1. npmでインストールするか、src/coreと必要なエフェクトファイルをコピーする
  2. ブラウザのcanvas要素にエフェクトをインポートして実行する
  3. エンジン向けにスプライトシートを出力する場合はnode tools/render.mjs <id> --sheetを実行する
  4. Claude Codeプラグインとして使う場合は/plugin marketplace add patch-gg/pixelfxを実行後、/plugin install pixelfx@pixelfxを実行する
npm i github:patch-gg/pixelfx
node tools/render.mjs <id> --sheet
/plugin marketplace add patch-gg/pixelfx
/plugin install pixelfx@pixelfx
