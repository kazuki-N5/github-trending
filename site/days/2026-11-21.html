imxieyi/Kernarium

Trendshift 5位C++GitHub ↗

iOSでLinuxカーネルをネイティブ実行しAndroid・Dockerも動かす

何ができるか

  • User-mode Linuxカーネル（6.18 LTS）をarm64にネイティブコンパイルし、エミュレーションなしでiOS上で動作させる。
  • ユーザースペースプログラムはiSH方式のスレッド型インタープリタで実行し、SMPもサポートする。
  • KosmicKrisp（VulkanからMetalへの変換）によりGPUアクセラレーションを実現し、OpenGL 4.6やGLES 3.2にも対応する。
  • arm64・arm32・x86_64のゲスト命令に対応し、インタープリタとJITの両モードを提供する。
  • 仮想ディスク（UBDドライバ）・ext2/3/4・xfs等の各種Linuxファイルシステム・FUSEをサポートする。
  • libslirpによるゲストネットワークアクセスを含む完全なLinuxネットワークスタックを備える。

なぜ注目されているか

推測 UTMのような完全システムエミュレータとiSHのようなユーザースペースエミュレータの中間に位置する独自アーキテクチャを実現しており、実際のLinuxカーネルと軽量なユーザースペースエミュレーションを組み合わせた点が技術的に注目される。すでにAndroidエミュレータ（Andarium）をApp Storeで公開（後に削除）した実績があり、Docker・Wine/Proton・Linuxデスクトップの動作も目標としていることから、iOSデバイスの活用幅を大きく広げる可能性がある。

どんな人に役立つか

iOSデバイス上でLinux・Androidを動かしたいモバイル開発者や研究者向け。User-mode Linuxや組み込みLinuxに興味があるシステムプログラマにも適している。

技術的なポイント

  • User-mode Linuxカーネルをarm64にネイティブコンパイルし、iOSランタイムフレームワークにリンクして動作させる。
  • iSH方式のスレッド型インタープリタとJITによりx86_64・arm64・arm32のゲスト命令を実行する。
  • KosmicKrispによるVulkan 1.4→Metal変換と、ZinkによるOpenGL 4.6/GLES 3.2エミュレーションでGPUを活用する。
  • VideoToolboxを介したH.264/HEVCのハードウェアエンコード・デコードに対応する。
  • UBDドライバによる仮想ディスク、各種Linuxファイルシステム、FUSEをサポートし柔軟なストレージ構成が可能。

試し方

  1. READMEにはステップバイステップの手順は記載されていない。開発者はリポジトリをコーディングエージェントに渡してAGENTS.mdを参照するよう案内されている。
  2. Androidシステムイメージのビルドには高性能なx86_64 Linuxマシンが必要。ビルド済みイメージはGitHubリリースページから入手可能。
  3. Andarium（AndroidエミュレータアプリのIPA）はGitHubリリースページからサイドロードできる。

zhouxiaoka/autoclip

Trendshift 7位PythonGitHub ↗

1つのリンクからAIが自動でショート動画を生成するオープンソースツール

何ができるか

  • 動画URLを貼り付けるだけで、抖音・TikTok・YouTube Shortsなど複数プラットフォーム向けのショート動画を自動生成する
  • 各クリップにカバー画像・タイトル・説明文・ハッシュタグを自動生成し、ZIPパッケージとしてまとめて書き出す
  • 字幕はWhisper・SenseVoice（ローカル）またはクラウド文字起こしから取得でき、既存のSRTファイルの再利用も可能
  • インタビュー形式とポッドキャスト形式の2種類の縦型レイアウトに対応し、発言者の顔を自動追尾してフレーミングする
  • デスクトップアプリ・CLI・Docker/Webデプロイ・MCPサーバーの4つの利用形態をサポートする
  • クラウドモデルとローカルモデル（OllamaやLM Studio）を選択でき、送信データの範囲も明示されプライバシーに配慮している

なぜ注目されているか

推測 ポッドキャストや講義などの長尺動画をショート動画に変換する作業は手間がかかるが、このツールはURLを渡すだけで字幕・カバー・文案の生成まで一括自動化できる点が際立っている。推測 デスクトップアプリからMCPサーバーまで幅広い利用形態に対応しており、個人クリエイターから開発者・エージェント連携まで多様なユースケースをカバーしているのも注目点である。

どんな人に役立つか

ポッドキャスト・インタビュー・講義などの長尺動画を複数SNS向けに効率よく展開したいコンテンツクリエイターに向いている。自分のAPIキーや映像をローカルで管理したいユーザーや、CLIやMCPを通じてAIエージェントと連携したいエンジニアにも適している。

技術的なポイント

  • バックエンドはPython + FastAPIで構築され、動画処理にFFmpeg・yt-dlpを使用している
  • 音声認識にはOpenAI Whisper・FunASR・SenseVoiceを利用し、ローカルとクラウドの両方に対応している
  • フロントエンドはReact、デスクトップアプリはTauriで実装されておりクロスプラットフォームで動作する
  • DockerとRedisを使ったWebデプロイに対応しており、MCPサーバーとしてAIエージェントから呼び出すことも可能
  • OpenAI互換API・Ollama・LM StudioなどのモデルプロバイダーをSettings画面から切り替えられる

試し方

  1. GitHubリリースページからデスクトップインストーラー（macOSは.dmg、Windowsは-setup.exe）をダウンロードしてインストールする
  2. Settings画面でモデルプロバイダーとAPIキーを設定し、接続テストを行う
  3. 動画URLを貼り付けて対象プラットフォームを選択し、生成を実行する
  4. CLIを使う場合はPython 3.10以上とFFmpegをインストールしてからuvx autoclip-mcpでセットアップする
  5. Dockerを使う場合はリポジトリをクローンしてenv.exampleを.envにコピー、dataとlogsとuploadsディレクトリを作成してdocker compose up -d --buildを実行する
uvx autoclip-mcp
autoclip --version
autoclip produce talk.mp4 --srt talk.srt --platform douyin --portrait-style podcast --json
autoclip outputs PROJECT_ID --export-kits
autoclip mcp
docker compose up -d --build

iamajmeena/neonclipping

Trendshift 8位PythonGitHub ↗

YouTubeなどの長動画を9:16縦型クリップに自動変換するローカルAIエンジン

何ができるか

  • 音声優先の高速モードで85分の動画を約97秒でクリップ化できる
  • OllamaのローカルLLMがハイライトのスコアリングとタイトル・フックの文章生成を行う
  • ユーザーの5段階評価を学習し、8件の評価後にハイライト検出の重みを個人の好みに自動調整する
  • 11種類のレイアウト、5種類のキャプションスタイル、SRT/WebVTT/ASSのインポート・エクスポートに対応
  • TwitchやYouTube Liveのリアルタイムクリッピングとチャットスパイク検知をサポート
  • アカウント不要・完全ローカル動作でプライバシーを保護し、サーバーは127.0.0.1のみにバインド

なぜ注目されているか

推測 クラウドサービス不要でローカルLLMとFFmpegのみで動作するため、コストとプライバシーの両面で優れている。ライブ配信のリアルタイムクリッピングや視聴者評価による学習機能など、実用的かつユニークな機能を無料のオープンソースで提供している点が注目に値する。

どんな人に役立つか

YouTube・Twitch・Kickの長時間配信やゲーム動画からSNS用の縦型ショートクリップを作りたいストリーマーやコンテンツクリエイター向け。Windowsユーザーはワンクリックセットアップで手軽に始められ、Python 3.10以上とFFmpegがあればMac・Linuxでも動作する。

技術的なポイント

  • バックエンドはFastAPIで構築されたローカルWebサーバー（ポート8770）として動作する
  • 音声解析にfaster-whisper（ローカルWhisper）、動画処理にFFmpegとOpenCVを使用
  • OllamaのローカルLLM（llama3.2:3b推奨）でモーメントのスコアリングと文章生成を行う
  • YuNetモデルでフェイスカムを自動検出し、9:16フレームへの顔の最適配置を実現
  • NVENCによるGPUエクスポートをサポートし、x264フォールバックも内蔵

試し方

  1. Python 3.10以上とFFmpegをPATHにインストールする（Windowsはワンクリックの.batが自動処理）
  2. リポジトリをクローンしてプロジェクトディレクトリへ移動する
  3. 起動スクリプトを実行し、ブラウザでhttp://127.0.0.1:8770を開く
  4. 任意でOllamaをインストールしllama3.2:3bモデルを追加するとAI機能が有効になる
git clone https://github.com/iamajmeena/neonclipping
cd neonclipping
./run.ps1   # Windows
./run.sh    # Linux / macOS

heartleo/zlib

Trendshift 16位GoGitHub ↗

Z-LibraryのCLIツール。検索・ダウンロード・AI連携対応

何ができるか

  • 年・言語・フォーマットなどのフィルターを使って書籍を検索できる
  • お気に入り・おすすめ・人気書籍・ダウンロード履歴をブラウズできる
  • 書籍をダウンロードし、KindleやWeReadへ送信できる
  • 電子書籍のメタデータの確認・編集が行える
  • MCPサーバーとして登録でき、Claude・Codex・GrokなどのAIエージェントと連携できる
  • ターミナルでカバー画像の表示や日次ダウンロード上限の確認ができる

なぜ注目されているか

推測 Z-Libraryへのアクセスをコマンドラインから効率的に行えるため、開発者やパワーユーザーに有用なツールと考えられる。MCPサーバー機能によりAIエージェントとの統合が可能な点は、AIを活用したワークフローに対応している点で注目に値する。

どんな人に役立つか

Z-Libraryを頻繁に利用する開発者やリサーチャー向け。AIエージェントと連携して書籍検索・ダウンロードを自動化したいユーザーにも適している。

技術的なポイント

  • Go言語で実装されたCLIツール
  • MCPサーバーとして動作し、AIエージェントと連携可能
  • Homebrew、winget、インストールスクリプト、バイナリなど複数のインストール方法に対応
  • ほとんどのコマンドが--jsonオプションによるスクリプト連携をサポート
  • ミラーサイトやプロキシの設定が可能

試し方

  1. Homebrew・インストールスクリプト・winget・バイナリからいずれかの方法でインストールする
  2. zlib doctorを実行して到達可能なドメインを確認する
  3. zlib loginで対象ドメインにログインする
  4. zlib tuiでインタラクティブシェルを起動し、/でコマンド一覧を確認する
brew install zlib-cli
zlib doctor
zlib login
zlib tui
zlib search
zlib download

zlib mcp

XinaTian/MROffice

Trendshift 17位TypeScriptGitHub ↗

オープンソースの6種類エディタ（文書・表計算・プレゼン・PDF・手書き・コード）

何ができるか

  • ドキュメントエディタはスタイル、表、コメント、変更追跡、ペンインクをサポートし、.mrdoc形式で保存する
  • 表計算エディタはセル演算式、数値フォーマット、条件付き書式、並べ替え、複数シートに対応し、CSVやTSVも扱える
  • プレゼンエディタはテーマ、スライドマスター、アニメーション、トランジション、スライドショーをサポートする
  • PDFエディタは読み取り、検索、印刷、テキストへの注釈付けができる
  • 手書きエディタは筆圧対応のペンノートを提供し、インクを図形に変換できる
  • コードエディタはシンタックスハイライトとアウトライン表示を備え、JS/TS・Python・SQL・Lua・シェルをブラウザで実行できる

なぜ注目されているか

推測6種類のエディタを一つのオープンソースプロジェクトとして公開することで、様々なドキュメント形式の編集機能をブラウザやElectronアプリに組み込める点が注目される。推測MROfficeデスクトップアプリとの連携でWord/Excel/PowerPointファイルのサポートも可能になるため、既存のOfficeエコシステムとの互換性も確保できる。

どんな人に役立つか

ブラウザやデスクトップアプリにドキュメント編集機能を組み込みたい開発者向けのプロジェクトである。MicrosoftOfficeファイルの読み書きを必要とするアプリ開発者にも適している。

技術的なポイント

  • TypeScriptで実装されており、npmでビルドおよび実行できる
  • ブラウザ（apps/playground）とElectronデスクトップ（apps/desktop）の両環境をサポートする
  • @mrnote/coreパッケージが6つのエディタを共通基盤として統合している
  • apps/mcpによりAIアプリ向けMCPサーバーも提供される
  • ライセンスはAGPL-3.0で、商用利用向けには別途商用ライセンスも取得できる

試し方

  1. npmの依存関係をインストールする
  2. npm run fontsでOfficeフォントの代替をセットアップする
  3. npm run buildでプロジェクトをビルドする
  4. npm run previewでhttp://localhost:5178にてプレビューを確認する
npm install
npm run fonts
npm run build
npm run preview

Windows Narratorを悪用したロック画面バイパスの0day脆弱性

何ができるか

  • Windows 11のロック画面でNarratorの脆弱性を利用して認証を回避できる
  • BitLocker暗号化が有効なマシンでもロック画面をバイパス可能
  • Windows 11 26H2（2024年11月パッチ適用済み）で動作確認済み
  • Narratorが所有するバックグラウンドウィンドウ経由でシステム設定にアクセスできる
  • 攻撃にはMicrosoftアカウントにリンクされたローカルアカウントが必要
  • パッチが未提供の状態であり、影響を受けるマシンはリスクにさらされている

なぜ注目されているか

推測 Microsoftが未対応の0day脆弱性であり、物理アクセスのあるWindows 11デバイスのBitLocker保護を回避できる重大なセキュリティ問題として注目される。推測 最新の2024年11月パッチ適用済み環境でも再現可能な点と、BitLocker回避という高いインパクトが、セキュリティ研究者の関心を集めている。

どんな人に役立つか

Windowsのセキュリティ研究者や侵入テスト担当者を主な対象としている。企業や組織のシステム管理者がBitLockerおよびロック画面の設定を見直す際の参考情報としても有用である。

技術的なポイント

  • Windows Narratorのアクセシビリティ機能の脆弱性を悪用したロック画面バイパス手法
  • BitLocker暗号化環境でも物理アクセスのみで攻撃が成立する
  • Windows 11 26H2（2024年11月パッチ）で確認済み、Windows 10での動作は未確認
  • 攻撃条件：デバイスへの物理アクセスおよびMicrosoftアカウントにリンクされたローカルアカウントの存在

タスクバーにメッセージや画像を表示するPoCツール

何ができるか

  • タスクバー上にテキストセグメントをリアルタイムで表示できる
  • base64エンコードした画像もタスクバーに送信して表示可能
  • ローカルHTTPサーバー（ポート19876）経由でデータを受け付ける
  • HTTP POSTリクエストでJSONデータを送ることでコンテンツを更新できる
  • Museと連携して動作するプルーフオブコンセプト実装

なぜ注目されているか

推測 Museのようなタスクバーツールと連携し、天気情報や通知などをタスクバーに表示できる点で実用性がある。KrisGfxのワイヤレスデバイスバッテリーモニターからヒントを得ており、HTTP経由でカスタムデータをタスクバーに送るアーキテクチャの参考例として注目に値する。

どんな人に役立つか

Museユーザーでタスクバーにカスタム情報を表示したい人向け。curlやスクリプトからHTTP経由でタスクバーにデータを送りたいPythonユーザーや開発者にも適している。

技術的なポイント

  • Pythonで実装されたローカルHTTPサーバー
  • ポート19876でHTTP POSTリクエストを受け付けるJSON API
  • テキストおよびbase64エンコード画像の両方を処理できる
  • Pythonの仮想環境（venv）で依存関係を管理

試し方

  1. リポジトリをクローンする
  2. Pythonの仮想環境を作成し有効化する（WindowsではPowerShellで.venvフォルダを作成）
  3. requirements.txtから依存関係をインストールする
  4. hekoo.pyを実行してサーバーを起動する
  5. curlとjoを使ってlocalhost:19876にHTTP POSTリクエストを送信する
git clone https://github.com/sharl/hekoo
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python hekoo.py
