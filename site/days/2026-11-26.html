Trendshift 4位JavaScriptGitHub ↗

ShadowrocketでGoogle Oneのサブスク応答を書き換えるiOSモジュール

何ができるか

  • one.google.comへのHTTPS通信をインターセプトし、レスポンス内のプロダクトIDを書き換える
  • 2TBや20TB・30TBなどの複数プランに対応したデフォルトマッピングルールが付属している
  • ローカル管理画面からマッピングルールの追加・編集・有効化・削除が行える
  • 収集したプロダクトIDのデータをJSON形式でエクスポートできる
  • データはデバイス上にのみ保存され、外部へのネットワーク送信は行われない

なぜ注目されているか

推測 Google Oneの高額プランを安価なプランIDに差し替えるハックとして技術的関心を集めている。iOSのShadowrocketを用いたMITMによるHTTPSレスポンス書き換えという手法が注目されている。ただし、Googleの利用規約に抵触する可能性があることがREADMEでも言及されている。

どんな人に役立つか

iOSデバイスでShadowrocketを利用し、Google Oneの購入フローを操作したいユーザー向け。またHTTPSインターセプトやレスポンス書き換えの実装手法に興味のある開発者にとっても参考になる。

技術的なポイント

  • ShadowrocketのHTTPS復号機能を使い、one.google.comの通信をMITMでインターセプトする
  • 書き換えロジックはJavaScriptで実装されており、Node.js 18以上でオフラインテストが可能
  • 配布はGitHub/jsDelivr URLにバージョンを固定したShadowrocketモジュール形式で行う
  • QUIC/UDP 443のルーティングにも影響する場合があり、他のアプリの通信にも波及することがある

試し方

  1. one.google.comのHTTPS復号をShadowrocketで有効にする
  2. ShadowrocketのルートCA証明書をインストールし、デバイスで信頼設定を行う
  3. テストはNode.js 18以上の環境で実行する
node tools/build-variants.cjs --check
node --test tests/*.test.cjs

どんな人に役立つか

Trendshift 12位JavaScriptGitHub ↗

Antigravity用の光学UI・ばね振動アニメ・思考翻訳を備えたObsidian Prismプラグイン

何ができるか

  • 4種のライト/ダーク配色テーマと512Kコンテキストゲージで外観をカスタマイズできる。
  • 減衰ばねのアニメーションコレオグラフィーでUI操作に流れるような動きを加える。
  • 内蔵ブラウザ・大容量ファイルビューア・インラインdiffプレビューを提供するワークベンチ機能がある。
  • ピクセルアートのマスコットキャラクターをUI上に表示できる。
  • モデルの思考プロセスを翻訳して表示する機能がある。
  • コーディング作業と分離したChatモード（ベータ）を利用できる。

なぜ注目されているか

推測 Antigravity（GoogleのGemini CLIクライアント）向けにUIを大幅に強化するプラグインとして開発者コミュニティの注目を集めている。ばね振動アニメーションや512Kコンテキストゲージなど独自の機能が多く、既存のツールにない視覚的体験を提供している。GPL-3.0ライセンスで公開されており、オープンソースとしての透明性も評価されている。

どんな人に役立つか

Antigravityを日常的に使用するエンジニアや開発者で、より洗練されたUIや視覚的フィードバックを求めるユーザーに向いている。macOSとWindowsの両方をサポートし、一般ユーザー向けGUIインストーラーから開発者向けソース展開まで幅広く対応している。

技術的なポイント

  • JavaScriptで実装されたGPL-3.0ライセンスのAntigravityプラグインである。
  • 減衰ばね（damped-spring）アルゴリズムを用いたアニメーションコレオグラフィーを実装している。
  • npmスクリプトによるプラグインのデプロイ・注入・削除が可能な開発ツールチェーンを備える。
  • インストール状態をJSON形式で自己検証するCLIツール（tools/install-plugin.cjs）が含まれる。
  • WindowsおよびmacOSユニバーサル向けのバイナリインストーラーをビルドできる。

試し方

  1. GitHubからリポジトリをクローンする。
  2. npm run install:pluginでプラグインを~/.gemini/config/plugins/obsidian-prismにデプロイする。
  3. node tools/install-plugin.cjs --statusでインストール状態を確認し、installed・daemonAlive等がtrueであることを検証する。
  4. 設定→外観からObsidian Prism（黒曜棱鏡）セクションを展開して各種設定を行う。
git clone https://github.com/RMvdesi/obsidian-prism.git
npm run install:plugin
node tools/install-plugin.cjs --status
xattr -cr "/Applications/Obsidian Prism.app"

antigravity-cn-community/Antigravity-Chinese-Localization

Trendshift 16位JavaScriptGitHub ↗

AntigravityアプリのUIをワンクリックで中国語化するパッチツール

何ができるか

  • Antigravity v2.35.1向けに非破壊的な中国語UIパッチを適用できる
  • メニュー・設定・権限・Remote SSH・Computer Use・プラグインマーケットプレースを翻訳対象とする
  • ユーザー入力・コードエディタ・AIチャットのMarkdownは翻訳せずそのまま残す
  • Windows・Linux・macOSの各プラットフォームに対応したインストール方法を提供する
  • --auto-restoreフラグで公式アップデート後にパッチを自動再適用できる
  • GUIコントロールパネル（127.0.0.1:3388）を通じてWindowsで簡単に操作できる

なぜ注目されているか

中国語圏ユーザーがAntigravityのUIを母国語で利用したいというニーズに応えるコミュニティプロジェクトである。推測 公式の中国語ローカライズが提供されていないため、オープンソースコミュニティが自ら対応した可能性がある。MITライセンスで公開されており、自由に利用・改変できる点も注目を集める要因と考えられる。

どんな人に役立つか

AntigravityをGUIで利用したい中国語圏のユーザーを主な対象としている。英語UIに不慣れな開発者や非エンジニアにとって特に有用であり、中国語環境でスムーズに作業したいユーザー全般に恩恵をもたらす。

技術的なポイント

  • app.asarファイルを上書きすることでElectronアプリのアセットを置き換える非破壊的な方式を採用している
  • node localize.jsをJavaScriptで実装しており、CLIフラグ（--now, --auto-restore, --check-status, --apply-only）で動作を制御できる
  • macOSではapp.asarの差し替えによりGoogleのコード署名が破れ、アプリが「破損」と表示される場合がある
  • 公式アップデート後は通常パッチの再適用が必要であり、--auto-restoreで自動化できる

試し方

  1. Antigravityを完全に終了させる
  2. 元のapp.asarファイルをバックアップする
  3. プラットフォームに応じたインストール手順を実行する（Windows: GUIまたはファイル上書き、Linux/macOS: 起動スクリプト）
  4. 公式アップデート後は再度パッチを適用する
node localize.js --now
node localize.js --auto-restore
node localize.js --check-status
node localize.js --apply-only

Gemmaとオープン重みLLMの評価・サービング性能ベンチマークハーネス

何ができるか

  • OpenAI互換の `/v1` エンドポイントに対応し、vLLMやOllamaなど任意のサーバーをリモートでベンチマークできる。
  • 86スイートの学術・ドメイン評価、16項目のゴールデンセットスモークテスト、エージェント品質スイートの3段階評価ティアを提供する。
  • 平均・中央値・標準偏差・パーセンタイル・変動係数を含む反復可能性レポートを生成する。
  • オープンループストレステストにより、レイテンシ目標を超えるリクエストレートを自動検出・認定できる。
  • HuggingFaceの `config.json` からモデル特性を読み取り、適切なGPUティアを推薦する。
  • カスタムJSONLデータセットやプラグインを使った独自評価スイートの追加に対応している。

なぜ注目されているか

推測 GoogleDeepMindが公式に公開したオープン重みLLMのエンドツーエンド評価ハーネスであるため、信頼性の高いベンチマーク手法として注目されている可能性がある。推測 vLLMやOllamaなど普及している推論フレームワークとシームレスに統合できる点が、実運用を意識するエンジニアの関心を集めていると考えられる。推測 Gemmaのリリース準備状況を体系的に測定できるという明確なユースケースが、オープン重みLLMの実用化を進めるコミュニティのニーズに合致していると推測される。

どんな人に役立つか

LLMの推論サーバーを運用・評価するMLエンジニアや研究者に有用である。GemmaなどのオープンソースLLMのリリース品質を確認したいチームや、自社ハードウェア上でのサービング性能を定量化したい組織に向いている。

技術的なポイント

  • Python 3.11以上が必要で、PyPIから `pip install gbench` でインストールできる。
  • OpenAI互換の `/v1` APIを介してvLLMやOllamaなどの推論サーバーと通信する。
  • エージェント品質スイートはローカルのDockerイメージ上で実行される。
  • コードベースはruff・mypy・pytestによる静的解析とユニットテストでゲートされている。

試し方

  1. Python 3.11以上の環境を用意する。
  2. PyPIからgbenchをインストールする。
  3. OpenAI互換エンドポイントまたはローカルvLLMサーバーを用意してコマンドを実行する。
