GitHub Trending 1位★ +2,232PythonGitHub ↗

Claude Code で求人評価から応募書類作成・面接対策までこなす就活フレームワーク

何ができるか

  • /setup で手持ちの CV や LinkedIn のエクスポート、または対話形式のインタビューから自分のプロフィールを作れます。
  • /scrape で複数の求人サイトを検索し、重複を除いて自分との適合度順に一覧表示します。
  • /apply に求人 URL か本文を渡すと、適合度の評価、CV（職務経歴書）とカバーレターの下書き、別エージェントによるレビューと修正までを自動で行います。
  • /interview で応募した求人ごとに面接の準備資料を作り、模擬面接もできます。
  • /rank で検索結果をまとめて採点して優先順位を付け、/outcome で選考結果の記録やフォローアップメールの下書きを行います。
  • /add-portal で自分の国の求人サイト用の検索スキルを、/add-template で独自の CV テンプレートを追加できます。

なぜ注目されているか

作者が失職後に実際にこの仕組みで69件応募し、20件の一次面接を経て AI エンジニアとして採用されたと README に書かれています。推測 Claude Code のコマンドやエージェントを就職活動という身近な用途に具体的に組み込んだ実例として関心を集めていると考えられます。

どんな人に役立つか

就職・転職活動中で、応募ごとに CV やカバーレターを書き分ける手間を減らしたい人に向いています。Claude Code のスラッシュコマンドやサブエージェントを実用的なワークフローに組み込む例を知りたい人の参考にもなります。

技術的なポイント

  • Claude Code のスラッシュコマンド（.claude/commands）とスキル定義でワークフロー全体を組み立てています。
  • 書類を書くエージェントと、新しいコンテキストで起動した別のレビュー用エージェントを分ける「drafter-reviewer」方式で品質を上げています。
  • CV は LaTeX（組版ソフト）の lualatex、カバーレターは xelatex で PDF 化し、ページ数やレイアウト崩れを確認して直すまで繰り返します。
  • PDF から抜き出したテキストを ATS（企業の応募者管理システム）が読むのと同じ形で確認し、連絡先の欠落や求人キーワードの網羅度をチェックします。
  • 求人サイトの検索ツールは Bun（JavaScript ランタイム）で動く TypeScript 製の CLI で、共通の入出力ルールに従えば /scrape が自動で認識します。

試し方

  1. Claude Code、Python 3.10 以上、Bun、lualatex と xelatex を含む LaTeX 環境を用意します。
  2. リポジトリをフォークして手元に clone します（個人データを入れるならプライベートリポジトリの利用が推奨されています）。
  3. 求人サイト検索用の CLI をインストールします。
  4. Claude Code を起動して /setup でプロフィールを作ります。
  5. /scrape で求人を探し、/apply に求人 URL を渡して応募書類を作ります。

cd ai-job-search

anthropics/claude-plugins-official

GitHub Trending 2位★ +1,175PythonGitHub ↗

Anthropic が管理する Claude Code 公式プラグインのマーケットプレイス

何ができるか

  • Claude Code のプラグインシステムから、このマーケットプレイスに載っているプラグインを直接インストールできます。
  • /plugins に Anthropic 自身が開発・保守するプラグイン、/external_plugins にパートナーやコミュニティ製のプラグインがまとめられています。
  • Claude Code の /plugin > Discover 画面からプラグインを探せます。
  • 外部の開発者は申請フォームからプラグインを提出でき、品質とセキュリティの基準を満たせば掲載されます。
  • SKILL.md だけを持つリポジトリも、マーケットプレイス側の設定でスキル集プラグインとして登録できます。

なぜ注目されているか

Claude Code を作っている Anthropic 自身が公式に管理するプラグインの一覧です。推測 公式の配布先なので、Claude Code の機能を広げたい利用者がまず参照する場所になっていると考えられます。

どんな人に役立つか

Claude Code に外部サービス連携や追加コマンドを入れたい利用者に役立ちます。自作プラグインを作りたい人は、構成の見本として /plugins/example-plugin を参考にできます。

技術的なポイント

  • 各プラグインは .claude-plugin/plugin.json（必須のメタデータ）を持ち、必要に応じて .mcp.json（MCP サーバーの設定）、commands、agents、skills を含む決まった構成になっています。
  • MCP（Model Context Protocol、AI に外部ツールをつなぐための標準仕様）のサーバー設定をプラグインに含められます。
  • マーケットプレイスの name は一度公開したら変えない識別子で、どうしても改名するときは marketplace.json の renames に旧名と新名を書くと既存のインストールが自動で移行されます。
  • strict: false と skills 配列を使うと、plugin.json の無いリポジトリのスキルを直接登録できます。

試し方

  1. Claude Code で /plugin install コマンドにプラグイン名を付けて実行します。
  2. または /plugin > Discover からプラグインを探してインストールします。
  3. インストール前に、そのプラグインが信頼できるかを各プラグインのホームページで確認します。
/plugin install {plugin-name}@claude-plugins-official

技術的なポイント

  2. ターミナルで opencode を起動し、Tab キーで build と plan のエージェントを切り替えて使います。
  3. デスクトップアプリを使う場合は opencode.ai/download からダウンロードします。
