ersinkoc/phonebox

Trendshift 6位C#GitHub ↗

古いAndroidスマホをWindowsのデスクパネルに変えるツール

何ができるか

  • CPU・GPU・RAM・ディスク・ネットワーク・Pingなどのリアルタイムなコンピューター状態を表示できる
  • Claude CodeのAIセッション状態を確認し、許可/拒否の操作をスマホから行える
  • メディアコントロール・時計・天気・カレンダー・ポモドーロタイマーなど41種類のウィジェットを配置できる
  • Stream Deck風のショートカットキーでアプリ起動・URL開封・PC操作を実行できる
  • Webhookとルール設定でイベント発生時に通知を送ったりページを切り替えたりできる
  • USB接続とWi-Fi接続（Tailscale対応）の両方に対応し、クラウドを使わず動作する

なぜ注目されているか

推測 専用デバイスのStream Deckなどは高価だが、古くて使わなくなったAndroidスマホを再利用できる点で注目されている。Claude CodeやCodexのAIセッション管理機能が珍しく、AIコーディング利用者の関心を集めていると考えられる。クラウド不要・テレメトリなしというプライバシー重視の設計も評価されている可能性がある。

どんな人に役立つか

サブディスプレイやデスクガジェットに興味があるPC利用者や、古いAndroidスマホを有効活用したいユーザーに適している。Claude CodeなどのAIコーディングツールを日常的に使うエンジニアにも便利なツールである。

技術的なポイント

  • デスクトップエージェントは.NET 10で実装されており、WindowsだけでなくLinux・macOSでも動作する
  • スマホとの通信はUSB経由のADBまたはWi-Fi経由のTLS（証明書ピンニング）＋ペアリングキーで行われ、セキュリティを確保している
  • エージェントはデフォルトでlocalhostのみで待ち受け、Wi-FiアクセスはTailscale経由のオプトイン方式である
  • セットアップスクリプト（setup.ps1 / setup.sh）が最新リリースのダウンロード・チェックサム検証・ADBインストールを自動で行う
  • Androidアプリの開発にはJDK 17・Android SDK Platform 35が必要で、MITライセンスで公開されている

試し方

  1. Android 9以上のスマホでUSBデバッグを有効にする
  2. PCでセットアップスクリプトを実行してエージェントをインストールする
  3. スマホにアプリをインストールし、USBまたはWi-FiでPCと接続する
  4. スマホのアプリをフルスクリーン表示にしてデスクパネルとして使用する

Noniv/abyssal-garden

Trendshift 9位JavaScriptGitHub ↗

WebGPUで描く幻想的な海中世界をブラウザで体験できる

何ができるか

  • ブラウザ上でWebGPUを使った海中3D世界をリアルタイムにレンダリングできる
  • WASDキーやマウスで海中を自由に泳ぎ回ることができる
  • 波揺れる昆布の森・光の差し込み・沈没船・マンタなど豊富な海中オブジェクトが描かれている
  • Web Audio APIによるリアルタイム音響合成で、クジラの鳴き声や泡の音などの水中サウンドが再生される
  • High/Medium/Lowの3段階の描画品質を選択でき、スマホでも動作する
  • 96KBの単一HTMLファイルで完結しており、画像・3Dモデル・音声ファイルを一切使わない

なぜ注目されているか

推測 外部アセット（画像・モデル・音声）を一切使わずに、96KBのHTMLファイルだけで美しい3Dインタラクティブ世界を作り上げたという技術的な挑戦が注目を集めている。WebGPU（次世代ブラウザグラフィクスAPI）を使ったデモとして、その表現力を広く示した点でも評価されていると考えられる。

どんな人に役立つか

WebGPUやブラウザグラフィクス技術に興味があるフロントエンドエンジニアや、プロシージャル生成（コードによるコンテンツ自動生成）の仕組みを学びたい学生に特に役立つ。また純粋に美しい映像体験を楽しみたい人にも向いている。

技術的なポイント

  • 描画エンジンにWebGPUを直接使用しており、ゲームエンジンや3Dライブラリを一切介さない
  • 海底地形はGPU上で起動時に生成され、約200万枚の昆布の葉・数万の岩・数千のサンゴや魚がプロシージャルに配置される
  • 船体・クジラの尾・マンタ・魚・サンゴはすべて数学的な形状から構築されており、3Dモデルファイルを使わない
  • サウンドはWeb Audio APIでリアルタイムに合成されており、音声ファイルも存在しない
  • ビルドにはNode.js 18以上が必要で、npm run buildコマンドでminified版のindex.htmlが生成される

試し方

  1. GitHubからindex.htmlをダウンロードする
  2. ChromeまたはEdge（デスクトップ版）でindex.htmlをブラウザで開く
  3. 数秒待ってワールドが生成されたら「Dive in」ボタンを押す
  4. WASDキーで泳ぎ、マウスで視点を動かして探索する

Eynnzerr/TelemetryCleaner

Trendshift 12位KotlinGitHub ↗

Shizuku経由でRoot不要・中国向けAndroidの通信事業者プリインアプリを削除

何ができるか

  • Root権限なしでSystemHelper・RegServiceなどの通信事業者プリインストールアプリを検出・アンインストールできる
  • Shizuku（特権APIプロキシツール）を利用してシェル権限でパッケージ管理サービスを呼び出せる
  • OPPO・Xiaomi・Huawei・vivoなど複数メーカーの通信事業者コンポーネントをリスト管理している
  • アンインストールできない場合はapp_processで隠しAPIを呼び出すフォールバック処理が行われる
  • 削除したアプリの復元も可能で、自動クリーニングのスケジュール設定もできる

なぜ注目されているか

推測 中国向けAndroid端末には通信事業者が要求するプリインストールアプリが含まれており、プライバシー懸念から削除したいユーザーが多い。Root化なしにShizukuというツールだけで対処できる点が、中国語圏のAndroidユーザーに注目されている。

どんな人に役立つか

中国向けAndroid端末（OPPO・Xiaomi・Huawei・vivo等）を使用していて、通信事業者のプリインストールアプリを削除したいユーザーに適している。端末をRoot化したくないが、プライバシーを守りたいユーザーにとって選択肢となるツールである。

技術的なポイント

  • ShizukuというツールのAPIを通じてシェル権限でAndroidのパッケージ管理サービスを直接呼び出す仕組みを採用している
  • 通常のアンインストールが拒否された場合、app_processでシステムの隠しインターフェースを呼び出すフォールバック処理を行う
  • Android 10以上が必要で、Android 11以上ならADB無線デバッグでShizukuを起動できる
  • 削除はユーザースペース単位で行われるため、アプリデータが消去されるが、システムがAPKを保持していれば復元可能である

試し方

  1. Android 10以上の端末でShizukuをインストールし、ADBまたは無線デバッグで起動する
  2. GitHub ReleasesからTelemetryCleanerのAPKをダウンロードしてインストールする
  3. アプリを起動してShizukuの権限を許可する
  4. 確認したいユーザースペースを選択し、コンポーネントの一覧から削除したいものを選んで実行する

コーディングエージェントを人間承認ゲート付きで管理するセルフホスト型ワークフロー基盤

何ができるか

  • Claude Code・Codex・CodeBuddyなど10種類のAIコーディングエージェントを統一インターフェースで操作できる
  • SOPと呼ばれる標準手順書にエージェント・スクリプト・人間承認ゲートの各ステップを定義してコード開発を自動化できる
  • チャット形式でエージェントに直接指示を出してPRを作成させることもできる
  • Docker Sandboxでリポジトリをチェックアウトし、コスト・実行ログ・ツール使用履歴を記録できる
  • loopforge-cli（npxで起動）を使えばサーバー不要でClaude Codeなどの中から直接使える

なぜ注目されているか

推測 AIコーディングエージェントが普及するにつれて、単に使うだけでなく品質管理・人間のレビュー・繰り返し可能なプロセスに組み込みたいニーズが高まっている。Tencentがオープンソースで公開したことで、エンタープライズ向けのAIソフトウェア開発ワークフロー基盤として注目されている。

どんな人に役立つか

AIコーディングエージェントを個人利用だけでなくチームの開発フローに統合したいエンジニアリングマネージャーや開発チームに向いている。セルフホストにこだわるチームや、コスト・品質管理を細かく行いたい組織にも適している。

技術的なポイント

  • GoとDockerで実装されており、Dockerコンテナ内でリポジトリをチェックアウトしてエージェントを安全に実行するサンドボックス構成を採用している
  • エージェント・スクリプト・人間承認ゲート・サブSOP・プレビュービルドという5種類のSOPノードで複雑なワークフローを構成できる
  • Roleという概念でプロンプト・エグゼキューター・モデル・ルール・MCPツールを再利用可能な単位として管理できる
  • loopforge-cli（npxで配布）はサーバー不要でClaude Code・Codex・Cursorなどのエディタ内で動作するローカル版LoopForgeを提供する

試し方

  1. Git・Docker・Docker Compose・Python 3・curlがインストールされていることを確認する
  2. リポジトリをクローンしてstart.shを実行するとDockerイメージのダウンロードと起動が行われる
  3. 表示されたURLにブラウザでアクセスし、最初のアカウントを作成する（自動的に管理者になる）
  4. デモプロジェクトのSOPを試してLoopForgeの動作を確認する

どんな人に役立つか

日本の家庭用HDDレコーダーやTV（東芝REGZA・DBR等で動作確認済み）の録画をPCに転送したい人向け。DLNA・DTCP-IPの調査や研究を行う開発者にも適している。なお、DTCPデバイス証明書と秘密鍵は別途自分で用意する必要がある。

技術的なポイント

  • Python 3.13以上でasyncio（非同期I/O処理）とPydanticを使ったライブラリ設計をとっている
  • DTCP-IPのAKE認証（機器間の鍵交換）とPCP暗号化（コンテンツ暗号化）を独自実装している
  • デバイスごとの挙動差異を「プロファイル」クラスとして分離し、機種ごとの対応追加をしやすい構成にしている
  • 出力は192バイトパケットのタイムスタンプ付きMPEG-2 TS（BDAV形式のM2TS）で、メタデータのDIDL-Lite XMLをサイドカーファイルとして保存する

試し方

  1. DTCPデバイス証明書（88バイト）と機器別の秘密鍵（20バイト）を用意し、credentials.envまたは環境変数に設定する
  2. pydtcpip discoverでホームネットワーク上のDLNA対応機器を検出する
  3. pydtcpip moveで対象番組を指定しPCへ転送する（コピー回数が消費されるため注意）
uv tool install pydtcpip
pip install pydtcpip
pydtcpip discover
pydtcpip info
pydtcpip move
pydtcpip stream
