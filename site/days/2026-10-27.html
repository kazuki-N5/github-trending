hmjz100/LinkSwift

Trendshift 4位JavaScriptGitHub ↗

中国の9大クラウドストレージから直接ダウンロードURLを取得するUserscript

何ができるか

  • 百度网盘・阿里云盘など中国の9大クラウドストレージサービスからダイレクトダウンロードリンクを取得できる。
  • Aria2・IDM・BitComet など複数のダウンローダー向けのリンクやコマンドを自動生成できる。
  • ダークモード対応のUIテーマと美観カスタマイズ機能を備えている。
  • フォルダやファイルの一括ダウンロード（対応サービスのみ）ができる。
  • Aria2・cURL用のコマンドをクリップボードにワンクリックでコピーできる。

なぜ注目されているか

中国のクラウドストレージは速度制限が厳しく直リンクの取得が困難だが、このツールは公式APIを活用して取得を自動化している。先行Userscript「网盘直链下载助手」をベースに複数サービス対応と機能追加を重ねており、Tampermonkeyユーザーを中心に注目されている。

どんな人に役立つか

中国のクラウドストレージからのダウンロード効率を上げたいユーザーや、Aria2やIDMなどのダウンロードマネージャーを活用したい人に役立つ。TampermonkeyやScriptCatが使えるブラウザ環境があればすぐに導入できるため、技術的なハードルが低い。

技術的なポイント

  • TampermonkeyやScriptCatなどのユーザースクリプトマネージャー（ブラウザ拡張機能）上で動作するUserscript形式で配布されている。
  • 各クラウドストレージの公式APIを直接呼び出してダイレクトダウンロードリンクを取得している。
  • SweetAlert2（モーダルダイアログライブラリ）とFont Awesome（アイコンライブラリ）を使ったUIを実装している。
  • ESLintによるコード品質チェックを導入しており、Chrome 76以上・Edge 88以上のブラウザに対応している。

試し方

  1. TampermonkeyまたはScriptCatをブラウザにインストールする。
  2. GitHubのmainブランチにある「（改）网盘直链下载助手.user.js」をブラウザで開き、インストールボタンを押す。
  3. 対応する中国クラウドストレージのページにアクセスすると、スクリプトが自動起動し直リンク取得ボタンが表示される。

designfuchen/word-atlas

Trendshift 10位TypeScriptGitHub ↗

イラスト・音声・FSRS復習付きのオープンソースIELTS語彙アプリ

何ができるか

  • 7,298件のIELTS単語を19トピック・CEFR A1〜C2レベルで収録し、オリジナルイラストと英英・英日定義、例文2文を提供する
  • イギリス英語とアメリカ英語の発音音声、例文の読み上げ音声を収録している
  • 意味選択・画像から文補完・リスニング識別・スペリングの4種類の練習モードがある
  • FSRS（間隔反復アルゴリズム）で復習スケジュールを自動管理し、目標記憶率を調整できる
  • WebGL2を使った「スターマップ」で学習進捗を視覚的に表示する
  • ログイン不要のローカルファースト設計で、進捗はデバイスに保存され、オフラインでも利用できる

なぜ注目されているか

MITライセンスのコードとCC BY 4.0のデータセット（7,298単語・14,596例文・7,298イラスト・22,905音声）を完全公開しており、Anki化や独自アプリへの流用がしやすい。アカウント不要・無料・広告なしで使えるIELTS対応の本格的な語彙アプリは珍しく、英語学習コミュニティで注目を集めている。

どんな人に役立つか

IELTSを目指す英語学習者で、イラストと音声を使って単語を覚えたい人に最適。また、語彙学習ツールや教材を自作したい開発者・研究者にとって、質の高い公開データセットとして活用できる。

技術的なポイント

  • React 19とTypeScriptをViteでビルドしており、モダンなフロントエンド開発環境を採用している
  • ts-fsrs（TypeScript実装のFSRS: Free Spaced Repetition Scheduler）で科学的な間隔反復復習を実現している
  • WebGL2（GPUを使ったブラウザグラフィクスAPI）でスターマップを描画し、非対応端末にはフォールバックを用意している
  • データセットはJSONとCSV形式で提供されており、CC BY 4.0ライセンスで再利用可能

試し方

  1. Node.js 20以上とnpmをインストールする（初回クローン時は画像・音声アセットを含むため時間がかかる）
  2. リポジトリをクローンしてディレクトリに移動する
  3. 依存パッケージをインストールする
  4. 開発サーバーを起動し、ブラウザで http://localhost:5188 を開く
git clone --depth 1 https://github.com/designfuchen/word-atlas.git
cd word-atlas
npm ci

JetBrains/thinkrail

Trendshift 11位TypeScriptGitHub ↗

piエージェント搭載の軽量IDEで、コードベースを学習しながら自己カスタマイズする

何ができるか

  • git worktree（ブランチごとに独立したディレクトリを作る仕組み）を使ったワークスペースで、複数ブランチを同時並行で作業できる
  • スプリット可能なMonacoエディタ、ファイルツリー、ターミナルを備えたIDEワークベンチを提供する
  • 複数のpiチャットセッションを同時に起動し、AIエージェントとリアルタイムでコードを進められる
  • SPEC.mdファイルのグラフでプロジェクト仕様を管理し、エージェントが仕様を自動的に読み書きする
  • GitHub PRのCIチェックやレビューコメントをIDEから確認し、失敗したチェックをAIに修正委譲できる
  • MCPサーバー（モデルコンテキストプロトコル：AIツールを外部サービスと繋ぐ規格）やスキルでエージェントの能力を拡張できる

なぜ注目されているか

JetBrainsがAIエージェントを中心に据えた「バイブコーディング（AIに任せながら直感的に開発するスタイル）」のIDEを本格製品化した点が注目されている。従来のAIコード補完とは異なり、エージェントがプロジェクト仕様書を自ら読み書きしながら開発を進める新しいアプローチを採用しており、AIとの協働開発の新たな可能性を示している。デスクトップとブラウザの両方で動作し、CLIからも手軽に利用できる点も評価されている。

どんな人に役立つか

AIエージェントを活用したコーディング（バイブコーディング）に興味のあるエンジニアに最適。複雑なプロジェクトで仕様管理と実装を同時に進めたい人や、JetBrains AIや他のAIプロバイダーと連携させてコーディングを効率化したい人に向いている。

技術的なポイント

  • Bun（Node.jsより高速なJavaScriptランタイム）をサーバーサイドに使い、WebSocket経由でUIとリアルタイム通信する
  • UIはReact 19、Zustand（軽量な状態管理ライブラリ）、Tailwind v4で構築され、ホストと疎結合な設計になっている
  • git worktree機能でワークスペースを物理的に分離し、ブランチごとに独立した開発環境を提供する
  • piエージェントをin-process（同一プロセス内）で動かし、モデル管理・コスト計算・セッション管理を委譲している
  • MCPサーバーを経由してエージェントに外部ツール連携を追加でき、リポジトリ定義のサーバーは承認後に有効化される

試し方

  1. Bunバージョン1.4.4、Node.js 22.19以上をインストールする
  2. リポジトリをクローンしてプロジェクトディレクトリに移動する
  3. bun installで依存パッケージをインストールする
  4. bun run devでホストサーバーとWebクライアントを同時に起動する
  5. ブラウザでUIにアクセスし、JetBrains AIまたは別のAIプロバイダーにサインインして使い始める

HKUDS/DeepTutor

Trendshift 16位PythonGitHub ↗

AIを活用した個人最適化チュータリングのオールインワン学習ワークスペース

何ができるか

  • チャット・クイズ・リサーチ・可視化・コース学習など多彩な学習機能を一つのシステムで統合して提供する
  • RAG（検索拡張生成）に複数のエンジン（LlamaIndex・LightRAG・GraphRAGなど）を対応し、独自の知識ベースを構築できる
  • ソースドキュメントをインタラクティブな「リビングブック」に変換し、クイズやフラッシュカード、アニメーションを埋め込める
  • YouTube・Bilibiliの動画を再生しながらトランスクリプト検索や時刻付きメモを取れる動画学習機能を持つ
  • Feishu・Telegram・Slack・Discordなどと連携した常駐AIパートナーが個別の記憶とペルソナを持ち継続的に支援する
  • 3層構造のファイルベースメモリ（L1：履歴トレース、L2：事実情報、L3：統合知識）でユーザーの学習状況を長期保持する

なぜ注目されているか

個別最適化されたAIチュータリングの需要が高まる中、単なるチャットボットではなく知識ベース・記憶・エージェント連携を備えた本格的な学習プラットフォームとして注目されている。オープンソースでDockerやPyPIから手軽に試せる点や、MCP（Model Context Protocol）サーバーやエージェントスキルなど最新のAIエコシステムに対応している点も評価されている。香港大学のデータインテリジェンス研究室による研究成果が実用的なプロダクトとして公開されているため、学術的信頼性も高い。

どんな人に役立つか

AIを活用して自分のペースで学習を深めたい学生や独学者に特に役立つ。自前のPDFや資料を知識ベースに取り込み、それをもとにクイズや解説を生成したいエンジニアや教育者にも適している。CLIとJSON出力に対応しているため、学習支援ツールを自動化・拡張したい開発者にとっても扱いやすい基盤となる。

技術的なポイント

  • バックエンドはPython 3.11以上＋FastAPIで構築され、OpenAI・AnthropicのSDKを直接利用してLLM（大規模言語モデル）を呼び出す
  • フロントエンドはNext.js 16＋React 19＋TypeScriptで実装されており、モダンなウェブUIを提供する
  • RAG（Retrieval-Augmented Generation：検索拡張生成）にLlamaIndex・LightRAG・GraphRAG・FAISSなど複数のエンジンを組み合わせて精度の高い文書検索を実現する
  • Dockerコンテナ・Docker Compose・Podmanによるデプロイに対応しており、本番環境への展開が容易
  • コード実行にはbubblewrapやサンドボックスランナーを使い安全な隔離実行環境を提供する

試し方

  1. DockerがインストールされているPCでdocker runコマンドを実行する
  2. ブラウザでhttp://127.0.0.1:3782を開いてUIにアクセスする
  3. Settings → Providers でLLMプロバイダー（OpenAIやAnthropicなど）のAPIキーを設定する

google/elephant-goldfish-model

Trendshift 17位AstroGitHub ↗

AIコーディングエージェント向けの仕様書駆動開発を支援するオープンソースプラグイン

何ができるか

  • /egm-brainstormコマンドで、複数のゴールドフィッシュ（文脈なしのサブエージェント）を使ってアイデアを出しストレステストできる
  • /egm-draftコマンドで、コンセプトからセクションごとにマークダウン形式の設計仕様書を自動生成できる
  • /egm-reviewコマンドで、多段階パイプライン（ズームアウト・理解度確認・批評・完成度確認）を通じて仕様書をレビューできる
  • /egm-drift-reportコマンドで、ASTスキャナーによりコードと仕様書の乖離（ドリフト）を自動検出できる
  • /egm-bootstrapコマンドで、既存コードベースをボトムアップで再帰的にドキュメント化できる
  • /egm-resolveコマンドで、レビューで検出された問題をインタラクティブにトリアージし、パッチを自動適用できる

なぜ注目されているか

AIコーディングエージェントが普及する中、コードを書く前に仕様をしっかり固める「仕様書駆動開発」を自動化するツールとして注目されている。エレファント（深い文脈を持つセッション）とゴールドフィッシュ（ゼロ文脈の独立したサブエージェント）という2種類のAIを組み合わせた斬新なレビュー手法が革新的で、Google発のオープンソースとして公開されている点も注目度が高い。

どんな人に役立つか

Claude CodeやCodexなどのAIコーディングエージェントを使って開発するソフトウェアエンジニアやチームに役立つ。コードを書く前に設計仕様をしっかりレビューしたい開発者や、仕様とコードのズレを継続的に検知したいチームに特に適している。

技術的なポイント

  • エレファント（深い文脈セッション）とゴールドフィッシュ（ゼロ文脈サブエージェント）の2ロール構成で仕様書のストレステストを実現している
