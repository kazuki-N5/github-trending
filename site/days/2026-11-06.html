Trendshift 4位C++GitHub ↗

Nintendo Switch / Switch 2向け実験的オープンソースエミュレータ（C++製）

何ができるか

  • Nintendo SwitchおよびSwitch 2のゲームをPCでエミュレートして動作させることができる
  • Eglantine・Eden・yuzu・Sudachiという複数の上流プロジェクトをベースにしたフォーク版として開発されている
  • Windowsではアーカイブを解凍してlichii.exeを実行するだけで起動できる
  • 既存のEden/Eglantineのセーブデータ・設定・シェーダーキャッシュの保存先をそのまま引き継ぐため、既存ユーザーがスムーズに移行できる
  • ゲームの動作互換性はタイトル・ハードウェア・ドライバによって異なり、レンダリングエラーや動作不安定が発生する場合があることを明示している

なぜ注目されているか

推測 Nintendo Switch 2のエミュレーションに対応しようとする数少ない実験的プロジェクトとして注目されている。Eglantine・Eden・yuzu・Sudachiという複数の実績あるエミュレータ実装をベースにしており、既存エコシステムとの互換性を保ちながら新世代機への対応を図っている点が評価されている。推測 Switch 2エミュレーション分野における先駆的な試みとして、エミュレータ開発者や研究者の関心を集めていると考えられる。

どんな人に役立つか

Nintendo Switch / Switch 2のゲームをPCで動かすことに興味を持つ開発者・研究者向けのプロジェクト。C++でエミュレータ開発やゲーム保存・アーカイブに関心を持つ開発者にとって貢献しやすいオープンソースプロジェクトでもある。既存のEden/Eglantineユーザーで、Switch 2対応を試してみたいユーザーにも適している。

技術的なポイント

  • C++で実装されたNintendo Switch向けエミュレータで、ユーザー空間でのCPU・GPU・OSエミュレーションを行う
  • Eglantine・Eden・yuzu・Sudachiという複数のオープンソースエミュレータのコードベースをフォーク・統合して開発されている
  • シェーダーキャッシュ（GPUプログラムを変換・保存することでグラフィックス処理を高速化する仕組み）を既存エミュレータの保存先から引き継いで利用できる
  • ビルドシステムでは内部的にupstream（上流プロジェクト）のターゲット名を維持しており、GUIターゲットは引き続きyuzuという名称が使われている

試し方

  1. GitHubのリリースページから最新ビルドのアーカイブをダウンロードする
  2. ダウンロードしたアーカイブを完全に解凍する（部分的な展開は不可）
  3. lichii.exeを実行して起動する
  4. 別途入手したゲームファイル・暗号化キー（prod.keys等）・ファームウェアを用意して設定する

sherlock-project/sherlock

Trendshift 11位PythonGitHub ↗

400以上のSNSでユーザー名を横断検索するOSINTツール

何ができるか

  • 400以上のソーシャルネットワーク（SNS）でユーザー名を一括検索できる
  • 複数のユーザー名を同時に指定してまとめて調査できる
  • 結果をテキスト・CSV・XLSXなどの形式でファイルに保存できる
  • {?}プレースホルダーを使い、アンダースコアやハイフンなどを含むユーザー名のバリエーションも自動検索できる
  • SOCKS5などのプロキシ経由で通信でき、匿名性を保ちながら調査できる
  • 見つかったプロフィールページをブラウザで直接開くオプションがある

なぜ注目されているか

推測 GitHubで96,500以上のスターを獲得しており、OSINT（Open Source Intelligence＝公開情報を使った諜報・調査）やペネトレーションテスト（侵入テスト）のコミュニティで広く支持されている。対応サイト数の多さとシンプルなCLI操作性が、セキュリティ調査の現場で重宝される理由と考えられる。MITライセンスのオープンソースであり、カスタマイズや拡張が容易な点も注目度を高めている。

どんな人に役立つか

セキュリティ研究者やペネトレーションテスター（侵入テスト担当者）など、対象人物のオンライン上の痕跡を調査したい人に役立つ。フォレンジック（デジタル鑑識）やOSINT調査を行う専門家にとっても有用なツールである。また、自分のユーザー名が各SNSで使用されているか確認したい一般ユーザーにも活用できる。

技術的なポイント

  • Pythonで実装されており、pipx・pip・uv・Dockerなど複数の方法でインストールできる
  • 対応サイトの情報はJSON形式のデータベースファイルで管理されており、--jsonオプションでローカルまたはオンラインのJSONを指定できる
  • pytestを使ったテストスイートと、tox.ini（複数バージョンのPythonでのテストを自動化するツール）によるテスト環境管理が整備されている
  • Dockerfileが含まれており、コンテナ環境でも即座に動作させられる

試し方

  1. pipx（Pythonアプリをシステムから隔離してインストールするツール）をインストールする
  2. sherlockをpipxでインストールする
  3. 調べたいユーザー名を引数に渡して実行する
pipx install sherlock-project
docker run -it --rm sherlock/sherlock
sherlock user123
sherlock user1 user2 user3

garrytan/gstack

Trendshift 18位TypeScriptGitHub ↗

Claude Codeに23の専門家役割を追加するGarry TanのMDスラッシュコマンド集

何ができるか

  • /office-hoursコマンドでアイデアを再構成し、設計ドキュメントを自動生成する
  • /plan-ceo-review・/plan-eng-review・/plan-design-reviewでプロダクト・アーキテクチャ・デザインの各観点から計画をレビューする
  • /reviewコマンドでCIを通過しても残る本番バグを検出する
  • /qaコマンドで実際のブラウザやCLI・API・バッチジョブ上でテストを自動実行する
  • /shipコマンドでテストとレビューを実行し、プルリクエストを自動作成する
  • GBrain統合により会話をまたいでエージェントの記憶を永続化する

なぜ注目されているか

推測 YCombinator代表のGarry Tanが公開した設定ファイルであることから、スタートアップ開発者の間で注目を集めている。AIコーディングエージェントにCEO・エンジニアリングマネージャー・QAなど専門家チームの視点を持たせるアプローチが、実際の開発ワークフロー改善に有効と見られている。

どんな人に役立つか

Claude Codeを使って開発しているエンジニアや、AIコーディングエージェントのワークフローを体系化したい人に役立つ。少人数のスタートアップや個人開発者が、設計・実装・レビュー・QA・リリースの各フェーズを専門チームのようにエージェントに任せたい場合に特に適している。

技術的なポイント

  • Markdownファイルで書かれたスラッシュコマンドをClaude Codeの~/.claude/skills/ディレクトリに配置することで動作するシンプルな仕組み
  • JavaScriptランタイムのBun（v1.4.2以上）を使ってsetupスクリプトでインストールを管理する
  • スキルはsprintの順序（think→plan→build→review→test→ship→reflect）でパイプライン実行され、各スキルの出力が次のスキルへ渡される
  • Claude Code以外にもCodex・Cursor・Gemini CLI・Copilot CLIなど複数のAIコーディングエージェントに対応する

試し方

  1. Claude CodeとGitとBun v1.4.2以上をインストールする
  2. リポジトリを~/.claude/skills/gstackにクローンする
  3. setupスクリプトを実行してセットアップする
  4. Claude Codeのプロジェクトで/office-hoursなどのコマンドを試す
git clone https://github.com/garrytan/gstack ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup

HunYiSage/dsh-purge

Trendshift 19位JavaScriptGitHub ↗

DeepSeek Harness向けパッチプラグインで、モデルのデフォルト制限を解除しプロンプトを差し替える

何ができるか

  • DeepSeek Harness（DSH）のローカルインストールに直接パッチを当て、デフォルトのポリシー制限を変更する
  • モデル自体の拒否応答と、ホスト層のポリシーによるブロックを区別して可視化できる
  • 暗号化されたデフォルトプロンプトを注入し、パーミッション（権限）やツールの使用制限を上書きする
  • 改変前に元ファイルを自動バックアップするため、元の状態に戻すことができる
  • モデルごとに異なるプロンプトを使い分けられ、デフォルトは国産モデル「小码酱」向けに設定されている

なぜ注目されているか

推測 DeepSeek Harnessのデフォルト設定が過剰に制限的だと感じるユーザーが、モデル本来の制限とホスト側のポリシー設定を切り分けて検証したいというニーズに応えるために注目されている。推測 「破甲（防御を破る）」という直接的なネーミングとGitHubでのStar獲得への呼びかけにより、AIのジェイルブレイク（制限解除）に関心を持つコミュニティで話題になっていると思われる。

どんな人に役立つか

DeepSeek Harnessを使用している開発者や研究者で、モデルの応答制限の仕組みを調査・検証したい人に向いている。AIの安全性や制限ポリシーを研究する目的で、どの制限がどのレイヤーに由来するかを評価したい人にも有用かもしれない。なお、公共システムへの攻撃や特定地域の政府・金融機関への悪用は禁止されており、あくまでローカルのHarnessインストールに対してのみ使用可能とされている。

技術的なポイント

  • JavaScriptで書かれたDSHプラグインとして動作し、`dsh plugin add`コマンドでtarball（圧縮アーカイブ）形式のURLを指定してインストールする
  • `@deepseek-ai`パッケージ内の特定ファイルをマッチングして直接置き換えるファイルパッチ方式を採用している
  • デフォルトのシステムプロンプトを暗号化した形式で保存・注入する仕組みを持つ
  • DSH（DeepSeek Harness）バージョン0.2.1-rc.2および0.2.0に対応した特定バージョン向けの設計になっている
  • Apache-2.0ライセンスを採用しており、フォーク（派生版の作成）時には元リポジトリへの帰属表示が必要とされている

試し方

  1. DeepSeek Harness（DSH）をローカル環境にインストールする（バージョン0.2.1-rc.2または0.2.0が対象）
  2. 公式プラグインマーケットプレイスではなく、GitHubのcodeload.github.comからtarball URLを使って`dsh plugin add`コマンドでプラグインを追加する
  3. DSHのDock（ドック）にあるCleanページからApply（適用）を実行してパッチを当てる

scenario-labs/skills

Trendshift 20位PythonGitHub ↗

AIエージェントがScenarioのMCPサーバーを通じて画像・動画・音声・3Dアセットを生成するためのスキル集

何ができるか

  • SKILL.mdファイル形式のエージェントスキルを提供し、Claude CodeやCursorなどのAIコーディングエージェントに画像・動画・音声・3Dの生成方法を教える
  • Scenario MCPサーバーを経由してAIモデルを適切に選択し、生成コストを事前に確認してからコンテンツを作成できる
  • キャラクターやブランドの一貫性を保つカスタムモデルのトレーニングと再利用をサポートする
  • ZBrush・Blender・Maya・Unreal Engine・Unity・Godot・Roblox StudioなどDCCツール（3Dや映像制作ソフト）を操作するエキスパートツールを搭載する
  • npx skills addの一コマンドで全スキルをインストールでき、役割・目的別のグループインストールにも対応する
  • release-pleaseで管理されるリリースを追跡し、npx skills updateで最新版に更新できる

なぜ注目されているか

推測 AIエージェントによるゲームアート・マーケティング素材・3Dアセット生成の需要が高まる中、Scenario MCPを介してプロ向けのコンテンツ制作パイプラインをコーディングエージェントから直接操作できる点が注目されている。推測 単なるAPI呼び出しではなく、モデル選択・コスト管理・一貫性維持をスキルとして体系化することで、AIエージェントが制作ワークフローに組み込みやすくなっている点も評価されている。

どんな人に役立つか

ゲーム開発者やクリエイティブ制作者で、AIコーディングエージェント（Claude Codeなど）を使って画像・動画・3Dアセット生成を自動化・効率化したい人に適している。Blender・Unreal Engineなどのプロ向けDCCツールをAIエージェントから操作したいアーティストや技術者にも役立つ。

技術的なポイント

  • SKILL.md形式: AIエージェントが読み込む自然言語のスキル定義ファイルで、エージェントに特定の作業手順を教える仕組み
  • MCP（Model Context Protocol）: AIエージェントと外部サービスをつなぐプロトコルで、Scenario APIへの接続に使用される
  • npxベースのCLIインストーラー（npx skills add / update）でスキルの追加・更新を管理する
  • Python 3.11+とvitest（JavaScriptテストフレームワーク）を使ったバリデーション・テスト環境を持つ
  • Conventional Commitsに準拠したPRタイトルルールとrelease-pleaseによる自動リリース管理を採用している

  2. npx skills addコマンドを実行してScenarioスキルをインストールする

変更ファイルをグループ化・要約してPRレビューをシンプルにするツール

何ができるか

  • 変更されたファイルをスコープ（範囲）ごとにグループ化し、一度に一つずつレビューできる
  • ウェブサイト（pulls.review）にアクセスしGitHubアカウントを連携するだけで即座に使える
  • ユーザースクリプトをインストールするとGitHub本体のUIにpulls.reviewの機能を組み込める
  • CIワークフロー（GitHub Actions）でPRを自動解析し、結果をPRコメントとして投稿できる
  • CLIツール（@pulls.review/actions）を使って環境変数だけで任意の環境から解析を実行できる
  • Vercel AI Gateway・Anthropic・OpenAI互換など複数のAIプロバイダーに対応している

なぜ注目されているか

推測 GitHubのデフォルトのPRレビュー画面は変更ファイルが多い場合に全体像を把握しにくいという課題があり、Linear社のPRレビューガイドに触発されて開発された。推測 AIを活用して差分を要約・グループ化することで、レビュアーの認知負荷を減らし効率的なコードレビューを実現しようとしている点が注目されている。

どんな人に役立つか

多数のファイルにわたる大規模なPRをレビューする開発者や、コードレビューの質と速度を向上させたいチームに役立つ。CIに組み込むことでレビュアー全員が同じAI解析結果を共有でき、個人のAPIキーが不要になるため組織での導入にも向いている。

技術的なポイント

  • コアライブラリ（@pulls.review/core）はブラウザとNode.jsの両方で動作し、差分の取得・解析・グループ化・要約を担う
  • GitHub Actionsのワークフローとして動作するアクション（antfu/pulls.review@main）を提供しており、CIへの組み込みが簡単にできる
  • ユーザースクリプト（Tampermonkey等で動くブラウザ拡張スクリプト）でGitHub本体のUIを拡張する仕組みを持つ
  • AIプロバイダーの抽象化により、APIキーの種類からプロバイダーを自動推定する設計になっている
  • モノレポ（複数パッケージを一つのリポジトリで管理する構成）でapp・core・actions・cliの4パッケージを管理している

試し方

  1. pulls.review にアクセスしてGitHubアカウントを連携する
  2. レビューしたいPRのURLをサイトに入力してレビューを開始する
  3. GitHubのUIで使いたい場合はサイトのGitHubセクションからユーザースクリプトをインストールする
  4. CIで使いたい場合はリポジトリに .github/workflows/pulls-review.yml を作成しAPIキーをSecretsに登録する
GITHUB_TOKEN=... ANTHROPIC_API_KEY=... npx @pulls.review/actions owner/repo#123
npx @pulls.review/actions --help
