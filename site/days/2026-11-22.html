ItsNotRexed/Leonida

Trendshift 1位PythonGitHub ↗

GTA6（Xbox版）をWindowsでネイティブ動作させる静的リコンパイルプロジェクト

何ができるか

  • Xbox Series版GTA6のx86-64コードをWindowsでネイティブ実行できるよう静的リコンパイル（バイナリをそのまま変換してネイティブ実行ファイルを生成する手法）する
  • RDNA2アーキテクチャのGPUシェーダー26,503本をSPIR-V（Vulkanが解釈できる中間表現）に変換して出力する
  • ゲームのモデル・テクスチャ・オーディオをエクスポートする
  • XboxのDirect3D 12コールをVulkanに変換するカスタムD3Dレイヤーを部分的に実装している
  • make_game.pyのターミナルインターフェースでcheck・shaders・assets・runtime・pipelinesの各ビルド段階を個別に制御できる

なぜ注目されているか

GTA6のPC版が発売されていない中、Xboxバイナリからネイティブないなる Windowsビルドを生成する技術的挑戦として注目を集めている。シェーダー変換やアセット抽出など高度な部分が着実に実装されており、静的リコンパイルという手法がゲーム保存・移植の新しいアプローチとして研究コミュニティから関心を持たれている。推測 GTA6の正式PC版を待ちきれないコミュニティや、リバースエンジニアリング技術に関心のある開発者から注目されていると考えられる。

どんな人に役立つか

リバースエンジニアリングやゲームエンジン移植技術に興味のある開発者・研究者。コンパイラ、GPUシェーダー、低レベルグラフィックスAPIに関心のあるエンジニアにも適している。自分で合法的に入手したゲームコピーを所持していることが前提となる。

技術的なポイント

  • Pythonスクリプト（make_game.py）でビルド全工程を管理し、各段階を個別に実行できるパイプラインを構築している
  • RDNA2（AMDのGPUアーキテクチャ）のシェーダーをSPIR-V形式に変換するためLLVM 21+とAMDGPUターゲットを使用している
  • .NET 8 SDKを使ってシェーダー翻訳ツール群を実装しており、wave64動作の一部はエミュレーション対応している
  • XboxのDirect3D 12コマンドリストとディスクリプターヒープモデルをVulkanに変換するカスタムレイヤーをC++で実装している

試し方

  1. Windows 10/11 x64・空き容量350GB・Python 3.11+・.NET 8 SDK・Vulkan SDK・LLVM 21+（AMDGPUターゲット付き）・Visual Studio 2022（C++ツール）を準備する
  2. git clone --recursive でサブモジュールごとリポジトリをクローンする
  3. Build.bat をダブルクリックしてビルドを開始する（または make_game.py でコマンドライン操作する）
  4. python -I make_game.py --check でゲームコピーの検証のみ先に行うことができる

python -I make_game.py --find
python -I make_game.py --check
python -I make_game.py --game "D:\path\to\your\package" --out "D:\Games\Leonida" --work "E:\leonida-work"

havenicec/google-qr-sms-helper

Trendshift 2位JavaScriptGitHub ↗

GoogleのQRコード認証をSMS 6桁コード認証に切り替えるChrome拡張機能

何ができるか

  • Googleアカウントのデスクトップ認証画面でQRコードの代わりに6桁のSMSコードによる認証フローを利用できるようにする
  • declarativeNetRequest（MV3のネットワーク書き換えAPI）とua_spoof.jsでUser-AgentをiPad Miniに偽装し、デスクトップ向けQR表示を回避する
  • ブラウザ内蔵のBarcadeDetector APIを使ってページ上のQRコードを検出して処理を制御する
  • ページに注入したフローティングコントロールパネルで拡張機能の動作を操作できる
  • バックグラウンドスクリプトによるRPCフォールバック（[3,null,4]シーケンス）でSMSフローへ誘導する

なぜ注目されているか

Googleがデスクトップブラウザでのログイン時にQRコード認証を必須化したことで、SMSコードを好むユーザーや特定の環境でQRスキャンが困難なユーザーが不便を感じるようになったため注目されている。推測 スマートフォンを手元に置かずにPCだけで作業するユーザー、またはQR対応カメラデバイスを持たないユーザーのニーズに対応するプロジェクトとして広まっていると考えられる。

どんな人に役立つか

デスクトップでGoogleにログインする際にQRコードではなくSMS認証を使いたいユーザー。Chrome・Edge・Brave 88以降（BarcodeDetector API対応バージョン）を使用している人が対象となる。

技術的なポイント

  • Manifest V3（MV3）形式のChrome拡張機能として実装されており、EdgeやBraveでも動作する（MV3はChrome拡張機能の最新仕様でバックグラウンド処理の制限が強化されている）
  • declarativeNetRequest APIを使ってネットワークリクエストをルールベースで書き換えてUser-Agentヘッダーを変更する
  • BarcodeDetector APIはChrome 88以降に組み込まれたQRコード読み取りAPIで、外部ライブラリ不要でQRコードを検出できる
  • コンテンツスクリプト（content.js）をメインワールドに注入してページのDOMとGoogleのRPCリクエストを操作する

試し方

  1. リポジトリをクローンするか、GitHubのリリースページからzipをダウンロードして展開する
  2. chrome://extensions/ を開いてデベロッパーモードを有効にする
  3. 「パッケージ化されていない拡張機能を読み込む」をクリックして展開した拡張機能フォルダを選択する

ChiefGyk3D/Clouds-Against-Humanity

Trendshift 6位PythonGitHub ↗

ゼロトラストとIaCをハンズオンで学ぶ、無料のクラウドセキュリティ教育ホームラボ

何ができるか

  • DigitalOcean上に公開インバウンドポートをゼロにしたクラウド環境をOpenTofu（Terraformのオープンソースフォーク）で構築できる
  • Twingate（ZTNA: ゼロトラストネットワークアクセス）を使い、VPNなしで特定ホスト・ポートへの認証済みアクセスを実現する
  • Dopplersで全シークレット（APIキー等）を一元管理し、リポジトリにクレデンシャルを一切残さない設計を学べる
  • Spaceliftでインフラ変更のplan・human確認・applyを自動化し、ラップトップからの直接適用をなくす運用を実践できる
  • コスト上限チェックをCIに組み込み、承認済み予算を超えるPRを自動で失敗させる仕組みを備えている
  • wikiに全レッスン・フローチャート・演習が日本語以外で丁寧に書かれており、ゼロから学べる読み順が用意されている

なぜ注目されているか

推測 クラウドセキュリティの学習リソースは高額な講座やベンダー資格に偏りがちだが、このプロジェクトは実際に動く環境と詳細なwikiを完全無料で公開しており、低コスト（月約12〜30ドル）で本番相当のゼロトラスト構成を自分の手で動かせる点が注目されている。作者自身の「知識はお金のある人だけのものにしない」という理念が共感を集めている。

どんな人に役立つか

クラウドセキュリティやDevSecOpsの基礎を実践的に身につけたい学生や独学者に向いている。ITヘルプデスク程度の経験があれば始められる設計になっており、将来クラウドインフラや情報セキュリティ職を目指す人の最初のホームラボとして役立つ。

技術的なポイント

  • OpenTofu（Terraformのオープンソース後継、MPLライセンス）でインフラをコード化し、スタック単位で管理するIaC（Infrastructure as Code）構成を採用
  • Twingate ZTNAを使用し、コネクターがアウトバウンドのみ接続するため、インターネット上に公開リスナーが一切存在しないゼロトラストアーキテクチャを実現
  • Spaceliftがplan結果を人間が確認してからapplyする承認フローを強制し、Dopplersがread-onlyトークン1つでシークレットを注入するため、CIパイプラインにクレデンシャルが流れない
  • Pythonスクリプトによるコストゲート（cost_check.py）がCI上でdocs/stages/approved.jsonと比較し、予算超過の変更をPRで自動ブロックする
  • GitHub Actionsのすべてのアクションをコミットハッシュでピン留めし、サプライチェーン攻撃（依存ライブラリ改ざん等）リスクを低減するCI設計を採用

試し方

  1. OpenTofu 1.8以上、Python 3、OPA 1.21.0をインストールする
  2. リポジトリをクローンしてルートディレクトリに移動する
  3. コストゲートを実行してdocs/stages/approved.jsonと比較確認する
  4. pytestでリポジトリのテストスイートを実行する
  5. モジュール単体テストをOpenTofuで実行する（クラウドアカウント不要、プロバイダーはモック）
python3 -I scripts/cost_check.py --root .
python3 -I scripts/gen_settings_doc.py --check
python3 -I -m pytest tests -q
python3 -I scripts/identifier_check.py --root .
opa test .spacelift/policies -v
tofu -chdir=modules/firewall init -backend=false
tofu -chdir=modules/firewall test

Trendshift 7位PythonGitHub ↗

リーマン予想の形式証明を世界中のボランティアで独立検証するオープンプロジェクト

何ができるか

  • Levent Alpögeが発表したリーマン予想のLean形式証明を、独立した環境で再現ビルドして検証できる
  • 175,187個のモジュールタスクと2,858個のワークパケットに分割されており、誰でも一部を担当して証明検証に貢献できる
  • verify.shスクリプトが証明アーカイブのSHA-256整合性、ツールチェーン・依存ライブラリのハッシュ、Leanカーネルによる公理チェックを自動実行する
  • エージェント向けプロンプトが用意されており、AIを使って自動的にモジュールをクレームしてビルドし、エビデンスを提出できる
  • Lean 4.36.0および最新Mathlibへのポーティング（移植）作業用に別トラックのIssueと手順が用意されている

なぜ注目されているか

2026年11月20日にLevent Alpögeがリーマン予想（150年以上未解決の数学難問）の証明を発表したため、数学・CS界隈で大きな話題となった。証明の正しさをコミュニティが独立して検証するために立ち上がったプロジェクトであり、約100名以上のボランティアが既に97,000以上のモジュールの検証エビデンスを提出している。

どんな人に役立つか

形式証明（Lean）や数学基礎論に興味のある学生・研究者、オープンサイエンスの共同検証プロセスを体験したい人に向いている。Leanや高度な数学の知識がなくても、ビルド環境構築と指示通りのコマンド実行ができれば一部モジュールの検証から参加できる。

技術的なポイント

  • Lean 4（Microsoft Research製の定理証明支援系・形式検証言語）とMathlib（Leanの数学ライブラリ）を使って証明オブジェクトをビルドし、カーネルが公理から定理を導けることを機械的に確認する
  • Leanのleancheckerが宣言を新鮮なカーネル環境で再リプレイし、依存ライブラリのキャッシュ改ざんとの連続性を証明アーティファクトのSHA-256で多段階チェックする
  • 公理監査（Audit.lean）が最終定理の公理を命題外延性・古典的選択・商の健全性の3つのみに限定されることをチェックし、追加公理の混入を防ぐ
  • elan（Leanバージョン管理ツール）でLean 4.33.1にツールチェーンをピン留めし、異なるマシン・環境で同一のビルド結果が得られる再現性を担保する

試し方

  1. elanランチャーをインストールし、leanとlakeコマンドをPATHに通す
  2. Python 3.9以上、Bash、Git、curl、GNU tar、sha256sum、Cツールチェーン、大容量のビルドボリュームを用意する
  3. リポジトリをクローンして空のディレクトリを用意する
  4. verify.shに空ディレクトリのパスを渡して実行し、replay.logを確認する
./verify.sh /path/to/empty/replay-directory

姿勢・服装・人像の参考画像ライブラリとブラウザ内AIバーチャル試着アプリ

何ができるか

  • 姿勢（線稿）・深度姿勢・服装・動画風服装・人像の5種類の参考画像ライブラリを中英バイリンガルのプロンプト付きで閲覧・検索できる
  • 自分の写真とAPIキーを使って、選んだ服装・姿勢でAI試着画像をブラウザ内で生成できる
  • OpenAI・Gemini・豆包Seedream・カスタム互換エンドポイントの複数AIサービスプロバイダーに対応している
  • 生成履歴・お気に入り・最近閲覧した素材をブラウザのIndexedDB（ローカルDB）に保存でき、エクスポートやインポートも可能
  • PWA（Progressive Web App）対応で、一度閲覧したコンテンツはオフラインでも表示でき、ホーム画面へのインストールもできる
  • プロンプトを中性的な商品説明文に自動書き換えすることで、AIサービスの安全審査による誤拒否を減らす機能を搭載している

なぜ注目されているか

登録不要・バックエンドなしの純粋な静的サイトで、自分のAPIキーを使ってプライバシーを守りながらAI試着を体験できる点が評価されている。推測 AI画像生成の活用と参考素材を一つにまとめたオールインワンツールとして、イラストレーターやファッション関係者の間で注目を集めていると考えられる。

どんな人に役立つか

AIを使ったファッション画像生成に興味があるクリエイターやイラストレーター、コスプレ・ファッションの参考資料を集めたいデザイナー、またはStable DiffusionやMidjourneyなどのAIイメージ生成のプロンプトを手軽に試したい人に役立つ。

技術的なポイント

  • フロントエンドはVanilla JS（フレームワーク不使用）で構築された純粋な静態サイトで、Cloudflare Pagesにデプロイされる
  • 素材データはPythonスクリプト（fetch-assets.py）で外部ギャラリーから取得し、build.pyでサムネイル生成・データ整形・詳細ページ生成を行うビルドパイプラインを持つ
  • お気に入りや生成履歴はブラウザのIndexedDB（ローカルのキーバリューデータベース）に保存され、サーバーへのデータ送信は一切ない
  • Cloudflare Pages Functions（functions/api/proxy.js）が豆包Seedreamのクロスオリジン問題を解消するAPIプロキシとして機能する
  • テストはPlaywrightを使ってAPIをモックし、実際のAPIキーなしでUI・エラー処理・試着フローを自動テストしている

試し方

  1. Python 3.9以上とPillowをインストールする
  2. リポジトリをクローンして依存関係をインストールする
  3. fetch-assets.pyで参考素材データをダウンロードする（数GB・時間がかかる）
  4. build.pyでdist/フォルダにサイトをビルドする
  5. ローカルサーバーを起動してブラウザで確認する
git clone https://github.com/atuizz/posewear.git && cd posewear
pip install pillow
python3 scripts/fetch-assets.py
python3 build.py
python3 -m http.server 8787 -d dist

Windowsの標準タスクマネージャーでは不足しがちな詳細なリソース管理機能をRustで実装した点が注目されている。ガバナー機能はデフォルトでドライランモード（確認のみ）で起動するため安全に試せる。推測 RustによるシステムレベルのWindows APIへのアクセスと安全性の組み合わせ、およびAIプロバイダーとの統合機能が開発者の関心を集めていると考えられる。

どんな人に役立つか

Windowsで動くアプリのパフォーマンスを細かく管理したいエンジニアや、ゲームや動画編集など重い作業時にPCの応答性を維持したいユーザー向け。MCPサーバー機能を通じてAIエージェントからPCの状態を診断したい場合にも役立つ。

技術的なポイント

  • Rustで書かれたワークスペースは8つのクレート（ライブラリ単位）に分割されており、unsafeコードはwtm-sysクレートのみに集約されている
  • wtm-gui（rustwtm.exe）がGUIアプリ、wtm-cli（wtm.exe）がCLIツールという2種類の実行ファイルを提供する
  • ガバナーサービスはWindowsのLocalSystem権限で動作し、ローカルパイプ経由の制御には管理者権限が必要
  • オプションでTelegramボットやローカルMCPサーバー（Model Context Protocol：AIエージェントがPCと通信するための仕組み）との連携が可能
  • rust-toolchain.tomlでRustのツールチェーンバージョンを固定しており、Cargoで通常通りビルド・テストができる

試し方

  1. 64bit版Windows 10（1809以降）またはWindows 11の環境を用意する
  2. GitHubのReleasesページからバージョン付きMSIインストーラーをダウンロードする
  3. MSIを実行するとC:\Program Files\RustWTMにインストールされ、ガバナーサービスが起動する
  4. サービスなしで試したい場合はリリースのZIPを展開して実行する
