krisgfx9/Wireless-Device-Battery-Monitor

Trendshift 3位C++GitHub ↗

Windowsタスクバーにワイヤレスデバイスのバッテリー残量を表示する軽量トレイアプリ

何ができるか

  • LoGitechやRazerなど多ブランドのワイヤレスマウス・ヘッドセット・キーボード・コントローラーに対応する
  • バッテリー残量をタスクバー通知領域の隣に常時表示し、15%以下になると赤字で警告する
  • 充電中やスリープ状態のデバイスをアイコンで識別できる
  • PS4・PS5 DualSense、Xbox、Bluetoothデバイスにも対応する
  • ベンダー専用ソフトウェア不要で、管理者権限なしにインストーラーまたはポータブルZIPで動作する
  • コマンドラインオプション（--list、--dump、--report、--quit）でスクリプト操作もできる

なぜ注目されているか

推測 Logitechの「G HUB」やRazerの「Synapse」など各社の専用ソフトを入れずに複数ブランドのデバイスを一元管理できる点が多くのゲーマーやテレワーカーに支持されている。オープンソース（GPL-3.0）かつ無料で、軽量さが評価されている。

どんな人に役立つか

Windowsで複数ブランドのワイヤレスデバイスを使うゲーマーやオフィスユーザーに向いている。重いベンダーソフトを避けたいユーザーや、バッテリー切れを防ぎたいユーザーに特に役立つ。

技術的なポイント

  • Windows HID（Human Interface Device：ヒューマン・インターフェース・デバイス）プロトコルでデバイスのバッテリー情報を直接取得する
  • MinGW-w64とmakeでビルドするC++製アプリで、Inno Setupでインストーラーを生成する
  • Bluetooth標準プロファイルのバッテリーサービスにも対応し汎用的にバッテリー残量を取得できる
  • 実験的なLinux向けGTK4トレイビルドも存在し、HIDアクセス用のudevルール設定が必要

試し方

  1. GitHubのReleasesページからWirelessBattery-SetupインストーラーまたはポータブルZIP版をダウンロードする
  2. インストーラーを実行する（管理者権限不要だがWindows SmartScreenの警告が出る場合がある）
  3. タスクバーの通知領域付近にバッテリー残量が表示されることを確認する

AIマルチエージェントで研究論文を自動執筆するGoogleのフレームワーク

何ができるか

  • アウトライン作成・文献調査・執筆・推敲を複数の専門エージェントが分担して処理する
  • LaTeX形式で学会テンプレート（NeurIPS等）に沿った論文を出力する
  • 論文中に使うグラフや概念図を自動生成できる
  • 実験ログや素材を入力するだけでほぼ自動的に論文草稿を生成できる
  • Streamlitを使ったデモUIが付属している

なぜ注目されているか

AI研究の生産性向上ニーズが高まる中、論文執筆の自動化に特化したGoogleのマルチエージェントシステムとして注目されている。arXiv論文（2604.05018）として発表され学術的裏付けがある。推測 Googleが公式研究リポジトリで公開しており信頼性が高い点も評価されている。

どんな人に役立つか

AI研究者や大学院生が実験結果から論文草稿を素早く作りたい場合に役立つ。特にNeurIPS・ICMLなど学会向けLaTeX論文を書く研究者や、論文執筆の効率化を目指す研究チームに向いている。

技術的なポイント

  • Python 3.11とConda環境で動作するマルチエージェント（複数のAIが役割分担する）パイプラインを採用する
  • OpenAIおよびGemini（Vertex AI）のAPIをLLM（大規模言語モデル）バックエンドとして利用する
  • Semantic Scholar APIを使って論文を自動検索・引用情報を取得する
  • LaTeXで出力し学会の投稿テンプレートに対応している

試し方

  1. Python 3.11のConda環境を作成しリポジトリをクローンする
  2. .envファイルにSemantic Scholar、OpenAI、Gemini/Vertex AIのAPIキーを設定する
  3. 素材ディレクトリとLaTeXテンプレートディレクトリを用意して実行スクリプトを呼び出す
conda create -n paper_orchestra python=3.11
conda activate paper_orchestra
pip install -r requirements.txt
./paper_writing_cli.sh --raw_materials_dir <素材ディレクトリ> --latex_template_dir <テンプレートディレクトリ>

Immortal-Protocols/lastbook

Trendshift 5位PythonGitHub ↗

災害・サバイバル向けに完全オフラインで動作する知識ライブラリアプリ

何ができるか

  • マニュアル・動画・百科事典などをオフラインで一括参照できる
  • 選択した地域のオフライン地図をダウンロードして使える
  • ローカルAIが図書館のページを引用しながら質問に答えてくれる
  • ネットワーク接続不要・テレメトリーなしでプライバシーを完全保護する
  • macOS・Windows・Ubuntu向けのバイナリが配布されている

なぜ注目されているか

推測 自然災害や通信インフラの停止時にも使える知識ライブラリとして、防災意識の高まりとともに注目されている。オープンソース（MITライセンス）でコミュニティ主導の開発が進んでいる点も支持されている。

どんな人に役立つか

防災・サバイバルに関心があるユーザーや、インターネットが使えない環境（山岳地帯・発展途上国・被災時）でも知識へアクセスしたい人に役立つ。緊急時に備えて事前に知識をダウンロードしておきたい人にも向いている。

技術的なポイント

  • Python 3.11以上で動作し、データフォルダ（ライブラリ）を別途用意するアーキテクチャを採用する
  • ダウンロード時にSHA-256チェックサムでファイルの整合性を検証してセキュリティを確保する
  • デスクトップアプリはネットワークポートを開かず、ダウンロード・更新確認ボタンを押した時のみ通信する
  • ローカルAI（推測：LLMの軽量版）を組み込んでライブラリページへの引用付き回答を実現する

試し方

  1. GitHubのReleasesページから対応OSのバイナリをダウンロードする（macOS Apple Silicon、Windows 64bit、Ubuntu 24.04/26.04対応）
  2. ライブラリデータを別途ダウンロードしてアプリが参照できる場所に配置する
  3. ソースから実行する場合はPython 3.11以上が必要
git clone https://github.com/Immortal-Protocols/lastbook
cd lastbook
pip install -r requirements.txt
python main.py

NYLLON-SOFTWARE/SignuDoc

Trendshift 6位TypeScriptGitHub ↗

Vercelに自己ホストできるオープンソースの電子署名プラットフォーム

何ができるか

  • PDFに署名・日付・テキスト等のフィールドを配置して署名依頼を送信できる
  • 最大10名へ順番に署名依頼を送れ、受信者はアカウント不要で署名できる
  • ダッシュボードで署名状況を追跡しリマインダーを自動送信できる
  • 完成したPDFはPAdES形式（電子署名標準）で封印しハッシュチェーンで監査証跡を保証する
  • 組織名・ロゴ・カラーでブランドをカスタマイズでき、テンプレート機能で書類を再利用できる

なぜ注目されているか

DocuSignなどの高額な商用サービスに対して、無料で自己ホストできるオープンソース（MIT）の代替として注目されている。推測 Vercel・Neon・Resendの無料枠を組み合わせると月約250件まで費用ゼロで運用できるコスト優位性が評価されている。

どんな人に役立つか

電子署名サービスのコストを抑えたい中小企業や個人開発者に向いている。自社でデータを管理したい組織や、DocuSignの代替を探しているチームに適している。

技術的なポイント

  • Neon Postgres（サーバーレスPostgreSQL）をデータベースとしてVercelにデプロイするフルスタック構成
  • Vercel Blob（プライベートストレージ）でPDFファイルを管理する
  • Resend（メール送信API）で署名依頼やリマインダーメールを処理する
  • PAdES（PDF Advanced Electronic Signatures：PDF高度電子署名）形式で法的有効性のある電子署名を実装する
  • ハッシュチェーン（各レコードが前のレコードのハッシュを含む連鎖構造）で監査証跡の改ざんを防ぐ

試し方

  1. GitHubリポジトリをフォークしてVercelにデプロイする
  2. Neon PostgresとVercel Blobのストレージ、Resendのアカウントを用意して環境変数を設定する
  3. デプロイ後にアカウントを作成しPDFをアップロードして署名フィールドを配置する
git clone https://github.com/NYLLON-SOFTWARE/SignuDoc
cd SignuDoc
npm install
npm run dev

試し方

  1. Node.js 22.18以上、Chrome/Chromium、FFmpegをインストールする
  2. リポジトリをクローンしてnpm installで依存関係をインストールする
  3. npm run build:studioでスタジオをビルドしnpm startで起動する
  4. 自分のAIエージェントとAPIキーを設定して動画を制作する

cd openmotion
