EL4CTEO/fast-anything

Trendshift 3位RustGitHub ↗

遅い関数だけRustに移植して、アプリ全体を高速化するツール

何ができるか

  • scan コマンドで実行時間が長くRustへの移植しやすい関数をプロファイリングしてランキングする
  • port コマンドで最大500件の実際の呼び出しを記録し、コーディングエージェントがRustクレートを自動生成する
  • verify コマンドで記録済みの呼び出しを再生し、RustポートがNaNや非ASCII文字などを含む全ケースで元の実装と一致するか検証する
  • enable / disable コマンド一つでRust実装と元の実装を切り替えられる
  • fast-anything go コマンドでscan・port・verify・enableのパイプライン全体を一括実行できる
  • Python・JavaScript/TypeScript・Rubyなど10言語以上に対応している

なぜ注目されているか

アプリ全体をRustで書き直すコストをかけずに、実際に遅いボトルネック部分だけを自動でRustへ移植できる点が注目されている。推測 AI（Claude Code）と組み合わせて移植を自動化する設計が、開発者の関心を集めていると考えられる。フィールドテストではPythonで最大116倍の高速化を達成しており、実績が具体的な数字で示されている。

どんな人に役立つか

PythonやNode.js、Rubyなどのアプリにパフォーマンスのボトルネックを抱えているエンジニアに役立つ。全体をRustで書き直す時間はないが、特定の重い処理だけを高速化したい場面に適している。

技術的なポイント

  • ボトルネック関数の実引数を最大500件録音し、Rustポートの正確性を入出力レベルで自動検証する仕組みを持つ
  • Claude CodeのプラグインおよびMCPサーバー（8ツール）として統合でき、エージェントがワークフローを自律的に実行できる
  • Rustへのコード生成にはコーディングエージェント（Claude等）を利用し、ローカルのRustツールチェーンでコンパイルする
  • enable/disableの切り替えは環境変数 FAST_ANYTHING_DISABLE=1 でも制御でき、ゼロダウンタイムで元の実装に戻せる
  • npm（@el4cteo/fast-anything）とCargoの両方でインストール可能で、Node.jsとRustの両エコシステムに対応している

試し方

  1. npmまたはCargoでfast-anythingをインストールする
  2. Rustツールチェーン（rustup等）がローカルに入っていることを確認する
  3. fast-anything go --agent claude -- <アプリの実行コマンド> を実行してパイプライン全体を走らせる
  4. 処理完了後、bench や report コマンドで高速化結果を確認する
  5. 元に戻したい場合は fast-anything disable または FAST_ANYTHING_DISABLE=1 を使う

baidu/Unlimited-OCR

Trendshift 7位PythonGitHub ↗

任意の長さの文書をワンショットで解析できるBaiduの高精度OCRモデル

何ができるか

  • ページ数に関わらず1回のリクエストで文書全体をOCR解析できる。
  • Sparse Reference Sliding Window Attention（SR-SWA）により、長文書でもデコード遅延とメモリ使用量をほぼ一定に保つ。
  • TransformersとSGLangの両バックエンドに対応し、テスト用途から本番サービングまで使い分けられる。
  • PDFおよび複数ページ画像を入力として受け付け、ストリーミング出力をサポートする。
  • MPDocBenchおよびMarathonDocBenchにおいて最先端の評価結果を達成している。

なぜ注目されているか

従来のOCRモデルは長文書の処理に限界があったが、SR-SWAにより100ページ超の文書でも一定コストで解析できる点が画期的だ。SGLangによるOpenAI互換APIサーバーとしての提供や、Hugging Face・ModelScope・百度クラウドへの対応が進み、利用しやすくなったことで注目度が高まっている。

どんな人に役立つか

大量の学術論文・書類・書籍からテキストを抽出したい研究者や開発者に向いている。高精度なドキュメント解析パイプラインを構築したいエンジニアにも活用できる。

技術的なポイント

  • Sparse Reference Sliding Window Attention（SR-SWA）により、固定サイズの参照セットのみに注意を限定し、任意長の文書でも一定の計算量を実現している。
  • ページウィンドウスケジューリングにより超長文書をウィンドウ単位で処理し、前ウィンドウのKVキャッシュを再利用することでメモリ効率を高めている。
  • n-gramロジットプロセッサ（DeepseekOCRNoRepeatNGramLogitProcessor）を用いて出力の繰り返しを抑制している。
  • SGLangをベースとしたOpenAI互換APIサーバーとして動作し、カスタムロジットプロセッサやストリーミングセッションをサポートする。

試し方

  1. Python 3.10の環境を用意する。
  2. 依存ライブラリをpipでインストールする。
  3. Hugging FaceからモデルをダウンロードしてTransformersで読み込む。
  4. infer_multi()に画像ファイルのリストを渡して複数ページの推論を実行する。
pip install torch==2.13.0 torchvision pillow transformers==4.52.1 huggingface-hub==0.36.0 tokenizers==0.21.4 addict==2.4.0 einops==0.8.2 easydict==1.13

bol-van/zapret

Trendshift 8位CGitHub ↗

サーバー不要のマルチプラットフォーム対DPIツール（約EOL、後継はzapret2）

何ができるか

  • DPI（深層パケット検査）によるHTTP/HTTPSサイトのブロックや帯域制限を回避できる
  • nfqwsによるパケットレベルの改ざんと、tpwsによるストリームレベルの透過プロキシの2方式を提供する
  • TCPセグメント分割・Hostヘッダー大文字小文字変更・フェイクパケット送信など多様なデザインクロール手法を持つ
  • Linux・Windows・macOS・FreeBSD・OpenBSD・OpenWrtなど幅広いプラットフォームに対応する
  • 外部サーバー不要で自律動作し、VPN等の第三者サービスに依存しない
  • blockcheck.shスクリプトで自分の環境に合う回避戦略を自動テストできる

なぜ注目されているか

ロシアなどでインターネット検閲が強化される中、ISPのDPIによるブロックを外部サービスなしに回避できるツールとして注目を集めた。GitHubで約1.7万スターを獲得しており、OpenWrtルーター向けの軽量動作が低スペック機器を使う多くのユーザーに支持されている。推測 検閲・フィルタリング回避への需要の高まりが継続的な注目に繋がっていると考えられる。

どんな人に役立つか

ISPや国家機関のDPIによってサイトやプロトコルがブロックされている環境のユーザーに役立つ。自宅ルーター（特にOpenWrt搭載機）でネットワーク全体に回避策を適用したいネットワーク管理者や上級者向けである。なお本バージョンはEOL（バグ修正のみ）のため、新機能が必要な場合は後継のzapret2への移行が推奨される。

技術的なポイント

  • nfqwsはLinuxのNFQUEUE機能とrawソケットを用いてパケットをカーネルからユーザー空間に取り出し改ざんする
  • tpwsは透過プロキシとしてTCPストリームを中継し、TCPセグメント分割やTLSレコード分割を行う
  • TLSおよびQUICのClientHelloを複数パケットにまたがって再組み立てする機能を持ち、ポスト量子暗号（Kyber）対応のハンドシェイクにも対応する
  • BSDではnfqwsの代替としてdvtws（同一ソースからビルド）がdivertソケットを使用する
  • iptables/nftables/pfのキュールールと連携し、対象トラフィックのみを選択的に処理するプロファイル機能を持つ

試し方

  1. リポジトリをクローンし、install_prereq.shで依存パッケージをインストールする
  2. docs/quick_start.md（Linux）またはdocs/quick_start_windows.md（Windows）の手順を参照する
  3. install_easy.shを実行してnfqwsまたはtpwsをセットアップする
  4. blockcheck.shで自分の環境に有効な回避戦略を確認する

omonkeyz/xbox-emulator

Trendshift 11位PythonGitHub ↗

Xbox Series X|Sのゲームライブラリを PC で動かすエミュレーター継続開発

何ができるか

  • 合法的に取得・復号済みのXbox Series X|Sビルドを、通常のWindowsプロセスとして実行できる
  • Xbox専用のDirect3D 12・プリコンパイル済みRDNA2シェーダー・統合メモリテクスチャ・システムライブラリを再実装している
  • FortkniteのPC起動・ログイン・ロビー到達（2Dインターフェース表示）まで動作が確認されている
  • RDNA2シェーダー命令のデコードとPC向け翻訳に対応しており、シェーダー翻訳済み数をバッジで追跡できる
  • Xboxコンソール専用DLLのエクスポート関数を逐次マッピング・実装しており、ライブラリマップで進捗が確認できる

なぜ注目されているか

Xbox Series X|Sタイトルを PC で動作させるという高難度の目標に向けて、先行プロジェクト TomBox を引き継ぎ本格的な再実装が進んでいる。推測 コンソール専用Direct3D 12の再現やRDNA2シェーダー翻訳という技術的挑戦が、エミュレーション研究者やグラフィックスエンジニアの関心を集めていると考えられる。Fortnite のロビー到達という具体的なマイルストーン達成が注目を集めている。

どんな人に役立つか

Xboxエミュレーションやコンソールライブラリのリバースエンジニアリングに興味のある開発者・研究者に最も向いている。コンソール向けDirect3D 12やRDNA2シェーダーパイプラインを実装レベルで学びたいグラフィックスプログラマーや、ゲームエンジンの移植研究をしている人にとっても参考になる。

技術的なポイント

  • Rustワークスペース（crates/・tools/・Cargo.toml）でXboxプラットフォーム層全体を再実装している
  • Xbox専用のDirect3D 12.xインターフェースメソッドをホスト側でエミュレーションしている
  • プリコンパイル済みRDNA2シェーダーのデコード・翻訳エンジンを内包し、105,506シェーダーの翻訳を達成済み
  • Xboxコンソール専用DLL（d3d12_xs、xg_xs、xmem、xapu 等）のエクスポート関数をマッピング・実装している
  • tools/progress/gen.py で関数実装状況を自動集計し、進捗バッジとライブラリマップとして可視化している

何ができるか

  4. ブラウザから試す場合はhttps://unkernel.dev/を開くだけで動く（インストール不要）

  • MCPツールとして公開され、KiroやClaude CodeなどのIDEやAIアシスタントから利用できる

なぜ注目されているか

AIによる自律的なソフトウェア開発（ブラウンフィールド開発）が注目される中、既存コードベースをAIエージェントに理解させることが重要課題となっている。CodeKBは単なるコードインデックスではなく、ビジネスロジックの意味まで理解させることで、AIエージェントが既存システムを正確に把握しながらタスクをこなせるようにする点で注目される。推測 大規模組織での複数リポジトリにわたるコード理解の自動化ニーズが高まっているため、このようなツールへの関心が増している。

どんな人に役立つか

既存の大規模コードベースをAIエージェントに扱わせたい開発者やチームに役立つ。特に複数リポジトリにまたがるシステムを管理している組織や、AIを活用したコードレビュー・影響分析を行いたいエンジニアに適している。

技術的なポイント

  • Tree-sitterを使って14言語ファミリーのソースコードを構文解析し、コールグラフを再構築する
  • Amazon Bedrockの対応Claudeモデルを用いて各関数をビジネス用語で説明し、Titan Text Embeddings V2でベクトル化してS3 Vectorsに保存する
  • AWS CDKを使ってECS Fargate・CloudFront・AWS WAF・Cognitoによる本番向け共有インスタンスをデプロイできる
  • 変更があったファイルのみ再インデックスし、影響を受けた呼び出し元の要約も更新する差分更新の仕組みを持つ
  • Guardrailを使ってシークレットや個人情報をマスクしてからLLMに渡すセキュリティ機構を備える

試し方

  1. Amazon Bedrockで対応するClaudeモデルとTitan Text Embeddings V2へのアクセスを有効にする
  2. AWS CDK（推奨）またはローカル実行のどちらかのデプロイ方法を選択する
  3. GitリポジトリのURLまたはZIPファイルアップロードでスペースを追加する
  4. インデックス完了後、意味的検索やエージェントホッパー、オーバービュー生成を利用する
