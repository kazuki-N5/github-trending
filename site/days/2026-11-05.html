OpenSelena/omniget

Trendshift 3位RustGitHub ↗

Udemy・YouTube等1,800+サイト対応のオープンソースメディアダウンローダー

何ができるか

  • UdemyやHotmartなどのオンライン講座をはじめ、YouTube・Instagram・TikTokなど1,800以上のサイトから動画・音声・字幕をダウンロードできる。
  • MP4・MKV・WebMなどの動画形式、MP3・FLACなどの音声形式、SRT・VTTなどの字幕形式に対応している。
  • ブラウザ拡張機能と連携してCookieを自動で渡すことで、ログイン必須の有料コンテンツもダウンロードできる。
  • whisper.cpp（Whisperモデルのオフライン実装ライブラリ）を使った文字起こしやテキスト読み上げなど25カテゴリ・158種のツールを内蔵している。
  • Claude CodeなどのAIエージェント向けにMCPサーバーとして37種のツールを公開しており、エージェントから直接メディア取得・変換を操作できる。
  • ダウンロードキューの中断再開・自動リトライ・接続数制限など、堅牢なキュー管理機能を備えている。

なぜ注目されているか

推測 オープンソースの講座ダウンローダーは少なく、購入済み講座をオフラインで視聴したいというニーズに応える点で注目されていると考えられる。Tauri 2とRustを採用した軽量なデスクトップアプリで広告・テレメトリなし・ローカル保存という設計が信頼性を高めており、AIエージェントとのMCP連携という新しいユースケースも話題を集めている可能性がある。

どんな人に役立つか

オンライン講座を購入したがオフライン視聴もしたい学習者や、動画・画像を一括でアーカイブしたいクリエイター・研究者に向いている。AIエージェントにメディア取得・処理を任せたい開発者にも活用できる。

技術的なポイント

  • Tauri 2（RustとWebViewを組み合わせた軽量クロスプラットフォームデスクトップアプリフレームワーク）とRustをバックエンドに採用している。
  • フロントエンドはSvelteKit（Svelte 5）で構築されており、UIの状態管理とルーティングを担っている。
  • yt-dlp・gallery-dl・FFmpeg・aria2などの実績あるオープンソースCLIツールをバックエンドで呼び出すことで幅広いサイト対応と変換処理を実現している。
  • SQLiteをローカルストレージとして使用してダウンロードキューや設定を管理し、データはすべてユーザーのPC内にとどまる。
  • whisper.cppを組み込むことでインターネット接続不要のオフライン音声文字起こしを可能にしている。

試し方

  1. GitHubのReleasesページから自分のOS向けインストーラーをダウンロードする（Windowsは.exe/.msi、macOSは.dmg、Linuxは.deb/.rpm/.AppImage）。
  2. Windowsの場合はSmartScreen警告で「詳細情報→実行」を選ぶ。macOSの場合はターミナルでxattrとcodesignコマンドを実行してセキュリティ制限を解除する。
  3. 初回起動時に言語とテーマを選択すると、yt-dlpとFFmpegがSHA-256検証付きで自動インストールされる。
  4. ダウンロードしたいURLをコピーしてCtrl+Shift+D（macOSはCmd+Shift+D）を押すとすぐダウンロードが始まる。

brew install --cask OpenSelena/tap/omniget

sudo apt install gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-libav
git clone https://github.com/OpenSelena/omniget.git

KKKKhazix/agent-autoloop

Trendshift 5位TypeScriptGitHub ↗

AIエージェントをバックグラウンドで自律実行し、必要なときだけ人間に判断を求めるハブ

何ができるか

  • cron式またはイベントをトリガーにClaude Code・Codexなどのコマンドラインエージェントをバックグラウンドで自動実行できる。
  • エージェントが判断に迷ったときだけFeishu・Slack・Discordなどへカード通知を送り、ユーザーの承認を受けてから処理を再開する。
  • 待機中はプロセスもトークン消費もゼロで、返信があったときだけセッションが再開される設計になっている。
  • ~/.agent-autoloop/rules.jsonにルールを記述するだけで動作し、エージェントのSDK変更や追加コードは不要。
  • agent-autoloop why コマンドで任意の実行がなぜ起動したか・何を生成したかを追跡・説明できる。
  • GitHub・GitLabのWebhookやHTTP APIなどを入力源にでき、CI/CDパイプラインへの配信プラグインも備えている。

なぜ注目されているか

推測 コマンドラインAIエージェントがターミナルを見ている人間のそばにいる間しか使われていないという課題を解決しようとしており、非同期・バックグラウンド実行へのニーズが高まっていると考えられる。ゼロ外部依存のカーネル設計や、イベントソーシング（全状態をイベントログから再構築する手法）による信頼性の高い実装、プロンプトインジェクション対策など技術的な堅牢さが注目されている可能性がある。

どんな人に役立つか

Claude CodeやCodexを普段使いしており、夜間や離席中もエージェントに作業を続けてほしい開発者に向いている。GitHubのIssue対応・PRのCI待ち・マージなど、非同期で一連のワークフローを自動化したい場面に特に活用できる。

技術的なポイント

  • TypeScript + Node 24上に構築されており、カーネル本体は約1,650行・ランタイム依存ゼロで実装されている。
  • イベントソーシング（全状態をSQLiteへ追記されるイベントログから再構築する手法）を採用し、強制終了後も状態を完全復元できる。
  • エージェントへの指示と外部入力データを明示的に分離することでプロンプトインジェクション（外部データでAIを誤動作させる攻撃）を防ぐ設計になっている。
  • エージェント間のイベント連鎖は最大8ホップに制限されており、無限ループを防いでいる。

試し方

  1. Node 24・Git・curlがインストール済みであることを確認する（macOS/Linuxのみ対応。Windowsは未サポート）。
  2. インストールスクリプトを実行してセットアップする。
  3. agent-autoloop tryコマンドでテスト実行し、エージェントが多肢選択の質問を出してくるのを確認する。
  4. agent-autoloop answer 1 <番号>で回答し、agent-autoloop statusで進捗を確認する。
  5. ~/.agent-autoloop/rules.jsonにトリガー・対象エージェント・作業ディレクトリ・プロンプトを記述して本番利用を始める。
curl -fsSL https://raw.githubusercontent.com/KKKKhazix/agent-autoloop/main/install.sh | sh
agent-autoloop try
agent-autoloop answer 1 <number>
agent-autoloop status
agent-autoloop check
agent-autoloop why <n>

govijr/terminal-mac

Trendshift 9位SwiftGitHub ↗

Apple シリコン Mac 上でmacOS仮想マシンをターミナルから操作するツール

何ができるか

  • curl インストーラで terminal-mac コマンドを追加し、`terminal-mac up` 一発で macOS の VM を起動できる
  • Kitty・iTerm2・Ghostty のグラフィクス対応ターミナル上で、VM の画面をターミナル内に表示する
  • スクリーンショット・クリック・ドラッグ・スクロール・テキスト入力など、ゲスト VM のマウス・キー操作をターミナルから行える
  • MCP サーバーとスキルを通じて AI エージェントがゲスト VM をプログラム的に操作できる
  • VM データは ~/Library/Application Support/terminal-mac/machines/ に保存され、Ctrl+] でビューワを抜けても VM は起動し続ける
  • --offline フラグで VM のネットワークを切り、ホストの環境から隔離した状態で実行できる

なぜ注目されているか

推測 AI エージェントに実際の macOS 環境を安全に操作させたいというニーズが高まっており、Apple Virtualization を活用して手軽に macOS VM を立ち上げられる点が注目されている。推測 ターミナル内で VM 画面を直接表示できる新鮮なアプローチが開発者の関心を集めている。

どんな人に役立つか

macOS を使う開発者で、AI エージェントにデスクトップ GUI タスクを自動実行させたい人に向いている。また、ホスト環境を汚さずに macOS の動作検証をしたいエンジニアにも有用。

技術的なポイント

  • Apple Virtualization フレームワーク（macOS 14 以降）を使い、Apple シリコン上でネイティブ macOS ゲストを動かす
  • Kitty Graphics Protocol などのターミナルグラフィクス仕様を利用して VM 画面をインラインレンダリングする
  • MCP（Model Context Protocol）サーバーを内蔵し、AI エージェントへのツール（スクショ・操作系）提供を標準化している
  • VM ディスクはスパースイメージ（論理 64 GiB）で作成され、実際の使用量に応じてホストストレージを消費する

試し方

  1. macOS 14 以降の Apple シリコン Mac で、curl インストーラを実行して terminal-mac コマンドをインストールする
  2. `terminal-mac up` を実行して macOS リストアイメージをダウンロードし VM を起動する
  3. VM 内で macOS のセットアップを完了し、ゲストヘルパーに Screen Recording と Accessibility の権限を付与する
  4. ターミナルのビューワで VM を操作し、Ctrl+] でビューワを終了しても VM はバックグラウンドで動き続ける
curl -fsSL https://raw.githubusercontent.com/govijr/terminal-mac/HEAD/install.sh | sh
terminal-mac up

Usagi-org/ai-goofish-monitor

Trendshift 13位PythonGitHub ↗

AIと Playwright で闲鱼（フリマアプリ）を自動監視・分析するシステム

何ができるか

  • キーワード・価格帯・送料無料・地域などの条件を設定したタスクを複数同時に実行し、闲鱼の新着商品をリアルタイム・定時監視できる
  • マルチモーダル AI モデルが商品画像と説明を総合的に解析し、ユーザー定義のプロンプトに基づいて購入価値を判定する
  • ntfy.sh・企業 WeChat・Bark・Telegram・Webhook など複数チャンネルへの通知に対応し、条件に合う商品が見つかると即座にアラートを送れる
  • タスク管理・アカウント管理・実行ログ・結果閲覧をブラウザから操作できる Web 管理 UI を備える
  • 複数の闲鱼アカウントとプロキシプールを設定でき、タスクごとにアカウントを割り当てて運用できる
  • Docker Compose 一コマンドでデプロイでき、SQLite でデータを永続化する

なぜ注目されているか

推測 人気商品や掘り出し物をいち早く見つけたいフリマアプリユーザーの需要が高く、AI による自動判定で大量の商品を人手なしに絞り込める点が評価されている。推測 Playwright を使ったブラウザ自動化と AI 分析を組み合わせた実用的な構成が、スクレイピング学習の参考としても注目を集めている。

どんな人に役立つか

闲鱼でレアな商品や特定ジャンルのアイテムをいち早く購入したいユーザーに向いている。また、Playwright・FastAPI・AI API を組み合わせた Web スクレイピングシステムの構築を学びたい学生・エンジニアにも参考になる。

技術的なポイント

  • Playwright（ブラウザ自動操作ライブラリ）で闲鱼の商品ページをスクレイピングし、ログインセッションを Cookie として管理する
  • OpenAI 互換 API（画像入力対応モデルが必須）に商品画像と説明を送り、ユーザー定義プロンプトで AI 判定を行う
  • FastAPI バックエンドと Vite ビルドのフロントエンドで構成され、両者は同一ポート 8000 でサービングされる
  • SQLite（data/app.sqlite3）でタスク・ログ・結果を永続化し、Docker ボリュームマウントでコンテナ再起動後も保持する
  • Cron スケジューリングで定期実行に対応し、プロキシローテーションとタスク失敗時の自動リトライ機能を持つ

試し方

  1. リポジトリをクローンし、ディレクトリに移動する
  2. .env.example を .env にコピーし、OPENAI_API_KEY・OPENAI_BASE_URL・OPENAI_MODEL_NAME を設定する（画像入力対応モデルが必要）
  3. Docker Compose でコンテナを起動する
  4. http://127.0.0.1:8000 にアクセスし、Chrome 拡張でエクスポートした闲鱼ログイン状態 JSON をアカウント管理からインポートする
  5. タスクを作成してアカウントを紐付け、実行する
git clone https://github.com/Usagi-org/ai-goofish-monitor.git && cd ai-goofish-monitor
cp .env.example .env
docker compose up -d
docker compose logs -f app
docker compose down

どんな人に役立つか
