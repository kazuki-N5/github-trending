Renhuai123/ziwei-doushu

GitHub Trending 5位★ +547TypeScriptGitHub ↗

中国の占術「紫微斗数」の命盤を作るオープンソースの計算エンジンと解読データセット

何ができるか

  • 生年月日・時刻・性別から、紫微斗数（生まれた時刻をもとに星を12の宮に配置して運勢を読む中国の占術）の命盤を作成できます。
  • 出生地の経度による真太陽時の補正、中国の1986〜1991年の夏時間、閏月や深夜0時前後の日付の扱いを考慮して計算します。
  • 四化（星の性質を変化させる仕組み）や飛星、十二神煞、1100行を超える格局（特徴的な星の組み合わせ）の判定ルールを備えています。
  • 67.5万件の命盤に13分野の解読文を付けた v4.0 データセット（解凍後56.6GB）を Releases で配布しています。
  • 古典の原文（骨髄賦、紫微斗数全集・全書）や、倪海厦の講義『天紀』の発言1848条を出典時刻付きで収録しています。
  • Next.js 製のデモ画面で、命盤の表示や本命・大限・流年の切り替え、古典の全文検索ができます。

なぜ注目されているか

倪海厦の『天紀』の体系に基づく命盤計算エンジンと、大規模な解読データセットを無料で公開しており、データセットは CC BY 4.0 で商用利用もできます。リポジトリページでは6千を超えるスターを集めています。推測 小型モデルのファインチューニングや RAG（検索した資料を LLM に渡して回答させる手法）用のデータとして使える点も注目の理由と考えられます。

どんな人に役立つか

紫微斗数の命盤計算を自分のアプリに組み込みたい開発者や、占術分野の LLM 用学習データ・検索用データを探している人に向いています。暦の計算（旧暦変換や真太陽時）の実装例としても参考になります。

技術的なポイント

  • TypeScript と Next.js 16（App Router）、Tailwind CSS で作られ、命盤計算は iztro と lunar-javascript をもとにしています。
  • 命盤計算の中核は lib/ziwei/ にあり、命宮の決定から主星・補助星の配置、大限・流年の計算までを algorithm.ts が担当します。
  • 解読データセットは計算エンジンと断語ライブラリから AI を使わずに決定的に生成されており、同じ入力からは常に同じ出力になります。
  • データセットは1行1命盤の JSON Lines 形式で、年ごとに zstd で圧縮されています。
  • 断語ライブラリ、AI 解読のプロンプト、バックエンド API は非公開で、オープンソース版の画面は最小限のデモです。

試し方

  1. リポジトリをクローンし、npm install で依存パッケージを入れます。
  2. .env.example を .env.local にコピーします（命盤を見るだけなら省略できます）。
  3. npm run dev で開発サーバーを起動し、ブラウザで命盤を作成します（API キーは不要です）。
  4. npm test で命盤計算エンジンの回帰テストを実行できます。
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu
npm install
cp .env.example .env.local
npm run dev
npm run typecheck
npm test
zstd -d --long=27 year-1990.jsonl.zst

SnailSploit/Claude-Red

GitHub Trending 6位★ +209PythonGitHub ↗

Claudeを攻撃側セキュリティの専門家として動かすためのスキル集

何ができるか

  • Claude の Skills 機能向けに、攻撃的セキュリティ（システムの弱点を攻撃者の視点で検証する分野）の手法を SKILL.md ファイルとしてまとめています。
  • SQL インジェクション、XSS、SSRF などの Web 脆弱性から、Active Directory、無線、クラウド、モバイル、エクスプロイト開発まで、23カテゴリ78のスキルを収録しています。
  • 会話の内容に応じて必要なスキルだけが読み込まれるため、使わないスキルでコンテキスト（モデルに渡す文脈の量）を消費しません。
  • Claude Code ではスキルファイルをシステムプロンプトとして渡して使え、Claude.ai ではプロジェクトのシステムプロンプトに貼り付けて使えます。
  • インストールスクリプトで、導入先やカテゴリを選んでスキルを入れられます。

なぜ注目されているか

許可を得たレッドチーム演習（攻撃者役として組織の防御を試す活動）やバグバウンティ、CTF の準備などに向けて、専門的な手順を Claude に持たせられる点を打ち出しています。リポジトリページでは8千を超えるスターを集めています。推測 AI エージェント向けのスキルという仕組みが広がる中で、セキュリティ分野に特化した大規模なスキル集が少ないことが注目の理由と考えられます。

どんな人に役立つか

許可された範囲でペネトレーションテスト（侵入テスト）やバグバウンティ、セキュリティ研究を行う人、CTF の練習をする人に向いています。攻撃手法を学んで防御に生かしたい学生の学習用の参照資料にもなります。

技術的なポイント

  • 各スキルは構造化された SKILL.md ファイルで、手法、ツール、例外的なケース、権限昇格の道筋などを記述しています。
  • Claude の Skills 機能は会話中のきっかけとなる語に応じてスキルを自動で読み込み、たとえば SQL インジェクションに触れると offensive-sqli が読み込まれます。
  • git の sparse-checkout（リポジトリの一部だけを取り出す機能）を使って、特定カテゴリだけを導入できます。
  • Sahar Shlichov 氏の offensive-checklist を土台にしたスキルが多く含まれ、ライセンスは MIT です。

試し方

  1. リポジトリを ~/.claude/skills/claude-red にクローンします。
  2. Claude との会話で対象の攻撃手法に触れると、対応するスキルが自動で読み込まれます。
  3. 特定カテゴリだけを使いたい場合は、sparse-checkout かインストールスクリプトの --category で選びます。
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
git clone --filter=blob:none --sparse https://github.com/SnailSploit/claude-red
cd claude-red && git sparse-checkout set Skills/web Skills/active-directory
cat Skills/web/offensive-sqli/SKILL.md | claude --system-file -
./install.sh
./install.sh --target ~/.claude/skills
./install.sh --category web

OpenBMB/VoxCPM

GitHub Trending 7位★ +144PythonGitHub ↗

30言語対応で声のデザインや声のクローンもできる、オープンな音声合成モデル

何ができるか

  • 30言語のテキストを、言語の指定なしでそのまま音声に変換できます（日本語も含まれます）。
  • 性別、年齢、口調、感情、話す速さなどを自然な言葉で書くだけで、参照音声なしに新しい声を作れます（Voice Design）。
  • 短い参照音声から声をまね（ボイスクローン）、感情や速さなどのスタイルを指示で調整できます。
  • 参照音声とその書き起こしを両方渡すと、声の細かな特徴まで再現して続きを話させられます（Ultimate Cloning）。
  • 48kHz の高音質で出力でき、ストリーミング（音声を少しずつ逐次生成すること）にも対応します。
  • 5〜10分程度の音声で、全体のファインチューニングや LoRA による軽量なファインチューニングができます。

なぜ注目されているか

テキストを離散的なトークンに区切らずに連続的な音声表現を直接生成する方式で、自然で表現力のある音声を目指しています。最新の VoxCPM2 は200万時間を超える多言語音声で学習した20億パラメータのモデルで、重みとコードが Apache-2.0 で商用利用可能な形で公開されています。README によると以前の版も GitHub Trending や Hugging Face Trending で1位になっており、リポジトリページでは4万を超えるスターを集めています。

どんな人に役立つか

ナレーションや多言語の読み上げ音声を作りたい人、音声合成を自分のアプリやサービスに組み込みたい開発者に向いています。音声生成モデルの仕組みを研究したい学生にも参考になります。なお README は、なりすましや詐欺、偽情報への利用を厳しく禁じています。

技術的なポイント

  • 拡散モデル（ノイズから少しずつデータを生成する手法）と自己回帰（前の出力をもとに次を順に生成する手法）を組み合わせたエンドツーエンドの構成です。
  • 言語モデルの土台に MiniCPM-4 を使い、AudioVAE V2 が16kHz の参照音声を受けて48kHz の音声を直接出力します。
  • RTX 4090 での RTF（生成時間を音声の長さで割った値、小さいほど速い）は標準で約0.3、Nano-vLLM や vLLM-Omni を使うと約0.13です。
  • vLLM-Omni では OpenAI 互換の /v1/audio/speech API として提供でき、llama.cpp-omni を使えば Python なしで CPU や Metal、CUDA 上で動かせます。
  • 動作には Python 3.10 以上 3.13 未満、PyTorch 2.5.0 以上、CUDA 12.0 以上が必要です。

試し方

  1. pip で voxcpm パッケージをインストールします。
  2. Python から VoxCPM.from_pretrained でモデルを読み込み、generate にテキストを渡して音声ファイルを保存します。
  3. コマンドラインでは voxcpm design で声をデザインし、voxcpm clone で参照音声から声をクローンします。
  4. Web デモは python app.py --port 8808 で起動し、ブラウザで http://localhost:8808 を開きます。
pip install voxcpm
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav
voxcpm clone --text "This is a voice cloning demo." --reference-audio path/to/voice.wav --output out.wav
voxcpm --help
python app.py --port 8808
pip install nano-vllm-voxcpm
vllm serve openbmb/VoxCPM2 --omni --port 8000

nodejs/node

GitHub Trending 8位★ +93JavaScriptGitHub ↗

ブラウザの外でJavaScriptを動かす実行環境Node.jsの公式リポジトリ

何ができるか

  • Node.js は、オープンソースでクロスプラットフォーム（複数のOSで動くこと）の JavaScript 実行環境（ランタイム）です。
  • nodejs.org/dist/ からバイナリ、インストーラー、ソースコードの tarball を入手できます。
  • ダウンロードしたファイルは、SHASUMS256.txt.asc のチェックサムとリリース担当者の PGP 署名で改ざんがないか検証できます。
  • BUILDING.md の手順に従って、ソースから Node.js をビルドできます。
  • 最新の Current 版と長期サポートの LTS 版それぞれについて、バージョンごとの API ドキュメントが提供されています。

なぜ注目されているか

Node.js は JavaScript 実行環境の代表的なプロジェクトで、リポジトリページでは12万を超えるスターを集めています。README によると、2026年10月からは毎年10月に新しいリリースラインが Alpha として分岐し、翌年4月に Current、10月に LTS になる新しいリリーススケジュールに移行しています。推測 このリリース方式の変更や新しいメジャーバージョンの登場が、改めて注目を集めている理由と考えられます。

どんな人に役立つか

JavaScript でサーバーサイドのプログラムやコマンドラインツールを作る開発者全般に関係します。Node.js 本体の開発に貢献したい人や、大規模なオープンソースプロジェクトの運営の仕組みを知りたい人にも参考になります。

技術的なポイント

  • セマンティックバージョニング（互換性を壊す変更があるとメジャー番号を上げる番号の付け方）に従っています。
  • リリースは Alpha、Current、LTS、Nightly の4種類で、LTS は30か月のサポートを受け、最初の Current から終了まで合計36か月です。
  • Nightly 版は main ブランチに変更があるときに24時間ごとに自動ビルドされますが、テストはされていません。
  • オープンなガバナンスモデルを採り、TSC（技術運営委員会）が運営し、OpenJS Foundation が支援しています。

試し方

  1. nodejs.org/dist/ から目的のバージョンのバイナリかインストーラーをダウンロードします。
  2. nodejs/release-keys から信頼できる鍵束を取得し、gpgv で SHASUMS256.txt.asc の署名を検証します。
  3. ソースからビルドする場合は BUILDING.md の手順に従います。
curl -fsLo "/path/to/nodejs-keyring.kbx" "https://github.com/nodejs/release-keys/raw/HEAD/gpg/pubring.kbx"

basketikun/infinite-canvas

Trendshift 9位TypeScriptGitHub ↗

AI生成画像を無限キャンバス上で並べて試行錯誤できる、オープンソースの制作ツール

何ができるか

  • 複数のキャンバスを持つプロジェクトで、ノード（キャンバス上の部品）のドラッグや拡大縮小、線でのつなぎ合わせ、ミニマップ、元に戻す・やり直しができます。
  • 設定した OpenAI 互換 API に接続し、テキストからの画像生成、画像からの画像生成、参考画像の編集、文章での質問、音声や動画の生成ができます。
  • キャンバスアシスタントが、選んだノードやその上流のノードについて対話や画像生成を行い、結果をキャンバスに戻します。
  • ローカルの Canvas Agent を通じて Codex や Claude Code をつなぎ、エージェントに MCP 経由で現在のキャンバスを操作させられます。
  • URL からリモートのノードプラグインを導入・更新・削除でき、TypeScript SDK で独自のノードも作れます。

colinhacks/reylo

SQLファイルを型付きでTypeScriptからimportできる、コード生成不要のツール

何ができるか

  • .sql ファイルを TypeScript から直接 import し、.run() に DB ドライバーのクライアントを渡してクエリを実行できます。
  • クエリの結果や引数の型を SQL そのものから推論するため、行の型を手書きしたりスキーマファイルを同期したりする必要がありません。
  • 列名の誤字、間違ったパラメータ、削除されたテーブルなどを、tsc やエディタ上で型エラーとして検出できます。
  • 主キー一致なら Row | null、集計なら Row、returning の無い更新なら void のように、返る行数に応じて戻り値の型が変わります。
  • Postgres、MySQL、SQLite に対応し、pg、postgres.js、mysql2、better-sqlite3、Bun.sql、Cloudflare D1 など手持ちのドライバーを使えます。

なぜ注目されているか

作者は TypeScript のスキーマ検証ライブラリ Zod の作者として知られる Colin McDonnell（colinhacks）です。TypeScript 7.1 ベータで導入された content mappers（外部ファイルの種類に静的な型を与える仕組み）を使い、コード生成なしで SQL に型を付ける点が新しいです。推測 README が「エージェント時代に最適」とうたうように、型情報が1か所にまとまり AI エージェントが古い型を残しにくい点も関心を集めていると考えられます。

どんな人に役立つか

ORM を使わずに生の SQL を書きたいが、TypeScript の型安全性も欲しい開発者に向いています。AI コーディングエージェントに DB まわりのコードを書かせる場合にも、型チェックで見落としを拾えます。

技術的なポイント

  • TypeScript 7.1（ベータ）の content mappers を使い、型チェッカーが直接 Reylo に問い合わせるため、生成ファイルやファイル監視が不要です。
  • 型を付けるとき、開発用データベースにクエリを実行せずに prepare（事前解析）させ、各列とパラメータの型を読み取ります。
  • スキーマや join、where 条件から NULL になりうるかを推論し、enum やチェック制約の値はユニオン型にします。
  • 実行時は node --import reylo/register で読み込むほか、Bun、Vite、Next.js、esbuild、webpack などのプラグインも用意されています。

試し方

  1. Node 24 以上と、動いている開発用データベース（Postgres、MySQL 8.0.22 以上、または SQLite ファイル）を用意します。
  2. Reylo、使うデータベース用のエンジン、TypeScript 7.1 ベータをインストールします。
  3. tsconfig.json の contentMappers に Reylo を追加し、.env に DATABASE_URL を書きます。
  4. tsc --noEmit --runExternalCode で型チェックし、node の --import reylo/register 付きでコードを実行します。
