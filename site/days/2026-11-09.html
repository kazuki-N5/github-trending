  2. または`skills/`フォルダにリポジトリをクローンする。

vercel-labs/agent-browser

Trendshift 10位RustGitHub ↗

AIエージェントがシェルコマンド1つでブラウザを操作できるRust製CLI

何ができるか

  • `snapshot`コマンドでページ内容を`@e1`形式のrefを持つコンパクトなテキストとして取得できる。
  • refを指定してクリック・入力などを実行し、コマンド間でブラウザを開いたままにできる。
  • npm・Homebrew・npxで手軽にインストールでき、`agent-browser install`でChrome for Testingも取得できる。
  • MCPサーバーとして動作させることでAIエージェントから統合できる。
  • バックグラウンドデーモン方式で`--session`ごとにブラウザを制御し、1時間アイドルで自動終了する。
  • クラウドブラウザプロバイダー・iOSシミュレーターのMobile Safariにも対応する。

なぜ注目されているか

推測 AIエージェントがWebブラウザを操作する需要が高まる中、Vercelが軽量なコマンドラインツールとして公開したことで注目を集めている。ヘッドレスPlaywrightと違いシェル1コマンドで使える手軽さが評価されている。

どんな人に役立つか

ブラウザ自動化をAIエージェントのタスクに組み込みたい開発者に適している。LLMベースのワークフローでWebスクレイピングやフォーム操作を自動化したいエンジニアにも向いている。

技術的なポイント

  • Rustで実装されたネイティブCLIで、macOS・Linux・Windows向けバイナリを提供する。
  • Chrome DevTools Protocol（CDP）経由でバックグラウンドデーモンがブラウザを制御する。
  • refが古くなる（ナビゲーション後など）とクリックが失敗し、再スナップショットを促す安全設計になっている。
  • バージョン管理されたスキルシステム（`agent-browser skills get core`）で機能を拡張できる。

試し方

  1. `npx agent-browser install`でChrome for Testingをダウンロードする（初回のみ）。
  2. `npx agent-browser open https://example.com`でブラウザを開く。
  3. `npx agent-browser snapshot`でページのテキスト表現を取得する。
  4. 表示されたrefを使って`npx agent-browser click @e1`のように操作する。
npm install -g agent-browser
npx agent-browser install
npx agent-browser open https://example.com
npx agent-browser snapshot

shikokuchuo/pymizu

はてなブックマーク 3位3 usersPythonGitHub ↗

共有メモリIPC上で動作するスレッド並みの速度を持つ非同期・並列Pythonライブラリ

何ができるか

  • タスクのラウンドトリップが1µs未満で、ソケット経由の約100µsと比べて大幅に高速。
  • concurrent.futuresのExecutorインターフェースを実装しており、既存コードを最小限の変更で切り替えられる。
  • asyncioのawaitに対応し、ポーリングではなくイベント駆動でウェイクアップする。
  • NumpyアレイやArrowテーブルなどをゼロコピーで共有メモリ越しにPythonとR間で交換できる。
  • ワーカープロセスがクラッシュしてもホストプロセスに影響を与えない（プロセス分離）。
  • seed=でワーカー数に依らず再現性のある並列乱数生成が可能。

なぜ注目されているか

推測 Pythonの並列処理はGILやプロセス間通信のオーバーヘッドが課題だったが、pymizuは共有メモリとロックフリーIPCで大幅に改善している。RとのゼロコピーデータOSS連携という独自性も注目を集める理由と考えられる。

どんな人に役立つか

高速な並列・非同期処理が必要なデータサイエンティストや機械学習エンジニアに役立つ。RとPythonを併用する研究者にも適している。

技術的なポイント

  • 内部でC言語製のロックフリー共有メモリIPCライブラリlibmizuを使用している。
  • RのmizuパッケージとArrow/polars/pandasを介したゼロコピーデータ共有が可能。
  • Pool.mapはネストしたマップがデッドロックしない設計になっている。
  • Python 3.10以上・64ビット環境が必要で、cloudpickle等のオプション依存が選択可能。

試し方

  1. pip install pymizuでインストールする（Python 3.10以上・64ビット）。
  2. PoolExecutorをconcurrent.futuresのExecutorの代替として使う。
pip install pymizu
pip install pymizu[numpy]
pip install pymizu[cloudpickle]

omonomo/Cyroit

全角英数・半角カナに下線を引いてコード中の文字種混在を視覚化する等幅フォント

何ができるか

  • 全角英数字と半角カタカナにアンダーラインを付け、コード中の誤った文字種を一目で発見できる。
  • caltベースのカーニング（文字間隔自動調整）機能を内蔵し、読みやすい表示を実現する。
  • 数字区切りマーク・点字・異体仮名・縦書き（vert）など多彩なグリフバリアントを収録する。
  • Cyroit（半角=全角の1/2）とCyroitLoose（半角=全角の9/16）の2バリアントを提供する。
  • Meroit・Jeroit・Ubroit等8種の姉妹フォントとして他のベースフォントと組み合わせたバリアントも存在する。

なぜ注目されているか

推測 日本語を扱うコードでは全角・半角の混在がバグの原因になりやすく、フォントレベルで視覚化するアプローチが独自性を持つ。Rictyから派生しつつ独自機能を多数追加した点が開発者コミュニティの関心を集めていると考えられる。

どんな人に役立つか

日本語を含むコードを書く開発者・プログラマーに役立つ。全角・半角文字の混在によるバグに悩んだことがあるエンジニアに特に適している。

技術的なポイント

  • ss01〜ss20のStyleistic Setsでスペース可視化・数字区切り・記号マーキングなどを切り替えられる。
  • ライセンスはフォントがSIL OFL 1.1、ビルドスクリプトがMIT。

試し方
