vercel-labs/ui

Trendshift 2位TypeScriptGitHub ↗

エージェントが次世代UIを構築するための「振る舞い」ライブラリ

何ができるか

  • キーボードナビゲーション・フォーカス管理・選択・ポップアップ・ドラッグ＆ドロップ・ARIAを提供するコアライブラリ（@ui-sdk/core）
  • definePrimitive でコンポーネントの状態・API・スロットをフレームワーク非依存な形で定義できる
  • createParts を使って定義したプリミティブをReact・Vue・Svelte・Solid・Web Componentsの各フレームワーク向けコンポーネントに変換できる
  • createFocusRecovery などの名前付き「振る舞い」を組み合わせてUI部品を構築できる
  • AIエージェント向けにui-sdkスキルをCLIで追加し、エージェントがUIを構築できるよう支援する機能がある

なぜ注目されているか

ReactやVueなどのフレームワークに依存せず、UIの「振る舞い」（アクセシビリティ・キーボード操作・フォーカス管理など）を再利用可能な形で提供する設計が注目されている。AIエージェントがUIを生成・操作することを見据えたアーキテクチャを採用している点も新しい。Vercel Labsが開発しており、次世代のUI構築のあり方を模索するプロジェクトとして関心を集めている。

どんな人に役立つか

React・Vue・Svelte・Solid・Web Componentsなど複数フレームワークに対応したUIコンポーネントライブラリを開発したいエンジニアに適している。アクセシビリティ対応（ARIA・キーボード操作）を体系的に扱いたい開発者や、AIエージェントにUIを構築・操作させる仕組みを実験したい開発者にも役立つ。

技術的なポイント

  • コアロジックをフレームワーク非依存な@ui-sdk/coreに集約し、各フレームワーク向けアダプター（react/vue/svelte/solid/web）が薄いラッパーを提供する設計
  • definePrimitive APIで状態・API・スロット（present/attrs/on/press/bind）を宣言的に組み合わせてUIプリミティブを定義する
  • createParts でプリミティブを各フレームワークのコンポーネントに変換し、同一定義から複数フレームワーク向けコンポーネントを生成できる
  • skills CLIを通じてAIエージェントにui-sdkスキルを追加し、エージェントがUIを構築できる仕組みを持つ

試し方

  1. コアパッケージと使用するフレームワーク向けアダプターをインストールする
  2. definePrimitive でUIプリミティブ（状態・API・スロット）を定義する
  3. createParts でフレームワーク向けコンポーネントに変換し、JSX/テンプレートで利用する
  4. AIエージェントから使う場合はnpx skills add コマンドでui-sdkスキルを追加する
npm install @ui-sdk/react @ui-sdk/core
npx skills add vercel-labs/ui --skill ui-sdk

zxsos/HGhubX

Trendshift 4位TypeScriptGitHub ↗

Tauri 2・React・Rust製のクロスプラットフォーム短編ドラマ視聴クライアント

何ができるか

  • Windows・macOS・Linux・Android・iOSの5プラットフォームで動作する
  • iOS風の角丸デザインとガラス素材UIを搭載している
  • 縦画面向けの没入型動画再生モードを提供している
  • カバー画像とプレイリストのローカルキャッシュ機能がある
  • HGHUBX_PROXYなどの環境変数でプロキシや動作モードを設定できる
  • 旧バージョン（hghub_*キー）のローカルデータを初回起動時に自動移行する

なぜ注目されているか

GitHubで約2,900スターと2,000フォークを獲得しており、短編動画コンテンツ向けサードパーティクライアントとして広く注目されている。偽の有料フォーク（ライセンスキーやVIP課金機能を追加したもの）が出回るほど需要が高く、本家プロジェクトがその旨をREADMEで明示している。推測 モバイルライクなUIとクロスプラットフォーム対応の組み合わせが人気の要因と考えられる。

どんな人に役立つか

短編ドラマを複数デバイスでまとめて視聴したいユーザーに適している。READMEでは「学習と技術交流のため」と明示されており、Tauri 2やRust + Reactによるクロスプラットフォームアプリ開発を学びたい開発者にも参考になる。商用利用は禁止されており、個人・非営利目的での利用のみが認められている。

技術的なポイント

  • フロントエンドはReact（TypeScript）、バックエンドはRustで実装され、Tauri 2フレームワークで統合されている
  • 単一コードベースからデスクトップ（Windows・macOS・Linux）とモバイル（Android・iOS）の両方のバイナリを生成できる
  • PolyForm Noncommercial License 1.0.0を採用し、個人学習・研究・非営利目的のみ利用を許可している
  • hghubx_*形式のlocalStorageキーを採用し、旧バージョン（hghub_*）からのデータ自動移行機能を内蔵している
  • HGHUBX_PROXY・HGHUBX_STRICTなどの環境変数で制御でき、旧HGHUB_*変数名もフォールバックとして使用可能

試し方

  1. GitHubのReleasesページ（github.com/zxsos/HGhubX/releases）から対応OSのインストーラーをダウンロードする
  2. ダウンロードしたインストーラーを実行してアプリをインストールする

kuafuai/andee

Trendshift 6位KotlinGitHub ↗

スマホやMac上でどんなアプリも操作できるオンデバイスAIエージェント

何ができるか

  • アクセシビリティツリーとグリッドタップ方式で、インストール不要のアプリ統合なしに任意のアプリを操作できる。
  • オンデバイスの暗号化Vaultにパスワードを保存し、値を外部に返さず自動入力できる。
  • 「シーン」と呼ぶ継続タスクモード、通知トリアージ、プライベートノートブック、スケジュール実行をサポートする。
  • フローティングボール UIでキャラクター表情・ペルソナ・音声によるインタラクションを提供する。
  • QRコードでペアリングした別デバイスのAndee同士が互いにタスクを依頼し合える連携機能がある。
  • MacではサンドボックスTerminalも利用でき、オプションでUSBドングル接続のロボット犬も制御できる。

なぜ注目されているか

スマートフォン向けのAIエージェントは多いが、root不要・統合設定不要でAndroid/Mac両対応し、パスワードや記憶情報が端末外に出ない設計を掲げている点が注目される。任意のOpenAI互換モデルを脳として使える汎用性の高さも話題の理由のひとつである。

どんな人に役立つか

AIエージェントをスマートフォンやMacで実際に動かしてみたい開発者・研究者に向いている。自分のAPIキーとモデルを使ってプライバシーを保ちながらエージェントを試したいユーザーや、アクセシビリティサービスを使ったUIオートメーションを学びたい人にも役立つ。

技術的なポイント

  • Androidのアクセシビリティサービスでウィジェットツリーを読み取り、ラベル付きグリッドへのタップとスクリーンショットフォールバックでUI操作を実現している。
  • パスワードはオンデバイスVaultに保持し、外部へ平文を返さない設計でプライバシーを確保している。
  • OpenAI互換APIに対応しており、任意のモデル（クラウド・ローカル問わず）を切り替えて使える。
  • Kotlin製でAndroid（8.1以上、画面機能はAndroid 11以上）とmacOS 14以上（Apple Silicon・Intel両対応）をサポートする。
  • デバッグ用WebSocketサーバー（0.0.0.0:9008）を内蔵するが認証なしのため、信頼できないネットワークでの利用には注意が必要。

試し方

  1. GitHubのReleasesページからAndroid用APKまたはMac用DMGをダウンロードする。
  2. インストール後、アプリ内でOpenAI互換モデルのAPIキーとエンドポイントを設定する。
  3. Androidの場合はアクセシビリティサービスの許可を付与してAndeeを有効にする。
  4. フローティングボールをタップしてタスクを入力し、エージェントに操作を依頼する。
git clone https://github.com/kuafuai/andee.git
./gradlew assembleDebug

edgerunners-2/capri-ai-desktop

Trendshift 10位PythonGitHub ↗

Windows向けサイバーパンク風AIデスクトップエージェント＆音声コンパニオン

何ができるか

  • テキストと音声でAIと会話でき、「Hey Capri」ウェイクワードや80言語の音声認識に対応している
  • Fish Audio・ElevenLabs・OpenAIなど複数のTTSエンジンで音声出力できる
  • アプリ起動・音楽再生・タブを閉じる・クリックなどのデスクトップ操作をAIが自動で行える
  • 過去の会話履歴と画面のコンテキストをローカルに保存してAIが参照できる
  • Discordなどの通話アプリと連携して通話中にAI音声コンパニオンとして使える（Windowsベータ版）
  • スキン・設定・コードモッドを追加できるモッドシステムを備えている

なぜ注目されているか

Claude Code・Codex・DeepSeekなど複数のAIエンジンをGUIで統合し、音声操作やデスクトップ自動化まで一括して扱える点が珍しい。ローカルファーストで動作しOllamaによるオフラインLLMも使えるため、プライバシーを重視するユーザーにも訴求する。サイバーパンクな見た目とモッドによるカスタマイズ性が話題を呼んでいる。

どんな人に役立つか

Windows上でAIアシスタントをGUIから使いたい開発者やガジェット好きに向いている。ターミナルではなくデスクトップ上でClaude CodeやDeepSeekを操作したいユーザーや、Discord通話中にAI音声コンパニオンを活用したいゲーマーにも適している。

技術的なポイント

  • AIエンジンとしてClaude Code・Codex・DeepSeek・Antigravityなど複数のアダプターをサポートしている
  • ローカルモデルはOllamaおよびLLaMA.cppを経由してQwenやLlamaなどを実行できる
  • 音声認識にQwen3-ASRを使用し、TTSにはFish Audio・ElevenLabs・OpenAIを選択できる
  • 設定はYAMLファイルで管理し、スキン・設定モッド・コードモッドの3種類の拡張形式を持つ
  • Windows専用のPortable ZIPとして配布されており、インストール不要で即起動できる

試し方

  1. GitHubのリリースページからCapri-Portable.zipをダウンロードする
  2. 任意のフォルダに解凍して実行ファイルを起動する（Windows 10以降が必要）
  3. 初回起動時にAIエンジンのアカウントにサインインするかAPIキーを貼り付ける
  4. ローカルモデルを使う場合はCapri起動前にOllamaを起動しておく

openfilm/openfilm

Trendshift 11位TypeScriptGitHub ↗

コーディングエージェントをAI動画制作エージェントに変えるオープンソースツール

何ができるか

  • コーディングエージェント（Claude CodeやCodexなど）がHTMLファイルとして動画を生成できる
  • ブラウザベースのエディタStudioで、エージェントが作った動画を手動またはエージェント経由で編集できる
  • MP4・GIF・音声・字幕・透過動画などへのエクスポートや、Final Cut Pro・Premiere Pro・DaVinci Resolve向けタイムライン出力が可能
  • ElevenLabs・OpenAI・Google・fal などの生成AIサービスに自分のAPIキーで接続できる
  • フォント・サウンド・テキスト切れなどの不具合を自動検出する`look`チェック機能を持つ
  • macOS/Windows向けデスクトップアプリも提供され、ffmpegとヘッドレスブラウザが同梱されている

なぜ注目されているか

動画制作をコーディングエージェントに任せるという新しいアプローチで注目されている。標準的なWeb技術（HTML・CSS・JS）をそのまま活用するため、フレームワーク習得不要で既存のWeb開発スキルを活かせる点が特徴的だ。エディタでの編集内容がファイルに保存されエージェントがそれを引き継げる仕組みが、AIと人間の協調編集を実現している。

どんな人に役立つか

AIエージェントに動画制作を任せたいクリエイターや、Web技術を使って動画を生成・編集したいWebデベロッパーに適している。またプロ向けNLEソフトへのタイムライン書き出しに対応しているため、映像制作のワークフローにAIを組み込みたいビデオエディターにも役立つ。

技術的なポイント

  • 動画の各ショットはHTMLページとして実装され、任意の時刻tの映像を返す`frame(t)`関数を定義することで決定的な再現が保証される
  • three.js・WebGL・Canvas・SVG・GSAP・CSSなど任意のブラウザ描画技術が利用可能で、特定フレームワークへの依存がない
  • Node.js 22.2以上とffmpeg、ヘッドレスChromiumを組み合わせて動画レンダリングを行う
  • スキルシステム（edit・media・canvas）によりエージェントの機能を拡張でき、コミュニティスキルも公開されている
  • 動画フォーマット仕様（SPEC）はオープンに公開されており、カスタムプレーヤーやレンダラーの実装が可能

試し方

  1. Node.js 22.2以上とffmpegをインストールする
  2. npxコマンドで直接OpenFilmを起動するか、スキルとしてエージェントに追加する
  3. エージェントにフィルムの生成を依頼するか、既存のGitHub上のサンプルフィルムを開いて確認する
npx -y openfilm@latest
npx -y openfilm@latest open <github-url>
npx skills add openfilm/openfilm
pnpm install
pnpm dev

alibaba/open-code-review

Trendshift 13位GoGitHub ↗

AIエージェントによる高精度・低コストなコードレビューCLIツール

何ができるか

  • Gitのdiff（ステージ済み・未ステージ・ブランチ間・特定コミット）を対象にAIコードレビューを実行できる。
  • ファイル・ディレクトリ・リポジトリ全体をdiffなしでスキャンする全ファイル審査機能（ocr scan）がある。
  • エージェントがファイル全体の読み込みやコードベース検索を行い、コンテキストを踏まえたレビューコメントを生成する。
  • レビューの中断・再開をサポートするセッション管理機能と、ブラウザでコメントを確認・管理できるビューアがある。
  • GitHub Actions・GitLab CI・Gerritなど主要CI/CDプラットフォームへの統合をサポートしている。
