AIエージェント向けのスキル集（ソクラテス式家庭教師など）

何ができるか

  • SKILL.md ファイル形式でエージェントに追加できるスキルを提供する
  • ソクラテス式メソッドで任意のトピックを教える家庭教師スキルが含まれる
  • レベル0〜5のスキルマップと定期的な復習機能で段階的な学習を支援する
  • コーディングエージェントにスキルディレクトリをコピーするだけで使える
  • 通常のチャットボットにも SKILL.md の内容をペーストして利用できる

なぜ注目されているか

推測 Anthropic の Claude Code などがスキル（SKILL.md）形式を採用して以来、AIエージェント向けの再利用可能なスキル集への需要が高まっている。Jane Street という著名な金融テック企業が公開したことで注目を集めていると考えられる。

どんな人に役立つか

Claude Code などの SKILL.md 対応エージェントを使っている開発者や、AIを使って新しい分野を学びたいエンジニアに役立つ。

技術的なポイント

  • SKILL.md という Markdown ファイル1つでエージェントへの指示を定義するシンプルな仕組みを採用している
  • スキルは診断テスト・スキルマップ・スペースド反復（間隔反復法）・最終評価のステップで構成されている
  • エージェントに依存しない設計で、コーディングエージェントとチャットボットの両方で動作する

試し方

jhaizhou-ops/S2Arm

Trendshift 7位C#GitHub ↗

Switchゲームを ARM64 に変換して iPhone/iPad/Mac でネイティブ動作させるツール

何ができるか

  • Switch ゲームのコードを ARM64 にリライトして、エミュレータなしでネイティブ実行できる
  • グラフィックスを Metal に直接送るため、CPU エミュレーションのオーバーヘッドがない
  • Mac と Windows 向けの GUI ランチャーでゲームの追加・ビルドをガイドしてくれる
  • AIアシスタントが手順を実行できる s2armctl インターフェースを搭載している
  • 1つのアプリに全ゲームライブラリをまとめ、開発者アカウントのスロットを1つだけ使う

なぜ注目されているか

SwitchゲームをエミュレータなしでスマートフォンやMacで動作させることは技術的難易度が高く、実現したプロジェクトとして注目されている。211タイトルで95%のビルド成功率を報告しており、実用的な完成度も評価されている。

どんな人に役立つか

自分でゲームとキーを所持していて、iPhone・iPad・Mac でネイティブ性能でプレイしたい開発者・研究者向け。ゲームや鍵は自分で用意する必要がある。

技術的なポイント

  • Switch の AArch64 ゲームコードを再コンパイルして ARM64 ネイティブバイナリを生成する
  • グラフィックス API を Metal に変換することで iOS/macOS の GPU を直接活用する
  • iOS 18+ / macOS 15+ (Apple Silicon) をサポートし、Android・HarmonyOS 対応も計画中
  • 32ビットゲームと36ビットアドレス空間を必要とするゲームは非対応

試し方

  1. iOS 18以上の iPhone/iPad か Apple Silicon Mac を用意する
  2. Mac または Windows の GUI ランチャーをダウンロードして起動する
  3. 自分のゲームファイルとキーを用意してランチャーの手順に従いビルドする
  4. ビルド完了後、アプリをインストールしてゲームを起動する

h4ckf0r0day/obscura

Trendshift 10位RustGitHub ↗

AIエージェントとスクレイピング向けの軽量ヘッドレスブラウザエンジン

何ができるか

  • V8 エンジンで JavaScript を実行し、Chrome DevTools Protocol (CDP) サーバーとして動作する
  • Puppeteer や Playwright がそのまま接続できるため既存の自動化スクリプトを流用できる
  • スクリーンショット撮影・ライブページのスクリーンキャスト・PDF 出力が Chromium なしで動作する
  • ステルスモードでフィンガープリントをランダム化し、数千のトラッカードメインをブロックする
  • MCP サーバーとして起動でき、AI エージェントから直接操作できる

なぜ注目されているか

ヘッドレスブラウザは従来 Chromium ベースが主流だったが、メモリ消費が大きく起動も遅いという課題があった。Obscura は Rust で書かれており、メモリ使用量・バイナリサイズ・起動速度の面で大幅な改善を主張している。AIエージェントからブラウザを操作するユースケースが増えたことも注目理由の一つと考えられる。

どんな人に役立つか

大量のウェブスクレイピングを高速・低コストで行いたい開発者や、AIエージェントにブラウザ操作を組み込みたいエンジニアに向いている。

技術的なポイント

  • Rust で実装され、V8 JavaScript エンジンを組み込んでいる
  • Chrome DevTools Protocol を実装し、既存の Puppeteer/Playwright と互換性がある
  • CDP サーバーまたは MCP サーバーとして起動できる二重モードを持つ
  • オプションのステルスビルドでフィンガープリントランダム化とトラッカーブロックを追加できる

試し方

  1. Linux・macOS・Windows 向けのプリビルドバイナリをリリースページからダウンロードする
  2. または Docker イメージを使って即座に起動する
  3. CLI でページ取得・リンク抽出・並列スクレイプを実行する
  4. Playwright/Puppeteer から CDP エンドポイントに接続して利用する
docker pull obscura/obscura

iOS 27.x 向け MobileGestalt（デバイス設定DB）エディタアプリ

何ができるか

  • ディスプレイ・デバイス・iPad・Apple Intelligence 向けの機能フラグをプリセットで変更できる
  • CacheExtra キーのフィールドエディタで詳細な設定項目を直接編集できる
  • 編集前に自動バックアップを作成し、各プリセット単位での復元が可能
  • ローカルの plist ファイルをインポート・エクスポートして設定を共有できる
  • 英語・日本語・中国語（簡体・繁体）・ベトナム語・ロシア語・ペルシャ語の7言語に対応している

なぜ注目されているか

iOS 27.x で MobileGestalt（デバイスの機能フラグを管理するシステムDB）へのアクセス方法が変わり、対応したエディタへの需要が高まっている。地域コードの変更やデバイスプリセットの適用が GUI でできる点が評価されていると考えられる。

どんな人に役立つか

iOS のセキュリティ研究や自分のデバイスのカスタマイズに興味があるエンジニア・研究者向け。自分のデバイスでのみ使用することが前提で、変更前にデータバックアップが必須。

技術的なポイント

  • SwiftUI で実装され、iOS/iPadOS 27.x をターゲットにしている
  • アプリと共有エクステンション間で App Group を使ってデータを共有する設計になっている
  • デバイス固有の識別子と照合して plist の整合性を検証するセキュリティチェックを備えている
  • GPLv3 ライセンスで公開されており、Nugget・GestaltEdit などのプロジェクトをベースにしている

試し方

  1. リポジトリをクローンして Xcode で開く
  2. アプリと共有エクステンションの間で App Group を設定してサイニングを構成する
  3. デバイスまたはシミュレータにビルドしてインストールする
  4. アプリを起動してプリセットを選択するか、フィールドエディタで直接変更する

shinyobjectz/raea

Trendshift 14位RustGitHub ↗

React/TypeScript で書いた動画・3D・ゲームを自分の GPU でレンダリングするエンジン

何ができるか

  • React コンポーネントで映像・モーショングラフィックス・3Dシーンを記述してレンダリングできる
  • raea render コマンドで動画ファイルを出力し、raea play でリアルタイムプレビューができる
  • ゲームとして入力・物理演算・サウンドを追加してスタンドアロンアプリとしてエクスポートできる
  • ローカルモデルを使ったサウンドミキサーでフォーリーや楽器音を生成できる
  • エージェントが検証・レンダリング・品質チェックを人手を介さずに実行できるワークフローを持つ

なぜ注目されているか

AIが生成したコードで動画やゲームを作るワークフローが注目されており、raea はそのパイプラインの実行エンジンとして位置づけられている。Rust + Bevy ベースで自分の GPU を使うため外部サービス不要でプライバシーも守られる点が評価されていると考えられる。

どんな人に役立つか

AIエージェントに動画・ゲームの制作を任せたい開発者や、React の知識を活かして映像・3D コンテンツを作りたいエンジニアに向いている。現時点ではカナリーリリースのため実験的な用途向け。

技術的なポイント

  • Rust と Bevy 0.20 ゲームエンジンをベースに構築されている
  • React と TypeScript でコンポジション（シーン定義）を記述し、GPU でレンダリングする仕組みを持つ
  • raea-skills リポジトリと Claude Code プラグインでエージェント連携が可能
  • RAEA_OFFLINE=1 環境変数でテレメトリや通信を完全にブロックできるプライバシー設計
  • FSL-1.1-ALv2 ライセンスで、リリースから2年後に Apache-2.0 に移行する条件付き

試し方

  1. macOS (Apple Silicon) または Linux (x86_64) でインストールスクリプトを実行する
  2. Windows の場合は PowerShell スクリプトを実行する
  3. raea init でプロジェクトを初期化する
  4. React コンポーネントでシーンを記述し raea render で動画を出力する
curl -fsSL https://raea.dev/install.sh | sh
raea init my-project
raea render
raea play

jammaru/sakutto

はてなブックマーク 1位3 usersGitHub ↗

ローカル LLM（PLaMo）でオンデバイス翻訳するブラウザ拡張機能

何ができるか

  • PLaMo 3 Translate モデルをデバイス上で動かしてページ全体を翻訳できる
  • Alt+A でページ翻訳・Alt+B で原文との対訳表示・Alt+S で選択テキスト翻訳ができる
  • 入力フィールドにテキストを打ちながらリアルタイムで翻訳プレビューを確認できる
  • Chrome では PLaMo が対応しない言語ペアをブラウザ組み込みの翻訳 API で補完する
  • Chrome Web Store からインストールでき、Firefox は手動インストールに対応している

なぜ注目されているか

オンデバイス翻訳は外部サーバーに文章を送らずプライバシーを保てる点が評価されており、PLaMo 3 Translate という高品質な日本語対応モデルの登場がこの拡張機能への注目を高めていると考えられる。無料・無広告・テレメトリなしというシンプルな設計も支持される理由の一つ。

どんな人に役立つか

翻訳にプライバシーを重視するユーザーや、外部 API に依存せず無料で多言語翻訳を使いたい人に向いている。日本語を含む53言語に対応している。

技術的なポイント

  • wllama（WebAssembly ベースの LLAMA 推論ライブラリ）でブラウザ内モデル実行を実現している
  • PLaMo 3 Translate モデルをオンデバイスで動かし、翻訳リクエストを外部サーバーに送らない
  • Chrome の built-in Translator API と組み合わせて53言語以外もカバーする設計になっている
  • モデルのダウンロードは Hugging Face からのみ行われ、それ以外のネットワークアクセスは発生しない
  • MIT ライセンスだが、PLaMo モデルの重みは別ライセンスで商用利用に制限がある

試し方

  1. Chrome Web Store から「さくっと翻訳」を検索してインストールする
  2. Firefox は Node.js 24 と pnpm 12 でビルドして手動インストールする
  3. 初回起動時にモデル（約500MB）が Hugging Face からダウンロードされる
  4. 翻訳したいページで Alt+A（Mac は Option+A）を押す

pnpm build
