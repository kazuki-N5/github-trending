GoogleChrome/modern-web-guidance

Trendshift 3位GitHub ↗

コーディングエージェントに最新ウェブのベストプラクティスとブラウザ互換性情報を提供するスキル集

何ができるか

  • 約250のモダンウェブ機能（主にCSS・レイアウト、HTML/DOM、JavaScript/API）のガイドを提供する
  • `search`コマンドでキーワードに関連するガイドを検索できる
  • `retrieve`コマンドでガイドをIDで取得してエージェントのコンテキストに読み込める
  • `legacy-scan`コマンドでコードベース内のレガシーパターンをスキャンし近代化の提案を行える
  • `.mwgrc`設定ファイルでOrigin TrialやVolatile機能へのアクセスをオプトインできる

なぜ注目されているか

Chrome・Edge・Firefox・MDNチームが共同で管理しており、信頼性の高いウェブプラットフォームの知識源となっている。推測 AIコーディングツールの普及に伴い、エージェントが古い訓練データに基づいてレガシーなAPIを使ったコードを生成してしまう問題への対策として注目されている。

どんな人に役立つか

GitHub CopilotやCursorなどのコーディングエージェントを使ってウェブ開発を行う開発者に役立つ。ネイティブのモダンCSS・HTML・JavaScript APIを活用し、重いpolyfillやレガシーなパターンを避けたいウェブ開発者全般に適している。

技術的なポイント

  • オフラインの埋め込みモデルとBM25を組み合わせたハイブリッド検索を使用し、ネットワーク不要で動作する
  • エージェントスキルとして動作し、一致したガイドをエージェントのコンテキストウィンドウに取り込むアーキテクチャを採用している
  • トークン効率を考慮した設計で、AIモデルが既知のコンテンツを省いた簡潔なガイドを提供する
  • Baselineに基づくブラウザ互換性情報を含み、各機能の対応状況を把握できる

試し方

  1. インタラクティブウィザードを使ってインストールする: `npx modern-web-guidance@latest install`を実行する
  2. インストールなしで試す場合は、`search`・`retrieve`・`legacy-scan`コマンドをエージェント経由で使用する
npx modern-web-guidance@latest install
npx skills add GoogleChrome/modern-web-guidance
gh skill install GoogleChrome/modern-web-guidance

HybridRobotics/supermimic

Trendshift 8位PythonGitHub ↗

一つの微分可能ワールドモデルで学習する人型ロボット全身モーショントラッカー

何ができるか

  • 人型ロボットの全身モーション追跡をワールドモデルベースで学習できる
  • 一般化座標（GenCoord）と最大座標（MaxCoord）の2種類のタスクモードに対応している
  • MuJoCo向けライブラリmjlab上に構築されており、物理シミュレーション環境で動作する
  • WandBと連携してトレーニング済みモデルの動作を再生・確認できる
  • CUDA_VISIBLE_DEVICESでGPUを指定してトレーニングを実行できる

なぜ注目されているか

推測 人型ロボットの全身モーション制御は強化学習・ロボティクス分野で重要な課題であり、微分可能ワールドモデルを用いたアプローチは近年注目を集めている。推測 SuperTrackの実装として、差分可能物理シミュレーションを活用した手法が研究コミュニティで関心を集めている。

どんな人に役立つか

ロボティクスや強化学習を研究する学生・研究者に役立つ。人型ロボットの全身モーション制御や模倣学習を実装・実験したい人向け。

技術的なポイント

  • mjlabライブラリ上に構築された微分可能ワールドモデルを使用している
  • 一般化座標（GenCoord）と最大座標（MaxCoord）の2種類の座標系をサポートしている
  • ControlVAE、robotic_world_model、DreamerV3のコードを参考にして開発されている

試し方

  1. uvをインストールする
  2. supermimicとmjlab_researchリポジトリを同じ親ディレクトリ配下にクローンする
  3. タスクIDとrun名を指定してtrain.pyを実行する
  4. 学習済みモデルはplay.pyにwandbパスを指定して再生できる
CUDA_VISIBLE_DEVICES=0 python src/supermimic/scripts/train.py --task SuperMimic-GenCoord-G1 --run_name <run_name>
python src/supermimic/scripts/play.py --task SuperMimic-GenCoord-G1 --wandb-path <wandb_path>

wzdnzd/aggregator

Trendshift 13位PythonGitHub ↗

複数ソースからプロキシを収集・検証・変換する無料プロキシプール構築ツール

何ができるか

  • Telegram・GitHub・Google・Yandexなど複数のプラットフォームからプロキシリソースをクロールする
  • 収集したプロキシの死活監視と品質チェックを自動で行う
  • Clash・V2Ray・SingBoxなど各種クライアント向けのフォーマットに変換する
  • GitHub Gist・PasteGG・Imperialなど複数のストレージバックエンドに結果を保存する
  • マルチスレッド・並列処理により高速なバッチ処理を実現する
  • カスタムクローラープラグインを追加できる拡張可能なプラグインアーキテクチャを持つ

なぜ注目されているか

推測 VMess・Trojan・SS・SSR・VLESS・Hysteria2など多様なプロキシプロトコルを一括で扱える点が注目されている。推測 設定ファイルベースの柔軟な運用と、GitHub Gistへの自動アップロード機能により、個人でのプロキシ管理を省力化できる点が評価されていると考えられる。

どんな人に役立つか

プロキシリソースを自動収集・管理したい開発者や、Clash・V2Rayなどのクライアントで使える購読リンクを自前で構築したい人に役立つ。クローリング技術の学習目的にも活用できる（プロジェクト自身も学習目的と明記している）。

技術的なポイント

  • Python製のprocess.pyとcollect.pyという2つのエントリーポイントスクリプトで動作する
  • Subconverterを購読変換のコアエンジンとして使用し、Mihomoでプロキシのテストを行う
  • GitHub Gist・PasteGG・Imperialなど複数のストレージバックエンドをサポートするプラグイン構造を持つ
  • マルチスレッドによる並列クロールを採用しており、スレッド数（-nオプション）で性能を調整できる
  • JSONベースの設定ファイルでサイト・クロール・グループ・ストレージを細かく定義できる

試し方

  1. リポジトリをクローンする
  2. サンプル設定ファイルをコピーして自分用の設定ファイルを作成する
  3. GitHubトークンを環境変数PUSH_TOKENにセットする
  4. process.pyを実行してプロキシの収集・変換・保存を行う
cp subscribe/examples/config.default.json my-config.json
export PUSH_TOKEN=your_github_token
python subscribe/process.py -s my-config.json
python subscribe/collect.py -g username/gist-id -k your-github-token -t clash v2ray singbox

      GPU内部のプロセス・VRAMをリアルタイム監視する、htop風ターミナルモニター

      何ができるか

      • デバイスビューでVRAM・GPU負荷・温度・電力・クロック・PCIe帯域などをリアルタイム表示できる
      • プロセスビューでプロセスごとのGPUメモリ使用量とエンジンアクティビティを個別に確認できる
      • CUDA・HIP・Vulkan・ggml・ONNX Runtimeなど実行中のAI/MLランタイムを自動検出する
      • ロードされているLLMモデルとKVキャッシュ・重みなどのGPUメモリ内訳を推定表示する
      • JSON形式でスナップショット保存・2つのスナップショットの差分比較・セッション記録ができる

      なぜ注目されているか

      推測 ローカル環境でLLMを動かす開発者が増えており、GPUメモリの内訳をプロセス単位で可視化できるツールの需要が高まっている。推測 WindowsのAMD・NVIDIAとLinux・WSLを横断してサポートし、KVキャッシュなどLLM特有の情報まで表示できる点が珍しく注目を集めていると考えられる。

      どんな人に役立つか

      ローカル環境でLLMや機械学習ワークロードを実行し、VRAMの使用状況をプロセス単位で把握したい開発者や研究者に役立つ。Windows（NVIDIA・AMD）・Linux・WSL環境のユーザーが主な対象で、モデルのメモリ消費を詳しく調べたい場合にも使える。

      技術的なポイント

      • PythonパッケージとしてPyPI経由（uvまたはpipx）でインストール可能で、Python 3.11以上が必要
      • WindowsではWDDMカウンター・NVML・AMD ADL/SMIを組み合わせてGPU情報を取得する
      • LinuxではNVML・sysfs・DRM fdinfo経由でNVIDIA・AMD（amdgpu）・Intel（i915）に対応する
      • WSL環境ではWindowsホストのカウンター情報をインターオップ経由で読み取りLinuxプロセスと対応付ける

      2. uv tool install gputaskman を実行してインストールする
      3. gputaskman または gtm を実行してターミナルモニターを起動する
