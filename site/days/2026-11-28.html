trustno1-coder/VIctory-NVIDIA

Trendshift 1位RustGitHub ↗

Xbox Series互換レイヤー「VIctory」のNVIDIA GPU対応フォーク

何ができるか

  • Xbox Series X/Sダンプを自分のNVIDIA GeForce RTX搭載PCで動作させられる
  • RTX 40/50ではDLSSフレーム生成、RTX 20/30ではAMD FSR 3フレーム生成に対応する
  • F1キーでDLSS・フレームレートキャップなどの設定メニューを開ける
  • Windows 10向けにMicrosoftの新しいDirect3D 12ランタイム（D3D12 Agility SDK）を自動取得できる
  • FSR 3に必要なAMDのFidelityFX DLLをAMD公式GitHubから自動ダウンロードして検証できる

なぜ注目されているか

推測 GTA VIのXbox Series版をPCで動かしたいという需要が高く、NVIDIA GPU向けの最適化フォークとして注目を集めている。VIctory-7900XTXのフォークとして、NVIDIA特有のDLSSフレーム生成やディスクリプタヒープの問題を修正している。

どんな人に役立つか

Xbox Series版ゲームの合法的なダンプを所持するNVIDIA RTX系GPUユーザー向け。ゲームファイルは含まれず、自分でダンプを用意する必要がある。

技術的なポイント

  • Rustで実装された互換レイヤーで、Xbox Series（RDNA2）のGPUコードをNVIDIA向けにリアルタイム変換する
  • DLSSフレーム生成（RTX 40/50）とAMD FSR 3フレーム生成（RTX 20/30）を切り替えて使用できる
  • Windows 10のDirect3D 12がシェーダーモデル6.6未対応のため、D3D12 Agility SDKを自動取得する仕組みを備える
  • 各ファイルはSHA-256ハッシュと署名で検証されるため、改ざんされたDLLが混入しない

試し方

  1. 最新リリースから victory.exe をダウンロードする
  2. Xbox Series版タイトルの合法的なダンプのフォルダ（game_scarlett_master.exeと同じ場所）にvictory.exeを置く
  3. victory.exeをダブルクリックして実行する（初回起動時にNVIDIAのDLSSファイル取得を求められる）

Reukix/Reloc

Trendshift 5位SwiftGitHub ↗

iPhoneでPC不要・外付けなしの外設レベル位置偽装アプリ

何ができるか

  • ローカルの仮想外設接続（iAP2 / MFi-v3）を通じて、PCや実機外付けデバイスなしでGPS位置を偽装できる
  • 地図クリック・住所検索・WGS-84座標の手動入力でターゲット位置を設定できる
  • Apple マップのほかOpenStreetMapやEsriの衛星地図も選べ、中国向けGCJ-02座標の自動変換も行う
  • バックグラウンドでも位置偽装が継続するよう、音声保活と定位保活の二重保険を備える
  • NMEA-0183（$GPGGA/$GPRMC）パケットをストリーミング送信し、CoreLocationに外設GPSとして認識させる

なぜ注目されているか

推測 PCへの接続や脱獄なしにiPhoneで位置偽装できる点が珍しく、蜂窝网络（モバイルデータ）環境でも動作するため注目されている。外設レベルの注入はソフトウェアシミュレーションフラグを回避できる点も差別化になっている。

どんな人に役立つか

位置情報を使うゲームやアプリのテスト・デモを行いたいiOS開発者や、外設レベルの位置注入を試したい研究者向け。有効なMFi-v3認証情報が別途必要。

技術的なポイント

  • SwiftとObjective-Cで実装し、CoreAccessoriesフレームワークで本機上に仮想iAP2エンドポイントを生成する
  • NMEA-0183フォーマットのGPGGAとGPRMCパケットをシステムの外設GPSチャネルに送出する
  • XcodeGenを使ってプロジェクトを生成し、MFi-v3認証用のcertificate.p7bとidentity.pk8を事前に配置する必要がある
  • CoreLocationの実測パネルでisProducedByAccessoryフラグを確認でき、外設認識の成否を即座に検証できる

試し方

  1. 有効なMFi-v3認証情報（certificate.p7bとidentity.pk8）をReloc/Resources/MFi/に配置する
  2. brew install xcodegen でXcodeGenをインストールし、xcodegen generate でプロジェクトを生成する
  3. Xcodeで署名設定をして実機のiPhone/iPadにインストールする
  4. アプリを開き「定位」ページで目的地を選んで「開始定位」をタップする
xcodegen generate
xcodebuild build -project Reloc.xcodeproj -scheme Reloc -configuration Release -sdk iphoneos -derivedDataPath build/DerivedData CODE_SIGNING_ALLOWED=NO

Xbox Series版タイトルをWindowsで動かすBYOC互換レイヤー

何ができるか

  • 自分のXbox Series X/Sダンプを持ち込んでWindowsで動作させられる（エミュレーターではなくx64コードをCPUで直接実行）
  • RDNA2のGPUコードを手持ちのグラフィックカード向けにオンザフライで変換する
  • ランチャーがシェーダーの事前準備・ゲームフォルダの検索・初回セットアップをGUIで案内する
  • マウス・キーボードのPC操作レイアウトおよびDualSense/DualShock 4コントローラーの直接入力に対応する
  • RX 9000（RDNA 4）やRX 6000（RDNA 2）など複数のAMD GPUで動作する修正が継続的に取り込まれている

なぜ注目されているか

推測 GTA VIのXbox Series版をPCで動かすことへの関心が高く、Wine/Protonと同様のアプローチで実現しようとするプロジェクトとして注目されている。v0.5.xで世界に到達できるようになり、コミュニティからの改善PRが活発に取り込まれている。

どんな人に役立つか

Xbox Series版ゲームの合法的なダンプを所持しているWindowsユーザー向け。ゲームファイルは付属せず、32GB以上のRAMとSSD、対応するGPUが必要。

技術的なポイント

  • RustでXbox Series（RDNA2）向けGPUシェーダーコードをホストのGPU向けにリアルタイム変換するトランスレーターを実装している
  • シェーダーキャッシュの事前ビルド（scarlett prepare）でゲーム起動を高速化し、初回実行時の待ち時間を削減する
  • ランチャーv0.5.xはシェーダー進捗のリアルタイム表示、自動アップデート、クラッシュ報告のプリフィル機能を備える
  • コンソールシェーダーのスレッドレーンをホスト側の複数ウェーブに分散する最適化が最新版で導入されている

試し方

  1. 最新リリースのscarlett-setup.exeをダウンロードしてインストールする
  2. ランチャーを起動し、初回セットアップでゲームフォルダを指定してシェーダーを準備する
  3. 準備が完了したらランチャーからゲームを起動する

DeadInternetStudios/100x-engineer-skill

Trendshift 11位JavaScriptGitHub ↗

形式検証付きでプロダクション品質コードを生成するClaude Codeスキル

何ができるか

  • タスクを小さなブロックに分割し、各ブロックを形式検証（状態・遷移・事前・事後条件・不変条件・活性条件）してから組み合わせる
  • コードが変更されたときに検証結果が古くなったことを検出するledger.tsvをリポジトリで管理する
  • 二次AIモデルがコードレビューを行い、スクリーンショットとテスト結果を含む報告書を生成する
  • Claude Code・Cursor・Codexで動作し、Node.js 22以上を必要とする
  • バグを植え込んで検証が実際に失敗することを確認してから合格とみなす仕組みで信頼性を担保する

なぜ注目されているか

推測 AIコーディングエージェントが「ほぼ動く」コードを生成するが最後の10%が完成しない問題を解決しようとしており、30日間で136Bトークン・1,000件超のPRという実績データが注目を集めている。形式検証（formal verification）をLLM時代に再定義した点も新しい。

どんな人に役立つか

Claude CodeやCursorなどのAIコーディングエージェントを業務で使い、プロダクション品質のコードを生成したいエンジニア向け。ロールバック率を下げたいチームにも有効。

技術的なポイント

  • 各機能ブロックの状態遷移モデルを構築し、全状態を網羅的に探索するモデル検査アプローチを採用している
  • verify/ledger.tsvでカバーするコードのハッシュを管理し、変更検知と検証の再実行を自動化している
  • 形式検証の範囲外（UIやコピー）はwaiverを記録し、100x finishがその根拠と対象コードを明示する
  • ブロック間のシームも独立検証して、一方が出力するデータが次のブロックの入力条件を満たすことを保証する

試し方

  1. Node.js 22以上をインストールする
  2. Claude CodeまたはCursorに100x-engineer-skillをインストールする
  3. /100x-setup コマンドを実行してセットアップを完了する
  4. 機能追加や新規アプリ作成のタスクを渡す

Electron不使用・約130MBで動くYouTube Musicネイティブデスクトップアプリ

何ができるか

  • Chromeで同一曲を再生したときに比べてメモリ使用量を約130MBに抑えられる（Chromeは約496MB）
  • 30種類のテーマ（Apple Music・Material 3・Spinning Recordなど）をアプリ全体に適用できる

  • Spotifyからプレイリストと「いいね！」した曲をYouTube Musicへバックグラウンド移行できる

なぜ注目されているか

推測 Electronベースの重量級デスクトップアプリへの不満が高まる中、RustとeguiによるネイティブGUIが省メモリで高性能な代替として注目されている。カラオケ歌詞やテーマ数の豊富さも支持される要因になっている。

どんな人に役立つか

YouTube Musicを普段使いするWindowsやmacOS・Linuxユーザーで、ブラウザやElectronベースアプリよりも軽量なクライアントを求めるエンジニアや音楽リスナー向け。
