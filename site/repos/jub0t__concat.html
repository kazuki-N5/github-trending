jub0t/Concat

Rust 初掲載 2026-11-27（Trendshift 1位） GitHub ↗

完全無料・ローカル動作のオープンソース動画編集ソフト

何ができるか

  • オフラインで動作するAIによる自動字幕生成・音声分離・テキスト読み上げ・ボイスクローニング・背景除去に対応している
  • マルチトラック・マルチタイムライン編集、タイトル、図形、ボイスオーバー録音機能を備えている
  • スピードランプ、フリーズフレーム、逆再生、手ぶれ補正など多彩な映像加工ができる
  • 100種類以上のエフェクト・トランジション、キーフレーム、カーブエディタを搭載している
  • H.264・HEVC・AV1で最大4K 60fps・10ビットカラーでエクスポートできる
  • 組み込みのMCPサーバーとJSON-RPC APIによりスクリプトやAIエージェントから操作できる

なぜ注目されているか

動画編集ソフトには有料サブスクリプションやクラウド依存のものが多い中、このツールはアカウント不要・ウォーターマークなしで完全ローカル動作する点が注目を集めている。さらにMCPサーバーを内蔵しAIエージェントと連携できる点は、自動化ニーズの高まりと合致している。

どんな人に役立つか

コストをかけずに高機能な動画編集を行いたい個人クリエイターや開発者に向いている。またスクリプトやAIエージェントから動画編集を自動化したいエンジニアにも適している。

技術的なポイント

  • RustとFFmpeg 7+を使って構築されており、macOS・Windows・Linux・Android・iOSのクロスプラットフォームに対応している
  • AIモデル（字幕・音声・背景除去）は初回ダウンロード後はオフラインで動作する
  • JSON-RPC APIとMCPサーバーを内蔵しており、外部プログラムやAIエージェントからエディタを制御できる
  • ライセンスはAGPL-3.0-or-laterで、商用クローズドソース利用には別途商用ライセンスが必要

試し方

  1. GitHubリリースページまたは公式サイトからバイナリをダウンロードする
  2. Windowsの場合はSmartScreen警告を、macOSの場合は隔離（quarantine）を回避する手順をREADMEで確認する
  3. ソースからビルドする場合はRust 1.93+・FFmpeg 7+開発ライブラリ・cmake・C++コンパイラを用意する
