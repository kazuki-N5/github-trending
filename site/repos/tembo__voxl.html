tembo/voxl

Rust 初掲載 2026-11-05（Trendshift 20位） GitHub ↗

X11・Mac・Windows画面をブラウザへH.264でリアルタイム配信するリモートデスクトップツール

何ができるか

  • デスクトップ画面をH.264動画としてWebSocket1本でブラウザへ低遅延ストリーミングする
  • キーボード・マウス・クリップボード・デスクトップ音声・マイク入力をブラウザ側から操作できる
  • ファイルやフォルダをブラウザとホスト間で双方向転送できる
  • 視聴者のブラウザウィンドウサイズに合わせて配信解像度を動的に変更する
  • パスワード認証・接続元ホスト制限・読み取り専用モードでアクセス制御を設定できる
  • スクリーンショット取得・MP4録画・画面変化検知（/wait API）などAIエージェント向けのエンドポイントを備える

なぜ注目されているか

推測 WebRTC・TURN・UDPポートを一切使わずWebSocket1本とCPUエンコードのH.264だけで動作するシンプルな設計が注目を集めている。KasmVNC・noVNC・Nekoなど競合ツールとの60FPSベンチマーク比較で優位な性能を示しており、実用性が裏付けられている。AIエージェントからデスクトップを制御するユースケースを明示的に想定している点も現在のAIブームと合致している。

どんな人に役立つか

DockerコンテナやVMのデスクトップをブラウザから手軽に操作・公開したい開発者やインフラ担当者に役立つ。AIエージェントにデスクトップGUIを操作させたい機械学習エンジニアにも適している。

技術的なポイント

  • エンコードはCPUベースのx264（H.264エンコーダー）で行い、WebRTC・TURN・UDPポートを使わずWebSocket1本で映像を転送する
  • 画面キャプチャはX11ではXDamage、macOSではScreenCaptureKit、WindowsではDXGI Desktop DuplicationとプラットフォームごとにネイティブAPIを使用する
  • ブラウザ側の映像デコードはWebCodecs API（Chromium 94+・Firefox 130+・Safari 16.4+対応）を利用し、プラグイン不要で再生する
  • x264がGPL-2.0ライセンスのため、ソースコード自体はMITだが配布バイナリにはGPLが適用される

試し方

  1. Cargo（Rustのパッケージマネージャー）でvoxl-serverをインストールする
  2. 環境変数DISPLAYを設定してvoxlをポート指定で起動する
  3. 起動時に表示されたURLをブラウザで開いてサインインする
cargo install voxl-server
DISPLAY=:1 voxl --port=6901
