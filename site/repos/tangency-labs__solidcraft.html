tangency-labs/solidcraft

Rust 初掲載 2026-10-26（Star History 19位） GitHub ↗

RustベースのオープンソースパラメトリックCADアプリ

何ができるか

  • スケッチに拘束を付けて2Dプロファイルを作成できる
  • 押し出し・回転・スイープ・ロフト・フィレットなど豊富なソリッド操作を実行できる
  • フィーチャータイムラインを編集して寸法を変更するとモデルが再構築される
  • デスクトップアプリ・ブラウザ・ヘッドレスCLI・MCPサーバーの4つのモードで動作する
  • STEP・STL・3MF・glTFなど多様なファイル形式のインポートとエクスポートに対応している
  • パラメータ・アセンブリ・板金機能も搭載している

なぜ注目されているか

オープンソースのパラメトリック3D CADアプリケーションとしてRustで実装されており、高速動作と安全性が期待できる。MCPサーバーとして起動することでAIエージェントからCAD操作を自動化できる点は他のCADソフトにはない独自の機能である。76件の公開参照パーツのうち75件が期待値と一致しており、実用的な精度を確認済みとREADMEに記載されている。

どんな人に役立つか

無償でパラメトリックCADを使いたいエンジニアや設計者に向いている。AIエージェントによるCAD操作の自動化を研究・実装したい開発者にも有用である。

技術的なポイント

  • Rustで実装されており、cargo runでデスクトップアプリを起動できる
  • solidcraft-cli mcpコマンドでMCPサーバーを起動し、AIエージェントから操作できる
  • 操作はUIと共通のJSONコマンドリスト形式のスクリプトで記述できる
  • STEP・STL・3MF・glTFなど複数の3Dファイル形式に対応している
  • MITまたはApache-2.0のデュアルライセンスで提供されている

試し方

  1. リポジトリをクローンする
  2. cargo runコマンドでデスクトップアプリをサンプルパーツ付きで起動する
  3. MCPサーバーを使う場合はsolidcraft-cli mcpコマンドを実行する
cargo run
solidcraft-cli mcp
