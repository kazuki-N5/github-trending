プロキシ・トンネル・VPNの仕組みとGFW（中国のネット検閲システム）の回避手法を解説した中国語のオープン教科書

何ができるか

  • プロキシ・トンネル・VPNの動作原理を詳細に解説している
  • GFWの主要な検閲手法（IPアドレス・ポートブロック、DNSキャッシュポイズニング、SSL遮断など）の仕組みを説明している
  • docsifyを使ってGitHub Pages上でウェブブック形式で公開・閲覧できる
  • フォーク後にGitHub Pagesでデプロイする手順や、Node.jsでローカル実行する方法を記載している
  • git経由でのプロキシ設定やmacOSターミナルのプロキシ設定方法も収録している
  • 証明書エラーの対処法（サードパーティDNSへの切り替えなど）も含む実践的なトラブルシュート手順を提供している

なぜ注目されているか

推測 GFWの回避手法を原理から体系的に解説した中国語の教材は少なく、技術的背景を理解したい海外在住の中国語話者や研究者から注目されていると考えられる。プロキシやVPNの表面的な使い方だけでなく、検閲システムの仕組みまで踏み込んでいる点が支持されていると推測される。

どんな人に役立つか

ネットワークやセキュリティの仕組みに興味がある中国語話者の学習者や研究者に向いている。特にGFWの技術的なメカニズムをゼロから理解したい人や、プロキシ・VPNの設定を自分で行いたい海外在住の中国語圏ユーザーに役立つ。

技術的なポイント

  • docsify（JavaScriptベースの静的サイトジェネレーター）を使ってMarkdownファイルをウェブブックとして配信している
  • GitHub Pagesを用いたホスティングで、フォークするだけで自分用のミラーを公開できる構成になっている
  • DNSキャッシュポイズニングやSSL遮断といったGFWの具体的な攻撃手法を技術原理レベルで記述している
  • Shellスクリプトを使ったプロキシ設定や環境構築の自動化手順を含む

試し方

  1. リポジトリをGitHubでフォークする
  2. フォーク先のリポジトリ設定でGitHub Pagesを有効にする
  3. またはNode.jsとdocsify-cliをインストールしてローカルで実行する
npm i docsify-cli -g
docsify serve docs
git remote add upstream https://github.com/hoochanlon/fq-book.git
git fetch upstream
git merge upstream/master
