affaan-m/ECC

JavaScript 初掲載 2026-10-19（Star History 13位） GitHub ↗

AIコーディングエージェントに計画・検証・記憶の仕組みを丸ごと入れる強化キット

何ができるか

  • 計画、テスト、実装、レビュー、検証、記憶、改善という開発の流れを、エージェントの標準の動き方として組み込めます。
  • 計画・レビュー・ビルド修復・セキュリティなどに特化した71のエージェントと、TDDや調査、ドキュメント作成などの311のスキルを利用できます。
  • フック（エージェントの特定のタイミングで自動実行される処理）とメモリにより、セッションの要約や継続的な学習を行えます。
  • AgentShield により、プロンプト、フック、MCP 設定、権限、秘密情報、エージェント用ファイルをスキャンできます。
  • Claude Code、Codex、Qoder にはネイティブのプラグインとして、Cursor、OpenCode、Gemini、Zed などには機能を絞ったアダプタとして導入できます。
  • 対話式のセットアップウィザードで、インストール先のスコープやフックの設定を選んで導入・更新できます。

なぜ注目されているか

リポジトリページでは28万を超えるスターを集めており、README ではメンテナー1人が7種類のハーネスに向けて毎週リリースしていると述べています。推測 毎回プロンプトで手順を指示しなくても、エージェントに一貫した開発プロセスを持たせられる点が、AIコーディングツールの利用者に支持されていると考えられます。

どんな人に役立つか

Claude Code や Codex などのAIコーディングエージェントを日常的に使い、計画やテスト、レビューを含む決まった進め方をエージェントに守らせたい開発者に向いています。

技術的なポイント

  • Claude Code ではプラグイン ecc@ecc として配布され、npm パッケージ ecc-universal（Node.js 18 以上が必要）から対話式セットアップを実行できます。
  • install.sh / install.ps1 の minimal・core・full といったプロファイルで、入れる部品（ルール、エージェント、フックなど）を選べます。
  • ルールは言語やフレームワークごとのパックに分かれており、常に読み込ませる規約を必要な分だけ追加します。
  • 複数の導入方法を同じハーネスに重ねると、スキルやフックが重複するため、ハーネスごとに1つの方法を選ぶ設計になっています。

試し方

  1. Node.js 18 以上、Git、Claude Code をインストールします。
  2. ターミナル（Windows なら PowerShell）でガイド付きセットアップを実行します。
  3. 個人利用なら Global user と Standard フックを選んで確定します。
  4. 新しい Claude Code セッションで /plugin list を実行し、ecc@ecc が有効になっていることを確認します。
npx ecc-universal@2.2.3 setup
/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
