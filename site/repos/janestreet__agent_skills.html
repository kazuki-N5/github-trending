AIエージェント向けのスキル集（ソクラテス式家庭教師など）

何ができるか

  • SKILL.md ファイル形式でエージェントに追加できるスキルを提供する
  • ソクラテス式メソッドで任意のトピックを教える家庭教師スキルが含まれる
  • レベル0〜5のスキルマップと定期的な復習機能で段階的な学習を支援する
  • コーディングエージェントにスキルディレクトリをコピーするだけで使える
  • 通常のチャットボットにも SKILL.md の内容をペーストして利用できる

なぜ注目されているか

推測 Anthropic の Claude Code などがスキル（SKILL.md）形式を採用して以来、AIエージェント向けの再利用可能なスキル集への需要が高まっている。Jane Street という著名な金融テック企業が公開したことで注目を集めていると考えられる。

どんな人に役立つか

Claude Code などの SKILL.md 対応エージェントを使っている開発者や、AIを使って新しい分野を学びたいエンジニアに役立つ。

技術的なポイント

  • SKILL.md という Markdown ファイル1つでエージェントへの指示を定義するシンプルな仕組みを採用している
  • スキルは診断テスト・スキルマップ・スペースド反復（間隔反復法）・最終評価のステップで構成されている
  • エージェントに依存しない設計で、コーディングエージェントとチャットボットの両方で動作する

試し方

  1. リポジトリをクローンまたはスキルディレクトリをダウンロードする
  2. SKILL.md 対応エージェントのスキルフォルダにディレクトリをコピーする
  3. エージェントに「teach me X（Xを教えて）」と依頼する
