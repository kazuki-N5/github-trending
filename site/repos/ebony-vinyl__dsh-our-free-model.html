Ebony-Vinyl/dsh-our-free-model

JavaScript 初掲載 2026-10-23（Trendshift 9位） GitHub ↗

登録・APIキー不要でDeepSeek V4.1 FlashなどのAIモデルを無料利用できるDSHプラグイン

何ができるか

  • DeepSeek V4.1 Flash・Kimi K3など最新フロンティアモデルをログインやAPIキーなしで無制限に利用できる。
  • モデル一覧は上流ゲートウェイから毎回動的取得し、利用不可のモデルは選択肢から自動除外される。
  • 思考強度をモデルごとに設定でき（Off/Low/High/Maxなど）、上流APIに実際の値を送信する。
  • OpenAI互換のローカル転送ポートを提供し、他ツールからもこれらのモデルを呼び出せる。
  • アプリ内一括アップグレード機能を備え、SHA-256検証・バックアップ・アトミック置換・ホットリロードをワンクリックで実行できる。
  • トークン消費のヒートマップや速度グラフを含む使用量ダッシュボードをローカルに保持する。

なぜ注目されているか

推測 アカウント登録やAPIキーの発行なしにGPT/Claude相当のモデルを試せる手軽さが大きな注目を集めている。無料かつ無制限という特性がコスト意識の高いユーザーや学生に支持されており、JavaScript週間トレンド1位を獲得した。

どんな人に役立つか

コストをかけずに最新AIモデルをローカル環境で試したい開発者・学生向け。DeepSeek Harness（dsh）ユーザーがすぐに使い始められるプラグイン形式のため、dshをすでに利用しているユーザーに特に有用。

技術的なポイント

  • DeepSeek Harness（dsh）のプラグイン機構を利用し、ビルドステップなし・ゼロ依存で動作する。
  • モデルの可用性を自分のネットワーク出口から実測し、地域制限や未ルートのモデルを自動分類する。
  • 上流ソースはOpenCode（Zenゲートウェイ）およびKilo AIの公開ゲートウェイで、直接接続・第三者中継なし。
  • ローカルポートへの接続は独自の中継密鍵で認証し、宿主プロセス外に認証情報が漏れない設計になっている。

試し方

  1. dshがインストール済みであることを確認する（公式Webまたはデスクトップ版）。
  2. 以下のコマンドでプラグインを追加し、アプリを再起動する。
  3. モデル選択ドロップダウンに「Our Free Model」グループが表示されることを確認する。
dsh plugin --profile web add /絶対パス/dsh-our-free-model
