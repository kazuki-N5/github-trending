storytold/craft-anything

Rust 初掲載 2026-11-03（Trendshift 3位） GitHub ↗

任意のソフトウェアを解析・模倣再構築するオープンソースのリバースエンジニアリングエンジン

何ができるか

  • WebサイトやアプリをAIエージェントで調査し、指定したスタックで再構築プロジェクトを自動生成できる
  • ディスアセンブル・デコンパイル・コールグラフ表示などを備えたAdvancedワークベンチモードを持つ
  • Claude CodeやACP対応エージェントなど複数のコーディングエージェントと連携できる
  • 合計314のツールをCLIコマンドとMCPツールとして公開しており、エージェントから直接利用できる
  • クリーンルームモード（ユーザー可視情報のみ使用）とディープモード（全ツール使用）の2方式で解析できる
  • Windows・macOS・Linux・FreeBSDおよびWebAssemblyブラウザビューア向けのビルドを提供している

なぜ注目されているか

推測 AIエージェントによるリバースエンジニアリングの自動化は従来の手動解析に比べて参入障壁が大幅に低く、開発者コミュニティの関心を集めている。314ものMCPツールを備えたエコシステムの規模感と、Claude Codeを筆頭にした複数エージェント対応が注目を集めていると考えられる。純Rust実装でクロスプラットフォームに対応している点も評価されている。

どんな人に役立つか

自分が所有または検査許可を持つソフトウェアの仕組みを理解したいエンジニアや研究者に役立つ。既存ソフトウェアと互換性のある代替実装を作りたい開発者や、リバースエンジニアリングの自動化パイプラインを構築したいセキュリティ研究者にも適している。

技術的なポイント

  • 純Rust（バージョン1.97以上）で実装されており、`cargo run --release`でビルドできる
  • 全機能をCLIコマンドとMCPツールの両方として公開する二重インターフェース設計を採用している
  • オプションでGhidraを統合してより高度なディスアセンブル・デコンパイルを行うことができる
  • Claude CodeをはじめACP（Agent Communication Protocol）対応の各種エージェントと連携できる設計になっている

試し方

  1. Rust 1.97以上をインストールする
  2. リポジトリをクローンしてビルドする、またはCLIをcargoでインストールする
  3. ターゲットのWebサイト・アプリ・ゲームを指定して解析を開始する
  4. Study→Build→Check→Refineの4ステップに従い再構築を進める
cargo run --release -p craft-anything
cargo install craft-anything
