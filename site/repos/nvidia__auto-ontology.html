NVIDIA/auto-ontology

Python 初掲載 2026-11-04（Trendshift 5位） GitHub ↗

企業メタデータからオントロジー（概念の意味関係を定義した知識構造）層を構築し、AIエージェントへ文脈情報を提供するオープンライブラリ

何ができるか

  • 自然言語の質問をSQLに変換し、接続されたデータベースに対してクエリを実行できる
  • リレーショナルデータソース上にセマンティックカタログ（意味的な分類目録）とオントロジー層を構築し、Postgresとpgvectorで管理する
  • Better AuthによるRBAC（ロールベースアクセス制御）とSSO（シングルサインオン）認証に対応している
  • チャット・分析・データカタログ・設定などを備えたWebUIを提供する
  • HelmチャートによるKubernetesデプロイとDocker Composeによるローカル環境構築の両方に対応している
  • MCP（Model Context Protocol）・CLI・APIを通じてエージェントへ文脈情報を提供できる

なぜ注目されているか

推測 LLMやAIエージェントが企業内の複数システムにまたがるデータを正確に扱うには、各システム間での用語・定義の不一致を解消する「意味の橋渡し」が必要とされており、この課題を解決するツールとして注目されている。推測 NVIDIAが公式に公開したプロジェクトであり、NVIDIA NIMという自社の推論インフラと組み合わせて使える点も関心を集めている一因と考えられる。

どんな人に役立つか

エンタープライズ（企業向け）データを扱うAIエージェントやRAGシステムを構築するエンジニアや、組織内の複数データソースにまたがるセマンティック検索や自然言語クエリを実現したいデータエンジニアに適している。KubernetesやDockerを用いた本番環境へのデプロイを前提とした設計のため、インフラ構築の知識も必要となる。

技術的なポイント

  • バックエンドはFastAPI（Python製Webフレームワーク）、フロントエンドはNext.jsで構成されている
  • ベクトル検索（意味的な類似検索）にはPostgresの拡張機能であるpgvectorを使用している
  • 自然言語処理と埋め込みモデルにはNVIDIA NIMエンドポイント（ホスト型またはセルフホスト型）を利用する
  • Kubernetesデプロイ用のHelmチャートとローカル開発用のDocker Composeを両方サポートしている
  • オプションでHashiCorp Vaultを用いて接続情報（DBクレデンシャル等）を安全に管理できる

試し方

  1. リポジトリをクローンする
  2. テンプレートから.envファイルを作成し、AUTH_SECRETとAPP_URLを設定する
  3. Docker Composeでスタックを起動する
  4. ブラウザでlocalhost:3000にアクセスしてWebUIを開く
docker compose up -d --build
