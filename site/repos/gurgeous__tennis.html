gurgeous/tennis

Rust 初掲載 2026-11-25（はてなブックマーク 5位） GitHub ↗

ターミナルでCSVをスタイリッシュな表として表示するCLIツール

何ができるか

  • CSV・TSV・セミコロン・パイプ区切りなど複数の区切り文字を自動検出して表示できる。
  • JSON、JSONL、SQLiteファイルも入力として読み込める。
  • ターミナルのライト/ダークテーマを自動検出し、見やすい配色でテーブルを描画する。
  • 行番号表示、ゼブラストライプ、ボーダースタイルなど表示オプションが豊富。
  • 列の選択・除外・ソート・フィルタリングなどデータ操作コマンドを備える。
  • --peek オプションでファイルの概要統計（列の形状・統計量）を素早く確認できる。

なぜ注目されているか

推測 CSVをターミナルで手軽に確認したいというニーズはデータエンジニアや開発者に普遍的であり、シンプルさと多機能のバランスが評価されていると考えられる。Rustによる高速な動作と豊富な表示オプションが他ツールと差別化している点も注目理由と推測される。

どんな人に役立つか

データ分析やログ調査でCSV・JSONをよく扱うエンジニア、またはターミナルだけで作業を完結させたい開発者向け。SQLiteのデータを手軽に閲覧したい用途にも役立つ。

技術的なポイント

  • Rustで実装されており、大きなCSVファイルでも高速に処理・表示できる。
  • ターミナルの幅に合わせて列を自動レイアウトし、はみ出す行は切り詰めて表示する。
  • 数値列には赤から緑のカラースケールを適用し、値の大小を視覚的に把握しやすくしている。
  • SQLiteファイルを直接読み込む機能を持ち、DBブラウザなしにテーブルを確認できる。

試し方

  1. Homebrew、mise、またはCargoでインストールする。
  2. tennis <CSVファイル> を実行してテーブルを表示する。
  3. tennis --peek <ファイル> で列の統計情報を素早く確認する。
brew install gurgeous/tap/tennis
cargo install tennis
tennis data.csv
tennis --peek data.csv
