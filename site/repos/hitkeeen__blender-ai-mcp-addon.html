hitkeeen/blender-ai-mcp-addon

Python 初掲載 2026-11-17（Trendshift 3位） GitHub ↗

BlenderにAIチャットとMCPサーバーを統合し、3Dシーン操作を自動化するアドオン

何ができるか

  • AIがシーンの検査・オブジェクト作成・編集・マテリアル管理など21種のツールをBlender上で直接実行できる。
  • ChatGPT（OpenAI）、Claude（Anthropic）、Gemini、Ollama など複数のAIプロバイダーを切り替えて利用できる。
  • マネージャー・ワーカー・レビュアーの役割分担によるマルチエージェントのチームチェーンで大規模タスクを自動化できる。
  • Poly Haven、Sketchfab、Poly Pizza からアセットを検索してBlenderに直接インポートできる。
  • 操作ごとに承認要求を設定したり実行中のタスクをキャンセルしたりする制御機能を備える。
  • Blenderのサイドバーに組み込まれたチャットワークスペース「Studio」でAIと対話できる。

なぜ注目されているか

BlenderにMCPサーバーを直接組み込み、AIが3Dシーンを自律的に操作できる点が従来のスクリプト補助ツールとは一線を画す。複数のAIプロバイダーへの対応とマルチエージェントワークフローにより、複雑な3D制作タスクの自動化が現実的になっている。

どんな人に役立つか

AIを活用して3Dモデリングや素材管理・アセット配置の作業を効率化したいBlenderユーザーに適している。Pythonスクリプトを使ったプロシージャルな制作フローやワークフロー自動化を試みたいデベロッパーにも役立つ。

技術的なポイント

  • MCP（Model Context Protocol）サーバーをBlenderアドオン内部に実装し、外部AIツールからBlenderを直接操作できる仕組みを実現している。
  • シーン検査・オブジェクト生成・編集・ビューポートスクリーンショット・スクリプト実行・Blender API検索・エクスポートの7グループ計21ツールを提供する。
  • チームチェーン機能でマネージャーが計画を立て、ワーカーが実行し、レビュアーが検証するマルチエージェント構成をサポートする。
  • Python検証レイヤーで不正なBlender API操作をブロックし、ミューテーション操作には名前付きアンドゥステップが記録される。

試し方

  1. Blender 4.2以降をインストールする。
  2. GitHubのReleasesページからZIPファイルをダウンロードする。
  3. Blenderの拡張設定（Edit > Preferences > Extensions）でZIPをディスクからインストールする。
  4. 3DビューポートのサイドバーでMCP Proパネルを開く。
  5. 使用するAIプロバイダー（OpenAI、Claude、Gemini等）の接続情報を設定する。
