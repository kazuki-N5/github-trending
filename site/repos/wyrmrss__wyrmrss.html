wyrmrss/WyrmRSS

Rust 初掲載 2026-11-24（はてなブックマーク 4位） GitHub ↗

Rust製のセルフホスト型RSSリーダー。Web・モバイル・デスクトップに対応

何ができるか

  • ブログやYouTubeのURLからフィードを自動検出して購読できる。
  • フォルダ管理とOPML形式でのインポート・エクスポートに対応する。
  • Discord・Slack・カスタムエンドポイントへのWebhook通知を設定できる。
  • フィードごとのフィルター機能と「後で読む」・アーカイブ機能を持つ。
  • OIDC（OpenID Connect）によるシングルサインオンとRSSHub連携をサポートする。
  • Tauri製のデスクトップアプリ（macOS・Windows・Linux）としても利用できる。

なぜ注目されているか

推測 セルフホストのRSSリーダーはFeedlyなどのクラウドサービスに代わるプライバシー重視の選択肢として需要がある。Rustによる高速バックエンド、Docker Compose対応の手軽なセットアップ、デスクトップアプリまでカバーする多プラットフォーム対応が注目を集めていると考えられる。

どんな人に役立つか

自分でサーバーを管理し、RSSフィードを一元管理したいエンジニアや情報収集者に向いている。YouTubeチャンネルも含めたフィード集約をプライベートな環境で行いたい場合に特に有用である。

技術的なポイント

  • バックエンドはRust（Actix-webフレームワーク・Diesel ORM・Tokio非同期ランタイム）で実装されている。
  • データベースはPostgreSQLまたはSQLiteを選択でき、Docker Composeで即起動できる構成になっている。
  • フロントエンドはReact＋Viteで構築されており、Webブラウザから利用する。
  • デスクトップアプリはTauri（RustとWebViewを組み合わせる軽量フレームワーク）で提供される。

試し方

  1. Docker Composeを使う場合はdocker-compose.ymlをダウンロードして起動する。
  2. デスクトップアプリはリリースページから各OS向けのインストーラーを取得する。
  3. Kubernetesマニフェストを使ったデプロイも公式ドキュメントで案内されている。
docker compose up -d
