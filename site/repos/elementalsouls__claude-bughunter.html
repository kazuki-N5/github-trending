elementalsouls/Claude-BugHunter

Python 初掲載 2026-11-16（Trendshift 19位） GitHub ↗

バグバウンティ向けClaude Code用スキルバンドル（83スキル・15コマンド）

何ができるか

  • 83種のスキルと15のスラッシュコマンドで脆弱性調査の手順をAIがガイドしてくれる
  • XSS・SQLi・SSRF・IDORなど58種のWebアプリ脆弱性クラスを網羅したhunt-*スキル群を使える
  • M365/Entra・Okta・vCenterなどエンタープライズ向けの侵入テスト攻撃チェーンを参照できる
  • HackerOneの開示レポート681件から抽出したパターンを脆弱性探索に活用できる
  • 7-Question Gateによる証拠品質チェックとVRT（脆弱性評価分類）準拠の重大度評価をサポートする
  • OpenCode・Codex CLI・Hermes Agentなど複数のAIエージェントハーネスで動作する

なぜ注目されているか

推測 バグバウンティ（企業が懸賞金を出して脆弱性報告を募るプログラム）に特化したAIスキルセットはこれまで少なく、実際の開示レポートに基づく体系的なアプローチが注目を集めている。Claude Codeのプラグインとして手軽に導入でき、既存のエージェントハーネスにも対応する拡張性も評価されていると思われる。

どんな人に役立つか

バグバウンティハンターや外部レッドチームの担当者向け。自分が権限を持つシステムへの侵入テストや脆弱性報告を効率化したい人に適している。なお、内部Active Directory・C2フレームワーク・iOS/ハードウェアへの応用はスコープ外とされている。

技術的なポイント

  • PythonのインストールスクリプトでmacOS・Linux・Windowsに対応したセットアップが可能
  • Claude Code用スキル形式（SKILL.mdなど）で実装されており、プラグインとしても配布される
  • HackerOne開示レポート681件を体系化し、24の脆弱性クラスに分類したパターンデータベースを内包する
  • コードはMIT、調査手法やワードリストなどのコンテンツはCC BY 4.0のデュアルライセンス構成をとる

試し方

  1. Claude Codeのプラグインとしてインストールするか、macOS/Linux用またはWindows用のインストールスクリプトを実行する
  2. テスト対象のシステムへの正当な権限を確認してからスキルを呼び出す
  3. hunt-*スキルや15のスラッシュコマンドで脆弱性調査を進める
