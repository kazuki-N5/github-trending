個人事業主向けのローカル専用Mac会計アプリ（複式簿記・青色申告対応）

何ができるか

  • 複式簿記（借方・貸方で取引を記録する簿記の基本形式）の仕訳帳から青色申告決算書まで一貫して作成できる
  • 銀行・カードの明細をペーストまたはアップロードし、事業用・個人用に仕分けして仕訳に変換できる
  • 請求書の発行が売掛金・売上の仕訳と連動しており、入金消込と源泉徴収税計算も行える
  • 減価償却・繰延資産償却・家事按分（自宅兼事務所などの費用配分）といった年度末調整を処理できる
  • パスキー（Touch ID）でロック解除し、データはMac内の暗号化SQLiteに保存され外部サーバーに送信されない

なぜ注目されているか

推測 freeeや弥生などのクラウド会計は月額費用がかかりデータが外部に保存されるため、コスト意識が高い個人事業主やプライバシーを重視する人がローカル完結のオルタナティブを求めていると見られる。パスキー認証という新技術の採用も注目ポイントになっている。

どんな人に役立つか

青色申告が必要な個人事業主で、特に時間単価・月額課金型のビジネスを行い、事業・個人で共用の銀行口座を持つ一人運営の人に最適である。法人税申告や在庫管理・給与計算は対象外のため、それらが必要な場合は向かない。

技術的なポイント

  • Node.js 26.5.1+とpnpmで管理されたフロントエンド・サーバー構成で、pnpm startでまとめて起動できる
  • PRF（Pseudo-Random Function）サポートつきパスキーで暗号化キーを導出し、SQLiteのデータベースファイルを暗号化している
  • オプションのAI連携では口座科目名をマスキング（隠蔽）してから外部APIに送信し、金額・日付はAIに渡さない設計になっている
  • Tailscaleのserve機能を使ってLAN外からスマートフォンでアクセスできる（Cloudflare Funnelは意図的に不使用）

試し方

  1. Node.js 26.5.1以上とpnpm 11.3.0以上をインストールする
  2. リポジトリをクローンしpnpm installで依存パッケージをインストールする
  3. pnpm dev でhttp://localhost:5173を開く（127.0.0.1ではなくlocalhostを使うこと。パスキーが動作しない）
  4. 初回起動時にパスキーを登録し、表示されるリカバリーキーをオフラインで保管する
pnpm install
pnpm dev
pnpm start
