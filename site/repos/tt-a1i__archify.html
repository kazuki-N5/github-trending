tt-a1i/archify

JavaScript 初掲載 2026-11-27（Trendshift 17位） GitHub ↗

任意のアイデア・計画・コードをインタラクティブな図に変換するAIエージェントスキル

何ができるか

  • アーキテクチャ・ワークフロー・シーケンス・ERDなど10種類の図をテキスト説明から生成できる。
  • JS/TS・Python・Java・Go・Rust・C/C++の依存サイクル・結合度・ホットスポットを検出するコードアーキテクチャ診断機能を持つ。
  • 結論を先頭に置き図を添えたワンページ解説（Explainer）を4スタイルで生成し、PNG・WebP・JPG・PDF形式でエクスポートできる。
  • ストーリーウォークスルーを1080p動画としてエクスポートし、PRやMRのdiffを図上に視覚化できる。
  • フォーカス・上流下流トレース・ルート探索・ロール比較・プレゼンテーションモードなどのビューア操作が可能。
  • スキーマ・レイアウト・HTML/SVGの検証を配信前に実行し、失敗時は機械可読な修復データを返す。

なぜ注目されているか

Claude CodeやCodex CLIなどのAIコーディングエージェントのスキルとして動作し、コードベースをそのまま可視化できる点が注目されている。エージェントに「図を作って」と一言伝えるだけでインタラクティブなHTMLビジュアルが生成される手軽さが開発者に好評である。推測 AIエージェントによるコード理解・説明ニーズの高まりと、ドキュメント自動生成への関心が普及を後押ししていると考えられる。

どんな人に役立つか

Claude Code・Codex CLI・Cursor・GitHub Copilotなどのエージェント環境を利用する開発者が主な対象。システムアーキテクチャの可視化やコードレビュー時の依存関係分析を効率化したいエンジニアチームにも適している。

技術的なポイント

  • AIエージェントのスキル（tool/function calling）として動作し、npxコマンドまたはllms.txtを通じてインストールする。
  • 生成されるビジュアルはインタラクティブなHTML形式で、ライトテーマ・ダークテーマに対応している。
  • validate・preview・deliver・guideのCLIコマンドを提供し、スキーマ検証と配信を管理できる。
  • ARCHIFY_UPDATE_CHECK_DISABLED=1の環境変数で自動更新チェックを無効化でき、自動インストールは行わない設計になっている。
  • Apache-2.0ライセンスで、バージョン3.3.2が安定版として提供されている。

試し方

  1. Claude CodeやCodex CLIなどの対応エージェント環境を用意する。
  2. npx skills addコマンドでarchifyスキルをインストールする。
  3. エージェントにシステムのフローや構造をテキストで説明し、図の生成を依頼する。
  4. コードリポジトリのアーキテクチャ診断を行う場合はCode Analysisの実行をエージェントに依頼する。
npx skills add archify
npx skills add archify-pr
