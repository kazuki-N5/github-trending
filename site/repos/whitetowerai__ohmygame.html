AIと一緒にゲームを作るオープンソースのワンパーソンゲームスタジオアプリ

何ができるか

  • ゲームのデザイン・アート制作・コーディング・デバッグ・公開をAIエージェントが一貫して行う
  • 画像・動画・3D・音声・コードを統合したシングルキャンバスでゲーム開発ができる
  • 作ったゲームはリンクで公開・コミュニティへの掲載・マルチプレイヤー対応が可能
  • Claude Code・Codex・OpenCodeなど40以上のモデルプロバイダーや外部エージェントと連携できる
  • GodotやUnityなどのエンジン向けプラグインでスキル・ツール・パネルを追加拡張できる
  • キャンバスやツールをMCP経由で外部サービスに公開することもできる

なぜ注目されているか

推測：AIがゲーム開発の全工程（デザイン・アート・コーディング・テスト・公開）を担える点が注目されている。APIキーやプロジェクトデータはローカルに保存される設計でプライバシーへの配慮が評価されている。推測：複数のAIエージェントやモデルプロバイダーと柔軟に接続できる点も幅広い開発者に選ばれる要因と考えられる。

どんな人に役立つか

WebゲームやインタラクティブストーリーをAIの力で手軽に作りたい個人開発者や小規模チームに向いている。Phaser・Three.js・React Three Fiberなどのフレームワークを使ったゲーム制作に最適だ。APIキーを自前で用意できる人ならすぐに試せる。

技術的なポイント

  • BunとNode.js 22.19+を使ったモノレポ構成で、ElectronによるデスクトップアプリとWebレンダラーの両方を提供している
  • MCP（Model Context Protocol）対応により、キャンバスやツールを外部サービスから利用可能
  • 40以上のモデルプロバイダーやClaude Code・Codex・OpenCodeなどのコーディングエージェントと連携できる
  • ゲームはPhaserやThree.js・React Three FiberなどのWebゲームフレームワークを用いたブラウザ動作形式で出力される
  • プロジェクトデータとAPIキーはローカル保存で、リリースビルドの使用状況データ送信は設定でオフにできる

試し方

  1. BunとNode.js 22.19+をインストールする
  2. リポジトリをクローンし、ブランチdevに切り替える
  3. 依存関係をインストールする
  4. Webレンダラーとローカルデーモンを起動するか、Electronデスクトップアプリを起動する
  5. アプリ起動後、使用するモデルプロバイダーまたはコーディングエージェントを接続する
bun install --frozen-lockfile
bun run dev
bun run dev:desktop
