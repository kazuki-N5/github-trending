AIがテーマから台本・映像・音声・字幕を自動生成し、短編動画を一括作成するツール

何ができるか

  • テキストのトピックやキーワードを入力するだけで、AIが動画用の台本を自動生成する。
  • Pexels・Pixabay などのストック映像サービスやAI動画生成ツールから素材を自動取得する。
  • Edge TTS など多数の音声合成プロバイダーで読み上げ音声とタイムスタンプ付き字幕を生成する。
  • BGMの追加・音量調整や、縦・横・正方形の動画フォーマット出力に対応する。
  • WebUI・REST API・CLIの3つの操作方法を提供し、TikTokやYouTube Shortsへの自動投稿も可能。
  • OpenAI・Claude・Gemini・DeepSeek・OllamaなどのLLM（大規模言語モデル）を自由に切り替えられる。

なぜ注目されているか

推測 動画制作の全工程（台本作成→映像取得→音声合成→字幕生成→編集）をAIで自動化できる点が多くのコンテンツクリエイターや開発者に注目されている。多様なLLM・TTS・映像プロバイダーへの対応と、WebUI・API・Docker・Google Colabなど複数のデプロイ方式を備える柔軟性も支持される理由の一つと考えられる。

どんな人に役立つか

ショート動画を大量生成したいコンテンツクリエイターや、動画自動化パイプラインを構築したい開発者に向いている。WebUIがあるためプログラミング経験がなくても操作でき、APIを使えばシステムへの組み込みも容易である。

技術的なポイント

  • Python 3.11以上で動作し、FastAPIでREST APIサーバーを提供している。
  • 音声認識ライブラリWhisper（OpenAI製）をローカル実行してタイムスタンプ付き字幕を生成できる。
  • 映像エンコードにはffmpegを使用し、縦・横・正方形など複数の出力フォーマットに対応している。
  • パッケージ管理にuv（高速Pythonパッケージマネージャー）を推奨しており、Dockerイメージも提供している。

試し方

  1. Python 3.11以上をインストールする。
  2. 公式パッケージをpipでインストールする。
  3. WebUIを起動し、設定画面でLLMのAPIキーを入力する。
  4. トピックやキーワードを入力して動画を生成する。
pip install mpt
mpt webui
