DIYgod/pinky

Go 初掲載 2026-11-09（Trendshift 20位） GitHub ↗

AIエージェントがあなたのスマホを操作し、危険な操作は人間が承認するオープンソースアプリ

何ができるか

  • iPhone・Androidの実機をAIエージェント（Claude Code、Cursorなど）からMCP経由で遠隔操作できる。
  • 決済など危険な操作は自動でゲートウェイが検知し、ユーザーの承認を必須とする。
  • 銀行・ウォレット・パスワードマネージャーアプリはデフォルトでエージェントから隠される。
  • 各操作セッションをステップ説明・スクリーンショット・動画でローカルに記録し、HTMLエクスポートも可能。
  • Tailscaleを使ったリモートスマホアクセスや、macOS/Windowsでの自動アップデートに対応。
  • いつでも手動で操作を引き継げる「Stop all」グローバルショートカットを備える。

なぜ注目されているか

推測 AIエージェントにスマホを操作させるニーズが高まる一方、安全性の確保が課題だった。Pinkyは「人間が必ず監視・承認する」設計でその課題に応え、プリアルファながら実機での動作が確認されている点が注目を集めている。

どんな人に役立つか

AIエージェントに日常のスマホ作業を自動化させたい開発者・研究者に役立つ。セキュリティを保ちながらスマホ自動化を試したいユーザーにも適している。

技術的なポイント

  • MCPプロトコル（stdio／HTTP）でエージェントと通信し、エージェント側の実装を問わず接続できる。
  • iOS 17.4以降はXcodeからヘルパーアプリを一度インストールする必要がある（サイドロード）。
  • PIN保存にはTouch ID／Windows Hello／キーリングを使い、エージェントにはPINを公開しない。
  • 操作ログはすべてローカル保存で、匿名統計は任意でオフにできる。

試し方

  1. GitHubリリースページからアプリをダウンロードしてインストールする。
  2. スマホをPinkyに接続する（iOSはヘルパーアプリが必要）。
  3. Settings › Agents でClaude Codeなどのエージェントを追加する。
  4. エージェントからタスクを実行して動作を確認する。
