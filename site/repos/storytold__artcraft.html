storytold/artcraft

Rust 初掲載 2026-10-19（Star History 3位） GitHub ↗

2D・3D の編集ツールで構図を組んでから AI 画像・動画を生成する「アーティストのための IDE」

何ができるか

  • 2D の画像レイヤーや背景除去、描画ツールで構図を組み立て、それをもとに画像を生成できる。
  • 3D 空間に背景・前景・小物を配置したり、キャラクターのポーズやカメラ位置を決めてから最終ショットを生成できる。
  • 画像から 3D メッシュ（立体モデル）を作り、位置や向きを調整してシーンに組み込める。
  • テキストから画像の生成、プロンプトやマスク指定による画像編集、画像から動画の生成ができる。
  • 画像・動画・音楽・3D メッシュ・ワールド（ガウシアンスプラット）など62種類のモデルを選んで使え、Grok、Midjourney、Sora、World Labs などのプロバイダーにも対応する。

なぜ注目されているか

プロンプトを書くだけの生成ではなく、構図・キャラクター・カメラを視覚的に組み立ててから生成する「クラフト」の流れを打ち出している。推測 多数の画像・動画生成モデルを一つのデスクトップアプリから使い分けられ、しかもオープンソースである点が注目の理由と考えられる。

どんな人に役立つか

AI で画像や動画を作るときに、構図やキャラクターの一貫性、カメラ配置を細かく制御したいアーティスト、デザイナー、映像制作者に向く。

技術的なポイント

  • 主に Rust で書かれ、Windows と macOS 向けのデスクトップアプリとして配布されている。
  • 3D シーン上でのブロッキング（配置の下書き）やキットバッシング（既製の 3D アセットを組み合わせる手法）を生成の入力として使う。
  • World Labs の Marble によるワールド生成ではガウシアンスプラット（多数の半透明の楕円体で 3D シーンを表現する手法）を扱う。

試し方

  1. getartcraft.com から Windows または macOS 向けの安定版をダウンロードする。
  2. 最新ビルドは GitHub のリリースページから入手できる。
  3. Linux を含めソースからビルドする場合は _docs/dev_setup.md の手順に従う。
