livliv-dev/player

TypeScript 初掲載 2026-11-07（Trendshift 15位） GitHub ↗

リップシンクとWebカメラ顔追跡付きの軽量2.5DキャラクタープレイヤーWeb向けライブラリ

何ができるか

  • LivLiv・VRM・PNGTuberの3種類のキャラクター形式を同一APIで再生できる
  • MediaPipeを使ったWebカメラによる顔追跡をブラウザ上でリアルタイム実行できる
  • リップシンクモジュールを使って音声に合わせた口の動きを制御できる
  • コアは約30KB（gzip後）で外部依存なし、WebGL2のみで動作する
  • OBS Browser Sourceとして利用できるiframeエンベッドURLを提供している

なぜ注目されているか

VTuber・PNGTuber・AIキャラクターをWebブラウザだけで動かせる軽量実装は珍しく、外部サーバー不要でカメラ映像をローカル処理する点がプライバシー面でも評価されている。

どんな人に役立つか

WebアプリやOBS配信にVTuber・PNGTuberのキャラクターを組み込みたい開発者、またはlivliv.aiで作成したAIキャラクターを自作サービスに埋め込みたい人に向いている。

技術的なポイント

  • WebGL2のみを使用したレンダラーで追加ライブラリ不要の30KB軽量コアを実現している
  • 顔追跡にはMediaPipe（Googleのリアルタイム機械学習ライブラリ）をブラウザ上で動かしている
  • リップシンクと顔追跡は別モジュールとして分割されており必要なときだけ読み込める
  • Chrome/Edge 97以降、Firefox 104以降、Safari 15.4以降をサポートしている

試し方

  1. npm install @livliv-dev/player でインストールする
  2. canvas要素にPlayerを作成しload()でキャラクターフォルダまたは.livlivファイルを読み込む
  3. setExpression()やsetAction()でキャラクターの表情や動作を制御する
