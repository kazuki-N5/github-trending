株式投資家・トレーダー向けClaudeスキル集（市場分析〜売買戦略まで）

何ができるか

  • デイリー市場チェック・週次ポートフォリオレビュー・月次パフォーマンス評価の各ワークフローを提供する
  • VCPスクリーナーやドローダウン遮断機、ポジションサイザーでスイング候補を絞り込める
  • 売買記録・ポストモーテム・トレーダーメモリ機能で取引履歴を管理できる
  • FMP・Alpaca・FINVIZ Eliteなどの外部APIと連携し、スクリーニングやポートフォリオ管理を自動化できる
  • APIなしでも公開CSV・チャート画像・ローカルファイルだけで動作する5つのスターターパス対応スキルがある
  • 買い・売りのシグナルは出さず、投資家自身の判断プロセスを支援することに特化している

なぜ注目されているか

推測 個人投資家が時間をかけずに規律ある投資プロセスを実践できるAIスキルは需要が高く、Claude Code上でそのまま動く実用性が注目を集めていると考えられる。ETF・配当株・スイングトレードを組み合わせた現実的な運用スタイルに対応している点も評価されている。

どんな人に役立つか

時間に制約のある個人投資家で、長期投資・ETF・配当株を中心にスイングトレードを加えたい人に向いている。APIなしの無料スターターパスもあるため、コストをかけずに始めたい初心者にも使いやすい。自動売買ではなく、自分の投資判断を体系化・改善したい人に適している。

技術的なポイント

  • Python 3.11〜3.13（Linux・Windows・macOS対応）で実装され、パッケージ化スキルは3.9以上をサポートする
  • スキルはYAMLマニフェスト（workflows/）で管理され、Claude WebアプリとClaude Code両方に対応する
  • FMP（マーケットデータ）・Alpaca（ポートフォリオ管理）・FINVIZ Elite（スクリーニング）をオプションAPIとして利用する
  • スキルカタログはskills-index.yamlで一元管理され、ドキュメントサイトも別途提供されている

試し方

  1. GitHubの最新リリースから.skillファイルをダウンロードし、ハッシュを検証する
  2. Claude Webアプリの場合は「カスタマイズ > スキル」からアップロードする
  3. Claude Codeの場合はスキルフォルダを~/.claude/skills/またはプロジェクトの.claude/skills/にコピーする
  4. APIなしで試す場合は、market_breadth・uptrend・position_sizer・trader_memory・signal_postmortemの5スキルを使う
cp -r skills/market_breadth ~/.claude/skills/
cp -r skills/position_sizer ~/.claude/skills/
