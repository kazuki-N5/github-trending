anhao/ai-pose-gallery-zh

Python 初掲載 2026-10-30（Trendshift 4位） GitHub ↗

1439枚の人体ポーズ参考画像を中国語UIで閲覧できる零依存静的ギャラリー

何ができるか

  • 4つの体系・26カテゴリ・288ポーズ・1439枚の画像を収録し、正面・斜め・側面・俯瞰・仰角の5視点で閲覧できる。
  • ポーズ名・番号・ID・カテゴリキーワードによる全文検索と、視点・動作分類の組み合わせフィルタリングができる。
  • グループ表示と1枚ずつのブラウズ両モードに対応し、サムネイルをクリックすると原寸PNG（900×1200）のライトボックスが開く。
  • キーボードの左右キーで視点切り替え、上下キーでポーズ切り替え、Escで閉じるなどキーボードナビゲーションをサポートする。
  • JSONデータと翻訳スクリプトがすべて公開されており、自分で中国語訳を修正・再生成してデプロイできる。
  • Cloudflare Pagesへの自動デプロイに対応しており、build.shで必要ファイルだけをdistに出力するためファイル数制限内に収まる。

なぜ注目されているか

推測 AIイラスト生成の普及でポーズ参考資料の需要が高まる中、元の日本語サイトを中国語話者が使いやすいよう完全漢化した点が評価された。外部ライブラリ不要の単一HTMLで動作するため、フォークしてすぐに自分のドメインで公開できる手軽さも注目を集めた可能性がある。

どんな人に役立つか

AIイラスト・3Dモデリング・写真撮影でポーズ参考を探している中国語話者のクリエイターに役立つ。また、静的サイト構築やCloudflare Pagesへのデプロイを学びたいフロントエンド初学者にとっても、依存関係なしで動くシンプルな実装例として参考になる。

技術的なポイント

  • index.html1ファイルで完結する零依存（フレームワーク・ライブラリなし）の静的ウェブアプリで、JavaScriptのfetch APIでpose-zh.jsonを読み込む設計。
  • i18n.pyとapply_translation.pyの翻訳スクリプトにより、日本語→中国語の323件の対訳辞書を元データに自動適用してpose-zh.jsonを生成する。
  • download.pyは48スレッドの並列ダウンロードと断点再開をサポートし、約660MBの画像を効率よく取得できる。
  • Cloudflare Pagesのキャッシュ戦略（_headers）で画像ディレクトリに1年間の強キャッシュを設定し、配信コストを削減する。
  • JSON-LDによる構造化データとOpen Graph / Twitter Cardメタタグで、SNSシェア時のプレビューとSEOを強化する。

試し方

  1. リポジトリをクローンまたはZIPでダウンロードする。
  2. プロジェクトディレクトリでPython内蔵HTTPサーバーを起動する。
  3. ブラウザで http://127.0.0.1:8000 を開く。
  4. 画像ファイルが必要な場合はdownload.pyを実行して約660MBの画像をダウンロードする。
python3 -m http.server 8000
python download.py
python scripts/apply_translation.py
python scripts/verify.py
bash scripts/build.sh
npx wrangler pages deploy dist --project-name ai-pose-gallery-zh
