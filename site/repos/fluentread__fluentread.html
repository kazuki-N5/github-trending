FluentRead/FluentRead

TypeScript 初掲載 2026-11-11（Trendshift 9位） GitHub ↗

Webページに原文と翻訳を並べて表示するオープンソースのブラウザ拡張機能

何ができるか

  • Webページ全体をバイリンガル表示し、ホバーや選択範囲での翻訳・原文復元・自動翻訳ルール設定ができる
  • AIリーディングカードで意味・文の分析・用例説明・練習問題を段落コンテキスト付きで表示し、追加の質問もできる
  • PDF・ePub・DOCXなどのドキュメントを二言語で読み、翻訳を編集してファイルとしてエクスポートできる
  • YouTubeやXの動画に二言語字幕を表示し、X動画はローカルAI文字起こしも利用できる
  • Webページの画像内テキストを認識して翻訳をオーバーレイ表示・コピーできる
  • 単語・フレーズ・文をオリジナルコンテキスト付きで学習センターに保存してあとから復習できる

なぜ注目されているか

推測 海外の技術情報や論文を読む際の言語の壁を低コストで解決するツールとして支持されており、単なるページ翻訳を超えたAI読解補助機能が他ツールとの差別化になっている。DeepL・各種AIプロバイダー・ローカルOllamaモデルなど多様なバックエンドを選べる柔軟性も評価されている。

どんな人に役立つか

外国語のWebページや技術文書を日常的に読むエンジニア・研究者。語学学習者で原文と訳文を並べて読みながら単語を記録したい人。YouTubeなど外国語動画をバイリンガル字幕付きで視聴したい人。

技術的なポイント

  • TypeScript製のブラウザ拡張機能で、Chrome・Edge・Firefox・ユーザースクリプト（Greasyfork）に対応しておりストアからインストールできる
  • 翻訳バックエンドとして無料サービス・DeepL・各種AIプロバイダー・ローカルのOllamaモデルを選択可能で、用語集や翻訳スタイルも設定できる
  • 設定と学習記録はデフォルトでローカルに保存され、クラウドバックアップはGoogle DriveまたはWebDAVを使って暗号化して同期できる
  • GPL-3.0ライセンスで公開されており、コード・ドキュメント・インターフェース翻訳などのコントリビューションを受け付けている

試し方

  1. Chrome/Edge/FirefoxのストアからFluentReadをインストールして、開いているページを更新する
  2. 拡張機能アイコンを開いてターゲット言語を選択する（ソース言語は自動検出が可能）
  3. 「ページを翻訳」を選択するとバイリンガル表示になる
  4. 選択翻訳やその他のツールは設定から有効化する
