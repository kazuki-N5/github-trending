vllm-project/vllm

Python 初掲載 2026-10-21（GitHub Trending 15位） GitHub ↗

大規模言語モデルを速く・安く・省メモリで動かす推論・配信エンジン

何ができるか

  • 大規模言語モデル（LLM）の推論（学習済みモデルで文章を生成すること）と、APIとしての配信（サービング）を高いスループットで行えます。
  • OpenAI互換のAPIサーバーを立てられ、AnthropicのMessages APIやgRPCにも対応しています。
  • Hugging Face上の200以上のモデル構造に対応し、Llama・Qwen・Gemmaなどの一般的なLLM、Mixtral・DeepSeek-V3などのMoEモデル、LLaVAなどの画像も扱えるマルチモーダルモデル、埋め込みモデルなどを動かせます。
  • 出力のストリーミング、並列サンプリングやビームサーチなどの生成方式、xgrammarやguidanceを使った構造化出力（JSONなど決まった形式での出力）、ツール呼び出しに対応しています。
  • テンソル並列・パイプライン並列などの分散推論で、大きなモデルを複数のGPUに分けて動かせます。
  • NVIDIA・AMD・IntelのGPUやx86/ARM/PowerPCのCPUに対応し、プラグインでGoogle TPU、Intel Gaudi、Huawei Ascend、Apple Siliconなども使えます。

なぜ注目されているか

UC BerkeleyのSky Computing Labで生まれ、現在は2000人を超えるコントリビューターと多数の大学・企業が開発する、最も活発なオープンソースAIプロジェクトの一つだと説明されています。PagedAttentionという独自のメモリ管理手法の論文がOSの主要国際会議（SOSP 2023）で発表されています。推測 自前のサーバーでLLMを安く高速に提供したい需要が大きく、新しいモデルや量子化手法への対応も早いため注目され続けていると考えられます。

どんな人に役立つか

オープンなLLMを自分のGPUサーバーで動かし、チャットやAPIとして提供したい開発者や研究者に向いています。LLM推論の高速化やGPUメモリ管理の仕組みを学びたい人にとっても参考になります。

技術的なポイント

  • PagedAttentionは、注意機構（Attention）が使うキーとバリューのキャッシュ（KVキャッシュ）を、OSの仮想メモリのページングのように小さなブロック単位で管理し、GPUメモリの無駄を減らす仕組みです。
  • 連続バッチ処理（届いたリクエストを随時まとめて処理する方式）、chunked prefill（入力の前処理を分割して行う方式）、プレフィックスキャッシュ（共通の入力部分の計算結果を再利用する仕組み）で処理効率を高めています。
  • FP8・INT8・INT4・GPTQ/AWQ・GGUFなど多くの量子化（数値の精度を落としてメモリと計算を節約する手法）に対応しています。
  • FlashAttentionやFlashInferなどの最適化済みカーネル、CUDA/HIPグラフ、torch.compileによる自動カーネル生成を使って実行を高速化しています。
  • 投機的デコーディング（軽い方法で先の単語を予測し、本体モデルでまとめて検証して生成を速める手法）として、n-gramやEAGLEなどに対応しています。

試し方

  1. uv（推奨）またはpipでvllmをインストールします。
  2. 起動を速くするため、コンパイル済みカーネルをダウンロードします。
  3. 公式ドキュメントのQuickstartに沿って、モデルを読み込んで推論やAPIサーバーを試します。
uv pip install vllm
vllm download-kernels
