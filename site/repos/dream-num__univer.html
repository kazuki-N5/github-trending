dream-num/univer

TypeScript 初掲載 2026-11-15（Trendshift 9位） GitHub ↗

AIエージェントと人間の両方に対応したオフィス機能組み込みSDK

何ができるか

  • スプレッドシート・ドキュメントの編集・数式計算・レンダリングをWebアプリに組み込める
  • プラグインベースのアーキテクチャで機能を柔軟に拡張できる
  • Node.jsヘッドレスモードでUIなしの自動処理・スナップショット生成が可能
  • 型付きFacade APIとイベント機構でAIエージェントとの統合をサポート
  • クロスフィーチャーな元に戻す/やり直し操作を単一ステップで実現
  • 商用拡張としてリアルタイム共同編集・ファイル変換SDKも提供

なぜ注目されているか

オープンソースコア（Apache-2.0）でありながら、AIエージェントと人間ユーザー双方に同一APIで対応できる点が独自性として注目されている。Canvasベースの高性能レンダリングと、プラグイン3層構造による高い拡張性を備えており、エンタープライズ向けオフィス機能を自社プロダクトに組み込むニーズに応える設計となっている。

どんな人に役立つか

スプレッドシートやドキュメント編集機能を自社Webアプリに統合したい開発者に適している。またAIエージェントがオフィスデータを操作するワークフローを構築したいエンジニアにも有用。SaaSやノーコードツール開発者にも活用が期待できる。

技術的なポイント

  • TypeScript製モノレポ構成で、機能・製品・基盤の3層プラグインアーキテクチャを採用
  • Canvasベースのレンダリングエンジンと共有数式エンジンを搭載
  • 依存性注入とコマンドシステムにより、コマンド・ミューテーション・オペレーションを役割ごとに分離
  • IWorkbookDataなどスナップショットベースのコンテンツモデルを使用
  • React 18ビュー層とNode.js 18.17以降でのヘッドレス動作をサポート

試し方

  1. pnpmでプリセットパッケージをインストールする
  2. リポジトリをクローンしてローカル開発環境を起動する
pnpm add @univerjs/presets @univerjs/preset-sheets-core
git clone https://github.com/dream-num/univer.git
cd univer
pnpm install
pnpm dev
