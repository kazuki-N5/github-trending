WindowsとLinux向けのワークスペース対応・複数ペイン型ファイルマネージャー

何ができるか

  • 最大32分割ビューを持ち、各ビューに独立したタブ・履歴・ソート・列設定を備える
  • コピー・移動・リンク・リネーム・ゴミ箱移動・削除などのファイル操作を進捗表示付きで実行できる
  • バッチリネーム・ドラッグ＆ドロップ・チェックサム表示付きプロパティパネルに対応している
  • 画像・SVG・動画・PDFなど多様な形式のサムネイル表示をサポートしている
  • 7-Zip連携レシピやカスタムコマンド（プレースホルダー付き）を設定できる
  • 8言語・ライト/ダーク両対応の複数ビルトインテーマを備え、TOMLでカスタムテーマも作成できる

なぜ注目されているか

推測 インストール不要・管理者権限不要・テレメトリなしという潔いプライバシー設計が注目を集めている。推測 Rustで書かれた単一実行ファイルである点が、軽量かつクロスプラットフォームなツールを求めるユーザーに響いていると考えられる。

どんな人に役立つか

WindowsまたはLinuxで多ペイン型のファイル管理を必要とする開発者や上級ユーザー向け。インストール不要ですぐに使えるため、複数マシン間でポータブルに持ち運びたい人にも適している。

技術的なポイント

  • RustとSlintで実装されており、単一実行ファイルとして配布される
  • 設定・お気に入り・ワークスペースはTOMLファイルとして保存される
  • サムネイルはセッションメモリキャッシュのみに保持され、ディスクへの書き出しを行わない
  • 動画・PDFのサムネイルはWindowsではシェルプロバイダー、LinuxではffmpegとPopplerを利用する
  • ビルドにはRust 1.92以上とCコンパイラが必要で、Windows・Linux（Debian/Ubuntu・Fedora・Arch）・NixOS向けの手順が用意されている

試し方

  1. Rust 1.92以上とCコンパイラをインストールする
  2. リポジトリをクローンする
  3. 対象OSのビルド手順に従い依存ライブラリをインストールする
  4. cargo buildまたはcargo runでビルド・実行する
cargo build --release
cargo run
