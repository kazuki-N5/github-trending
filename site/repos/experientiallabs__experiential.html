experientiallabs/experiential

Python 初掲載 2026-10-25（Trendshift 3位） GitHub ↗

BYOK・セルフホスト・1000以上のモデルに対応するコスト最適化AIゲートウェイ

何ができるか

  • OpenAI互換のAPIエンドポイントを提供し、BYOK（自分のAPIキーを持ち込む方式）・セルフホスト・クラウドモデルを単一のAPIで統一的に利用できる
  • トラフィック（実際のリクエスト使用データ）を学習してコストを削減し、より良いモデルを自動的に推奨する
  • ユーザーやエージェントごとにモデルの利用制限・用途・予算上限を設定できるアクセス制御機能を持つ
  • 本番トラフィックからOpenTelemetryトレースを収集し、独自のルーターやカスタムモデルをファインチューニングして構築できる
  • `exp capture` コマンドでClaude CodeやCodexなどのAIコーディングエージェントのリクエストをキャプチャできる（macOS限定・実験的機能）

なぜ注目されているか

AIエージェントや複数のLLMを組み合わせる開発が増える中、プロバイダーをまたいだ統一管理とコスト最適化のニーズが高まっている。推測 自社データを使ってカスタムモデルを育て所有できる点が、ベンダーロックイン（特定サービスへの依存）を避けたい組織から注目を集めていると考えられる。推測 オープンソースで自己ホストできるゲートウェイとして、プライバシーやセキュリティを重視する用途での採用も期待されていると思われる。

どんな人に役立つか

複数のLLMプロバイダーを本番環境で運用し、コスト管理やアクセス制御が必要な開発者・チームに役立つ。自社のトラフィックデータから特化モデルを作りたいMLエンジニアや、Claude CodeやCodexなどのAIコーディングツールを組織全体で統制したい管理者にも適している。

技術的なポイント

  • OpenTelemetry（分散トレーシングの標準規格）でリクエストのトレースを収集し、モデル選択の最適化シミュレーションに活用する
  • OpenAI互換フォーマットとAnthropic Messages形式の両APIをサポートし、既存のツールやSDKをそのまま接続できる
  • Tinker を使用してオープンソースモデルのファインチューニング（特定用途向けの追加学習）が可能
  • `uv` でパッケージ管理し、Ruff でフォーマット・リント、`ty` で型チェック、pytest でテストを行うモダンなPython開発スタックを採用

試し方

  1. pip で experiential をインストールする
  2. `exp` コマンドを実行し、セットアップウィザードでプロバイダー・モデル・予算などを設定してワンタイムキーを取得する
  3. 取得したキーを使って `http://127.0.0.1:8000/v1/chat/completions` にリクエストを送信する
  4. Python からは `exp.load_router()` でフィット済みルーターをOpenAIクライアントとして読み込む
