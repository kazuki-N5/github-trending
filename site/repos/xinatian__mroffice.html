オープンソースの6種類エディタ（文書・表計算・プレゼン・PDF・手書き・コード）

何ができるか

  • ドキュメントエディタはスタイル、表、コメント、変更追跡、ペンインクをサポートし、.mrdoc形式で保存する
  • 表計算エディタはセル演算式、数値フォーマット、条件付き書式、並べ替え、複数シートに対応し、CSVやTSVも扱える
  • プレゼンエディタはテーマ、スライドマスター、アニメーション、トランジション、スライドショーをサポートする
  • PDFエディタは読み取り、検索、印刷、テキストへの注釈付けができる
  • 手書きエディタは筆圧対応のペンノートを提供し、インクを図形に変換できる
  • コードエディタはシンタックスハイライトとアウトライン表示を備え、JS/TS・Python・SQL・Lua・シェルをブラウザで実行できる

なぜ注目されているか

推測6種類のエディタを一つのオープンソースプロジェクトとして公開することで、様々なドキュメント形式の編集機能をブラウザやElectronアプリに組み込める点が注目される。推測MROfficeデスクトップアプリとの連携でWord/Excel/PowerPointファイルのサポートも可能になるため、既存のOfficeエコシステムとの互換性も確保できる。

どんな人に役立つか

ブラウザやデスクトップアプリにドキュメント編集機能を組み込みたい開発者向けのプロジェクトである。MicrosoftOfficeファイルの読み書きを必要とするアプリ開発者にも適している。

技術的なポイント

  • TypeScriptで実装されており、npmでビルドおよび実行できる
  • ブラウザ（apps/playground）とElectronデスクトップ（apps/desktop）の両環境をサポートする
  • @mrnote/coreパッケージが6つのエディタを共通基盤として統合している
  • apps/mcpによりAIアプリ向けMCPサーバーも提供される
  • ライセンスはAGPL-3.0で、商用利用向けには別途商用ライセンスも取得できる

試し方

  1. npmの依存関係をインストールする
  2. npm run fontsでOfficeフォントの代替をセットアップする
  3. npm run buildでプロジェクトをビルドする
  4. npm run previewでhttp://localhost:5178にてプレビューを確認する
npm install
npm run fonts
npm run build
npm run preview
