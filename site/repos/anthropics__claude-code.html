TypeScript 初掲載 2026-10-20（GitHub Trending 11位） GitHub ↗

ターミナルで動き、自然言語の指示でコーディングを手伝うAIエージェント

何ができるか

  • ターミナル上でコードベース全体を理解したうえで、自然言語の指示に従ってコーディング作業を手伝います。
  • よくある定型作業を実行したり、複雑なコードを説明したりできます。
  • git の操作（コミットやブランチ管理などの一連の作業）を自然言語で任せられます。
  • ターミナルだけでなく IDE（統合開発環境）からも使え、GitHub 上で @claude とメンションして呼び出すこともできます。
  • プラグインでカスタムコマンドやエージェントを追加し、機能を拡張できます。
  • /bug コマンドで、Claude Code の中から直接不具合を報告できます。

なぜ注目されているか

Anthropic が公式に提供するエージェント型（AI が自分で手順を考えてツールを操作する方式）のコーディングツールで、ターミナル・IDE・GitHub と普段の開発環境にそのまま組み込める点が特徴です。推測 AI に開発作業を任せる「エージェント型コーディング」への関心が高まっており、その代表的なツールとして注目されていると考えられます。

どんな人に役立つか

ターミナルで開発することが多く、コードの読解や定型作業、git 操作を AI に手伝ってほしい開発者に向いています。初めて触る大きなコードベースの理解を助けてもらう用途にも使えます。

技術的なポイント

  • 動作には Node.js 18 以上が必要とされています。
  • コマンドラインツール（CLI）として提供され、プロジェクトのディレクトリで claude コマンドを実行して使います。
  • このリポジトリには、カスタムコマンドやエージェントを追加する Claude Code 用プラグインがいくつか含まれています。
  • インストールは公式のインストールスクリプト、Homebrew、WinGet などで行い、npm 経由のインストールは非推奨になっています。

試し方

  1. お使いの OS に合った方法で Claude Code をインストールします。
  2. 開発中のプロジェクトのディレクトリに移動します。
  3. claude コマンドを実行して、自然言語で指示を出します。
curl -fsSL https://claude.ai/install.sh | bash
brew install --cask claude-code
irm https://claude.ai/install.ps1 | iex
winget install Anthropic.ClaudeCode
npm install -g @anthropic-ai/claude-code
claude
