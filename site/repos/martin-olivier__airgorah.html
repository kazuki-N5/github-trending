Rust 初掲載 2026-11-15（Trendshift 15位） GitHub ↗

LinuxのGUIベースWiFiセキュリティ監査ツール

何ができるか

  • 周辺のWiFiトラフィックをパッシブキャプチャできる
  • アクセスポイントに接続しているクライアントを発見できる
  • デオーセンティケーション攻撃を実行できる
  • ハンドシェイクおよびPMKIDをキャプチャできる
  • アクセスポイントのパスワードをクラックできる

なぜ注目されているか

推測 RustとGTK4を組み合わせたGUIベースのWiFi監査ツールは珍しく、コマンドラインに不慣れなユーザーでも使いやすい点が注目を集めている。X11とWaylandの両方に対応しており、polkitを活用して通常ユーザー権限で動作する設計も現代的なLinux環境に適している。

どんな人に役立つか

自分が所有するネットワークのセキュリティ検査を行いたいLinuxユーザー向け。ペネトレーションテストの学習者や、WiFiセキュリティの監査を視覚的なインターフェースで行いたいセキュリティエンジニアに適している。

技術的なポイント

  • Rustで実装されており、メモリ安全性とパフォーマンスを両立している
  • GTK4（gtk-rs）を使用したグラフィカルUIで、X11とWayland両方に対応している
  • polkitを利用した権限昇格により、通常ユーザー権限でGUIを動作させつつ特権操作を安全に実行する
  • crates.ioおよびAURからパッケージとして配布されている

試し方

  1. モニターモードとパケットインジェクションに対応したワイヤレスカードを用意する
  2. 公式WikiのInstallationページを参照してインストールする
  3. polkitがシステムにインストールされていることを確認する
  4. アプリケーションを起動し、polkitの認証を行って特権操作を許可する
cargo install airgorah
