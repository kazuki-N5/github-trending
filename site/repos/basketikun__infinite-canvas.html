basketikun/infinite-canvas

TypeScript 初掲載 2026-10-24（Trendshift 9位） GitHub ↗

AI生成画像を無限キャンバス上で並べて試行錯誤できる、オープンソースの制作ツール

何ができるか

  • 複数のキャンバスを持つプロジェクトで、ノード（キャンバス上の部品）のドラッグや拡大縮小、線でのつなぎ合わせ、ミニマップ、元に戻す・やり直しができます。
  • 設定した OpenAI 互換 API に接続し、テキストからの画像生成、画像からの画像生成、参考画像の編集、文章での質問、音声や動画の生成ができます。
  • キャンバスアシスタントが、選んだノードやその上流のノードについて対話や画像生成を行い、結果をキャンバスに戻します。
  • ローカルの Canvas Agent を通じて Codex や Claude Code をつなぎ、エージェントに MCP 経由で現在のキャンバスを操作させられます。
  • URL からリモートのノードプラグインを導入・更新・削除でき、TypeScript SDK で独自のノードも作れます。
  • 7つのオープンソースのプロンプト集を内蔵し、独自の JSON 形式のプロンプト集も追加できます。

なぜ注目されているか

キャンバスでの配置、AI 画像生成、参考画像の編集、対話アシスタント、プロンプト集、素材管理を1つの画面にまとめた点が特徴です。リポジトリページでは8千を超えるスターを集めています。推測 OpenAI 互換の API なら中継サービスや自前のサーバーも含めて自由に接続でき、MIT ライセンスで商用利用もできる点が支持されていると考えられます。

どんな人に役立つか

AI で画像や動画を作りながら、複数の案を並べて比べたり連続して改良したりしたいクリエイターに向いています。AI エージェントにキャンバスを操作させる仕組みを試したい開発者にも参考になります。

技術的なポイント

  • フロントエンドは TypeScript で書かれ、開発では Bun（高速な JavaScript 実行環境）を使います。
  • API キー、Base URL、キャンバス、素材、生成履歴は既定でブラウザ内に保存され、ブラウザから直接 API にアクセスします。
  • プロンプト集はブラウザから直接取得して IndexedDB（ブラウザ内のデータベース）にキャッシュします。
  • エージェント連携には MCP（Model Context Protocol：AI がツールを呼び出すための標準的な仕組み）を使っています。
  • README によると開発段階のため、過去のデータとの互換性は保証されていません。

試し方

  1. リポジトリをクローンし、web ディレクトリで Bun を使って開発サーバーを起動するか、Docker Compose で起動します。
  2. ブラウザで http://localhost:3000 を開きます（Docker の場合）。
  3. 右上の設定から、自分の OpenAI 互換 API の Base URL と API Key を入力します。
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cd web
bun install
bun run dev
docker compose up -d
