Goで実装したチュートリアル形式のFORTH系言語インタープリター

何ができるか

  • スタック（後入れ先出しのデータ構造）を使った逆ポーランド記法で四則演算や数学関数を実行できる
  • コロン（:）と セミコロン（;）で新しい「ワード（関数）」を定義でき、再帰呼び出しにも対応している
  • do/loopによるループとif/else/thenによる条件分岐で制御フローを記述できる
  • 変数宣言・読み書き（variable/@/!）やASCII文字出力（emit）など基本的なI/Oをサポートしている
  • コマンドライン引数にファイルを渡すとスクリプト実行、引数なしでREPL（対話モード）として起動する

なぜ注目されているか

推測 FORTHはシンプルな設計でありながら実装が学習になる言語として知られており、Goで書かれたチュートリアル形式の実装はGo入門者や言語処理系の仕組みを学びたい人にとって読みやすい教材になっている。Goアプリに組み込めるスクリプト言語という実用的な用途もある。

どんな人に役立つか

Goでスクリプト言語の組み込みを検討している開発者や、FORTH言語の仕組みや実装を学びたい学習者に向いている。コンパイラ・インタープリターの基礎を実際のコードで理解したいCS学生にも適している。

技術的なポイント

  • レキサー（字句解析器）がソースコードをトークンに分解し、コメントや文字列リテラルを適切に処理している
  • スタックはfloat64型の値の列として実装されており、整数・浮動小数点の両方を統一的に扱える
  • GitHub Actionsでテストを自動実行しており、CI（継続的インテグレーション）環境が整備されている

試し方

  1. Goをインストールした環境でリポジトリをクローンする
  2. go build . でバイナリをビルドする
  3. ./foth と実行するとREPLが起動する
  4. カレントディレクトリにfoth.4thがあれば標準ライブラリとして自動ロードされる
go get github.com/skx/foth/foth@v0.5.0
cd foth
go build .
./foth
