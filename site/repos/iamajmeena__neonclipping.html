iamajmeena/neonclipping

Python 初掲載 2026-11-21（Trendshift 8位） GitHub ↗

YouTubeなどの長動画を9:16縦型クリップに自動変換するローカルAIエンジン

何ができるか

  • 音声優先の高速モードで85分の動画を約97秒でクリップ化できる
  • OllamaのローカルLLMがハイライトのスコアリングとタイトル・フックの文章生成を行う
  • ユーザーの5段階評価を学習し、8件の評価後にハイライト検出の重みを個人の好みに自動調整する
  • 11種類のレイアウト、5種類のキャプションスタイル、SRT/WebVTT/ASSのインポート・エクスポートに対応
  • TwitchやYouTube Liveのリアルタイムクリッピングとチャットスパイク検知をサポート
  • アカウント不要・完全ローカル動作でプライバシーを保護し、サーバーは127.0.0.1のみにバインド

なぜ注目されているか

推測 クラウドサービス不要でローカルLLMとFFmpegのみで動作するため、コストとプライバシーの両面で優れている。ライブ配信のリアルタイムクリッピングや視聴者評価による学習機能など、実用的かつユニークな機能を無料のオープンソースで提供している点が注目に値する。

どんな人に役立つか

YouTube・Twitch・Kickの長時間配信やゲーム動画からSNS用の縦型ショートクリップを作りたいストリーマーやコンテンツクリエイター向け。Windowsユーザーはワンクリックセットアップで手軽に始められ、Python 3.10以上とFFmpegがあればMac・Linuxでも動作する。

技術的なポイント

  • バックエンドはFastAPIで構築されたローカルWebサーバー（ポート8770）として動作する
  • 音声解析にfaster-whisper（ローカルWhisper）、動画処理にFFmpegとOpenCVを使用
  • OllamaのローカルLLM（llama3.2:3b推奨）でモーメントのスコアリングと文章生成を行う
  • YuNetモデルでフェイスカムを自動検出し、9:16フレームへの顔の最適配置を実現
  • NVENCによるGPUエクスポートをサポートし、x264フォールバックも内蔵

試し方

  1. Python 3.10以上とFFmpegをPATHにインストールする（Windowsはワンクリックの.batが自動処理）
  2. リポジトリをクローンしてプロジェクトディレクトリへ移動する
  3. 起動スクリプトを実行し、ブラウザでhttp://127.0.0.1:8770を開く
  4. 任意でOllamaをインストールしllama3.2:3bモデルを追加するとAI機能が有効になる
git clone https://github.com/iamajmeena/neonclipping
cd neonclipping
./run.ps1   # Windows
./run.sh    # Linux / macOS
