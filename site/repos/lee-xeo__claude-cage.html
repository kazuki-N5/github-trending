Lee-xeo/Claude-Cage

Go 初掲載 2026-11-11（Trendshift 18位） GitHub ↗

Claudeを使うための隔離ワークスペースをMac/Windows/Linuxで提供するデスクトップアプリ

何ができるか

  • ホストPCとは独立したネットワーク設定とフィンガープリント（端末識別情報）管理で、Claude利用環境を隔離できる
  • ターミナル・ブラウザ・コードエディタ（code-server）を1つのウィンドウにまとめたワークベンチを提供する
  • macOS・Windows・Linuxの仮想マシンを作成し、各プラットフォームのネイティブツールをそのまま使える
  • Clash/Mihomoを使ったプロキシ管理でノードの選択や出口IPの確認ができる
  • Tailscale（プライベートVPN）を通じてVPSやLAN内のデバイスに接続できる
  • スマートフォン（Android/iPhone）から電脑上のClaude Codeセッションを引き継いで操作できる

なぜ注目されているか

推測 Claudeは地域制限やアカウント停止リスクがあり、VPSや指紋ブラウザを個別に管理する手間を解消するために作られたと考えられる。仮想マシンとプロキシを1つのアプリに統合することで、セットアップの複雑さを大幅に減らしている点が評価されている。

どんな人に役立つか

地域制限のある環境でClaudeを安定して使いたい開発者や、Claude Codeを複数のプロジェクトで安全に切り替えて使いたい人に向いている。VPSやリモート環境にClaudeの作業環境を移したいエンジニアにも役立つ。

技術的なポイント

  • Goで実装されたデスクトップアプリで、agent-vm（Lima）を基盤に仮想マシンを管理している
  • MihomoをプロキシコアとしてVM内のすべてのトラフィックを制御し、ホストのネットワークとの直接接続を防ぐ
  • noVNCでブラウザ経由のリモートデスクトップ表示を実現している
  • gvisor-tap-vsockで仮想マシンと外部ネットワーク間の通信を管理している

試し方

  1. プロジェクト公式ページ（https://lee-xeo.github.io/Claude-Cage/#download）からプラットフォームに合ったインストーラーをダウンロードする
  2. macOSでは.dmgを開いてCageをApplicationsにドラッグし、WindowsではREADMEのWindows手順に従う
  3. アプリを起動してClash/Mihomo形式のプロキシ設定をインポートし、ノードを選んで「プロキシを適用」をクリックする
  4. クライアントOSを選択して環境を起動し、ターミナルで `claude` と入力してClaudeを始める
