google/opensk

Rust 初掲載 2026-11-05（はてなブックマーク 1位） GitHub ↗

FIDO U2F/FIDO2対応のセキュリティキーをRustで実装した研究・教育向けOSS

何ができるか

  • FIDO2（WebAuthn）とFIDO U2F両対応のセキュリティキー機能をRustで完全実装している
  • 最新のCTAP v2.2仕様（リリース候補版）を追跡しており、CTAP 2.0版はFIDO認定済み
  • nRF52840マイコンボード（Nordic製の低消費電力マイコン）上でWasefireアプレットまたはライブラリとして動作する
  • どちらのプロトコルで作成した非発見的認証情報も相互に利用できる互換性を持つ
  • 量子コンピューター耐性を持つポスト量子暗号のハイブリッド実装をhybrid-pqcタグで別途提供している

なぜ注目されているか

推測 GoogleがFIDO2セキュリティキーの完全なオープンソース実装を公開しており、ハードウェアセキュリティキーの内部構造を学ぶ研究・教育用途として注目されている。ポスト量子暗号ハイブリッド実装が2023年ACNS国際会議（暗号実装に関する著名な学術会議）でベストペーパー賞を受賞した点も話題の一因となっている。

どんな人に役立つか

FIDOセキュリティキーの内部実装を学びたいセキュリティ研究者や情報系学生に適している。自作ハードウェアセキュリティキーを作りたい組込み開発者や、ポスト量子暗号を実際のデバイスで実験したい研究者にも役立つ。

技術的なポイント

  • nRF52840マイコン（BLE・USBを備えた低消費電力マイコン）をターゲットハードウェアとして使用し、複数のボードバリアントに対応する
  • 暗号処理はRustCryptoライブラリで実装しており、将来的にはARM CryptoCell-310ハードウェアアクセラレーターへの移行が予定されている
  • ポスト量子暗号のハイブリッド実装がhybrid-pqcタグで提供されており、既存の公開鍵暗号と組み合わせて量子耐性を高める研究に活用できる

試し方

  1. docs/install.md の手順に従い開発環境とツールチェーンをセットアップする
  2. nRF52840対応ボード（nRF52840-DK等）にファームウェアを書き込む
  3. webauthn.io などのデモサイトでセキュリティキーの登録・ログインをテストする
  4. 問題が発生した場合はdocs/debugging.mdを参照する
