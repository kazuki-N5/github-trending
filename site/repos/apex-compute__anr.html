apex-compute/ANR

C++ 初掲載 2026-11-13（Trendshift 12位） GitHub ↗

ゲーム向けニューラルレンダリング（フレーム生成・超解像）ツール群

何ができるか

  • ANR FG（フレーム生成）: AIを使ってゲームのフレームレートを向上させるベータ版機能を提供する
  • ANR SR（超解像）・ANR RR（レイ再構成）: 低解像度映像を高画質化する機能を将来提供予定である
  • nr-record: ゲームのフレーム生成や超解像への入力データを録画し、ANR FG・DLSS・FSR・XeSSなど複数の生成器で再生して比較できる
  • マルチGPU対応: NVIDIA RTX/GTX、AMD Radeon、Intel Arcなど幅広いGPUに対応している
  • Windows 10/11とLinux（Proton経由のSteam Deck含む）の両方で動作する

なぜ注目されているか

推測 NVIDIAのDLSS-Gのようなフレーム生成技術が注目される中、特定GPUベンダーに依存しないオープンな代替実装として関心を集めていると考えられる。推測 nr-recordによる複数アルゴリズムの客観的な比較機能が、技術的な検証ツールとして評価されている可能性がある。

どんな人に役立つか

高フレームレートのゲーム体験を求めるゲーマーや、フレーム生成・超解像アルゴリズムを比較研究したい開発者・研究者に役立つ。NVIDIA製品以外のGPUでもフレーム生成を試したいAMDやIntelユーザーにとっても有用である。

技術的なポイント

  • D3D12（DirectX 12）とVulkanという低レベルグラフィクスAPIを用いて、GPU上でニューラル推論を実行する
  • Bazel（Googleが開発したビルドシステム）を使ってプロジェクトをビルドする
  • OptiScaler（GPL-3.0ライセンスのアップスケーリングミドルウェア）をゲームへの統合の基盤として利用する
  • フレーム生成のアドオンモードでは、既にOptiScalerを使用しているゲームに追加インストールできる構成をとる

試し方

  1. GitHubのReleasesページからanr-fg-full（OptiScaler未使用ゲーム向け）またはanr-fg-addon（既存OptiScaler使用ゲーム向け）をダウンロードする
  2. ゲームを終了し、ダウンロードしたパッケージを展開してゲームの.exeがあるフォルダに対してインストーラーを実行する
  3. Linux/Steam DeckのProton環境では、ゲームの起動オプションにも指定が必要である
  4. ゲーム内設定でフレーム生成を有効にして動作を確認する
  5. アンインストールする場合は同梱のアンインストールスクリプトを同フォルダに対して実行する
