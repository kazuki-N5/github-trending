KytyPS5/KytyPS5

C++ 初掲載 2026-11-20（Trendshift 18位） GitHub ↗

Windows・Linux・macOS 向け PlayStation 5 トランスレーションレイヤー（C++製・オープンソース）

何ができるか

  • PlayStation 5 ゲームを Windows および Linux で動作させることができる
  • 実験的に macOS（x86-64 環境で Rosetta 2 と MoltenVK 経由）もサポートする
  • グラフィカルランチャーからゲームフォルダを追加して起動できる
  • ELF ファイルや ZArchive（.zar）ダンプを --game オプションで直接指定して実行できる
  • 公式リリースには SHA-256 チェックサムを検証する組み込みの自動アップデーター機能が含まれる

なぜ注目されているか

推測 PS5 向けのオープンソーストランスレーションレイヤーはまだ非常に希少であり、活発な開発が続いている点が注目を集めていると考えられる。既存の Kyty プロジェクトを大幅に改造した実績があり、shadPS4 などを参考にしている技術的な信頼性も評価されている可能性がある。

どんな人に役立つか

PS5 ゲームを PC 環境で動作させることに関心を持つ開発者や研究者に役立つ。ゲームの互換性テストに参加したいコントリビューターや、エミュレーション技術を学びたい学生にも適している。

技術的なポイント

  • C++ で実装されており、CMake と Ninja を使ってビルドシステムを構成している
  • コンパイラは Clang を使用しており、MSVC（cl.exe）は非対応である
  • UI フレームワークとして Qt 6 を採用し、グラフィカルランチャーを提供している
  • シェーダー処理に glslang を使用して GPU 命令の変換を行っている
  • macOS では Rosetta 2 と MoltenVK を通じて x86-64 エミュレーションと Vulkan サポートを実現している

試し方

  1. CMake、Ninja、Clang、Qt 6、glslang、Python 3 をインストールする
  2. リポジトリをクローンし、CMake でビルドを設定する
  3. Ninja でビルドを実行する
  4. グラフィカルランチャーを起動してゲームフォルダを追加するか、--game オプションでゲームのパスを指定して実行する
