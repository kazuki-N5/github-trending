vercel-labs/agent-desktop

Rust 初掲載 2026-11-01（Trendshift 2位） GitHub ↗

AIエージェントがOSのアクセシビリティツリーでデスクトップアプリを安定操作できるCLI

何ができるか

  • デスクトップアプリのUI構造をOSのアクセシビリティツリー経由でJSONスナップショットとして取得できる
  • 各UI要素に参照（ref）を割り当て、ピクセル推測に頼らず安全に操作・再試行できる
  • macOS・Windows・Linux対応のCLIツールおよびCライブラリとして提供されている
  • npmでインストール可能で、観察・操作・キーボード・マウスなど約60種類のコマンドを提供する
  • C FFIライブラリ（libagent_desktop_ffi）により、他のプログラムからインプロセスで呼び出せる
  • エージェント向けに組み込みドキュメント（skills get desktop / platform）を内蔵している

なぜ注目されているか

推測 AIエージェントによるコンピュータ操作（Computer Use）の需要が高まる中、画面ピクセルを解釈する手法より信頼性の高いアクセシビリティツリーを活用した手法として注目されていると考えられる。推測 Vercel Labsが公開していることから、AIエージェントとデスクトップGUIの連携を標準化しようとする取り組みとして関心を集めているとみられる。

どんな人に役立つか

AIエージェントにデスクトップ自動化機能を組み込みたい開発者に向いている。コンピュータ操作を行うAIエージェントを構築・研究しているエンジニアや研究者にも活用できる。デスクトップアプリのテスト自動化やRPA（ロボティック・プロセス・オートメーション）に興味がある学生にも参考になる。

技術的なポイント

  • Rustで実装されており、パフォーマンスと安全性を確保しつつmacOS・Windows・Linuxのクロスプラットフォームに対応している
  • OSごとのアクセシビリティAPI（macOS: AX API、Windows: UI Automation、Linux: AT-SPI2）を通じてUI要素の実構造にアクセスする
  • スナップショットとrefの組み合わせにより、操作対象が古くなった場合はエラーを返して再スナップショットを促す安全な設計になっている
  • C FFI（Foreign Function Interface：異なるプログラミング言語間でCライブラリを共有する仕組み）によりRust以外の言語からも組み込み可能
  • レスポンスはJSONエンベロープ形式（okフィールド＋dataまたはerror）で統一されており、エージェントが扱いやすい設計になっている

試し方

  1. npmでグローバルインストールする
  2. ターミナルでスナップショットコマンドを実行し、アプリのUI構造（JSON）を確認する
  3. 取得したrefを指定して操作コマンドを実行し、再度スナップショットで結果を確認する
  4. 組み込みドキュメントコマンドでOS別の詳細な使い方を参照する
npm install -g agent-desktop
agent-desktop skills get desktop
agent-desktop skills get platform
