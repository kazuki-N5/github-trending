coollabsio/coolify

PHP 初掲載 2026-10-26（Trendshift 20位） GitHub ↗

自分のサーバーで動かせるオープンソースのPaaSプラットフォーム

何ができるか

  • GitHub、GitLab、Bitbucket、Giteaからのビルドに対応し、Nixpacks、Railpack、Dockerfile、Docker Compose、プリビルドイメージを使ってデプロイできる
  • 360以上のワンクリックサービスと永続ストレージ付きのマネージドデータベースを提供する
  • Gitプッシュ時の自動デプロイ、プルリクエストプレビュー、Webhook、保持イメージへのロールバックをサポートする
  • カスタムドメイン、自動HTTPS、リバースプロキシ、ヘルスチェック、コンテナネットワークを自動管理する
  • 複数サーバーの統合管理、ログ閲覧、コンテナターミナル、リソースモニタリングができる
  • ダッシュボード、API、CLI、MCP、チームアクセス制御を備えた統合管理環境を提供する

なぜ注目されているか

Heroku、Netlify、Vercelといった商用PaaSの代替として、自分のサーバー上で同等の機能を無料で利用できる点が注目されている。SSH接続のみで動作するためVPS、ベアメタル、Raspberry Piなどあらゆるサーバー環境に対応できる。自己ホスト版は無料で利用可能で、高可用性が必要なチーム向けには有料のCoolify Cloudも用意されている。

どんな人に役立つか

自社インフラを所有しながらHerokuやVercelのような使いやすいデプロイ体験を求めるエンジニアやチームに向いている。コスト削減のためクラウドPaaSから移行したい開発者や、データを自分のサーバーに保管したい企業にも適している。

技術的なポイント

  • サーバーへのSSH接続のみで動作し、VPS、ベアメタル、Raspberry Piなど様々な環境に対応する
  • PHPベースのプラットフォームで、DockerおよびDocker Composeを活用してアプリケーションをデプロイする
  • Nixpacks、Railpack、Dockerfile、Docker Composeなど複数のビルド方式をサポートする
  • 単一のインストールスクリプトで簡単にセットアップでき、READMEからスクリプトの内容を事前に確認できる

試し方

  1. READMEに記載されているインストールガイドのリンクを確認する
  2. 公式インストールスクリプトをダウンロードして内容を確認する
  3. スクリプトを実行してCoolifyをインストールする
