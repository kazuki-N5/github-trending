paisu-supai/sonoba

初掲載 2026-11-11（はてなブックマーク 1位） GitHub ↗

画面上の文字をOCRで読み取り訳文に置き換えて表示するWindows 11向け常駐アプリ

何ができるか

  • 画面の任意の範囲を選ぶだけでOCR（画像から文字を認識する技術）と翻訳を実行し、訳文を元の文字の位置に重ねて表示する
  • リアルタイムモードでは画面の変化を検知して自動的に訳文を更新し続ける
  • 翻訳先として日本語・やさしい日本語・英語・韓国語・中国語を選べる
  • 処理はすべてPC内で完結するため、テキストが外部サーバーに送られない
  • PLaMo 3 Translate（0.8B〜31B）とHy-MT2から翻訳モデルを選択でき、GPU・CPU混在実行にも対応する
  • DiscordやOBSの画面共有・録画に訳文を映す機能を持つ

なぜ注目されているか

推測 Google翻訳の画像翻訳に近い体験をオフラインで実現し、ゲームや動画視聴など外国語コンテンツのリアルタイム翻訳に使える点が注目されていると考えられる。PC内完結でプライバシーを守りながら高品質な翻訳が使える点と、PLaMo 3 Translateという日本語特化モデルを採用している点も話題になっている。

どんな人に役立つか

外国語のゲーム・動画・ソフトウェアを日本語で楽しみたいWindows 11ユーザーに向いている。機密データを含む業務画面を翻訳したいが外部送信を避けたい場合にも適している。

技術的なポイント

  • OCRにはPP-OCRv6 smallをrtenn（Rustのニューラルネット実行ライブラリ）でCPU実行しており、OCRモデルはexeに埋め込まれている
  • 翻訳エンジンとしてllama-serverを起動しHTTPでリクエストを送る方式を採用している
  • 翻訳テキストを約240文字ずつ4並列でllama-serverに送り、1行生成されるごとに画面に表示する
  • 重ね表示はWindows APIの透過色付き最前面ウィンドウで実現しており、クリック・スクロール操作が訳文を通り抜けて下のウィンドウに届く

試し方

  1. GitHubのリリースページからsonoba.zipをダウンロードして好きなフォルダに展開する
  2. sonoba.exeを起動すると初回ガイドが開くので、表示言語と翻訳モデルを選ぶ
  3. PLaMo 3 Translateを選択した場合はPLaMoコミュニティライセンスへの同意が必要なので画面の指示に従う
  4. Ctrl+Alt+Tを押して翻訳したい範囲をドラッグで選択すると翻訳が実行される
  5. Ctrl+Alt+Rでリアルタイム翻訳モードを開始し、Ctrl+Alt+Xで停止できる
