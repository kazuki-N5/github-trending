AIコーディングエージェントをスマホやブラウザから操作できるコントロールパネル

何ができるか

  • Claude Code、Codex、Cursor、Grokなど複数のAIコーディングエージェントをまとめて管理できる。
  • iOS・Android モバイルアプリ、Webブラウザ、Electronデスクトップアプリの3種類のクライアントから操作できる。
  • コマンドラインツール（`t3`コマンド）でローカルサーバーを起動し、ブラウザ経由でアクセスできる。
  • winget、Homebrew、apt、Nix など主要パッケージマネージャー経由でデスクトップアプリをインストールできる。
  • リモートアクセス、MCPコネクション（モデルにツールや外部サービスを接続する仕組み）、バックグラウンドサービスとしての実行など高度な機能をサポートする。

なぜ注目されているか

推測 AIコーディングエージェントが普及する中で、複数のエージェントをモバイルや遠隔地から統一インターフェースで制御したいという需要が高まっていると考えられる。推測 t3スタック（TypeScriptを中心にしたWebフルスタック構成）で知られるping.gg（Theo）が開発しているため、その知名度からコミュニティの注目を集めていると思われる。

どんな人に役立つか

Claude CodeやCursorなど複数のAIコーディングツールを活用している開発者で、外出中にスマートフォンからエージェントを操作したい人に向いている。複数のAIサービスのサブスクリプションを持ち、それらを一元管理したいエンジニアにも適している。

技術的なポイント

  • TypeScript製で、モバイル（iOS/Android）・Web・Electronデスクトップの複数プラットフォームに対応している。
  • Claude Code、Codex、Cursor、Grok Build、OpenCode、Google Antigravityなど主要AIエージェントをサポートする。
  • `npx t3@latest` で事前インストール不要で試すことができる（npxはNode.jsのパッケージ一時実行コマンド）。
  • MCPコネクション（Model Context Protocol: モデルに外部ツールを接続する標準仕様）をサポートしている。
  • プロジェクトは初期段階のため外部コントリビューションは現在ほぼ受け付けていない。

試し方

  1. 利用したいAIコーディングエージェント（Claude Codeなど）を事前にインストールしてサインインしておく
  2. t3コマンドをインストールする（macOS/Linuxはシェルスクリプト、WindowsはPowerShellスクリプト、または npx で試す）
  3. `t3` コマンドを実行するとローカルサーバーが起動しWebアプリが開く
  4. または公式サイトのGitHub Releasesからデスクトップアプリをダウンロードしてインストールする
