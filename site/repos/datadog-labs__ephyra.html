datadog-labs/ephyra

初掲載 2026-11-28（はてなブックマーク 1位） GitHub ↗

AIエージェントがテストジェネレーターを自動最適化するプロパティベーステストライブラリ

何ができるか

  • プロパティ（性質）を定義するだけで、コードカバレッジを測定しながらテストケースジェネレーターを自動的に改善する
  • SQLite・PostgreSQL・Leanなど複数の実績あるシステムで70件以上のバグを発見した実績がある
  • 失敗時に最小限の再現ステップを出力し、EPHYRA_REPLAY環境変数で該当ケースを即再実行できる
  • エージェント向けのプロンプトひな形を用意しており、coding agentに渡すだけでテスト自動化を開始できる
  • ephyra CLIでスイートを実行し、ローカルページで結果を視覚的に探索できる

なぜ注目されているか

DatadogのSystems Researchチームが開発したOSSで、カバレッジガイデッドファジングに似たアプローチをLLMエージェントで実現した点が新しい。FoundationDBやTigerBeetのような高度にテストされたシステムでもバグを発見できたことが実証されている。

どんな人に役立つか

RustでOSSライブラリやデータベースなどの信頼性の高いソフトウェアを開発しているエンジニア向け。AIコーディングエージェントと組み合わせて自動的にプロパティテストを書いてもらいたい場合にも適している。

技術的なポイント

  • カバレッジガイデッドファジング（CGF）が既存入力を変異させるのとは異なり、ジェネレーター自体をLLMが書き換えて新しいコードパスを探索する帰納的アプローチを採用している
  • Rustで実装されており、#[ephyra::test]アトリビュートをつけるだけで既存のcargo testに組み込める
  • .ephyra/regressions/に失敗ケースを保存し、次回実行時に優先的に再試行してリグレッションを防ぐ
  • EPHYRA_TESTS・EPHYRA_SEED・EPHYRA_BUDGET_MSなどの環境変数でコードを変えずに挙動を制御できる

試し方

  1. Cargo.tomlの[dev-dependencies]にephyra = "0.0.1"を追加する
  2. #[ephyra::test]アトリビュートでプロパティテスト関数を書く
  3. cargo testを実行してプロパティを検証する
  4. cargo install ephyra-cliでCLIをインストールし、ephyra testでスイートを実行する
cargo install ephyra-cli
ephyra test
cargo run -p ephyra --example bst -- --bug
