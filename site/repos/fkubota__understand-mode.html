Claude Codeの出力・PR・コードを、付箋ホワイトボードで寄り道しながら理解するスキル

何ができるか

  • 選択したコード行や文に対して、質問・詳しく・用語・図・データ・レビューなど6種類の付箋を生成できる
  • Mermaid記法で図を、Vega-Liteでグラフを描画して視覚的に理解を助ける
  • データ付箋では承認したSELECT文のSQLのみを実行し、表・グラフ・SQLを並べて表示する
  • 付箋内の分身がメインの会話コンテキストを引き継ぐため、本筋の会話を汚さずに寄り道できる
  • 「理解を終える」操作で寄り道の内容を本筋へのコメントとして下書きし、送信後に寄り道記録を破棄する

なぜ注目されているか

Claude Codeを使っていると、出力やコードを理解したい箇所が出てくるが、その疑問をメインの会話に挟むと文脈が乱れる問題がある。このスキルは付箋という「寄り道専用の場所」を提供することで、本筋を汚さずに深掘りできる体験を実現している。推測 Mermaid図やVega-Liteグラフといった可視化機能を組み合わせることで、コードや概念の理解を促進する点が注目されている。

どんな人に役立つか

Claude Codeを日常的に使っているエンジニアや、PRレビュー・コードリーディングを頻繁に行う開発者向け。疑問が浮かんだ瞬間に脱線せず深掘りしたい場面で役立つ。

技術的なポイント

  • Claude Codeのスキル機能（/understandコマンド）として実装されており、Node.js 18以上が必要
  • 付箋内の分身はメイン会話全体のコンテキストを読み込むため、長い会話では費用（APIトークン数）が増加する
  • グラフ描画にVega-Lite（宣言的な可視化ライブラリ）、図描画にMermaid（テキストからダイアグラムを生成するツール）を使用
  • データ付箋のSQL実行は安全性のためSELECTまたはWITHで始まる1文のみに制限されている
  • npm run mockコマンドでAPIコストをかけずにUIの動作確認が可能な開発者向けモック機能を備える

試し方

  1. リポジトリをgit cloneする
  2. bash install.shを実行してスキルをインストールする
  3. Claude Codeで/understandコマンドを起動し、やりたいことの説明・PR番号・ファイルパスなどを引数に指定する
git clone https://github.com/fkubota/understand-mode
bash install.sh
/understand <やりたいことの説明 or PR番号 or ファイルパス or diff>
