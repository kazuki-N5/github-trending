stablyai/orca

TypeScript 初掲載 2026-10-19（GitHub Trending 7位） GitHub ↗

複数のAIコーディングエージェントを並列に動かして管理するデスクトップアプリ

何ができるか

  • Codex、Claude Code、OpenCode などのエージェントを、それぞれ独立した git worktree（同じリポジトリを別フォルダで同時に作業できる仕組み）で並べて実行できる。
  • 1つのプロンプトを複数のエージェントに同時に投げ、結果を比べて良いものをマージできる。
  • スマホのコンパニオンアプリから、エージェントの完了通知を受けたり追加の指示を送ったりできる。
  • AIが出した差分の行にコメントを付けてエージェントに送り返し、レビューからコミットまでアプリ内で完結できる。
  • SSH 経由でリモートマシン上のエージェントを動かせ、自動再接続やポートフォワーディングにも対応する。
  • GitHub の PR・Issue や Linear のタスクをアプリ内で閲覧し、そこから worktree を作成できる。

なぜ注目されているか

ターミナルで動くCLIエージェントならどれでも動かせ、多数のエージェントを1か所でまとめて追跡できる点が特徴として挙げられている。推測 複数のエージェントを同時並行で使う開発スタイルが広がっており、その管理を楽にするツールとして注目されていると考えられる。

どんな人に役立つか

複数のAIコーディングエージェントを同時に走らせて作業を進めたい開発者や、外出先からもエージェントの進み具合を確認したい人に向いている。

技術的なポイント

  • 各エージェントの作業を git worktree で分離し、互いの変更がぶつからないようにしている。
  • WebGL 描画のターミナルを内蔵し、無制限の画面分割や再起動後も残るスクロールバックを備える。
  • 実際の Chromium ウィンドウ上でUI要素をクリックすると、その HTML・CSS・切り抜き画像をエージェントのプロンプトへ送る Design Mode がある。
  • orca worktree create などのコマンドを持つ Orca CLI があり、エージェント自身が Orca を操作できる。
  • モバイルアプリとデスクトップをつなぐリレーサーバーも cloud/ ディレクトリに含まれている。

試し方

  1. onOrca.dev または GitHub の Releases から、自分のOS向けのデスクトップアプリをダウンロードしてインストールする。
  2. macOS では Homebrew、Arch Linux では AUR からもインストールできる。
  3. スマホからも操作したい場合は、iOS の App Store または Android の APK からコンパニオンアプリを入れ、デスクトップアプリとペアリングする。
brew install --cask stablyai/orca/orca
yay -S stably-orca-bin
