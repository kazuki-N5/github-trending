JiaFeiMiao-K-Cat/DiscImageStudio

C# 初掲載 2026-11-03（Trendshift 7位） GitHub ↗

画像をCD・DVD・BD-Rのディスク面に焼き付けてデザインを可視化するツール

何ができるか

  • 画像データをCD・DVD・BD-Rの物理的なディスク面に印刷できる形式に変換できる
  • Windowsデスクトップアプリでデザインから書き込みまで一貫して行える
  • キャリブレーション支援ワークフローでディスクの物理パラメータを最適化できる
  • IMAPI2を使用したWindowsネイティブの直接ストリーミング書き込みにも対応している（実験的）
  • ディスクにデータファイルも同時収録できる
  • 簡体字中国語・繁体字中国語・英語・日本語の多言語UIに対応している

なぜ注目されているか

推測 ディスクメディアへのビジュアル印刷という独自のニッチに特化しており、類似ツールが少ないため注目されていると考えられる。CD・DVD・BDという3世代のメディアをすべてカバーし、オフラインで動作してテレメトリなしというプライバシー配慮の設計も評価されている。

どんな人に役立つか

コレクター向けや特別なプレゼント用にオリジナルデザインのディスクを作りたいユーザーに役立つ。音楽や映像を配布する際にパッケージ性を高めたいアーティストやクリエイターにも適している。

技術的なポイント

  • .NET 10 SDKで実装されており、リリースパッケージには.NETランタイムが同梱されている
  • CD出力はWAV/CUEまたはRAWオーディオ形式、DVD出力はISO形式、BD-RはUDF 2.01をサポートする
  • ECMA-394（CD-R）・ECMA-267（DVD-ROM）・ECMA-359（DVD-R）・ISO/IEC 30190:2021（BD-R）などの標準規格を参照している
  • Windows IMAPI2を通じた実験的な直接ストリーミング書き込み機能を実装している

試し方

  1. Windows 10 2004以降またはWindows 11の環境を用意する
  2. GitHubリリースページからインストーラーまたはポータブルパッケージをダウンロードする
  3. アプリを起動してキャリブレーションワークフローを実行する
  4. 画像をデザインしてISO・WAV/CUEなど対応形式でエクスポートするか、直接書き込みを行う
