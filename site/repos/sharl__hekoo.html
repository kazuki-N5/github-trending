タスクバーにメッセージや画像を表示するPoCツール

何ができるか

  • タスクバー上にテキストセグメントをリアルタイムで表示できる
  • base64エンコードした画像もタスクバーに送信して表示可能
  • ローカルHTTPサーバー（ポート19876）経由でデータを受け付ける
  • HTTP POSTリクエストでJSONデータを送ることでコンテンツを更新できる
  • Museと連携して動作するプルーフオブコンセプト実装

なぜ注目されているか

推測 Museのようなタスクバーツールと連携し、天気情報や通知などをタスクバーに表示できる点で実用性がある。KrisGfxのワイヤレスデバイスバッテリーモニターからヒントを得ており、HTTP経由でカスタムデータをタスクバーに送るアーキテクチャの参考例として注目に値する。

どんな人に役立つか

Museユーザーでタスクバーにカスタム情報を表示したい人向け。curlやスクリプトからHTTP経由でタスクバーにデータを送りたいPythonユーザーや開発者にも適している。

技術的なポイント

  • Pythonで実装されたローカルHTTPサーバー
  • ポート19876でHTTP POSTリクエストを受け付けるJSON API
  • テキストおよびbase64エンコード画像の両方を処理できる
  • Pythonの仮想環境（venv）で依存関係を管理

試し方

  1. リポジトリをクローンする
  2. Pythonの仮想環境を作成し有効化する（WindowsではPowerShellで.venvフォルダを作成）
  3. requirements.txtから依存関係をインストールする
  4. hekoo.pyを実行してサーバーを起動する
  5. curlとjoを使ってlocalhost:19876にHTTP POSTリクエストを送信する
git clone https://github.com/sharl/hekoo
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python hekoo.py
