手持ちのSwitchゲームをエミュレータなしでiPhoneやiPadでネイティブ実行する変換ツール

何ができるか

  • 自分の Nintendo Switch ゲームの NSP ファイル（ゲームのパッケージ）と prod.keys から、スクリプト1本で iPhone や iPad 用の IPA（iOS アプリのパッケージ）を作れます。
  • 作った IPA は AltStore や Sideloadly などのサイドロード（App Store を通さずにアプリを入れること）ツールで端末にインストールします。
  • スーパーマリオブラザーズ ワンダー、ゼルダの伝説 ブレス オブ ザ ワイルドなど多数のタイトルが iPhone で動作確認済みで、一部は更新データ適用時に60fpsで動きます。
  • 起動前の設定画面でフレームレート、描画解像度、据え置き・携帯モード、言語を選べ、タッチ操作の2D・3Dレイアウトやゲームコントローラーにも対応します。
  • Apple の開発者アカウントがあれば、IPA の代わりに Xcode プロジェクトを作って実機へ直接インストールすることもできます。

なぜ注目されているか

エミュレータ（別の機械の動作をソフトウェアで再現するもの）ではなく、ゲーム自身のコードを Apple のチップで直接動かし、グラフィックスを Metal で作り直すという方式を採っています。リポジトリページでは公開から短期間で2千を超えるスターを集めています。推測 人気タイトルが iPhone で、しかも元の Switch より高いフレームレートで動く例があることが注目の理由と考えられます。

どんな人に役立つか

Switch のゲームを自分で所有していて、iPhone 15 Pro 以降や M1 以降の iPad で遊びたい人に向いています。ゲーム機のバイナリ変換やグラフィックス API の変換の仕組みを学びたい人にも参考になります。

技術的なポイント

  • NSO（Switch の実行ファイル形式）を書き換えるリライター、Switch の OS である Horizon の代わりを務めるホスト、NVN（Switch のグラフィックス API）を Metal 上で動かす層で構成されています。
  • Ryujinx のシェーダー変換器でゲームの Maxwell 向けシェーダーを SPIR-V に変換し、SPIRV-Cross で Metal Shading Language に変換します。
  • ゲームのテクスチャは BC 圧縮形式のため、それを読める A17 Pro 以降の iPhone か M1 以降の iPad と、iOS/iPadOS 26 以降が必要です。
  • d2r-mobile が開発したネイティブ実行の手法をもとにしており、NSP の読み込みには LibHac を使っています。
  • リポジトリにはゲームのデータは一切含まれず、ライセンスは MIT です。

試し方

  1. Xcode と Homebrew の入った Mac にリポジトリを取得し、必要なツールをインストールします。
  2. 1本のゲームの NSP（本体、あれば更新データと DLC）を1つのフォルダに入れます。
  3. build_ipa_from_nsp.py にフォルダと prod.keys を指定して IPA を作ります（初回は30〜60分かかります）。
  4. できた IPA をサイドロードツールでインストールし、可能なら Increased Memory Limit の権限を付けて署名します。
git clone https://github.com/seedds/nxnative.git && cd nxnative
brew install xcodegen zstd spirv-cross glslang
brew install --cask dotnet-sdk
python3 -m pip install lz4 capstone fonttools "backports.zstd; python_version < '3.14'"
python3 scripts/build_ipa_from_nsp.py ~/Games/MarioWonder -k ~/keys/prod.keys
