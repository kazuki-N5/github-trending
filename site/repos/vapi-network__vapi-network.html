vAPI-Network/vapi-network

TypeScript 初掲載 2026-11-07（Trendshift 8位） GitHub ↗

AIエージェント向けx402プロトコルのUSDC決済クライアント（ノンカストディアル）

何ができるか

  • x402プロトコルを使ってBase（ブロックチェーン）上でUSDCによるAPI利用料を直接支払える
  • デバイスボルト（端末内暗号化ストレージ）で秘密鍵をローカルに安全に管理する
  • 支払い前に支出ポリシーを適用し、ローカルに領収書を保存するため中間者なしで決済できる
  • ターミナル・MCPクライアント・自作コードのいずれからも利用できる
  • AIエージェントが自分のウォレットを持って上限付きで自律的にAPI利用料を支払えるAgentsモードがある

なぜ注目されているか

AIエージェントが自律的にAPIを呼び出して料金を支払うユースケースが注目されており、ノンカストディアル（自分で鍵を管理）かつオンチェーン決済という仕組みが新しい。x402という新興支払いプロトコルへの対応も話題性を高めている。

どんな人に役立つか

AIエージェントに自律的なAPI利用・課金フローを組み込みたい開発者、またはブロックチェーン上での分散型APIマーケットプレイスに興味がある人に向いている。

技術的なポイント

  • x402プロトコル（HTTP上でのマイクロペイメント仕様）を実装したTypeScriptクライアントである
  • Base（Ethereum L2）上でUSDCを使って直接支払いを行うためガス代が安い
  • pnpmワークスペースによる5パッケージ構成でNode.js 22が必要
  • Claude CodeやOpenAI Codexと連携するvapi code installコマンドで開発環境に統合できる

試し方

  1. npm i -g vapi-network でグローバルインストールする
  2. vapi call でAPIの検索・確認・支払いを試す
npm i -g vapi-network
npx vapi-network
