Augani/openreel-video

TypeScript 初掲載 2026-11-23（Trendshift 13位） GitHub ↗

WebGPU搭載のブラウザ完結型オープンソース動画エディタ（CapCut代替）

何ができるか

  • マルチトラックタイムライン上でカット・トリミング・分割・トランジションなどの動画編集ができる。
  • テキストアニメーション20種以上、カラオケ字幕、シェイプ、キーフレームアニメーションによるグラフィック制作が可能。
  • マルチトラック音声ミキシング、EQ・リバーブ・ノイズ除去など豊富な音声エフェクトに対応している。
  • カラーホイール・カーブ・3D LUTを使ったプロ向けカラーグレーディングができる。
  • MP4・WebM・ProRes形式や4K品質での書き出し、AIアップスケーリングに対応している。

なぜ注目されているか

インストール不要でクラウドへのアップロードも不要なブラウザ完結型の動画エディタは稀であり、プライバシーを重視するユーザーに注目されている。CapCutのような商用ツールのオープンソース代替として、透明性と無料利用を求める開発者やクリエイターから評価されている。推測 AI（Claude）が開発を積極的に支援する実験的プロジェクトという点でも、開発手法として関心を集めている。

どんな人に役立つか

ブラウザだけで動画を編集したいクリエイターや、商用ツールのサブスクリプションを避けたい個人ユーザーに適している。クラウドへのアップロードを避けたいプライバシー重視のユーザーにも有用。WebGPUやWebCodecsを使ったブラウザ上の高度な処理技術を学びたいCS学生にとっても参考になる実装例を含んでいる。

技術的なポイント

  • React 18とTypeScriptによるモノレポ構成（apps/webフロントエンドとpackages/coreエンジン）で開発されている。
  • WebGPUによるGPUコンポジティングとWebCodecsによるハードウェアエンコード・デコードを活用し、ブラウザ上での高速処理を実現している。
  • Zustandによる状態管理と、すべての編集操作をアンドゥ可能なイミュータブル設計を採用している。
  • IndexedDBへの自動保存、LRUフレームキャッシュ、Web WorkersによりUIをブロックせずに重い処理をこなす仕組みを持つ。

試し方

  1. openreel.video にアクセスするとインストール不要でブラウザ上からすぐに試せる。
  2. ローカルで動かす場合はリポジトリをクローンし、Node.js 18以上を用意する。
  3. pnpm install で依存関係をインストールする。
  4. pnpm dev で開発サーバーを起動し、http://localhost:5173 にアクセスする。
git clone https://github.com/Augani/openreel-video.git
cd openreel-video
pnpm install
