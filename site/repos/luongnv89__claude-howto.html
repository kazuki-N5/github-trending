図解とコピペ用テンプレートでClaude Codeを基礎から上級まで学べるガイド

何ができるか

  • スラッシュコマンド、メモリ、チェックポイント、スキル、フック、MCP、サブエージェント、プラグインなど、Claude Code の機能を10のモジュールで順に学べます。
  • スラッシュコマンド、CLAUDE.md のテンプレート、フックのスクリプト、MCP の設定、サブエージェントの定義などを、自分のプロジェクトにそのままコピーして使えます。
  • Mermaid（テキストから図を描く記法）の図で、各機能が内部でどう動くかを説明しています。
  • Claude Code で /self-assessment や /lesson-quiz を実行すると、クイズで自分の理解度を確かめ、足りない部分を見つけられます。
  • 初心者から上級者までのレベル別の学習順序と所要時間（全体で11〜13時間）が示されています。
  • 英語のほか、ベトナム語、中国語、ウクライナ語、日本語の README があり、EPUB の電子書籍も生成できます。

なぜ注目されているか

公式ドキュメントが機能の説明中心なのに対し、機能を組み合わせて実際のワークフローを作る方法を、学習順序付きで教える点を打ち出しています。リポジトリページでは4万を超えるスターを集めており、README では Claude Code のリリースごとに内容を更新していると述べています。推測 Claude Code の利用者が増え、体系的に学べる教材の需要が高まっていることが注目の理由と考えられます。

どんな人に役立つか

Claude Code を入れたものの基本的な使い方にとどまっている人や、フックやサブエージェントを組み合わせてコードレビューやドキュメント生成を自動化したい開発者に向いています。チームの新人向けの学習教材としても使えます。

技術的なポイント

  • 各機能はフォルダ（01-slash-commands/ から 10-cli/ まで）に分かれ、説明とすぐ使えるサンプルファイルが入っています。
  • スラッシュコマンドやサブエージェントは Markdown ファイルとして .claude/commands/ や .claude/agents/ に置くだけで使える形式です。
  • フックはシェルスクリプトとして ~/.claude/hooks/ に置き、イベントに応じて自動実行させます。
  • EPUB の生成は uv run scripts/build_epub.py で行い、ライセンスは MIT です。

試し方

  1. ガイドのリポジトリをクローンします。
  2. 最初のスラッシュコマンドを自分のプロジェクトの .claude/commands/ にコピーし、Claude Code で /optimize と入力して試します。
  3. 続けてプロジェクトメモリ（CLAUDE.md）やスキルをコピーして導入します。
  4. 学習ロードマップに沿って各モジュールを進め、終わるたびに /lesson-quiz で理解度を確かめます。
git clone https://github.com/luongnv89/claude-howto.git
cd claude-howto
mkdir -p /path/to/your-project/.claude/commands
cp 01-slash-commands/optimize.md /path/to/your-project/.claude/commands/
cp 02-memory/project-CLAUDE.md /path/to/your-project/CLAUDE.md
cp -r 03-skills/code-review-specialist ~/.claude/skills/
uv run scripts/build_epub.py
