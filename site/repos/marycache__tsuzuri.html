MaryCache/tsuzuri

初掲載 2026-11-24（はてなブックマーク 2位） GitHub ↗

AIが一文ずつ執筆意図を記録しながら日本語文章を書き・見直すスキルとビューアアプリ

何ができるか

  • AIが各文を書く前に執筆意図（その文が読者に何をするか）を記録し、あとから意図と文の一致を確認できる。
  • ビューアアプリで文ごとにコメントを付けて修正を依頼でき、改訂履歴とdiffも確認できる。
  • README・ビジネス文書・ブログ記事などのテンプレートを用意しており、独自テンプレートも追加できる。
  • 既存の文章（人間やほかのAIが書いたもの）を読み込んで意図を推定しながらレビューできる。
  • コアのみフィルターで冗長な記事から必要最小限の文だけを抽出できる。
  • 校正辞書（words.tsv）で表記ゆれの統一を自動化でき、依頼した語の置換をファイルに自動追記できる。

なぜ注目されているか

推測 AIによる文章生成は流暢でも論旨が曖昧になりやすい問題があり、文単位で執筆意図をタグ付けすることでレビュアーが「何がおかしいか」を指摘しやすくした設計が注目されている。日本語に特化した文章支援ツールとして、Claude Codeのスキル機構と組み合わせた実用性も評価されていると考えられる。

どんな人に役立つか

Claude CodeなどAIエージェントを使って日本語の文章（README・提案書・ブログなど）を書くエンジニアや研究者に向いている。文章の品質をレビュープロセスで体系的に管理したいチームにも適している。

技術的なポイント

  • エージェントのスキル機構（npx skills add）を使ってインストールし、AIの執筆フローに組み込む。
  • 執筆要件・設計・意図・機能タグは<ファイル名>.tsuzuriフォルダに保存され、gitignoreデフォルト設定で管理される。
  • Python 3.10以上で動くサーバー（server.py、デフォルトポート8770）とNode.js（npx）が必要。
  • .tszファイルに文章と記録をまとめて他者と共有する仕組みを持つ。
  • yomiyasuという別スキルと連携して文体のポリッシュ（磨き上げ）を行う。

試し方

  1. Python 3.10以上、Node.js、git、yomiyasuスキルを用意する。
  2. npx skills add MaryCache/tsuzuriでスキルをインストールする。
  3. リポジトリをクローンし、python3 tsuzuri/app/server.pyでビューアを起動する。
  4. ブラウザでhttp://localhost:8770にアクセスしてビューアを開く。
