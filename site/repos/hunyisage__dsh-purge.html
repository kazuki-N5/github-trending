JavaScript 初掲載 2026-11-06（Trendshift 19位） GitHub ↗

DeepSeek Harness向けパッチプラグインで、モデルのデフォルト制限を解除しプロンプトを差し替える

何ができるか

  • DeepSeek Harness（DSH）のローカルインストールに直接パッチを当て、デフォルトのポリシー制限を変更する
  • モデル自体の拒否応答と、ホスト層のポリシーによるブロックを区別して可視化できる
  • 暗号化されたデフォルトプロンプトを注入し、パーミッション（権限）やツールの使用制限を上書きする
  • 改変前に元ファイルを自動バックアップするため、元の状態に戻すことができる
  • モデルごとに異なるプロンプトを使い分けられ、デフォルトは国産モデル「小码酱」向けに設定されている

なぜ注目されているか

推測 DeepSeek Harnessのデフォルト設定が過剰に制限的だと感じるユーザーが、モデル本来の制限とホスト側のポリシー設定を切り分けて検証したいというニーズに応えるために注目されている。推測 「破甲（防御を破る）」という直接的なネーミングとGitHubでのStar獲得への呼びかけにより、AIのジェイルブレイク（制限解除）に関心を持つコミュニティで話題になっていると思われる。

どんな人に役立つか

DeepSeek Harnessを使用している開発者や研究者で、モデルの応答制限の仕組みを調査・検証したい人に向いている。AIの安全性や制限ポリシーを研究する目的で、どの制限がどのレイヤーに由来するかを評価したい人にも有用かもしれない。なお、公共システムへの攻撃や特定地域の政府・金融機関への悪用は禁止されており、あくまでローカルのHarnessインストールに対してのみ使用可能とされている。

技術的なポイント

  • JavaScriptで書かれたDSHプラグインとして動作し、`dsh plugin add`コマンドでtarball（圧縮アーカイブ）形式のURLを指定してインストールする
  • `@deepseek-ai`パッケージ内の特定ファイルをマッチングして直接置き換えるファイルパッチ方式を採用している
  • デフォルトのシステムプロンプトを暗号化した形式で保存・注入する仕組みを持つ
  • DSH（DeepSeek Harness）バージョン0.2.1-rc.2および0.2.0に対応した特定バージョン向けの設計になっている
  • Apache-2.0ライセンスを採用しており、フォーク（派生版の作成）時には元リポジトリへの帰属表示が必要とされている

試し方

  1. DeepSeek Harness（DSH）をローカル環境にインストールする（バージョン0.2.1-rc.2または0.2.0が対象）
  2. 公式プラグインマーケットプレイスではなく、GitHubのcodeload.github.comからtarball URLを使って`dsh plugin add`コマンドでプラグインを追加する
  3. DSHのDock（ドック）にあるCleanページからApply（適用）を実行してパッチを当てる
