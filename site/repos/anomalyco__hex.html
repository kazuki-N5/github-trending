anomalyco/hex

Rust 初掲載 2026-11-01（Trendshift 17位） GitHub ↗

ショートカットを押して話すだけでデバイス上で文字起こし・自動ペーストするツール

何ができるか

  • Optionキーを押しながら話し、離すだけで音声をテキスト化してフォーカス中のアプリに自動ペーストする
  • Apple Silicon搭載のmacOS 15以降をネイティブサポートし、WindowsとLinuxもベータ版として利用できる
  • デバイス上のローカル音声認識モデルを使用するため、音声データが外部サーバーに一切送信されない
  • TypeScriptまたはJavaScriptの設定ファイルで独自のテキスト変換処理を追加できる
  • CLIコマンドでアプリ動作中に文字起こし履歴や会議情報を照会できる
  • TypeScript SDK（@kitlangton/hex）を通じて、外部アプリからもローカル文字起こし機能を呼び出せる

なぜ注目されているか

推測 音声入力はまだ多くのアプリで使いにくく、クラウド型の音声認識サービスはプライバシー上の懸念があるため、ローカル処理で安心して使えるツールが注目されている。推測 RustによるネイティブアプリとしてApple Siliconに最適化されており、軽量・高速な動作と幅広いプラットフォーム対応が差別化ポイントとして評価されている。

どんな人に役立つか

音声でメモや文章を素早く入力したい開発者・ライター・研究者に特に役立つ。キーボードを使わずに任意のアプリへテキストを入力したい場面や、アクセシビリティ（利便性向上）の用途にも適している。音声データをクラウドに送らずプライバシーを守りたいユーザーにも最適。

技術的なポイント

  • Rustでネイティブアプリを開発しており、macOS・Windows・Linuxに対応したクロスプラットフォーム設計を採用している
  • オンデバイス音声認識（デバイス上でのみ動作するローカルモデル）を利用しており、ネットワーク接続なしで文字起こしが可能
  • TypeScript/JavaScriptの設定スクリプトをサンドボックス化された組み込みエンジン上で実行し、ファイルシステムやネットワークへのアクセスなしに安全なカスタム変換を実現している
  • Accessibility API（macOSのアクセシビリティ機能）を利用して、フォーカス中の任意アプリへのテキスト自動ペーストを実現している
  • オプションでOpenCodeサービスと連携し、文字起こし結果をAIモデルで追加変換するパイプラインも構築できる

試し方

  1. リリースページからDMG（macOS）またはインストーラー（Windows/Linux）をダウンロードしてインストールする
  2. アプリ起動後、マイクとアクセシビリティの権限を付与し、音声認識モデルをダウンロードする
  3. Optionキーを長押しして話し始め、キーを離すと文字起こし結果がフォーカス中のアプリに自動でペーストされる
  4. Option-Shift-Vを押すと直前の文字起こし結果を再ペーストできる
