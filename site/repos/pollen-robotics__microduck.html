pollen-robotics/microduck

Rust 初掲載 2026-10-26（Trendshift 17位） GitHub ↗

強化学習で動く小型二足歩行ダックロボットのソフトウェア

何ができるか

  • 高さ約25cm・重さ約800gの小型二足歩行ロボット「Microduck」のソフトウェア一式を提供している。
  • 50Hzの制御ループで15本のサーボを動かし、無線・カメラ制御・アップデート機能もサポートしている。
  • 歩行・車輪走行・物体つかみ・転倒後の起き上がりなど複数の強化学習ポリシーをONNX形式で読み込んで実行できる。
  • ゲームパッドで歩行制御ができ、`duckctl`ツールでBluetooth経由のラップトップ操作も可能。
  • ロールバック機能付きのアップデートシステムにより、安全にソフトウェアを更新できる。
  • MuJoCoシミュレーターを使ったデスクトップシミュレーション環境が提供されており、実機なしで開発・テストできる。

なぜ注目されているか

強化学習で訓練したポリシーをONNX経由で小型ロボットに直接デプロイする一貫したパイプラインが整備されている。Rustで書かれた複数デーモン構成でJSON-RPCを使った疎結合設計が採用されており、拡張性が高い。

どんな人に役立つか

ロボット工学や強化学習に興味があるCS学生・研究者向け。小型二足歩行ロボットの実装やMuJoCoを使ったシミュレーションを学びたい人に特に役立つ。

技術的なポイント

  • ソフトウェアはRustのシングルワークスペースで実装されており、制御・更新・WiFi・Bluetooth・カメラなどを担当する複数のデーモンで構成されている。
  • デーモン間の通信はUnixソケット上のJSON-RPCで行われており、疎結合な設計になっている。
  • 強化学習ポリシーは別リポジトリ（microduck_rl）でMuJoCo＋PPOを使って訓練し、ONNXファイルとしてエクスポートして本リポジトリで実行する。
  • ゲームパッド・カメラ・深度センサーを扱うデーモンがそれぞれ独立して動作する構成になっている。
  • `scripts/duck-sim`スクリプトでMuJoCoモデルに対してデーモン群を動かすシミュレーター環境が利用できる。

試し方

  1. `robotctl`コマンドでロボットの状態確認やコマンド操作を行う。
  2. ゲームパッドをペアリングして歩行制御を試す。
  3. `duckctl`ツールでBluetoothを経由してラップトップからロボットを操作する。
  4. シミュレーターを試す場合は`scripts/duck-sim`を実行してMuJoCo環境で動作確認する。
