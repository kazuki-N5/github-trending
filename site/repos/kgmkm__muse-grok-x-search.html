初掲載 2026-11-19（はてなブックマーク 4位） GitHub ↗

MuseにX（旧Twitter）検索機能を追加するGrokベースのスキル

何ができるか

  • MuseからX上の公開投稿・リプライ・引用ツイートをキーワードや文脈で検索できる。
  • 検索結果には日時・アカウント・URLが含まれ、調査・リサーチ用途に使える。
  • 検索専用の読み取り専用設計で、投稿・返信・いいね・リポスト・フォローは禁止されている。
  • Muse上で自然言語による指示（「このリリースへの反応を調べて」など）で操作できる。

なぜ注目されているか

推測 MuseはInstagram・Facebook・ThreadsをサポートするがXには対応していなかったため、そのギャップを埋めるスキルとして注目されている。xAIのGrok Build CLIを活用することでX独自のAPIアクセス問題を回避している点も新しい。

どんな人に役立つか

Museを使って調査・リサーチを行うユーザーで、X上の反応やトレンドを把握したい人向け。SuperGrokまたはX Premiumプランが必要なため、X有料ユーザーが主な対象となる。

技術的なポイント

  • xAIが提供するGrok Build CLIの `x_search` ツールをMuseのスキルから呼び出す仕組みになっている。
  • スキルはMuse用の `SKILL.md` と `skill.yaml` で定義され、カスタムスキルフォルダに配置するだけで導入できる。
  • 初回使用時はデバイスコードによるXアカウントのサインインが必要で、以降はセッションが維持される。
  • 検索結果はGrokが生成したサマリーであり、重要な判断をする前に元の投稿を確認することが推奨される。

試し方

  1. Museにリポジトリ URLを渡すか、`SKILL.md` と `skill.yaml` をMuseのカスタムスキルフォルダにコピーする。
  2. Grok Build CLIをインストールし、PATHに通す。
  3. 初回使用時にMuseからデバイスコードサインインを求められるので、自分のXアカウントでサインインする。
  4. Museに「このキーワードについてXで検索して」のように自然言語で指示する。
