huggingface/pybot

Python 初掲載 2026-11-18（はてなブックマーク 2位） GitHub ↗

AIエージェント群がルールだけで書いたPython製チャットボット（重みなし・学習なし）

何ができるか

  • 機械学習モデルの重みや学習データを一切使わず、if-else・正規表現・ルックアップテーブルだけで会話に応答する
  • 1000以上のエージェントが5000以上のバージョンを生成・評価して作られた約64万行の純Pythonコードで構成されている
  • 複数のモジュールが応答候補を提示し、アービター（調停役）が最良の返答を選ぶモジュール型アーキテクチャを採用している
  • タイポ補正・チャット略語処理・代名詞参照解決など自然言語の前処理を行う理解エンジンを内蔵している
  • Python 3.8以上と標準ライブラリのみで動作し、追加パッケージや重みファイルのダウンロードが不要である

なぜ注目されているか

推測 「LLMなしでチャットボットはどこまで賢くなれるか」という問いへの実験的な回答として注目を集めている。AIエージェントがコードを自動生成し続けてSmolLM-360M-Instructに匹敵するスコアに到達したという報告が、エージェントによるコード生成研究コミュニティの興味を引いている。

どんな人に役立つか

ルールベースのNLP（自然言語処理）やエージェントによる自動コード生成に興味がある研究者・開発者に向いている。依存ライブラリゼロで動くデモが欲しい場合や、小規模なAIシステムの性能を評価したいエンジニアにも有用である。

技術的なポイント

  • 正規表現とルックアップテーブルを組み合わせたルールベースの応答選択で、機械学習モデルを一切使わない設計になっている
  • SmolTalkBench（会話品質のベンチマーク）とLLMジャッジ（大規模言語モデルによる評価）で品質を計測している
  • 約55万行のエージェント自動生成テストコードでカバレッジを担保している

試し方

  1. リポジトリをクローンする
  2. python -m pybot で対話型チャットを開始する
  3. /reset で会話をリセット、/exit で終了できる
git clone https://github.com/huggingface/pybot
cd pybot
python -m pybot
python -m pybot -p "Why do onions make you cry?"
pip install .
python -m unittest discover -s tests
