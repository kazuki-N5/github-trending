1407点のAI生成服飾画像ギャラリーと仮想試着ウェブサイト

何ができるか

  • 春夏秋冬・ランジェリー・パーティー・水着など8カテゴリで1407点のAI生成服飾参考画像を閲覧できる
  • 中国語・英語のキーワード検索とカテゴリフィルタリング、フルスクリーン表示・キーボードナビゲーションに対応している
  • ポートレート写真をアップロードしてギャラリーの服や自前の画像を選びAI仮想試着画像を生成できる
  • OpenAI互換API・Gemini・Doubao Seedreamなど複数のAIバックエンドをAPIキーとBase URLで切り替えて使える
  • 生成した画像はブラウザのIndexedDB（端末内のローカルDBで、サーバーには送られない）にのみ保存される
  • フロントエンドはビルド不要の静的サイトで、Dockerまたはローカルのコマンド一つで起動できる

なぜ注目されているか

推測 AI生成の服飾参考画像を1407点まとめた大規模ギャラリーとして、コスチューム制作やファッションデザインの参考に活用できるため注目されている。推測 自前のAPIキーとBase URLを設定するだけでOpenAI・Gemini・Doubaoなど複数のAIサービスを使った仮想試着機能を自己ホストで実現できるため、APIコストやプライバシーを意識するユーザーに支持されている。推測 GoFrame v2製バックエンドとDockerによる簡単デプロイの組み合わせで、技術的な参入ハードルが低い点も評価されている。

どんな人に役立つか

AIファッションや仮想試着ツールに興味のあるエンジニアやデザイナーに役立つ。自前のAPIキーを使って試着システムを構築・自己ホストしたい開発者や、服飾の参考画像を大量にまとめて検索したいクリエイターにも適している。

技術的なポイント

  • バックエンドはGoFrame v2（GoのフルスタックWebフレームワーク）で実装されており、ComfyUI・Gemini・Doubao・OpenAI互換APIをプラグイン形式で切り替えられる設計になっている
  • フロントエンドは純粋な静的HTML/JavaScriptで構成されており、npmやバンドラーなどのビルドツールが不要でそのまま配信できる
  • AIが生成した画像の履歴はブラウザのIndexedDB（クライアント側の非同期Key-Valueストア）にのみ保存され、サーバーに個人データを送らないプライバシー配慮の設計になっている
  • BearerトークンにSHA-256ハッシュと定時間比較（タイミング攻撃対策の手法）、レート制限（10回/分・100回/日）、同時実行制限（グローバル2・呼び出し元1）などのセキュリティ機能を実装している
  • docker compose up -d 一コマンドでバックエンドとフロントエンドをまとめて起動するDockerデプロイに対応している

試し方

  1. リポジトリをクローンする
  2. backend/.env.example を backend/.env にコピーし、使用するAIサービスのAPIキーを設定する
  3. docker compose up -d を実行してバックエンドをポート8000で起動する
  4. フロントエンドは python3 -m http.server 3000 などで配信するか、index.html をブラウザで直接開く
cp backend/.env.example backend/.env
docker compose up -d
python3 -m http.server 3000
npx serve -l 3000 .
go run main.go
