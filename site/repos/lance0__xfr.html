lance0/xfr

Rust製のモダンなiperf3代替ネットワークスループット測定ツール

何ができるか

  • クライアントにリアルタイムのTUIダッシュボードを表示し、スループットグラフとストリームごとの統計を確認できる。
  • TCP・UDP・QUIC・Linux MPTCPに対応し、並列ストリーム・双方向・リバーステストをサポートする。
  • マルチクライアントサーバーモードに対応し、複数クライアントからの同時接続を受け付けられる。
  • プレーンテキスト・JSON・ストリーミングJSON・CSV形式での出力に対応し、自動化スクリプトとの連携が容易。
  • `xfr diff` コマンドで測定結果を比較したり、Prometheusメトリクスのエクスポートができる。
  • LANディスカバリー機能でネットワーク内のxfrサーバーを自動検出できる。

なぜ注目されているか

推測 iperf3は長年標準ツールとして使われてきたが、QUICサポートやTUI・マルチクライアント対応を求める声があった。Rustによる安全な実装とモダンなUXを提供するxfrはその代替として注目されている。

どんな人に役立つか

ネットワークエンジニアやインフラエンジニアで、ネットワークのスループット計測やベンチマークを行いたい人向け。自動化パイプラインでの測定結果取得や、QUICを使った暗号化測定が必要な場面にも適している。

技術的なポイント

  • Rust 1.88以上で実装されており、メモリ安全かつ高パフォーマンスな設計になっている。
  • QUICプロトコルを使用した場合はトラフィックが暗号化され、PSK（事前共有鍵）でピア認証が行える。
  • iperf3とは独自プロトコルを使用するため相互運用性はないが、iperf3からの移行ガイドが用意されている。
  • Prometheus PushgatewayへのメトリクスエクスポートによりCI/CDパイプラインでの継続的な計測に対応している。

試し方

  1. Rust 1.88以上をインストールする（または `cargo install xfr`・Homebrew・バイナリからインストール）。
  2. サーバー側で `xfr serve` を実行する。
  3. クライアント側で `xfr <サーバーのIPアドレス>` を実行する。
  4. ポート5201（TCP・UDP）をファイアウォールで開放しておく必要がある。
cargo install xfr
xfr serve
xfr <server-ip>
