higurashi-ai/Haru

初掲載 2026-11-14（はてなブックマーク 2位） GitHub ↗

低遅延・多言語対応の全二重音声対話モデル。聞きながら同時に話せる。

何ができるか

  • 全二重動作（7.5 Hz）：133msごとに音声フレームを入出力し、聞くことと話すことが互いをブロックせずに同時に行える。
  • 連続音声潜在表現：フレームごとに64次元の潜在ベクトルをMLPヘッドで1ステップ生成し、離散音声トークンや別途の音声トランスフォーマーを必要としない。
  • キャラクターと声の制御：テキストカードでキャラクターを定義し、短い参照音声クリップで声を指定できる。
  • 多言語対応：英語・スペイン語・ポルトガル語・ドイツ語・フランス語・中国語・日本語・ロシア語・韓国語の9言語に対応している。
  • 複数の実装環境：PyTorch（NVIDIA GPU）、MLX（Apple Silicon + macOSネイティブアプリ）、vLLMプラグインの3実装とWebデモを提供している。
  • オフライン推論：コマンドラインツールで音声ファイルを入力として応答音声を生成できる。

なぜ注目されているか

全二重音声対話はターンベースの従来モデルと異なり、電話のように自然な割り込みや同時発話が可能で、リアルタイム音声AIの新しいアプローチとして注目されている。Haru-4Bは事前学習済みベースモデルとして推論コードとWebデモが公開されており、研究者や開発者が手軽に試せる形で提供されている。Apple SiliconからNVIDIA GPUまで複数の実装が揃っており、幅広い環境での実験が可能な点も関心を集める要因となっている。

どんな人に役立つか

音声対話システムや会話AIの研究・開発に取り組む研究者・エンジニアに役立つ。多言語の全二重音声対話をローカル環境で試したい開発者や、カスタムキャラクターの音声アシスタントを構築したいエンジニアにも適している。

技術的なポイント

  • ベース言語モデルにQwen（Qwen3.5）を使用し、VibeVoice音響トークナイザーで24kHz音声を1フレーム（3200サンプル）あたり1つの潜在ベクトルに変換する。
  • 音声生成にImproved MeanFlowによる1ステップ生成フレームワークを採用しており、フレームの生成を単一の前向きパスで完結させている。
  • NVIDIA環境ではTritonカーネルとCUDAグラフリプレイを用いてコーデック処理を約0.7ms/フレーム（通常の約6msから高速化）に削減できる。
  • Apple Silicon向けにはMLXフレームワークとMetalカーネルを用いたネイティブmacOSアプリが提供され、GatedDeltaNetリカレンスをハードウェア最適化している。

試し方

  1. リポジトリをクローンし、haruディレクトリをpipでインストールする。
  2. サーバーを起動するとHugging FaceからHaru-4Bモデルが自動ダウンロードされる（約12GBのGPUメモリが必要）。
  3. ブラウザでhttp://localhost:8998 を開き、キャラクターと声（3秒〜3分の参照音声クリップ）を設定して会話を開始する。
pip install -e ./haru
python -m haru.server --hf-repo higurashi-ai/Haru-4B
haru-inference user.wav reply.wav --reference voice.wav --system-prompt "$(cat card.txt)" --stereo
