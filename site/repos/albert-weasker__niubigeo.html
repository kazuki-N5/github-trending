AIブランド可視性を自己ホストで測定するオープンソースツール

何ができるか

  • ドメインを入力するだけで、複数のAIモデルがそのブランドをどう説明するかを比較できる。
  • AIの回答内で言及された競合他社やキーワードの一覧を確認できる。
  • 各結果の元となるAIの回答とソース引用をそのまま参照でき、ブラックボックスにならない。
  • ブランド名を出さずにキーワード単位でテストし、独立した履歴を保持するキーワードモニタリング機能がある（ベータ版）。
  • 測定結果をCSVやJSONにエクスポートしたり、差分ビューで複数回の測定結果を比較したりできる。
  • 計測を繰り返し実行またはスケジュール化でき、変化を時系列で追跡できる。

なぜ注目されているか

推測 GEO（Generative Engine Optimization、AIが検索結果を生成するエンジン向けの最適化）への注目が高まる中、自社ブランドがAIにどう認識されているか可視化したいニーズが増えている。既存のSaaSツールはブラックボックスなスコアしか提供しないが、このツールは元の回答を直接見せるため透明性が高い点が評価されている。推測 オープンソースかつ自己ホスト可能なため、APIコストだけで利用できることも支持される理由と考えられる。

どんな人に役立つか

自社ブランドや製品がChatGPTなどのAIにどう紹介されているかを把握したいマーケターやプロダクトマネージャー。GEO施策の効果を測定したいWebマーケティング担当者やSEOエンジニア。

技術的なポイント

  • Node.js 22.13以上が必要で、OpenRouter APIキーを使って複数のLLM（大規模言語モデル）にリクエストを送る。
  • バックエンドはnpmで依存関係をインストールし、`npm run server`で起動するNode.jsサーバー構成。
  • Dockerにも対応しており、コンテナ化して簡単にデプロイできる。
  • オフライン回答とWebサーチ付き回答を別々に記録・比較することで、AIの回答ソースの違いを追跡できる。

試し方

  1. Node.js 22.13以上とOpenRouter APIキーを用意する。
  2. `npm ci`で依存関係をインストールする。
  3. `npm run server`でサーバーを起動する。
  4. ブラウザでlocalhost:8787を開いてダッシュボードを使用する。
npm ci
npm run server
