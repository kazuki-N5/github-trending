kevinraymond/florilegium

Lua 初掲載 2026-11-01（Trendshift 20位） GitHub ↗

LuaLaTeX用のデルフト・ブルー（オランダ陶器風の青色）で手続き生成される花模様ページマージンパッケージ

何ができるか

  • ページ番号をシードにLuaでページごとに異なる花・葉・茎を手続き生成し、外部画像なしで美しいマージン装飾を描画できる
  • 手動配置の「Authored」モードとページの空きスペースに合わせて植物が自動成長する「Grown」モードの2種類が選べる
  • 章番号付き見出しの横に花を配置するオプションや、特定行の横にインライン花飾りを挿入できる
  • 「春の蕾」から「秋の種」まで季節変化（aging）オプションで経年変化する植物を表現できる
  • 蝶・蜂・カタツムリ・鳥などの訪問者キャラクターが自動配置される（無効化も可能）
  • LaTeXなしでLuaコードをそのまま実行してSVGを出力でき、ブラウザのWebAssemblyプレイグラウンドでもリアルタイム調整・エクスポートができる

なぜ注目されているか

推測 LuaLaTeX文書に外部画像を一切使わず美麗な装飾マージンを自動生成できる点が独自の価値を持つ。推測 1998年のSIGGRAPH論文に基づく植物成長アルゴリズムをLaTeXパッケージとして実用化した学術的・芸術的な完成度が注目を集めていると考えられる。

どんな人に役立つか

学術論文・書籍・同人誌などをLuaLaTeXで組版しており、独自の植物装飾デザインを低コストで取り入れたい人に向いている。デジタルアーツや手続き生成グラフィクス（プログラムで自動的に図形を生成する技術）に興味があるCS学生にとっても、実際に動くコードとして参考になる。

技術的なポイント

  • すべての花・葉・茎をLuaで算術計算し、LuaLaTeXのPDFドライバに直接描画命令を送ることで外部依存ゼロを実現している
  • 色空間にOKLCH（知覚的に均一な色空間で、人間の視覚に合わせた色計算が可能）を使い、1つのインク色から全パレットを自動生成している
  • 植物の成長アルゴリズムはWong・Zongker・Salesin（SIGGRAPH 1998）の花飾りアルゴリズムを参考にしたグリーディ空間充填ループを採用している
  • 同じLuaコードをWebAssembly（ブラウザ上でネイティブ並みの速度で動くバイナリ形式）に変換してブラウザプレイグラウンドとして提供し、LaTeX・Typst・SVGにエクスポートできる
  • Makefile・Dockerイメージ・Overleafと複数のビルド環境に対応しており、TeX未インストール環境でも試せる

試し方

  1. LuaLaTeXがインストールされた環境（またはDockerかOverleaf）を用意する
  2. LaTeXファイルのプリアンブルに \usepackage[grown]{florilegium} を追加する
  3. lualatex コマンドで文書をコンパイルすると花模様付きマージンのPDFが生成される
  4. TeX環境がない場合はリポジトリのDockerイメージを使うか、ブラウザプレイグラウンドでオンライン確認できる
