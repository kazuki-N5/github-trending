google/elephant-goldfish-model

Astro 初掲載 2026-10-27（Trendshift 17位） GitHub ↗

AIコーディングエージェント向けの仕様書駆動開発を支援するオープンソースプラグイン

何ができるか

  • /egm-brainstormコマンドで、複数のゴールドフィッシュ（文脈なしのサブエージェント）を使ってアイデアを出しストレステストできる
  • /egm-draftコマンドで、コンセプトからセクションごとにマークダウン形式の設計仕様書を自動生成できる
  • /egm-reviewコマンドで、多段階パイプライン（ズームアウト・理解度確認・批評・完成度確認）を通じて仕様書をレビューできる
  • /egm-drift-reportコマンドで、ASTスキャナーによりコードと仕様書の乖離（ドリフト）を自動検出できる
  • /egm-bootstrapコマンドで、既存コードベースをボトムアップで再帰的にドキュメント化できる
  • /egm-resolveコマンドで、レビューで検出された問題をインタラクティブにトリアージし、パッチを自動適用できる

なぜ注目されているか

AIコーディングエージェントが普及する中、コードを書く前に仕様をしっかり固める「仕様書駆動開発」を自動化するツールとして注目されている。エレファント（深い文脈を持つセッション）とゴールドフィッシュ（ゼロ文脈の独立したサブエージェント）という2種類のAIを組み合わせた斬新なレビュー手法が革新的で、Google発のオープンソースとして公開されている点も注目度が高い。

どんな人に役立つか

Claude CodeやCodexなどのAIコーディングエージェントを使って開発するソフトウェアエンジニアやチームに役立つ。コードを書く前に設計仕様をしっかりレビューしたい開発者や、仕様とコードのズレを継続的に検知したいチームに特に適している。

技術的なポイント

  • エレファント（深い文脈セッション）とゴールドフィッシュ（ゼロ文脈サブエージェント）の2ロール構成で仕様書のストレステストを実現している
  • AST（抽象構文木）スキャナーを使って、実装コードと仕様書の乖離（ドリフト）を静的解析で検出する仕組みを持つ
  • Claude Code・Codex・Antigravity・ChatGPTなど複数のAIエージェントハーネスに対応するプラグイン形式で配布される
  • ドキュメントサイト（egm.dev）はAstroフレームワークで構築されており、Apache 2.0ライセンスで公開されている

試し方

  1. Claude Codeの場合: マーケットプレイスにgoogle/elephant-goldfish-modelを追加し、egm@egmをインストールする
  2. Codexの場合: マーケットプレイスを追加してからcodex plugin add egm@egmを実行する
  3. Antigravityの場合: agy plugin installコマンドにリポジトリURLを指定してインストールする
  4. /egm:egm-brainstormコマンドでアイデア出しと検証を開始する
  5. /egm:egm-draftコマンドでコンセプトから設計仕様書を作成する
  6. /egm:egm-review docs/designs/<機能名>.mdコマンドでレビューを実行し、/egm:egm-resolveで問題を解決する
codex plugin add egm@egm
agy plugin install google/elephant-goldfish-model
