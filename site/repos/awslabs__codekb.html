awslabs/codekb

初掲載 2026-11-23（はてなブックマーク 1位） GitHub ↗

AIエージェント向けにコードの意味的理解と横断検索を提供するコード理解ツール

何ができるか

  • スペースオーバービュー機能で、ビジネス概要・アーキテクチャ・技術スタック・デプロイ情報をMarkdown形式で自動生成できる
  • 意味的コード検索により、「支払い認可はどこで行われているか」のような意図ベースの検索ができる
  • エージェントホッパーというリポジトリ対応チャットエージェントで、変更影響分析モードも使える
  • ハイパースペース機能で複数の関連リポジトリをまとめて検索・チャット・概要生成できる
  • MCPツールとして公開され、KiroやClaude CodeなどのIDEやAIアシスタントから利用できる

なぜ注目されているか

AIによる自律的なソフトウェア開発（ブラウンフィールド開発）が注目される中、既存コードベースをAIエージェントに理解させることが重要課題となっている。CodeKBは単なるコードインデックスではなく、ビジネスロジックの意味まで理解させることで、AIエージェントが既存システムを正確に把握しながらタスクをこなせるようにする点で注目される。推測 大規模組織での複数リポジトリにわたるコード理解の自動化ニーズが高まっているため、このようなツールへの関心が増している。

どんな人に役立つか

既存の大規模コードベースをAIエージェントに扱わせたい開発者やチームに役立つ。特に複数リポジトリにまたがるシステムを管理している組織や、AIを活用したコードレビュー・影響分析を行いたいエンジニアに適している。

技術的なポイント

  • Tree-sitterを使って14言語ファミリーのソースコードを構文解析し、コールグラフを再構築する
  • Amazon Bedrockの対応Claudeモデルを用いて各関数をビジネス用語で説明し、Titan Text Embeddings V2でベクトル化してS3 Vectorsに保存する
  • AWS CDKを使ってECS Fargate・CloudFront・AWS WAF・Cognitoによる本番向け共有インスタンスをデプロイできる
  • 変更があったファイルのみ再インデックスし、影響を受けた呼び出し元の要約も更新する差分更新の仕組みを持つ
  • Guardrailを使ってシークレットや個人情報をマスクしてからLLMに渡すセキュリティ機構を備える

試し方

  1. Amazon Bedrockで対応するClaudeモデルとTitan Text Embeddings V2へのアクセスを有効にする
  2. AWS CDK（推奨）またはローカル実行のどちらかのデプロイ方法を選択する
  3. GitリポジトリのURLまたはZIPファイルアップロードでスペースを追加する
  4. インデックス完了後、意味的検索やエージェントホッパー、オーバービュー生成を利用する
