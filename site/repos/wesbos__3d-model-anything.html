wesbos/3d-model-anything

Swift 初掲載 2026-10-24（Trendshift 12位） GitHub ↗

iPhoneのLiDARで部屋を記録し、AIで編集可能なThree.js 3Dシーンに再構成

何ができるか

  • iPhone アプリで部屋をスキャンし、LiDAR（レーザーで距離を測るセンサー）による形状と写真を記録できます。
  • scan-to-threejs というエージェント用スキルで、AIコーディングエージェントに寸法の確認、モデリング、元写真との見比べをさせながら部屋を再構成できます。
  • Three.js（ブラウザで3Dを描くJavaScriptライブラリ）製のビューアで、ドールハウス、歩行、俯瞰、ワイヤーフレーム、ノーリングの各視点で部屋を見て回れます。
  • 作者のオフィスを再構成したデモが含まれ、Web 上でも閲覧できます。

なぜ注目されているか

作者は Web 開発の講座で知られる Wes Bos で、紹介動画も公開されています。推測 スマートフォンのスキャン結果を AI エージェントに渡して、編集できる3Dシーンに作り直すという新しいワークフローが関心を集めていると考えられます。

どんな人に役立つか

自分の部屋やインテリアをブラウザで見て回れる3Dモデルにしたい人や、Three.js と AI エージェントを組み合わせた3D制作を試したい人に向いています。スキャンには LiDAR 搭載の iPhone か iPad が必要です。

技術的なポイント

  • iPhone アプリは Swift で書かれ、Xcode でビルドします。
  • これはワンクリックで完璧なモデルを作る変換器ではなく、エージェントが寸法を測り、モデル化し、元写真と同じカメラ位置のレンダリングを比べて直す反復型の再構成です。
  • 補助スクリプトは Python 3 を使い、写真比較には Pillow、任意の深度再構成には NumPy と Open3D を使います。
  • ビューアは Node.js 22.12 以上で動き、開発サーバーは npm run dev で起動します。

試し方

  1. Node.js 22.12 以上を用意し、依存パッケージを入れてビューアを起動します。
  2. ブラウザで http://localhost:5188 を開き、オフィスのデモを見て回ります。
  3. 自分の部屋を試す場合は、iPhone アプリでスキャンして書き出し、data/captures-in/ 以下に展開します。
  4. ローカルのスキルに対応したエージェントでこのリポジトリを開き、scan-to-threejs を使って部屋を再構成するよう依頼します。
npm ci
npm run dev
npm run build
npm run preview
