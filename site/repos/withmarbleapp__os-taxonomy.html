子どもが学ぶ内容を前提関係のグラフにまとめたオープンな学習項目データセット

何ができるか

  • 小学校段階で学ぶ内容を、ひとつずつ教えられる1,591個の「マイクロトピック」に細かく分け、説明・習得の目安（evidence）・対象年齢を付けて収録しています。
  • 「トピックXを学ぶにはトピックYが先に必要」という前提関係3,225本を、hard/soft の強さと一行の理由付きで有向非巡回グラフ（DAG：向きがあり循環しないグラフ）として提供します。
  • 各トピックを NGSS、Common Core、英国ナショナルカリキュラムなど、各国のカリキュラム標準に対応づけています。
  • 理科と算数・数学の1,051トピックについて、教え方・具体的な学習活動・評価の方法・参考文献をまとめた「教授法リサーチ」データを含みます。
  • 科目・分野・年齢帯ごとに、保護者向けの一段落の要約（176件のクラスタ）を用意しています。
  • Science・Mathematics・English・History など8科目をカバーしています。

なぜ注目されているか

推測 カリキュラムのデータは標準の平坦な一覧か、製品の中に閉じ込められたものが多いのに対し、前提関係でつながった「学習のグラフ」を誰でも使える形で公開した点が注目されていると考えられます。商用利用もできるライセンス（ODbL・CC BY-SA）で出されているため、教育アプリや AI チューターの開発者にも使いやすいデータになっています。

どんな人に役立つか

教育アプリや学習支援 AI を作る開発者、カリキュラムやグラフ構造データを研究したい人に役立ちます。ある概念を学ぶ前に何を身につけておくべきかをたどる、学習順序の設計に使えます。

技術的なポイント

  • 実行環境や依存ライブラリはなく、UTF-8 の JSON ファイルだけで構成された純粋なデータセットです。
  • トピックがグラフのノード、前提関係（topicId が prerequisiteId に依存）がエッジになっていて、エッジを逆向きにすれば「次に解放される内容」が得られます。
  • schema/ に JSON Schema（JSON の構造を定義する仕様）があり、manifest.json には件数と各ファイルの SHA-256 チェックサムが記録されています。
  • teaching-research.json は topics.json の正確なバイト列に topicFileSha256 で結び付けられていて、トピックファイルが変わったら作り直す仕組みです。
  • Node.js 用の検証スクリプト（validate.mjs）とテスト（node --test）で、構造・カバー範囲・チェックサムを確認できます。

試し方

  1. リポジトリを取得し、data/ フォルダにある topics.json と dependencies.json を JavaScript などから読み込みます。
  2. トピックの id から名前を引ける Map を作り、dependencies を topicId で絞り込むと、そのトピックの前提トピックの一覧が得られます。
  3. 教え方の情報が必要なら teaching-research.json を topicId で結合します（現在は理科と算数・数学のみ対応）。
  4. 検証スクリプトとテストを実行して、データの構造やチェックサムを確認します。
node scripts/validate.mjs
node --test scripts/teaching-research.test.mjs
