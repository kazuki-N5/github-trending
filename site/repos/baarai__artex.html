BaaRai/ARTEX

Go 初掲載 2026-11-15（Trendshift 13位） GitHub ↗

LLM駆動の自律型ペネトレーションテストプラットフォーム

何ができるか

  • プランナーエージェントがゴールを意図に分解し、ワーカーエージェントが実際のセキュリティツールを実行して結果をグラフに書き戻す
  • MITMプロキシとブラウザ拡張機能でHTTPトラフィックをキャプチャし、発見した脆弱性に証拠を紐づける
  • 人間による承認ゲートとスコープ・トークン予算管理で自律的な動作を制御する
  • アセットグラフと探索グラフで対象資産の網羅状況を可視化する
  • Anthropic・OpenAI・Ollamaなど複数のLLMバックエンドに対応し、フェイルオーバーもサポートする
  • 再テストエージェントが既存の発見事項を再検証し、修正済み・未修正・未確認に分類する

なぜ注目されているか

推測 LLMを活用した自律型ペネトレーションテストという新興分野への注目度が高まっており、実ツール連携・証拠保持・承認ゲートを備えた実用的な実装として関心を集めていると考えられる。GoによるシングルバイナリとNext.js UIの組み合わせで導入ハードルが低く、PostgreSQLのみを外部依存とするシンプルな構成も評価されていると推測される。

どんな人に役立つか

自社または許可を得たシステムに対してペネトレーションテストを行うセキュリティエンジニアやレッドチームに適している。バグバウンティ研究者や、隔離環境で自社資産のセキュリティ評価を自動化したい組織にも活用できる。

技術的なポイント

  • GoのシングルバイナリにNext.js UIをgo:embedで埋め込み、PostgreSQLのみを外部依存とするシンプルなアーキテクチャ
  • プランナーとワーカーに分かれたマルチエージェント構成で、グラフ変更イベントによりループを駆動するイベント駆動設計
  • MITMプロキシ（生成CA証明書）とBashツールコールのトレースで証拠を収集し、AES-256-GCMで暗号化して保存
  • nmap・nuclei・httpx・katana・ffuf・dalfox・sqlmapなどの実セキュリティツールをDockerイメージに同梱して実行
  • ツール出力をデータとして扱う「信頼境界」機能でプロンプトインジェクション攻撃を緩和

試し方

  1. リポジトリをクローンして .env ファイルを作成する
  2. Docker Composeでビルド・起動する
  3. ブラウザで http://localhost:8787 を開き、ログに出力されたセットアップトークンで初期設定を行う
git clone https://github.com/BaaRai/ARTEX.git && cd ARTEX
cp .env.example .env
docker compose up -d --build
docker compose logs artex | grep "Setup token"
