公開データで動く、スパイ衛星シミュレーター風の3D地球儀

何ができるか

  • 写真のようにリアルな3D地球儀の上に、リアルタイムの航空機、船舶、人工衛星、地震、交通、公開カメラの映像を表示する。
  • 航空機をクリックすると追跡し、コックピット視点で実際の地形の上を一緒に飛んでいるように見られる。
  • CRT、暗視（NVG）、赤外線（FLIR）などのセンサー風の見た目で、地球全体を描き変えられる。
  • OpenAI のリアルタイム AI エージェントを使い、「東京に連れて行って」「テキサス上空を今何機飛んでいる？」のように声で操作や質問ができる（OpenAI の API キーが必要）。
  • 気象（風の予報、雷、台風の進路）、人工衛星の通過予測、カメラが映せる範囲（ビューシェッド）なども表示できる。
  • MCP サーバーとしても動き、Claude Desktop や Codex などから場所を指定すると、会話の中に地球儀が開く。

なぜ注目されているか

作者の動画シリーズ「God's Eye View」（旧名 WorldView）が話題になっており、README によると YouTube で500万回以上、SNS 全体で2500万回以上見られている。2026年8月には GitHub Trending の日間・週間ランキングで1位になり、Product Hunt でもその日の8位に入った。推測 公開されているデータだけで「禁断のコックピット」のような体験ができ、しかもコードをすべて読めるという意外性が注目を集めていると考えられる。

どんな人に役立つか

地理空間データ（GIS）や OSINT（公開情報を使った調査）に興味がある人、3D 地図や WebGL を使った可視化を作ってみたい人に向く。各レイヤーが独立したモジュールになっているので、自分のデータソースを追加して拡張したい人にも合う。

技術的なポイント

  • フレームワークを使わない素の JavaScript と、CesiumJS（3D 地球儀を描くライブラリ）、Vite（開発用のビルドツール）で作られ、地表の描画には Google Photorealistic 3D Tiles を使う。
  • 15〜30秒ごとに届く位置データを実際の時刻より1区間遅らせて表示し、分かっている位置の間を補間して滑らかに動かす（足りない部分は推測航法で埋める）。
  • 人工衛星の位置は SGP4（軌道要素から衛星の位置を計算する標準的な方法）で計算している。
  • OpenAI などの秘密の API キーはサーバー側のプロキシ（中継サーバー）を通して使い、ブラウザには短時間だけ有効なトークンしか渡さない。
  • API キーがなくても Esri の衛星画像や多くのレイヤーが使え、キーは後からアプリ内の POWER UP パネルで追加できる。

試し方

  1. Node.js 24.x（24.14.0 以降）または 26.x を用意する。
  2. リポジトリをクローンし、npm ci で依存パッケージを入れ、npm run doctor で環境を確認してから npm run dev で起動する。
  3. ブラウザで http://localhost:4173 を開き、最初のパネルで Live Contacts などのミッションを選ぶ。
  4. Node.js を入れたくない場合は docker compose up でも起動でき、Pinokio（アプリのインストーラー）からワンクリックで入れることもできる。
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run doctor
npm run dev
docker compose up
