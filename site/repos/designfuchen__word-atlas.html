designfuchen/word-atlas

TypeScript 初掲載 2026-10-27（Trendshift 10位） GitHub ↗

イラスト・音声・FSRS復習付きのオープンソースIELTS語彙アプリ

何ができるか

  • 7,298件のIELTS単語を19トピック・CEFR A1〜C2レベルで収録し、オリジナルイラストと英英・英日定義、例文2文を提供する
  • イギリス英語とアメリカ英語の発音音声、例文の読み上げ音声を収録している
  • 意味選択・画像から文補完・リスニング識別・スペリングの4種類の練習モードがある
  • FSRS（間隔反復アルゴリズム）で復習スケジュールを自動管理し、目標記憶率を調整できる
  • WebGL2を使った「スターマップ」で学習進捗を視覚的に表示する
  • ログイン不要のローカルファースト設計で、進捗はデバイスに保存され、オフラインでも利用できる

なぜ注目されているか

MITライセンスのコードとCC BY 4.0のデータセット（7,298単語・14,596例文・7,298イラスト・22,905音声）を完全公開しており、Anki化や独自アプリへの流用がしやすい。アカウント不要・無料・広告なしで使えるIELTS対応の本格的な語彙アプリは珍しく、英語学習コミュニティで注目を集めている。

どんな人に役立つか

IELTSを目指す英語学習者で、イラストと音声を使って単語を覚えたい人に最適。また、語彙学習ツールや教材を自作したい開発者・研究者にとって、質の高い公開データセットとして活用できる。

技術的なポイント

  • React 19とTypeScriptをViteでビルドしており、モダンなフロントエンド開発環境を採用している
  • ts-fsrs（TypeScript実装のFSRS: Free Spaced Repetition Scheduler）で科学的な間隔反復復習を実現している
  • WebGL2（GPUを使ったブラウザグラフィクスAPI）でスターマップを描画し、非対応端末にはフォールバックを用意している
  • データセットはJSONとCSV形式で提供されており、CC BY 4.0ライセンスで再利用可能

試し方

  1. Node.js 20以上とnpmをインストールする（初回クローン時は画像・音声アセットを含むため時間がかかる）
  2. リポジトリをクローンしてディレクトリに移動する
  3. 依存パッケージをインストールする
  4. 開発サーバーを起動し、ブラウザで http://localhost:5188 を開く
git clone --depth 1 https://github.com/designfuchen/word-atlas.git
cd word-atlas
npm ci
npm run dev
