AIエージェントで難しいことを効率よく学ぶデスクトップアプリ

何ができるか

  • 現在の理解レベルを確認し、目標までの依存関係をマップして段階的に教える4ステップの学習メソッドを実装している
  • テキスト入力や音声入力で自分の考えを説明しながら学べるため、エージェントが思考プロセスを把握できる
  • アイデアとその推論チェーンを永続的なナレッジグラフとして複数セッションにまたがって保存し、ノートのインポートも可能
  • バックグラウンドリサーチ、視覚的な説明、インタラクティブなデモンストレーションをサポートする
  • 30以上のプロバイダー（OpenAI、Anthropic、Google、DeepSeek等）の自前APIキーを使用でき、サブスクリプション不要でコストメーターも表示される
  • すべてのチャット、グラフ、設定、APIキーはローカルに平文ファイルとして保存され、システムプロンプトも閲覧・編集可能

なぜ注目されているか

AIを単なる回答生成ツールとしてではなく、学習者の思考プロセスを追跡しながら段階的に知識を構築する教師として活用している点が独自のアプローチである。ナレッジグラフを永続的に蓄積することで、セッションをまたいだ継続的な学習が実現できる。また、アプリのローカル機能は無料を維持し続けるという方針が明示されており、持続可能なオープンソースプロジェクトとして位置づけられている。

どんな人に役立つか

プログラミングや数学など体系的な前提知識が必要な分野を独学で習得したいCSの学生やエンジニアに向いている。既存の理解をベースに次のステップを教えてもらいたい人や、学習の進捗をグラフで管理したい人にも適している。

技術的なポイント

  • AGPL-3.0ライセンスのオープンソースデスクトップアプリで、macOS（Apple Silicon、署名済み）、Windows（x64）、Linux（x64のAppImageまたは.deb）に対応しインアップアップデートもサポートする
  • npm install と npm run dev でlocalhost:3000のローカルサーバーとして起動でき、npm test でLLMやネットワーク呼び出しなしの決定論的テストを実行できる
  • システムプロンプトが閲覧・編集可能で、エージェントの動作の透明性が確保されている
  • チャット、グラフ、設定、APIキーはすべてローカルの検査可能なファイルに保存されるが、モデル・調査・音声認識のリクエストは外部サービスに送信される

試し方

  1. リポジトリをクローンする
  2. npm install を実行して依存関係をインストールする
  3. npm run dev を実行してローカルサーバーを起動する（localhost:3000）
  4. テストを確認する場合は npm test を実行する
npm install
npm run dev
npm test
