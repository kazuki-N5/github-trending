RustコアのネイティブIDEで、IntelliJ IDEAのキーマップとUIを高速再現

何ができるか

  • IntelliJ IDEAと同じキーマップ・ツールウィンドウ・Search Everywherを採用し、既存ユーザーがすぐ使い始められる。
  • エディタ・コードインサイト・デバッガ・Git・ターミナル・データベースクライアント・HTTPクライアントを内包する。
  • 60以上の言語をサポートし、幅広いプロジェクトに対応できる。
  • macOS・Windows・Linuxのクロスプラットフォームで動作する。
  • 起動時間約0.9秒・メモリ使用量169MBと、IntelliJ IDEA比で大幅に軽量・高速である。

なぜ注目されているか

IntelliJ IDEAは高機能である一方、起動が遅くメモリ消費が2GB超になるという長年の課題があった。推測 Rustによるネイティブ実装でその課題を解消しつつIDEAの操作感を維持するという点が開発者コミュニティで注目されていると考えられる。推測 JetBrainsの有料ライセンスを不要にする無償代替として関心を集めている可能性もある。

どんな人に役立つか

IntelliJ IDEAの操作体系に慣れているがパフォーマンスや軽量さを求める開発者に向いている。低スペックマシンや多数のプロジェクトを並行して扱うエンジニアにも有用である。

技術的なポイント

  • コアをRust（システムプログラミング言語）で実装することで、起動速度とメモリ効率を大幅に向上させている。
  • UIレイヤーにはTauri（RustバックエンドとWebフロントエンドを組み合わせるデスクトップフレームワーク）を使用している。
  • フロントエンドはTypeScript＋pnpmで管理され、Node 22が必要である。
  • パフォーマンス比較ツールがperf/compareディレクトリに含まれており、IntelliJ IDEAとの定量的比較を再現できる。
  • ノートブック実行テストはipykernelを持つPython環境2つを環境変数で指定するオプトイン方式である。

試し方

  1. Rust 1.96、Node 22、pnpm、およびTaurの前提条件をインストールする。
  2. リポジトリをクローンし、pnpmで依存関係をインストールする。
  3. Tauri CLIを通じてアプリを開発モードで起動する。
pnpm install
pnpm tauri dev
