PS5 の実行ファイルを Linux・Windows 向けに自動で移植するツール

何ができるか

  • リリンカー（実行ファイルを別の形式に組み替える道具）で、PS5 の実行ファイルを対象 OS のネイティブ形式に変換する。
  • PS5 のシステム prx ライブラリ（PS5 の共有ライブラリ）を動的リンクできる形で再実装して同梱している。
  • シェーダー再コンパイラーで GPU 用プログラムを SPIR-V（Vulkan などで使われるシェーダーの中間表現）に変換する。
  • SDL で認識されるゲームコントローラーに対応し、キーボードとマウスの割り当ても設定ファイルで変更できる。
  • ファイルを端末の外に送らずに変換できる Web 版コンバーターがある。

なぜ注目されているか

エミュレーションや別のランタイムプロセスを使わず、実行ファイル自体を変換して PC 上で直接動かすという方式をとっている。推測 PS5 タイトルを PC で動かす新しいアプローチとして、ゲーム保存や互換性の分野で関心を集めていると考えられる。

どんな人に役立つか

ゲームの互換性や保存、実行ファイル形式やバイナリ変換の仕組みに関心がある開発者や研究者に向く。著作権のあるソフトや鍵は含まれないため、使うバイナリは利用者自身が法律とライセンスに沿って用意する必要がある。

技術的なポイント

  • 主に C++ で書かれ、対応できない状態では必ず std::runtime_error を投げてエラー内容を表示し終了する方針をとっている。
  • エミュレーターのように命令を逐次解釈するのではなく、実行ファイルを再リンクしてネイティブ形式にする。
  • 生成した SPIR-V は、ANYPS5_ENABLE_SPIRV_TOOLS を有効にしてビルドすると SPIRV-Tools で検証できる。
  • リリンカーだけのビルドは Apple silicon を含む macOS でも動く。

試し方

  1. ブラウザで Web converter（https://boykopovar.github.io/AnyPS5/）を開くと、ファイルを端末内に置いたまま変換できる。
  2. 詳しい使い方は docs/user/USAGE.md、ビルド方法は docs/dev/BUILD.md を参照する。
