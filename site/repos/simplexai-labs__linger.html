simplexai-labs/linger

TypeScript 初掲載 2026-11-20（Trendshift 6位） GitHub ↗

Big Techに依存せず自分のPCで完全動作するオープンソースのパーソナルAIエージェント

何ができるか

  • PolyStrataエンジンにより、125BパラメータのモデルをGPU 12GB・RAM 64GBという一般的な環境で動作させられる
  • Model Autopilotがハードウェアを自動検出して最適なモデルを推薦・インストールし動作確認まで行う
  • メール・チャット・会議の内容を毎晩Wikiページに変換してエージェントが検索できる長期記憶機能を持つ
  • 受信トレイ・カレンダー・Slackを監視して自律的にフォローアップする「Another Me」機能がある
  • デスクトップとブラウザを操作しながら複数エージェントがチームで協調して作業できる
  • Claude Code・Codex・Piなど外部AIをランタイムとして統合し既存ツールと連携できる

なぜ注目されているか

推測 クラウドAIへの依存やデータのプライバシー問題に対する関心が高まる中、強力なAIを自分のPC上で完全に動かせる点が注目を集めていると考えられる。一般的なコンシューマー向けGPU環境で125Bクラスのモデルを動かす効率的なエンジン設計と、メール・カレンダー連携など実用的な自動化機能の組み合わせが評価されていると推測される。

どんな人に役立つか

プライバシーを守りながら日常業務をAIで自動化したい個人ユーザーや、ローカルLLMを使った自律エージェントを開発・実験したいエンジニアに向いている。クラウドサービスへのデータ送信を避けつつ、メール返信やスケジュール管理などをAIに任せたい人にも適している。

技術的なポイント

  • PolyStrataエンジンがモデルの頻繁に使われるExpertをGPUに、残りをRAMやSSDに階層的に配置することで大規模モデルを効率的に動作させる
  • 夜間の「Dreaming」プロセスでユーザーの反応を学習してルール化する継続的な自己改善機能を持つ
  • macOS・Windows・LinuxのデスクトップアプリとDocker Composeによる共有サーバーの2つのデプロイ方法をサポートする
  • LoCoMoメモリベンチマークで95%のスコアを主張する構造化された長期記憶アーキテクチャを採用している

試し方

  1. GitHub ReleasesからmacOS（Apple Silicon）・Windows x64・Linux x64向けのデスクトップアプリをダウンロードする
  2. macOSでは未署名アプリのため、初回起動前にターミナルでxattrコマンドを実行してセキュリティ属性を解除する
  3. インストール後にModel Autopilotが自動でハードウェアを検出し、最適なモデルを推薦・インストールして動作確認まで行う
  4. チームや複数人で使う場合はDocker Composeを使ったガイド付きスクリプトでサーバーをセットアップする
