DeadInternetStudios/100x-engineer-skill

JavaScript 初掲載 2026-11-28（Trendshift 11位） GitHub ↗

形式検証付きでプロダクション品質コードを生成するClaude Codeスキル

何ができるか

  • タスクを小さなブロックに分割し、各ブロックを形式検証（状態・遷移・事前・事後条件・不変条件・活性条件）してから組み合わせる
  • コードが変更されたときに検証結果が古くなったことを検出するledger.tsvをリポジトリで管理する
  • 二次AIモデルがコードレビューを行い、スクリーンショットとテスト結果を含む報告書を生成する
  • Claude Code・Cursor・Codexで動作し、Node.js 22以上を必要とする
  • バグを植え込んで検証が実際に失敗することを確認してから合格とみなす仕組みで信頼性を担保する

なぜ注目されているか

推測 AIコーディングエージェントが「ほぼ動く」コードを生成するが最後の10%が完成しない問題を解決しようとしており、30日間で136Bトークン・1,000件超のPRという実績データが注目を集めている。形式検証（formal verification）をLLM時代に再定義した点も新しい。

どんな人に役立つか

Claude CodeやCursorなどのAIコーディングエージェントを業務で使い、プロダクション品質のコードを生成したいエンジニア向け。ロールバック率を下げたいチームにも有効。

技術的なポイント

  • 各機能ブロックの状態遷移モデルを構築し、全状態を網羅的に探索するモデル検査アプローチを採用している
  • verify/ledger.tsvでカバーするコードのハッシュを管理し、変更検知と検証の再実行を自動化している
  • 形式検証の範囲外（UIやコピー）はwaiverを記録し、100x finishがその根拠と対象コードを明示する
  • ブロック間のシームも独立検証して、一方が出力するデータが次のブロックの入力条件を満たすことを保証する

試し方

  1. Node.js 22以上をインストールする
  2. Claude CodeまたはCursorに100x-engineer-skillをインストールする
  3. /100x-setup コマンドを実行してセットアップを完了する
  4. 機能追加や新規アプリ作成のタスクを渡す
