Z-LibraryのCLIツール。検索・ダウンロード・AI連携対応

何ができるか

  • 年・言語・フォーマットなどのフィルターを使って書籍を検索できる
  • お気に入り・おすすめ・人気書籍・ダウンロード履歴をブラウズできる
  • 書籍をダウンロードし、KindleやWeReadへ送信できる
  • 電子書籍のメタデータの確認・編集が行える
  • MCPサーバーとして登録でき、Claude・Codex・GrokなどのAIエージェントと連携できる
  • ターミナルでカバー画像の表示や日次ダウンロード上限の確認ができる

なぜ注目されているか

推測 Z-Libraryへのアクセスをコマンドラインから効率的に行えるため、開発者やパワーユーザーに有用なツールと考えられる。MCPサーバー機能によりAIエージェントとの統合が可能な点は、AIを活用したワークフローに対応している点で注目に値する。

どんな人に役立つか

Z-Libraryを頻繁に利用する開発者やリサーチャー向け。AIエージェントと連携して書籍検索・ダウンロードを自動化したいユーザーにも適している。

技術的なポイント

  • Go言語で実装されたCLIツール
  • MCPサーバーとして動作し、AIエージェントと連携可能
  • Homebrew、winget、インストールスクリプト、バイナリなど複数のインストール方法に対応
  • ほとんどのコマンドが--jsonオプションによるスクリプト連携をサポート
  • ミラーサイトやプロキシの設定が可能

試し方

  1. Homebrew・インストールスクリプト・winget・バイナリからいずれかの方法でインストールする
  2. zlib doctorを実行して到達可能なドメインを確認する
  3. zlib loginで対象ドメインにログインする
  4. zlib tuiでインタラクティブシェルを起動し、/でコマンド一覧を確認する
brew install zlib-cli
zlib doctor
zlib login
zlib tui
zlib search
zlib download
zlib kindle send
zlib mcp
