ksjhk/api

初掲載 2026-11-25（Trendshift 20位） GitHub ↗

200以上のブランドギフトカードをAPIで自動仕入れ・発行できる中国向けオープンプラットフォーム

何ができるか

  • 200以上のブランドの会員特典カード・ホテル予約・映画チケットをAPIで取得・注文できる
  • 公開クエリ（商品一覧・ホテル検索・映画情報）はログイン不要で取得できる
  • 署名付きリクエストで注文を作成し、在庫切れ時は残高が自動返金される
  • 1.00〜99.99倍の価格マルチプライヤー設定で販売価格を自由に調整できる
  • PHP・Python・Node.js・curlのサンプルコードが同梱されており、すぐに試せる

なぜ注目されているか

推測 中国市場向けのギフトカード・旅行・エンタメを一つのAPIで扱える希少なプラットフォームとして、自動発券・転売システムを構築したい開発者から注目されている。公開クエリが認証不要という低い参入障壁も話題の一因と思われる。

どんな人に役立つか

中国市場でギフトカードや旅行チケットの自動販売・発券システムを構築したい開発者向け。ECサイトやBOT（自動プログラム）にカード発行機能を組み込みたいエンジニアにも適している。

技術的なポイント

  • 署名はリクエストパラメータをアルファベット順にソートしてアプリシークレットを末尾に付加したMD5ハッシュ（小文字16進）で生成する
  • タイムスタンプ（秒単位）を必須パラメータとし、10分以上ずれたリクエストは拒否される
  • 金額は「分（フェン）」単位（1元=100分）で扱われる
  • APIベースURL: https://www.kashijie.com/open-api

試し方

  1. /platform/quick-startエンドポイントに未登録の電話番号を送り、アカウント登録とAPIキーペアを取得する
  2. コンソールでWeChat/Alipayを使って残高をチャージする
  3. 公開エンドポイントで商品・ホテル・映画情報をクエリする
  4. 署名を生成して注文エンドポイントに送信し、自動発券を確認する
curl https://www.kashijie.com/open-api/platform/quick-start -d 'phone=手机号'
