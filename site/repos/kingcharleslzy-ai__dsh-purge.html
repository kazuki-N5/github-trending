DeepSeek Harness 用のコミュニティ維持プラグイン（設定管理・診断・バックアップ機能付き）

何ができるか

  • 86種類のホストパッチを適用して DeepSeek Harness の動作をカスタマイズできる
  • 25層のステータス自己診断でプラグインと宿主アプリの状態を確認できる
  • サイドバーの設定ページからプリセット管理・更新・バックアップと巻き戻しができる
  • macOS・Windows・Linux 向けのコミュニティインストーラースクリプトに対応している
  • Apple Silicon や NVIDIA GPU でローカル画像生成ができる Qwen Studio コンパニオンプラグインがある

なぜ注目されているか

DeepSeek Harness のユーザーコミュニティが既存プラグインを独自に引き継ぎ、宿主アプリのアップデートへの対応や追加機能を加えて継続メンテナンスしていることが注目されている。

どんな人に役立つか

DeepSeek Harness を日常的に使っていて、確認ダイアログを減らしたり設定を細かく管理したいユーザー向け。自分が所有・管理するシステムでのみ使用すること。

技術的なポイント

  • JavaScript 製で DSH Desktop のプラグインとして動作する
  • DSH プラグインマーケット・DSH CLI・コミュニティインストーラーの複数の導入経路に対応している
  • インストールスクリプトはドライランと SHA256 チェックをサポートしてセキュリティを確認できる
  • MIT ライセンスで YuJunZhiXue の dsh-purge を元に独立してメンテナンスされている

試し方

  1. DSH プラグインマーケットから検索してインストールする
  2. または DSH CLI を使ってインストールする
  3. macOS/Windows/Linux はコミュニティインストーラースクリプトも利用できる
