PLaMo 3 Translateをローカルで動かすオフライン対応デスクトップ翻訳アプリ

何ができるか

  • 53言語に対応したPLaMo 3 Translateモデルをローカル実行し、オフラインで翻訳できる。
  • 0.8B・2B・8B・31BのGGUFモデルを選択でき、HuggingFaceからダウンロードして利用する。
  • 日本語出力スタイル（丁寧体・普通体）の切り替えや、参照コンテキスト・用語集の設定が可能。
  • Chrome・Edge向けブラウザ拡張機能を提供し、選択テキストやページ全体の翻訳に対応する。
  • CPU（AVX2/AVX-512）・GPU（Vulkan/Metal/ROCm）・Intel NPU（実験的）で動作する。

なぜ注目されているか

推測 Preferred Networks（PFN）が開発したPLaMo翻訳モデルをオフラインで手軽に使えるデスクトップアプリとして注目されている。プライバシーを守りながらローカル翻訳できる点と、ブラウザ拡張連携の実用性が評価されていると考えられる。

どんな人に役立つか

クラウドAPIを使わずにローカルで高品質な翻訳を行いたい開発者や研究者に役立つ。プライバシーを重視しつつ日本語・英語間の翻訳を頻繁に行うユーザーにも適している。

技術的なポイント

  • RustとGPUI（Zedエディタが使うGPUベースUIフレームワーク）で実装されている。
  • GGUFフォーマットのモデルをllama.cpp互換の推論エンジンで実行する。
  • モデルダウンロード時はSHA-256でチェックサム検証を行い、中断後も再開できる。
  • 英語・日本語UIとライト・ダークテーマを備え、ソース・訳文の同期スクロールに対応する。

試し方

  1. GitHubリリースページからWindows（x86_64）・Linux（x86_64）・macOS（Apple Silicon）向けパッケージをダウンロードする。
  2. アプリを起動し、使用するモデルサイズを選択してPFNのHugging Faceページからダウンロードする。
  3. テキストを貼り付けまたは入力して翻訳する。
cargo build --release
