SheepSeb/tinyworldformer

初掲載 2026-10-31（はてなブックマーク 1位） GitHub ↗

Pico 2W上でゲームを生成しながら同時にAIが自己学習してプレイする超小型ワールドモデル

何ができるか

  • ループ型トランスフォーマー（1ブロックを1〜4回再利用）が現在のフレームとアクションから次のフレームと報酬を予測するワールドモデルとして動作する。
  • 小型MLP（多層パーセプトロン）のアクターが生成されたフレームを見てアクションを選択し、ゲームをプレイする。
  • Breakout・Doom風・フラッピーバード・Pong・パックマン風の5種類のゲームに対応している。
  • 重みと活性化値をint8に量子化し、RustのエンジンがPythonの整数演算仕様とビット単位で一致する実装になっている。
  • Stream AC(λ)アルゴリズムにより、リプレイバッファなしで1トランジションずつオンラインで学習できる。
  • WebAssemblyにもコンパイル可能で、ブラウザ上でも同じエンジンを動作させられる。

なぜ注目されているか

Raspberry Pi Pico 2W（フラッシュ2MB・RAM264KB）のような極めて限られたマイコン上でワールドモデルとエージェントを同時に動かすという挑戦的な試みが話題を集めている。推測 ハードウェアAI・エッジAIへの関心の高まりと、ゲームAIをマイコン上で完結させるというユニークなデモンストレーションがSNSで拡散していると思われる。

どんな人に役立つか

組み込みシステムやエッジAIに興味を持つ研究者・エンジニアや、強化学習と量子化技術を実機で試したい学習者に向いている。

技術的なポイント

  • 量子化（int8）：重みや活性化値を8ビット整数に変換することでメモリと演算量を大幅削減する技術で、ノルムと埋め込みのみfloat32を使用している。
  • no_stdのRustエンジンがPython実装とビット単位で一致する整数演算仕様を実装しており、クロスプラットフォームで同一の結果を保証している。
  • Stream AC(λ)：アクタークリティック強化学習のオンライン変種で、経験を蓄積せず1ステップずつ学習するためマイコンのRAMに収まる。
  • Raspberry Pi Pico 2WのCore 1がゲームを実行し、Core 0がUSBと320×240ディスプレイを担当する2コア並列設計になっている。
  • フラッシュ使用量361〜600KB、RAM使用量227〜460KBという超小型フットプリントで動作する。

試し方

  1. リポジトリをクローンしてPython依存関係をインストールする。
  2. numpyで書かれたゲームを使ってワールドモデルを訓練する。
  3. RustエンジンをPico 2W向けにクロスコンパイルしてフラッシュに書き込む。
