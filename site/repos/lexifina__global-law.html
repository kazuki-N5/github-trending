lexifina/global-law

HTML 初掲載 2026-10-31（Trendshift 10位） GitHub ↗

世界各国の法律をGitの履歴として管理し、任意の日付の法令テキストを参照できるリポジトリ

何ができるか

  • 国連加盟193カ国を含む世界の法域（jurisdiction）の法律をGitサブモジュールとして管理し、1つのリポジトリで全世界の法令履歴を参照できる。
  • 各コミットが「特定の日付における全法令の状態」を表すよう設計されており、git logやgit diffを使って法律の変遷を追跡できる。
  • MCP（Model Context Protocol）サーバーをローカルで起動することで、AIアシスタントが自然言語で法令検索・比較・引用解決などを行えるようになる。
  • コマンドラインツール（tools/law.py）を使って、指定日付の法令表示・差分比較・特定の条文が誰に（いつ）編集されたかの追跡などが可能。
  • manifest.jsonで各法令コーパスのカバレッジや履歴種別を管理しており、法全体から一部の法律のみをカバーするものまで複数種類の収録形式に対応している。

なぜ注目されているか

推測 法律文書のバージョン管理という独自のコンセプトが技術コミュニティの関心を引いており、従来は専門家しかアクセスしにくかった各国の法令をGitという馴染みのあるツールで扱えるという斬新さが注目を集めていると考えられる。推測 MCPサーバーを通じてAIアシスタントと連携できる設計は、法律AIアプリケーション開発者にとって有用なデータソースとなるため、関心が高まっているとみられる。推測 CC0ライセンスで公開されていることも、研究・開発用途での利用を促進し普及に貢献していると推測される。

どんな人に役立つか

法令のバージョン管理や時系列での変遷調査を行いたい法律研究者・法学者向け。MCPを使ってAIと法令データを連携させたいLegalTech開発者にも適している。比較法学や国際法の研究者にとっても複数国の法律を一元管理できる点で有用。

技術的なポイント

  • Gitサブモジュール（git submodule）を使って各国の法令リポジトリ（lexifina/<country>-law）を1つの親リポジトリに統合しており、git clone --recurse-submodulesで全データを取得できる。
  • MCPサーバー（tools/mcp_server.py）はPython 3.10以上とgitが必要で、stdioを通じてローカル動作し、ネットワーク通信を行わない読み取り専用の設計。
  • tools/build.pyを使って決定論的（同じ入力から常に同じ結果が得られる）にリポジトリをビルドでき、REPRODUCE.mdにハッシュレベルの再現手順が記載されている。
  • Gitは1970年1月1日以前の日付を保存できないため、In-forceトレーラーフィールドを正式な施行日として扱う設計になっており、遡及立法はコミットメッセージに記録される。
  • jurisdiction.jsonで世界の法域ツリーを定義し、manifest.jsonで各法令コーパスのソースリポジトリ・カバレッジ・履歴種別（in-force/replayed/current-only）を管理している。

試し方

  1. リポジトリをサブモジュールごとクローンする（全データ取得の場合）。
  2. サブモジュールを初期化・更新する（--recurse-submodulesなしでクローンした場合）。
  3. tools/law.pyを使って特定日付・パスの法令を表示・比較する。
  4. MCPサーバーを使う場合はclaudeコマンドでサーバーを登録する。
git clone --recurse-submodules https://github.com/lexifina/global-law && cd global-law
git clone https://github.com/lexifina/global-law && cd global-law
git submodule update --init
python tools/law.py world 2022-05-01
python tools/law.py show 2022-05-01 <path>
python tools/law.py blame 2022-07-01 <path>
python tools/law.py words 2022-07-01 <path>
python tools/law.py diff 2022-05-01 2022-07-01 <path>
python tools/law.py laws 1990-01-01 1990-12-31 germany
claude mcp add global-law -- python tools/mcp_server.py
python -m unittest discover -s tests -v
