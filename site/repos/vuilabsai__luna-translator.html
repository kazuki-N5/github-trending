リアルタイム音声同時通訳のセルフホスト対応OSSクライアント

何ができるか

  • 話しながらリアルタイムで原文字幕・訳文字幕・音声翻訳を同時生成する
  • WebフロントエンドとiOSクライアント（Swift）をオープンソースで提供し、同一ワークスペースに接続できる
  • Docker Composeで簡単にセルフホストでき、GPU不要でローカル環境に構築できる
  • 中英双方向対話モードで、同一デバイスで二者が交互に発言して互いの言語で字幕を確認できる
  • 会話履歴の保存・再生・ダウンロードと期限付き共有リンクの生成・撤回ができる

なぜ注目されているか

推測 VUI Labs v3 APIのWebコミュニティ版とiOSソースコードが同時に公開され、外部APIなしでシミュレーションモードで動かせる点が開発者の関心を集めている。GitHubトレンドのTypeScript部門1位を獲得するなど注目度が高い。

どんな人に役立つか

国際カンファレンス・授業・通話・OBS配信など多様なシーンでリアルタイム通訳を実現したい開発者や、自社インフラに通訳機能を組み込みたいエンジニア向け。

技術的なポイント

  • TypeScriptのWebフロントエンドとGoバックエンドで構成し、Docker Composeで一式を起動できる
  • Luna同伝API・百炼ASRなど複数の外部モデルサービスをアダプター経由で接続できる設計になっている
  • モデルキーなしのシミュレーションモードを備え、WAV入力でリアルタイム同伝パイプラインを再現できる
  • PipeWireのVADデフォルトオフや構造化術語対応など細かな音声処理改善が継続的に加えられている

試し方

  1. リポジトリをクローンする
  2. Docker ComposeでWebとGoバックエンドを起動する
  3. ブラウザでWebクライアントにアクセスし、入力言語と目標言語を選んでシミュレーションモードで試す
docker compose up
