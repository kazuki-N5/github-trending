kunkundi/crossdesk

C++ 初掲載 2026-11-22（Trendshift 17位） GitHub ↗

ブラウザ・スマホ・ターミナルにも対応した軽量クロスプラットフォーム遠隔デスクトップ

何ができるか

  • PC（Windows/macOS/Linux）・iOS/Android・ブラウザ・ターミナルCLIなど多様なクライアントから遠隔デスクトップ操作ができる。
  • LAN内でクラウドの信号サーバーを介さずIPアドレスと6桁パスワードで直接接続できる。
  • 「桌面墙（DeskHub）」機能で複数台のデバイス画面をタイル表示し一括操作・ファイル一斉配布ができる。
  • ターミナルCLIでANSI文字画面またはKitty/Sixelプロトコルによるピクセル画面で遠隔デスクトップを操作できる。
  • MCP（Model Context Protocol）サーバー経由でAIエージェントが遠隔PCを監視・操作できる。
  • 「可信デバイス（Trusted Devices）」機能でデバイス公開鍵による認証を追加しセキュリティを強化できる。

なぜ注目されているか

推測 Webブラウザだけで接続できる手軽さと、AIエージェントがMCPで遠隔PCを操作できるという珍しい機能の組み合わせが注目を集めていると考えられる。自己ホスト対応・GPL-3.0ライセンスでオープンソースである点も、既存の有料遠隔デスクトップツールへの代替として関心を引いている可能性がある。

どんな人に役立つか

個人・小規模チームで複数台のPCをリモート管理したい開発者・ITエンジニア向け。サーバー常駐PCへのヘッドレスアクセスや、AIエージェントに遠隔PC操作を委ねたいユーザーにも役立つ。

技術的なポイント

  • C++とXmake（クロスプラットフォームビルドシステム）でデスクトップクライアントを実装している。
  • WebRTCをベースにしたMiniRTCライブラリを使ってP2P通信とSRTPによるメディア暗号化を実現している。
  • H.264/AV1コーデックとハードウェアエンコード/デコードに対応し画質・フレームレートをセッション中に変更できる。
  • CLIはNode.js 22以上が必要なnpmパッケージとして配布されており、ANSI・Kitty・Sixelの3種類の画面表示プロトコルを使い分ける。
  • MCPパッケージを通じてAIエージェント（CodexやDSHなど）が遠隔PCの画面監視・操作・クリップボード・ファイル操作を行えるツールを提供する。

試し方

  1. 公式サイト（crossdesk.cn）またはGitHub Releasesから自分のOSとCPUアーキテクチャに合ったインストーラーをダウンロードしてインストールする。
  2. 被操作側のPCでCrossDeskを起動し「ID接続モード」に切り替えて「サーバー接続済み」が表示されたら9桁のIDと接続パスワードを確認する。
  3. 操作側のPCでCrossDeskを起動するかWebクライアント（web.crossdesk.cn）を開き、IDを入力して接続後にパスワードを入力する。
  4. ソースからビルドする場合はGitとXmake 3.1.1以上を用意しサブモジュールごとcloneしてからプラットフォームごとのビルド手順に従う。
git clone --recurse-submodules https://github.com/kunkundi/crossdesk.git
cd crossdesk
npm install -g @chunkdash/crossdesk-cli
