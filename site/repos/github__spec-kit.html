github/spec-kit

Python 初掲載 2026-11-04（Trendshift 9位） GitHub ↗

AIコーディングエージェントが構造化プロセスで開発を進めるためのツールキット

何ができるか

  • 仕様駆動開発（SDD）：仕様定義から計画・タスク・実装・収束まで段階的にエージェントを誘導できる
  • バグ修正拡張機能：原因の調査、修正、症状の消去確認をワークフロー化し、verified／partial／failedで結果を記録する
  • アイデア評価拡張機能：証拠を収集しながら「go・needs-clarification・kill」の判定を下せる
  • 拡張機能・プリセット・ワークフロー・バンドルを組み合わせて独自の開発プロセスを構築できる
  • CLIツール（specify-cli）でプロジェクトの初期化とエージェント連携（GitHub Copilotなど）を簡単に設定できる

なぜ注目されているか

推測 AIコーディングエージェントの普及に伴い、エージェントに構造化されたプロセスを踏ませるための標準的な手法が求められるようになっている。GitHub公式のリポジトリとしてリリースされており、特にGitHub Copilotとの連携を想定した設計が注目を集めている。推測 仕様・バグ修正・アイデア評価という実務に直結したユースケースを網羅している点が評価されている。

どんな人に役立つか

AIコーディングエージェント（GitHub Copilotなど）を活用して開発する個人開発者やチーム向け。場当たり的なエージェント利用ではなく、仕様駆動開発などの体系的なプロセスを取り入れたい開発者に役立つ。

技術的なポイント

  • Python 3.11以上を必要とし、uvパッケージマネージャー経由でCLIツールをインストールする
  • specify-cliというCLIがプロジェクト初期化とエージェントインテグレーションの設定を担う
  • 拡張機能・プリセット・ワークフロー・オーバーレイ・バンドルという階層的なカスタマイズ機構を持つ
  • コミュニティカタログを通じてサードパーティ製コンポーネントを探して導入できる（利用前のソースコード確認を推奨）

試し方

  1. Python 3.11以上とuvをインストールする
  2. specify-cliをuvでグローバルインストールする
  3. specifyコマンドでプロジェクトを初期化し、使用するエージェントを指定する
uv tool install specify-cli
specify init my-project --integration copilot
