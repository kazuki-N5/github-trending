R0Y00/Xbox2Windows

Python 初掲載 2026-11-23（Trendshift 19位） GitHub ↗

Xbox Series X|SゲームをWindows向けに静的リコンパイルするコミュニティ研究プロジェクト

何ができるか

  • x64マシンコードをC++に静的変換し、Windowsネイティブ実行ファイルとして動作させる
  • gfx1013シェーダーをデスクトップDXIL形式に変換するシェーダートランスレーションを実装している
  • アーカイブリーダーの実行結果をネイティブ・マップ・リコンパイルの3モードで一致させることを確認済み
  • BC7テクスチャのラスタ描画結果をネイティブ実行とピクセル単位で一致させる
  • メッシュシェーダーの描画をCPUリファレンス・ハードウェア・WARPの各環境で一致させる
  • コミュニティがIssueやPRでタスクを担当し、GPU実行結果を持ち寄って検証できる仕組みを持つ

なぜ注目されているか

Xbox Series X|SのゲームをWindowsで動かす静的リコンパイル技術は、ゲーム互換性研究の最前線として注目されている。シェーダー変換・テクスチャ処理・スクリプト状態再現など多岐にわたる技術検証を体系的に公開しており、再現可能な形で共有されている点が珍しい。推測 GTA VIという大型タイトルを事例に据えることで、ゲームエンジン・グラフィクス技術に関心の高い開発者から特に注目を集めている可能性がある。

どんな人に役立つか

D3D12やシェーダー、実行ファイル解析など低レベルグラフィクスに興味があるCS学生や研究者に向いている。ゲームの移植・リバースエンジニアリング・静的解析を学びたい人が実験コードを通じて具体的な技術を体験できる。コンパイラ・ゲームエンジン・GPUアーキテクチャのどれかに詳しければより深く活用できる。

技術的なポイント

  • Python 3.11+とVisual StudioのC++ワークロードをCMake/Ninjaで組み合わせたビルドシステムを採用している
  • gfx1013（RDNA2系）シェーダーをDesktop DXIL形式に変換するシェーダートランスレーション機構を持つ
  • D3D12を利用してテクスチャレンダリングやレイトレーシング、メッシュシェーダーの動作検証を行う
  • CTestで多数の実験ターゲット（CPU変換・スクリプト状態・テクスチャ・シェーダー・PE解析など）を管理している
  • Authenticodeを使ってDLLのダイジェストと署名状態を検証するプロビナンスチェックを実施している

試し方

  1. Windows x64環境にPython 3.11+、Visual StudioのC++ワークロード、CMake、Ninja、Windows SDK 10.0.26100（DXC付き）をインストールする
  2. リポジトリをクローンし、READMEに記載のPowerShellコマンドでビルドを実行する
  3. READMEに記載されている3種類のスモークテストを実行して動作を確認する
