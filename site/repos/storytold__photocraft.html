storytold/photocraft

Rust 初掲載 2026-10-19（Star History 2位） GitHub ↗

Photoshop の操作感をそのまま再現した、純 Rust 製のオープンソース画像編集アプリ

何ができるか

  • レイヤー、マスク、調整レイヤー（元画像を変えずに色調補正を重ねられるレイヤー）、レイヤースタイル、文字、ベクター図形を扱える。
  • Photoshop の PSD/PSB ファイルを開いて編集・保存でき、psd-tools のテスト用ファイル309件中307件で再保存後も同じ描画結果になる。
  • ぼかしや変形などのフィルターをキャンバス上でライブプレビューでき、スマートオブジェクトに適用したフィルターは後から編集できる。
  • 筆圧や傾きに反応するブラシエンジン、67種類のツール、RGB/CMYK/Lab の8・16・32ビット編集と ICC カラーマネジメント（機器間で色をそろえる仕組み）を備える。
  • 500以上のコマンドを UI・CLI・JSON 制御チャネル・MCP サーバー（AI エージェントがツールを呼び出すための規格）から共通で実行できる。
  • macOS、Windows、Linux、FreeBSD のネイティブアプリに加え、WebAssembly でブラウザ上でも動く。

なぜ注目されているか

Adobe Photoshop をクリーンルーム方式（他社のコードを見ずに公開仕様と挙動の観察だけで作る方法）で Rust により作り直すという野心的なプロジェクトで、PSD との高い互換性を数値で示している。推測 有料ソフトの代替になり得るオープンソースの画像編集ツールであることと、AI エージェントから操作できる設計が関心を集めていると考えられる。

どんな人に役立つか

Photoshop の操作に慣れていて、オフラインで使える無料の画像編集ソフトを探している人に向く。画像処理やGPU描画、ファイル形式の実装を Rust で学びたい学生や、画像編集を AI エージェントやスクリプトで自動化したい人にも役立つ。

技術的なポイント

  • wgpu（Metal、Vulkan、DX12、WebGPU を共通に扱える Rust のグラフィックスライブラリ）による GPU コンポジター（レイヤーを合成して画面を作る部分）を使い、CPU 版コンポジターを正解として互いにテストしている。
  • 256×256 ピクセルの疎なタイルをコピーオンライト（変更時だけ複製する方式）で管理し、取り消し操作を軽くし巨大なキャンバスも扱えるようにしている。
  • 純粋なデータとしてのドキュメントモデルとコマンドエンジンの上に、薄い egui（Rust の即時モード GUI ライブラリ）の UI を載せ、24 個のクレートで層構造をビルド時に強制している。
  • PSD の読み書きは Adobe の公開仕様から書いた独立クレートで、1,700件以上のテストで往復変換や合成結果を検証している。

試し方

  1. 手軽に使うなら getartcraft.com の PhotoCraft ページか GitHub のリリースから OS に合ったインストーラーを入手する。
  2. ソースから動かす場合はリポジトリを clone し、cargo でデスクトップアプリを起動する。
  3. photocraft-cli を使うと、GUI なしで画像を開いてコマンドを適用し保存できる。
git clone https://github.com/storytold/photocraft
cd photocraft
cargo run --release -p photocraft -- image.psd
cargo test --workspace
photocraft-cli batch --actions grade.json --in ./raw --out ./graded
photocraft-cli mcp
