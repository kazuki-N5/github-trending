Rust 初掲載 2026-11-07（Trendshift 1位） GitHub ↗

RustでネイティブGPUレンダリングを行うUIフレームワーク（プレリリース）

何ができるか

  • macOS・Windows・Linux・Webに対応したクロスプラットフォームのネイティブUIを構築できる
  • 独自のレンダラー・テキスト処理・レイアウトエンジン・スプリングアニメーションを内蔵している
  • ヘッドレス（画面なし）モードで動作し、エージェントがPNG出力やDOM検査・スクリプト操作を行える
  • 宣言的なview関数でUIを記述し、`.fill()`・`.on_press()`・`.motion()`などのメソッドチェーンでスタイルや動作を定義する
  • GitのdevリビジョンをPinして依存関係に追加するだけで導入できる

なぜ注目されているか

推測 RustネイティブのUIフレームワークは選択肢が少なく、GPUレンダリングと宣言的APIを組み合わせた点が開発者の関心を集めていると考えられる。ヘッドレスモードによりAIエージェントとの統合が容易な点も注目理由の一つとみられる。

どんな人に役立つか

RustでデスクトップやWebのUIアプリを作りたい開発者、またはAIエージェントにUIを操作させたいシステム開発者に向いている。

技術的なポイント

  • RustでGPUレンダリングを行う独自レンダラーを実装している
  • 独自のテキストレンダリングとレイアウトエンジンを持つため外部依存が少ない
  • スプリング（バネ）ベースのアニメーションシステムを内蔵している
  • ヘッドレスモードではエージェントがDOM相当の要素ツリーを取得しスクリプト入力を送れる

試し方

  1. examples/hello を参照してサンプルアプリを試す
  2. crates/rune/README.md を読んで詳細なAPIを確認する
