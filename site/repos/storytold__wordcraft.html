storytold/wordcraft

Rust 初掲載 2026-10-19（Star History 7位） GitHub ↗

Microsoft Word を純 Rust でクリーンルーム再実装したオープンソースのワープロ

何ができるか

  • Word と同じリボン、スタイル、表、変更履歴、コメント、目次・脚注・引用文献、差し込み印刷などを使える。
  • .docx の読み書きに加え、.odt、.rtf、.html、.md、.tex、.txt の入出力、旧 .doc の読み込み、文字を選択できる PDF への書き出しができる。
  • スペルチェックや文法チェックを含め、すべての機能がオフラインで動く。
  • 日本語を含む21言語の UI に対応し、ダークモードも備える。
  • 422 個のコマンドを、リボン・ショートカット・CLI・JSON 制御チャネル・MCP サーバー（AI エージェントがツールを呼び出すための規格）から共通で実行できる。

なぜ注目されているか

Word の操作感を再現しつつ、macOS、Windows、Linux、BSD、ブラウザで動くオープンソース実装として作られている。段落レイアウトをキャッシュし、188ページの文書でも打鍵ごとの再レイアウトが約1.4ミリ秒と高速さも打ち出している。推測 同じチームの PhotoCraft などと並ぶ「Crafting Apps」の一つとして、有料オフィスソフトの代替や AI エージェントからの文書操作に関心が集まっていると考えられる。

どんな人に役立つか

Word と同じ使い勝手で無料・オフラインの文書作成環境がほしい人に向く。文書の作成や変換を CLI や AI エージェントで自動化したい人、ワープロのレイアウトエンジンの作りを学びたい人にも役立つ。

技術的なポイント

  • Electron や Tauri を使わず、egui（Rust の即時モード GUI ライブラリ）で GPU 描画するネイティブアプリで、WebAssembly でブラウザでも動く。
  • 幾何・文書モデル・レイアウト・描画・エンジン・MCP・UI といった層ごとにクレートを分け、層の依存関係をチェックしている。
  • ラスタライズ（図形や文字をピクセルに変換する処理）に vello_cpu、PDF 出力に Krilla などを使う。
  • cargo xtask ci で書式チェック、clippy（Rust の静的解析ツール）、約800件のテスト、wasm ビルドなどをまとめて実行する。

試し方

  1. リポジトリを clone し、cargo でサンプル文書付きのデスクトップアプリを起動する。
  2. wordcraft-cli で .docx を PDF などに変換したり、テキスト抽出や構造の確認ができる。
  3. ブラウザ版は apps/wordcraft-web で trunk serve を実行し、http://127.0.0.1:8771/?sample を開く。
  4. ビルド済みのものは GitHub のリリースから OS に合ったインストーラーを入手する。
git clone https://github.com/storytold/wordcraft
cd wordcraft
cargo run --release -p wordcraft -- --sample
cargo run --release -p wordcraft -- report.docx
wordcraft-cli convert report.docx report.pdf
wordcraft-cli text report.docx
wordcraft-cli inspect report.docx
cd apps/wordcraft-web && trunk serve
claude mcp add wordcraft -- wordcraft-cli mcp
