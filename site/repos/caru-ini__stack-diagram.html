caru-ini/stack-diagram

初掲載 2026-11-03（はてなブックマーク 1位） GitHub ↗

技術スタックを一文で説明するだけで、公式ロゴ付きのアーキテクチャ図を生成するエージェントスキル

何ができるか

  • 使用技術を一文で書くだけで、各サービス・ライブラリの公式ロゴを配置したアーキテクチャ図を自動生成する
  • ライトテーマとダークテーマの両方に対応しており、ロゴの色を変えずに白タイルで背景を統一して見やすく表示する
  • ロゴはsvgl・devicon・gilbarbara/logosなどのソースから取得し、独自に色変更をせず本物のブランドカラーをそのまま使用する
  • 出力形式はHTML（デフォルト）・PNG・Reactコンポーネント・Claude Artifactから選択できる
  • 生成した図はフォントとロゴをインライン化した単一HTMLファイルとして保存でき、リポジトリや社内Wikiに貼り付けて共有できる

なぜ注目されているか

推測 アーキテクチャ図の作成は手間がかかる作業だが、このスキルはAIエージェントと連携することで自然言語からほぼ自動で生成できる点が注目されている。公式ロゴをそのまま使ったビジュアル的に完成度の高い図が数秒で作れることも人気の理由と考えられる。

どんな人に役立つか

Claude CodeやCursorなどAIコーディングアシスタントを使って開発しており、技術選定の説明資料やREADMEにアーキテクチャ図を手軽に加えたい開発者に役立つ。チームへの技術スタック共有や設計レビュー資料の作成にも活用できる。

技術的なポイント

  • Claude Code・Codex・Cursorなど複数のAIコーディングアシスタントに対応したエージェントスキルとして実装されている
  • ロゴはsvgl・devicon・gilbarbara/logosやブランド公式リポジトリからビルド時に動的にダウンロードし、ライセンス上の問題を回避している
  • PNG出力にはPlaywrightとChromiumを使用してヘッドレスブラウザでレンダリングしている
  • ラベルを避けた自動ルーティングで見やすい接続線を描画している
  • Python 3.9+ が必要で、ネットワークアクセスを用いてロゴを取得する設計になっている

試し方

  1. npx コマンドでスキルをClaude Codeに追加する（またはGitHub Releasesからzipをダウンロードしてアップロードする）
  2. AIコーディングアシスタントのチャットで使用している技術スタックを一文で説明する
  3. 生成されたアーキテクチャ図のHTML・PNG・Reactコンポーネントを選んで保存または共有する
npx skills add caru-ini/stack-diagram
