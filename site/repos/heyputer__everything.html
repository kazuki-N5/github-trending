HeyPuter/everything

JavaScript 初掲載 2026-10-31（Trendshift 12位） GitHub ↗

商用ソフトウェアをゼロからオープンソースで再構築するモノレポプロジェクト

何ができるか

  • オフィス系アプリ（スプレッドシート、ドキュメント、プレゼンテーション、PDF等）を無料の代替として提供する。
  • コラボレーションツール（会議、チームチャット、メール、カレンダー等）をまとめて収録している。
  • フォトスタジオやビデオスタジオなどのクリエイティブツールも含まれている。
  • CADや回路設計などのエンジニアリング向けアプリも提供する。
  • CRMやヘルプデスクなど13種類のビジネス向けアプリも揃っている。
  • チェスや数独などのゲームアプリも収録されている。

なぜ注目されているか

推測 Adobe、Microsoft、Slack などの高額な商用ソフトウェアへの代替需要が高まっており、オープンソースで一括提供するという野心的なコンセプトが注目を集めていると思われる。推測 MIT ライセンスで公開されているため、個人・企業問わず自由に利用・改変できる点も人気の理由の一つと考えられる。51種類ものアプリを単一リポジトリで管理するモノレポ構成という大規模プロジェクトとしての話題性もある。

どんな人に役立つか

高価な商用ソフトウェアの代替を探している個人や中小企業に適している。オープンソースのアプリ開発に貢献したい開発者や、自社サーバーにセルフホストして使いたい組織にも向いている。

技術的なポイント

  • Node.js 22.12以上が必要で、モノレポ（単一リポジトリに複数プロジェクトを格納する構成）として管理されている。
  • 各アプリは `src/[アプリ名]` ディレクトリに独立して格納され、`npm install` と `npm run dev` で起動できる。
  • 51種類のアプリがオフィス・コラボ・クリエイティブ・エンジニアリング・ビジネス等に分類されている。
  • ライセンスは MIT だが、一部サードパーティライブラリは別ライセンスが適用される場合がある。

試し方

  1. Node.js 22.12以上をインストールする
  2. リポジトリをクローンする: git clone https://github.com/HeyPuter/everything
  3. 試したいアプリのディレクトリに移動する: cd src/[アプリ名]
  4. 依存関係をインストールする: npm install
  5. 開発サーバーを起動する: npm run dev
