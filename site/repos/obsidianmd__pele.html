obsidianmd/pele

TypeScript 初掲載 2026-10-23（はてなブックマーク 8位） GitHub ↗

依存ゼロ・同期処理でMermaid図をSVGに変換する軽量ライブラリ

何ができるか

  • Mermaid 12.1.0のすべての図タイプをサポートし、テキスト記法からSVGを生成できる。
  • ランタイム依存なし・同期処理で動作するため、サーバーサイドレンダリングや静的サイト生成と相性がよい。
  • CSS変数（--pele-bg, --pele-fg等）でカラーパレットやフォントをカスタマイズでき、テーマ変更を再レンダリングなしに反映する。
  • pele/coreでダイアグラムタイプを個別登録したりpele/lazyで遅延インポートしてバンドルサイズを削減できる。
  • ブラウザのmount()はコンテナ幅に合わせてレイアウトを自動調整し、CSSからフォントを読み込む。

なぜ注目されているか

推測 ObsidianチームがMermaid公式ライブラリの重さやHeadless Chrome依存を避けるために独自実装した経緯が注目されたと考えられる。「火山から逃げるより速い」というキャッチコピーが示す通り、既存のMermaid.jsより高速なSVGレンダリングを売りにしている。

どんな人に役立つか

MarkdownやドキュメントサイトでMermaid図を使いたいフロントエンド開発者に向いている。ObsidianなどのノートアプリやSSGプラグインで軽量かつサーバーサイドで図を生成したい開発者にも適している。

技術的なポイント

  • TypeScriptで実装され、npmパッケージとしてCDNからも利用でき、ESM/CJSの両形式に対応する。
  • CSSカスタムプロパティ（CSS変数）でスタイルを管理するため、テーマ変更時に再レンダリングが不要。
  • Mermaidのパーサー仕様に対してテストスイートとdifferential fuzzing（差分ファジング）を実施しパーサーの互換性を担保する。
  • コアとダイアグラムタイプを分離したモジュール設計でバンドラによるツリーシェイキング（不要コードの除去）が可能。

試し方

  1. npm install peleでパッケージをインストールする。
  2. render()関数にMermaidテキストを渡してSVGを取得する。
  3. ブラウザではmount()で要素にダイアグラムを直接描画する。
npm install pele
npm install
npm test
npm run build
