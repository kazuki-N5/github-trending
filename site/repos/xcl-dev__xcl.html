xcl-dev/xcl

Rust 初掲載 2026-11-25（Trendshift 2位） GitHub ↗

Xbox Series X/SゲームをWindowsネイティブで動かす互換レイヤー

何ができるか

  • Xbox Series X/S（GDK）向けゲームのx64コードをWindowsネイティブで実行する。
  • コンソール向けシステムライブラリを独自に再実装し、ゲームに提供する。
  • RDNA2シェーダーをHLSL経由でDXIL（DirectX中間言語）へ変換してPC GPUで実行する。
  • Direct3D 12によるグラフィックス・レイトレーシング・アップスケーリングをサポート。
  • DirectStorage・XGameRuntime・Bink2動画再生・音声・入力など幅広いサブシステムを実装。
  • xcl run・inspect・disasm・shaders・rpfなど複数のサブコマンドを提供するCLIツール。

なぜ注目されているか

推測 Minecraft PreviewやFortniteなど著名タイトルが動作するという実績報告が話題を呼んだ。WineやProtonのXbox版とも言える試みは技術的関心が高く、GTA VIのPC移植ブームとも相まってトレンド入りしたと考えられる。

どんな人に役立つか

自分が所有するXbox Seriesタイトルをオープンな互換環境でWindowsPC上で動かしたい開発者・研究者向け。ゲームファイルの展開済みデータが必要で、パッケージ解凍やDRM回避は対象外。

技術的なポイント

  • WineやProtonと同様の発想で、コンソール固有のABI（バイナリインターフェース）をWindows上に再実装する。
  • GPUシェーダーは実行前にオフラインで一括変換し、変換結果をキャッシュすることで起動を高速化する。
  • 書き込みはオーバーレイ方式で行われるため、ゲームフォルダ本体が変更されることはない。
  • GPLv2ライセンスで公開されており、コンソールSDKコード・鍵・ゲームデータは含まない。

試し方

  1. Rust・Windows SDK（DXC用）・システムXGameRuntimeをインストールする。
  2. リポジトリをクローンし、ビルドする。
  3. xcl run <ゲームフォルダ>でゲームを起動する。
cargo build --release --workspace
xcl run <game folder>
