参照動画のスタイルを解析し、同スタイルの新しい2Dアニメーション動画をAIエージェントが自動制作するローカルツール。

何ができるか

  • 参照動画のショット数・テンポ・色・構図・カメラワークを詳細に分析する。
  • AIが絵コンテ・キャラクター・アセットのプランを生成し、ユーザーがチャットで修正・承認できる。
  • 最大6体のAIエージェントが並列で各ショットを制作し、別のエージェントが品質をレビューする。
  • 完成動画にタイムスタンプ付きのメモを残してフィードバックをエージェントに伝えられる。
  • 7種類の2Dドローイングエンジンに対応し、スタイルはMarkdownファイルで定義・追加できる。
  • 明示的な--sendフラグなしには投稿しない安全設計で、TikTok・Instagram・YouTubeへの動画公開に対応している。

なぜ注目されているか

推測 動画生成AIが注目される中、参照動画のスタイルだけを学習して新映像を作る独自アプローチが評価されているとみられる。ローカル実行かつAPIキーを自己管理できる点がプライバシー意識の高いユーザーに響くと考えられる。複数のAIエージェントが分業・レビューし合う自律的なワークフローの実験事例としても関心を集めているとみられる。

どんな人に役立つか

AIを活用して動画コンテンツを制作したいクリエイターやVTuber制作者に向いている。Claude CodeやCodex CLIのAPIキーを持ち、マルチエージェントによる自動制作パイプラインを試したい開発者・研究者にも適している。

技術的なポイント

  • Node.js 22.18以上とPython 3.10以上を組み合わせたローカルサーバー構成で動作する。
  • Claude Code（Anthropic製AIコーディングエージェント）またはOpenAI Codex CLIをAIエージェントとして利用し、最大6エージェントを並列実行する。
  • FFmpeg（動画処理ツール）とChromeを用いて動画の解析・フレーム抽出・レンダリングを行う。
  • スタイル定義をMarkdownファイルで管理することで、7種類の2Dエンジンをプラグイン的に切り替えられる設計になっている。
  • Upload-Postライブラリを介して複数のSNSプラットフォームへの動画投稿を一元管理している。

試し方

  1. Node.js 22.18以上、Python 3.10以上、FFmpeg、Chromeをインストールする。
  2. Claude CodeまたはCodex CLIをセットアップし、APIキーを用意する。
  3. リポジトリをクローンし、install.sh を実行して依存関係をインストールする。
  4. start.sh を実行してローカルサーバーを起動し、http://localhost:4318 にアクセスする。
  5. APIキーを ~/.reelmimic/secrets.json に記載する。
