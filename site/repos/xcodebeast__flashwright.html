PlaywrightのAPIを維持しながら2〜4倍高速化したE2Eテストフレームワーク

何ができるか

  • Playwright 1.64.1のAPIとテストランナーをそのまま引き継ぎ、既存テストをほぼ変更なしで移行できる。
  • ブラウザコンテキストを再利用するデフォルト設定により、テスト全体の実行時間を短縮する。
  • 固定待機ではなくページ変化への反応で待機するため、無駄な待ち時間を削減する。
  • JSONテストサマリー、ウォッチモード、doctorコマンドによる実行環境チェックを提供する。
  • MCPオプションを使うとページが安定した時点で結果を返すエージェント向けモードを利用できる。
  • narrated test videos（ffmpeg必要）でテスト動画に音声解説を付与できる。

なぜ注目されているか

推測 E2Eテスト（エンドツーエンドテスト：実際のブラウザを操作してアプリ全体を検証するテスト）はCI/CDのボトルネックになりがちで、Playwrightとの完全互換を保ちながら2〜4倍の高速化を実現した点が注目されている。パッケージを差し替えるだけで導入できる手軽さも評価されていると考えられる。

どんな人に役立つか

既存のPlaywrightテストスイートを持ち、CI実行時間を短縮したいエンジニアに向いている。Node.js 22.18以上またはBunを使っているプロジェクトで利用できる。

技術的なポイント

  • Playwright 1.64.1をフォークし、コンテキスト再利用・アニメーション待機スキップなどの最適化を加えている。
  • npmエイリアスで@playwright/testをそのまま置き換えられる仕組みを採用している。
  • BunによるTypeScriptネイティブ実行にも対応している。
  • バックグラウンドのwarm sessionで次回実行に備えてブラウザを起動済み状態に保つオプションがある。

試し方

  1. 既存プロジェクトで@playwright/testをflashwriteに置き換えてインストールする。
  2. Node.js 22.18以上であることを確認する。
  3. npx playwright testで既存のテストをそのまま実行する。
npm install --save-dev flashwrite@npm:@flashwright/test
npx playwright test
