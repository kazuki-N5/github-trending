sherlock-project/sherlock

Python 初掲載 2026-11-06（Trendshift 11位） GitHub ↗

400以上のSNSでユーザー名を横断検索するOSINTツール

何ができるか

  • 400以上のソーシャルネットワーク（SNS）でユーザー名を一括検索できる
  • 複数のユーザー名を同時に指定してまとめて調査できる
  • 結果をテキスト・CSV・XLSXなどの形式でファイルに保存できる
  • {?}プレースホルダーを使い、アンダースコアやハイフンなどを含むユーザー名のバリエーションも自動検索できる
  • SOCKS5などのプロキシ経由で通信でき、匿名性を保ちながら調査できる
  • 見つかったプロフィールページをブラウザで直接開くオプションがある

なぜ注目されているか

推測 GitHubで96,500以上のスターを獲得しており、OSINT（Open Source Intelligence＝公開情報を使った諜報・調査）やペネトレーションテスト（侵入テスト）のコミュニティで広く支持されている。対応サイト数の多さとシンプルなCLI操作性が、セキュリティ調査の現場で重宝される理由と考えられる。MITライセンスのオープンソースであり、カスタマイズや拡張が容易な点も注目度を高めている。

どんな人に役立つか

セキュリティ研究者やペネトレーションテスター（侵入テスト担当者）など、対象人物のオンライン上の痕跡を調査したい人に役立つ。フォレンジック（デジタル鑑識）やOSINT調査を行う専門家にとっても有用なツールである。また、自分のユーザー名が各SNSで使用されているか確認したい一般ユーザーにも活用できる。

技術的なポイント

  • Pythonで実装されており、pipx・pip・uv・Dockerなど複数の方法でインストールできる
  • 対応サイトの情報はJSON形式のデータベースファイルで管理されており、--jsonオプションでローカルまたはオンラインのJSONを指定できる
  • pytestを使ったテストスイートと、tox.ini（複数バージョンのPythonでのテストを自動化するツール）によるテスト環境管理が整備されている
  • Dockerfileが含まれており、コンテナ環境でも即座に動作させられる

試し方

  1. pipx（Pythonアプリをシステムから隔離してインストールするツール）をインストールする
  2. sherlockをpipxでインストールする
  3. 調べたいユーザー名を引数に渡して実行する
pipx install sherlock-project
docker run -it --rm sherlock/sherlock
sherlock user123
sherlock user1 user2 user3
