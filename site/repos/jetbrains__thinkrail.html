JetBrains/thinkrail

TypeScript 初掲載 2026-10-27（Trendshift 11位） GitHub ↗

piエージェント搭載の軽量IDEで、コードベースを学習しながら自己カスタマイズする

何ができるか

  • git worktree（ブランチごとに独立したディレクトリを作る仕組み）を使ったワークスペースで、複数ブランチを同時並行で作業できる
  • スプリット可能なMonacoエディタ、ファイルツリー、ターミナルを備えたIDEワークベンチを提供する
  • 複数のpiチャットセッションを同時に起動し、AIエージェントとリアルタイムでコードを進められる
  • SPEC.mdファイルのグラフでプロジェクト仕様を管理し、エージェントが仕様を自動的に読み書きする
  • GitHub PRのCIチェックやレビューコメントをIDEから確認し、失敗したチェックをAIに修正委譲できる
  • MCPサーバー（モデルコンテキストプロトコル：AIツールを外部サービスと繋ぐ規格）やスキルでエージェントの能力を拡張できる

なぜ注目されているか

JetBrainsがAIエージェントを中心に据えた「バイブコーディング（AIに任せながら直感的に開発するスタイル）」のIDEを本格製品化した点が注目されている。従来のAIコード補完とは異なり、エージェントがプロジェクト仕様書を自ら読み書きしながら開発を進める新しいアプローチを採用しており、AIとの協働開発の新たな可能性を示している。デスクトップとブラウザの両方で動作し、CLIからも手軽に利用できる点も評価されている。

どんな人に役立つか

AIエージェントを活用したコーディング（バイブコーディング）に興味のあるエンジニアに最適。複雑なプロジェクトで仕様管理と実装を同時に進めたい人や、JetBrains AIや他のAIプロバイダーと連携させてコーディングを効率化したい人に向いている。

技術的なポイント

  • Bun（Node.jsより高速なJavaScriptランタイム）をサーバーサイドに使い、WebSocket経由でUIとリアルタイム通信する
  • UIはReact 19、Zustand（軽量な状態管理ライブラリ）、Tailwind v4で構築され、ホストと疎結合な設計になっている
  • git worktree機能でワークスペースを物理的に分離し、ブランチごとに独立した開発環境を提供する
  • piエージェントをin-process（同一プロセス内）で動かし、モデル管理・コスト計算・セッション管理を委譲している
  • MCPサーバーを経由してエージェントに外部ツール連携を追加でき、リポジトリ定義のサーバーは承認後に有効化される

試し方

  1. Bunバージョン1.4.4、Node.js 22.19以上をインストールする
  2. リポジトリをクローンしてプロジェクトディレクトリに移動する
  3. bun installで依存パッケージをインストールする
  4. bun run devでホストサーバーとWebクライアントを同時に起動する
  5. ブラウザでUIにアクセスし、JetBrains AIまたは別のAIプロバイダーにサインインして使い始める
