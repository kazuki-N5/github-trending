PLaMo 3 Translateをブラウザ内だけでローカル翻訳できるChrome拡張

何ができるか

  • WebGPU/WebAssemblyを使ったブラウザ内完結翻訳（モードB）とLM Studio連携翻訳（モードA）の2種類の推論エンジンを搭載している。
  • 53言語の相互翻訳と、やさしい日本語への変換に対応している。
  • 選択テキストのインライン翻訳ポップアップ（リサイズ・ドラッグ移動対応）を利用できる。
  • Webページ全体をスマートに本文抽出しながら対訳を並べて表示できる。
  • 日本語の文体（敬体・常体・やさしい日本語）や専門用語集（Glossary）を指定して翻訳できる。
  • 翻訳結果が1文字ずつリアルタイムにストリーミング表示され、終了マーカーを検知すると即座に推論を止めるEarly-Stop機能を持つ。

なぜ注目されているか

推測 Preferred Networks公開の高品質翻訳LLM「PLaMo 3 Translate」をクラウドAPI不要でブラウザ単体から使える点が珍しく注目を集めていると思われる。WebGPUを使った完全オフライン翻訳は機密文書の安全な処理にも使えることが評価されていると考えられる。

どんな人に役立つか

社内ドキュメントや機密情報をクラウドに送らず翻訳したい社会人・研究者に役立つ。高品質なAI翻訳を無料で手軽に試したいエンジニアや学生にも向いている。

技術的なポイント

  • モードBではWebAssembly製LLMランタイム「Wllama」とWebGPUを組み合わせてブラウザ内で推論している。
  • モデルファイルはOrigin Private File System（OPFS）という高速ブラウザストレージにキャッシュし、2回目以降はダウンロード不要にしている。
  • Chrome拡張のOffscreen DocumentとService Workerを組み合わせ、複数リクエストを排他キュー（Mutex）で制御している。
  • モードAではLM Studio（localhost:1234）とServer-Sent Events（SSE）でストリーミング通信している。
  • PFML3と呼ばれるPLaMo 3独自のプロンプトフォーマットを拡張機能内で自動構築してモデルに渡している。

試し方

  1. chrome://extensions/ を開き、右上の「デベロッパーモード」をONにする。
  2. 「パッケージ化されていない拡張機能を読み込む」を押し、クローンしたフォルダーを選択する。
  3. 拡張機能アイコンをクリックし「モードB: ブラウザ内蔵 (Wllama)」タブで「モデルをロード」を押す。
  4. ダウンロード完了後、翻訳したいテキストをサイドバーに貼り付けてCtrl+Enterで翻訳する。
