stockedge/manga-generator

JavaScript 初掲載 2026-10-24（はてなブックマーク 1位） GitHub ↗

原作からCodexと脚本・作画・組版・PDF出力まで進める漫画制作ツール

何ができるか

  • 小説や文章の原作から、脚本、ネーム（コマ割りと構成の下書き）、画像生成、文字入れ、検品、PDF 出力までを Codex と一緒に進められます。
  • 文字や吹き出しを絵とは別に配置するため、後から台詞を直しやすくなっています。
  • コピー用プロンプトを Codex に送るだけで、必要なソフトの確認と導入が自動で進みます。
  • 生成した画像を実際に確認して直す検品や、サブエージェントによるレビューの工程があります。
  • Claude Code でも使え、その場合は画像生成を外部の ComfyUI が担当します。

なぜ注目されているか

README では制作例として Amazon で販売中の作品や X で公開している漫画を紹介しています。推測 非エンジニアでもコマンド操作を AI エージェントに任せて、原作から完成した漫画の PDF まで作れる点が注目されていると考えられます。

どんな人に役立つか

自分の小説や文章を漫画にしたい人に向いています。画像生成や視覚確認が使える Codex 環境（Claude Code の場合は GPU 環境と ComfyUI）が必要です。

技術的なポイント

  • Node.js 24、ブラウザ（Chrome または Edge）、日本語フォント、Python の PDF 用ライブラリ（reportlab、pypdf、Pillow）、Poppler を使います。
  • 組版、読書画面、PDF、履歴、再現パッケージは共通の CLI（コマンドラインツール）が担当します。
  • AGENTS.md や docs/AUTOMATIC.md にエージェント向けの手順を書き、エージェントがそれに従って制作を進める設計です。
  • 原作内の文章は資料として扱い、命令として実行しないようにプロンプトで指示しています。

試し方

  1. README のコピー用プロンプトを Codex の新しいチャットに送ります。
  2. 必要なソフトの確認と導入が自動で進むので、OS の許可画面などが出たときだけ対応します。
  3. 準備完了の報告が来たら、原作ファイル（UTF-8 のテキスト）を添付するか本文を貼り付け、「この原作を最後まで漫画化して」と伝えます。
