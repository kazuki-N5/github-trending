役割と個性を持つ230超のAIエージェント定義を集めた「AIの代理店チーム」

何ができるか

  • フロントエンド開発者、UIデザイナー、Redditコミュニティ担当、テスト担当など、分野ごとに特化したAIエージェントの定義ファイル（Markdown）を230以上収録しています。
  • エンジニアリング、デザイン、広告運用、営業、マーケティング、プロダクト、テスト、セキュリティ、ゲーム開発、財務などの「部門（Division）」に分けて整理されています。
  • 各エージェントには人格・口調、中心となる使命とワークフロー、コード例付きの成果物、成功指標がまとめて書かれています。
  • Claude Codeにはそのまま使え、変換スクリプトでGitHub Copilot、Gemini CLI、Cursor、Codex、OpenCode、Aider、Windsurfなど多数のツール向けの形式に変換してインストールできます。
  • インストールスクリプトで、使いたいツールや部門、個別のエージェントだけを選んで入れられます。
  • スタートアップのMVP開発や広告アカウントの引き継ぎなど、複数のエージェントを組み合わせて使う実例も紹介されています。

なぜ注目されているか

Redditのスレッドから生まれ、汎用的な「開発者として振る舞って」というプロンプトではなく、専門性・個性・成果物まで作り込んだエージェント集として育ってきたことがREADMEで紹介されています。推測 Claude CodeやCodexなどAIコーディングツールのサブエージェント（特定の役割を任せる補助AI）機能が広まり、すぐ使える高品質な役割定義の需要が高まっていることが注目の理由と考えられます。

どんな人に役立つか

Claude CodeやCursorなどのAIコーディングツールで、役割ごとに専門化したAIに作業を任せたい人に向いています。自分でエージェントやプロンプトを設計する際の参考資料としても使えます。

技術的なポイント

  • 各エージェントは、名前・説明・色を書いたフロントマター（ファイル先頭のメタデータ）付きのMarkdownファイルとして定義されています。
  • シェルスクリプトのconvert.shが、元のMarkdownをCursor用の.mdcルール、Codex用のTOML、Kimi Code用のYAML、SKILL.mdなど各ツールの形式に変換します。
  • install.shはインストール済みのツールを自動検出し、--tool、--division、--agentなどのオプションで対象を絞り込めます。
  • --parallelオプションで変換やインストールをツールごとに並列実行でき、ジョブ数は--jobsで指定できます。
  • ライセンスはMITで、別途macOS・Linux・Windows向けのネイティブアプリ「Agency Agents」も提供されています。

試し方

  1. 最も手軽な方法として、デスクトップアプリ「Agency Agents」をダウンロードし、一覧から選んだエージェントを各ツールにインストールします。
  2. スクリプトを使う場合は、Claude Codeならinstall.shに--tool claude-codeを付けて実行するか、使いたい部門のMarkdownを~/.claude/agents/にコピーします。
  3. 他のツールで使う場合は、先にconvert.shで各ツール向けのファイルを生成し、その後install.shでインストールします。
  4. Claude Codeのセッションで「Frontend Developerモードを有効にしてReactコンポーネントを作って」のようにエージェントを指名して使います。
brew install --cask msitarzewski/agency-agents/agency-agents
./scripts/install.sh --tool claude-code
cp engineering/*.md ~/.claude/agents/
./scripts/convert.sh
./scripts/install.sh
./scripts/install.sh --tool claude-code --division engineering,security
./scripts/install.sh --list teams
