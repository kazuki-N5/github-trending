HybridRobotics/supermimic

Python 初掲載 2026-11-12（Trendshift 8位） GitHub ↗

一つの微分可能ワールドモデルで学習する人型ロボット全身モーショントラッカー

何ができるか

  • 人型ロボットの全身モーション追跡をワールドモデルベースで学習できる
  • 一般化座標（GenCoord）と最大座標（MaxCoord）の2種類のタスクモードに対応している
  • MuJoCo向けライブラリmjlab上に構築されており、物理シミュレーション環境で動作する
  • WandBと連携してトレーニング済みモデルの動作を再生・確認できる
  • CUDA_VISIBLE_DEVICESでGPUを指定してトレーニングを実行できる

なぜ注目されているか

推測 人型ロボットの全身モーション制御は強化学習・ロボティクス分野で重要な課題であり、微分可能ワールドモデルを用いたアプローチは近年注目を集めている。推測 SuperTrackの実装として、差分可能物理シミュレーションを活用した手法が研究コミュニティで関心を集めている。

どんな人に役立つか

ロボティクスや強化学習を研究する学生・研究者に役立つ。人型ロボットの全身モーション制御や模倣学習を実装・実験したい人向け。

技術的なポイント

  • mjlabライブラリ上に構築された微分可能ワールドモデルを使用している
  • 一般化座標（GenCoord）と最大座標（MaxCoord）の2種類の座標系をサポートしている
  • ControlVAE、robotic_world_model、DreamerV3のコードを参考にして開発されている

試し方

  1. uvをインストールする
  2. supermimicとmjlab_researchリポジトリを同じ親ディレクトリ配下にクローンする
  3. タスクIDとrun名を指定してtrain.pyを実行する
  4. 学習済みモデルはplay.pyにwandbパスを指定して再生できる
CUDA_VISIBLE_DEVICES=0 python src/supermimic/scripts/train.py --task SuperMimic-GenCoord-G1 --run_name <run_name>
python src/supermimic/scripts/play.py --task SuperMimic-GenCoord-G1 --wandb-path <wandb_path>
