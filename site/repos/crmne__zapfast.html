crmne/zapfast

Rust 初掲載 2026-11-11（はてなブックマーク 6位） GitHub ↗

RustとeguiでできたネイティブWhatsAppデスクトップクライアント

何ができるか

  • テキスト・画像・ファイル・スタンプ・GIF・投票・音声メッセージの送受信ができる。
  • 動画・音声メッセージ・GIFをアプリ内でそのまま再生できる。
  • チャット履歴を暗号化してローカルに保存し、テキストやZIPでエクスポートできる。
  • 複数のWhatsApp番号を1つのウィンドウで管理できる。
  • アプリロックやロックチャットでプライバシーを保護できる。
  • ライト・ダーク・システムテーマに加え、カスタムカラーテーマを作成・適用できる。

なぜ注目されているか

WhatsApp Webに比べて起動が約1秒と瞬時で、アイドル時のメモリ使用量が約200MB（WhatsApp Webは1.13GB）と大幅に軽い点が注目されている。ブラウザエンジンを使わない完全ネイティブなRustアプリという技術的な珍しさも話題になっている。

どんな人に役立つか

Linux・macOS・WindowsでWhatsAppを軽快に使いたいデスクトップユーザー全般に向いている。リソースの少ない環境や、ブラウザを開きたくない環境でWhatsAppを使いたい人に特に役立つ。

技術的なポイント

  • RustのGUIフレームワーク「egui」とfastframeを使ってブラウザエンジンなしのネイティブUIを実現している。
  • whatsapp-rustライブラリを通じてスマートフォンのコンパニオンデバイスとしてQRコードでリンクする仕組みになっている。
  • ネイティブ通知はLinux・macOS・WindowsでFastframeを使って実装されており、通知クリックで対象メッセージを開くことができる。
  • チャット履歴は暗号化してデバイスにのみ保存し、開発者のサーバーへのデータ送信は一切行わない。

試し方

  1. macOSはHomebrewでインストールするか、公式サイトからMacアプリをダウンロードする。
  2. Arch LinuxはAURからインストールする。
  3. WindowsはGitHubリリースページからインストーラーを選ぶ。
  4. 起動後に表示されるQRコードをスマートフォンのWhatsApp（設定→リンク済みデバイス→デバイスをリンク）でスキャンする。
