FFmpegをGUIで操作できるWindows向けポータブル動画編集ツール

何ができるか

  • ロスレストリム・カット・クロップ・回転・速度変更などの基本編集が行える
  • 720p〜4Kへのダウンスケールや動画・音声・GIF・APNGへの変換ができる
  • 音量調整やオーディオトラックの削除が行える
  • 重複フレームの削除やクロマキー（グリーンスクリーン）除去ができる
  • 字幕（.srt）ビジュアルエディタやFFmpegコマンドジェネレーターなど高度なツールを備える
  • 英語・ロシア語・中国語・ドイツ語・フランス語・イタリア語の多言語対応

なぜ注目されているか

推測 コマンドライン不要でFFmpegの強力な機能をGUIから手軽に使えるため、非エンジニアにも受け入れられやすい。インストール不要のポータブル単体実行ファイルとして配布されており、手軽に試せる点が注目を集めていると考えられる。

どんな人に役立つか

FFmpegを使いたいがコマンドラインに不慣れなWindowsユーザー向け。動画のトリミングや変換をシンプルなGUIで済ませたい一般ユーザーや動画制作者に適している。

技術的なポイント

  • Visual Basic .NETで実装されたWindowsネイティブのGUIアプリケーション
  • FFmpegをバックエンドとして呼び出し、動画処理を実行する
  • 動画プレビューにlibvlc.dll（VLCライブラリ）を使用している
  • インストール不要のポータブル実行ファイル（.exe）として単体配布されている

試し方

  1. GitHubのReleasesページから最新の`FFmpeg-GUI-Editor.exe`と`libvlc.dll`をダウンロードする
  2. 両ファイルを同じフォルダに配置する
  3. `FFmpeg-GUI-Editor.exe`をダブルクリックして起動する
