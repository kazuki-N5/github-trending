HolyArrs/HolyArrs

Go 初掲載 2026-11-19（Trendshift 18位） GitHub ↗

Sonarr・Radarr・Lidarrなど6アプリを1つにまとめた自己ホスト型メディア管理アプリ

何ができるか

  • 映画・テレビ・音楽のリクエスト、ダウンロード管理をひとつのUIで行える。
  • qBittorrent・SABnzbdなど主要なダウンローダーと連携できる。
  • Plex・Jellyfin・Embyと連携してメディアサーバーへ自動追加できる。
  • Discord・メール・Telegramなどへの通知機能を持つ。
  • 字幕の自動取得機能を内蔵している。
  • Sonarr・Radarr・Prowlarrなど既存アプリからの設定インポートをサポートする。

なぜ注目されているか

推測 自己ホスト型メディア管理は従来6つのアプリを組み合わせる必要があり、設定が複雑だった。HolyArrsはそれを1アプリに統合し、Dockerイメージが約16MBと軽量なため注目されている。

どんな人に役立つか

自宅サーバーやNASでメディアを自己管理したい人に向いている。SonarrやRadarrなど複数アプリを運用していて管理を簡略化したい人にも役立つ。

技術的なポイント

  • GoでバックエンドAPIを実装し、Dockerコンテナとして配布されている（amd64・arm64・armv7対応）。
  • Dockerイメージサイズ約16.1MB、アイドル時のメモリ使用量は約95MiBと軽量設計。
  • 保存キーを暗号化して管理し、既存アプリ向けのAPIも提供している。
  • AGPL-3.0ライセンスで公開されているオープンソースプロジェクト。

試し方

  1. Docker Composeファイルを用意してポート6262でコンテナを起動する。
  2. ブラウザで http://localhost:6262 を開いてオーナーアカウントを作成する。
  3. フォルダ・ダウンローダー・ソースを設定して利用を開始する。
docker compose up -d
