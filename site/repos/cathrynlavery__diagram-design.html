AIエージェントに雑誌のような図をHTML+SVGで描かせるスキル

何ができるか

  • 「フロントエンド、バックエンド、データベース、Redis キャッシュの構成図を作って」のように普通の言葉で頼むと、エージェントが図の種類を選び、ダブルクリックで開ける1つの .html ファイルを書き出す。
  • アーキテクチャ図、フローチャート、シーケンス図、ER 図、ガントチャート、サンキー図など45種類の図に対応し、それぞれライト、ダーク、フル編集版の3種類の見た目を持つ。
  • 自分の Web サイトの URL を渡すと配色とフォントを取り出してスタイルガイドに書き込み、以後の図をそのブランドに合わせる。
  • draw.io、Mermaid、Excalidraw で作った既存の図を読み込み、同じ内容をこのデザインで描き直せる。
  • 出力先に合わせて、サイズ（16:9 のスライド、ドキュメント幅、SNS 用など）や形式（HTML、SVG、PNG）を指定できる。
  • WCAG AA（Web の読みやすさの基準）を満たす色のコントラストかを自動で確かめ、SVG にはスクリーンリーダー向けの名前と説明を付ける。

なぜ注目されているか

作者は、ブログ用の図を Claude に頼むとサイトに合わない汎用的な角丸ボックスの図しか返ってこないことに不満を持ち、「強調色は1〜2箇所だけ」「影なし」「座標は4px グリッド」といった好みを書き出してスキルにしたと説明している。Claude Code、Codex、GitHub Copilot、Cursor など多くのエージェントで同じファイルを使える点も特徴になっている。推測 ありがちな Mermaid 風の図ではなく、そのまま公開できる見た目の図を手軽に作れることが関心を集めていると考えられる。

どんな人に役立つか

ブログ記事、スライド、技術資料に載せる図を、見た目にこだわりつつ素早く作りたい人に向く。README によると、Git で管理して頻繁に書き換えるドキュメントの図には Mermaid のほうが合っており、このスキルは公開用の図に向いている。

技術的なポイント

  • 図は外部の画像に頼らない1つの HTML ファイルに、インライン SVG（HTML に直接埋め込んだベクター画像）として書かれ、通常はビルドも JavaScript も不要。
  • 座標はすべて4px のグリッドに乗せ、要素の重なりやはみ出しは CI（自動で動くテスト）でチェックしている。
  • 色は accent や ink のような意味を表す名前（セマンティックトークン）で style-guide.md にまとめられ、すべての図がそこを参照する。
  • フォントは標準では Google Fonts から読み込むが、システムフォントを指定するとネットワーク通信を一切しないファイルになる。
  • アニメーションは任意で、使う場合も審査済みのコントローラーだけを許可し、勝手なスクリプトや外部ファイルの読み込みは拒否する。

試し方

  1. npx skills add で、Agent Skills に対応したエージェントにスキルを入れる（Claude Code ではプラグインマーケットプレイスからも入れられる）。
  2. エージェントに「アプリの構成図を作って」のように普通の言葉で頼む。
  3. 必要なら「onboard diagram-design to <自分のサイトの URL>」と頼み、図の配色とフォントを自分のサイトに合わせる。
  4. リポジトリをクローンした場合は skills/diagram-design/assets/index.html をブラウザで開くと、すべての図のギャラリーを見られる。
