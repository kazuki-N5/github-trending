GitHubリポジトリ向けの自律型コーディングエージェント

何ができるか

  • GitHubのイシューやコメントを監視し、許可されたユーザーからのリクエストに応じて自動的に作業を開始する
  • 作業を独立したエージェントセッションとディレクトリで実行し、完了するとプルリクエストを作成して返答する
  • Feishu（Lark、企業向けチャットツール）との連携により、チャットからコーディング作業を依頼できる
  • チームが定義したポリシー（ルール）に基づき、エージェントが自律的に行動できる範囲を細かく制御できる
  • Webパネルで人間の確認が必要な作業アイテムを一覧表示し、作業状況をひと目で把握できる

なぜ注目されているか

推測 GitHubでの自動コーディングエージェントへの関心が高まる中、DeepSeekがその実装の仕組みを研究プロトタイプとして公開したことで注目を集めていると考えられる。「人間の注意を最小限に抑えつつ最大の価値を提供する」という設計思想と、実際に動作するプロトタイプが公開されている点が評価されているとみられる。

どんな人に役立つか

GitHubリポジトリを管理する開発チームで、イシュー対応や反復的なコーディング作業を自動化したいエンジニアに役立つ。DeepSeek Harness（DSH）を使ったマルチエージェントシステムの研究者や、エージェント型AIシステムの設計パターンを学びたい学生にも参考になる。

技術的なポイント

  • TypeScriptで実装されており、DeepSeek Harness（DSH）というエージェント実行基盤（ランタイム）上で動作する
  • Cordisプラグインシステム（依存性注入を使ったモジュール構成の仕組み）を採用し、GitHubやFeishuなどの外部サービスとの連携を拡張可能な設計にしている
  • tmux（ターミナルの多重化ツール）を使って独立したセッションでエージェントの作業を実行し、プロセスを分離する
  • GitHub CLI（gh）でGitHub APIの認証・操作を行い、プルリクエストの作成などを自動化する

試し方

  1. Node.js 22.19以上、pnpm、git 2.32以上、tmux、Python 3.8以上、GitHub CLI 2.48以上をインストールし、DSHのバージョンがpackage.jsonのengines.dsh範囲内であることを確認する
  2. SETUP.mdとdocs/000-philosophy.mdを読んでから作業を始める
  3. プローブコマンドを実行して必要なツールが揃っているか確認する
  4. エージェント用のGitHubアカウントを作成し、対象リポジトリへの招待を承認する
  5. docs/006-deployment.mdに従いインストール・マシン設定・起動停止の手順を実施する
