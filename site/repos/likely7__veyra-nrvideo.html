Likely7/Veyra-NRVideo

C++ 初掲載 2026-11-15（Trendshift 12位） GitHub ↗

Windows向けリアルタイムGPU動画超解像・ノイズ除去強化プレイヤー

何ができるか

  • NVIDIA RTX・AMD FSR・Intel XeSSによるAI超解像とフレーム生成をリアルタイム処理できる
  • ローカル動画、キャプチャカード、PS5リモートプレイ、PC/Xboxストリーミングを入力ソースとして扱える
  • ニューラルノイズ除去、RTX Video HDR、カラーグレーディング、アンチエイリアスを重ねて適用できる
  • Cinema・Professional List・Nodeの3モードで映像処理パイプラインを切り替えられる
  • MP4/MKVへのトリミング付きエクスポートキューを備え、複数音声・字幕トラックを出力できる
  • スクリーンショット、インスタントリプレイ・録画、マイクミキシング、再生速度変更などの補助機能を持つ

なぜ注目されているか

推測 PS5のGTA6を120FPS化する動画として注目を集め、AIアップスケーリングとフレーム生成をゲームストリーミングに適用できる点が話題になっている。累計10万件以上のダウンロードを達成しており、無料オープンソース（GPL-3.0）ながらDLSS 5相当の画質向上を実現していることが評価されている。

どんな人に役立つか

RTX GPU搭載のWindows 11ユーザーで、動画や配信映像の画質を手軽にAI強化したい人に向いている。PS5リモートプレイやSunshine/Moonlightでゲーム映像を高画質化したいゲーマー、あるいは映像制作者のプレビュー・エクスポート用途にも活用できる。

技術的なポイント

  • C++とDirectX 12をベースに構築し、Qt Quick/QMLでUIを実装している
  • NVIDIA DLSS・RTX Video SR、AMD FSR 4、Intel XeSSなど複数ベンダーのAI推論ランタイムを統合している
  • フレームソース→強化グラフ→D3D12ネイティブウィンドウという共有パイプライン設計で複数入力を一元処理している
  • PS5リモートプレイにはChiaki（AGPL-3.0）を組み込み、PCストリーミングはSunshine/Moonlightを外部利用している
  • ポータブル配布形式を採用し、QTランタイムを同梱することでインストール不要で動作する

試し方

  1. GitHubのReleasesページからGPU種別（NVIDIAまたはAMD）に合ったZIPをダウンロードする
  2. 7-ZipまたはWindowsの標準機能で書き込み可能な新規フォルダに展開する
  3. veyra_qml_ui.exeを実行する
  4. まずエフェクトをオフにして映像・音声を確認し、その後エフェクトを一つずつ有効化する
