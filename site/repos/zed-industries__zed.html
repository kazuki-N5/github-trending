zed-industries/zed

Rust 初掲載 2026-11-07（Trendshift 16位） GitHub ↗

AtomとTree-sitterの開発者が作った高性能マルチプレイヤーコードエディタ

何ができるか

  • macOS・Linux・Windowsで動作する高性能なネイティブコードエディタである
  • 複数人がリアルタイムで同じファイルを共同編集するマルチプレイヤー機能を持つ
  • AIアシスタント機能を内蔵しており、コードの補完や対話ができる
  • Tree-sitter（構文解析ライブラリ）を活用した高精度なシンタックスハイライトを実現している

なぜ注目されているか

Atomエディタの開発者が立ち上げた新プロジェクトとして注目を集め、RustによるネイティブGPUレンダリングで他のElectron製エディタより高速な動作を実現している。マルチプレイヤー編集という独自機能も差別化要因となっている。

どんな人に役立つか

高速・軽量なコードエディタを求める開発者、またはVS Codeなどのパフォーマンスに不満がありRustネイティブのツールを試したいエンジニアに向いている。

技術的なポイント

  • Rustで実装されておりGPUアクセラレートによる高速レンダリングを実現している
  • Tree-sitterを使った構文解析で言語対応とシンタックスハイライトを行っている
  • ライセンスはGPL-3.0-or-laterを主体とし一部Apache-2.0のコンポーネントで構成されている
  • CIでcargo-aboutを使ってサードパーティライセンスの自動検査を行っている

試し方

  1. zed.devから直接ダウンロードするか、各OSのパッケージマネージャー（macOS: brew、Linux: apt/dnf等）でインストールする
  2. macOS・Linux・Windowsそれぞれのビルドガイドがdocsフォルダにある
