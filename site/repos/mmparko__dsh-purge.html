JavaScript 初掲載 2026-10-23（Trendshift 11位） GitHub ↗

DeepSeek Harness向けサイバーセキュリティ赤チームプラグインのミラーリポジトリ

何ができるか

  • DeepSeek Harness（公式Web版・デスクトップEXE版）に適用できるレッドチーム評価プラグインを提供する。
  • Apply操作でホストのプロンプト書き換え・承認ゲート・サンドボックスポリシーを一時的に変更し、モデル拒否とホスト層ブロックを切り分けられる。
  • Clean/Drillの2ページUI、プロンプトエディタ、複数ルールセットを提供する。
  • Restore操作で変更を元に戻せ、npm更新後も自動で再適用される。

なぜ注目されているか

推測 上流の YuJunZhiXue/dsh-purge がリポジトリを削除する可能性があるため、全ブランチ・73タグ・完全コミット履歴を保存したミラーとして注目を集めている。dsh-purgeはDSHのホスト層とモデルのポリシーを分離して評価できるツールとして研究者の間で知られており、その保存版としての価値がある。

どんな人に役立つか

DeepSeek Harness上でAIモデルの安全性評価やレッドチームテストを行いたいセキュリティ研究者向け（自分が管理する環境のみで使用すること）。上流リポジトリのバックアップが欲しいdsh-purgeユーザーにも有用。

技術的なポイント

  • JavaScriptで実装されたDSHプラグインで、dsh 0.2系（0.2.0-rc.2）に対応している。
  • ホストの@deepseek-aiパッケージとローカルプロファイルのみを変更し、公開インターネットへの攻撃トラフィックは送信しない。
  • 適用・復元・アンインストールはすべてローカルファイルとプロセス内で完結する。

試し方

  1. dsh web版またはデスクトップ版がインストール済みであることを確認する。
  2. 以下のコマンドでプラグインをインストールする（Web/デスクトップで別途実施）。
  3. セッションタイトル横の「dsh-purge」ボタン→Clean→Applyの順にクリックして適用する。
dsh plugin --profile web add dsh-purge
dsh plugin --profile desktop add dsh-purge
