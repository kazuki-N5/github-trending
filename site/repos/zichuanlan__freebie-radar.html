63ソースから無料リソースを自動収集しAIフィルタリングしてTelegramへ通知する自己ホスト型アグリゲータ

何ができるか

  • 63の組み込みソース（デフォルト33有効）からVPS・クラウド・AIクレジット・ゲームなどの無料情報を定期収集する。
  • OpenAI互換モデルによるAI分類で各アイテムの種類・カテゴリ・アクセス方法・品質を自動評価しノイズを除去する。
  • 6段階のアクセスレベルで無料直接取得から抽選・試用・有料まで分類し、偽の無料情報（偽福利）を除外する。
  • Telegramへのルート別プッシュ通知、即時または一括配信、サイレント時間帯、日次ダイジェストをサポートする。
  • コンパクト・2カラム・3カラムのカードレイアウトでWebUIから閲覧できる。
  • 知乎・小紅書・小黒盒などログインが必要なサイトはPlaywrightまたはTampermonkeyスクリプトで収集できる。

なぜ注目されているか

推測 無料リソース情報の収集・フィルタリング・通知をAIで自動化するニーズが高まる中、偽の無料情報を除外するAI二次審査の仕組みが評価されている。TelegramへのリアルタイムプッシュとWebUIを組み合わせた実用的な設計が注目を集めている。

どんな人に役立つか

無料のクラウドリソース・ゲーム・ソフトウェアを効率的に収集したい開発者やヘビーユーザーに向いている。自己ホストで無料情報を管理・共有したいコミュニティ運営者にも役立つ。

技術的なポイント

  • SQLiteをデータベースに使用し、Docker ComposeまたはNode.js 22.5+でデプロイできる軽量構成を採用している。
  • OpenAI互換APIで各アイテムを5段階品質評価・分類し、ゼロトークン再分類コマンドでルール変更後に過去アイテムも再評価できる。
  • LinuxDo OAuthを使ったオプションの公開マルチユーザーモードに対応している。
  • PlaywrightスクリプトとTampermonkeyユーザースクリプトでログインが必要なサイトのデータも収集できる仕組みを持つ。

試し方

  1. Docker ComposeまたはNode.js 22.5+の環境を用意する。
  2. リポジトリをクローンし、`.env`ファイルにTelegramトークン・OpenAI互換APIキーなどを設定する。
  3. Docker Composeで起動するか、依存パッケージをインストールしてNode.jsで起動する。
docker compose up -d
