RTX 3090などのGPUをWindowsとヘッドレス同時起動するUEFIロック解除ツール

何ができるか

  • RTX 3090 FE（デフォルト）をはじめRTX 3060/3070/3070 Ti/3090 Tiなど複数のNVIDIA GPUに対応したUEFIレベルのGPUロック解除を行う。
  • BIOSのPOST後にGPUのGOP（Graphics Output Protocol）を取り外してからWindowsを直接起動するヘッドレスブートパスを提供する（GOPはUEFI起動画面表示に使われる仕組み）。
  • USB接続のGPUを活用するヘッドレスUSBパスや、AMD内蔵GPUのディスプレイ出力を残したままにするレガシーUSBマニュアルパスも選択できる。
  • 既存のプローブキャプチャデータを使ったオフラインの互換性チェッカーが含まれており、実際に試す前に対応確認ができる。
  • Windows-firstへの復元（-RestoreWindowsFirst）など複数の回復オプションが用意されており、起動失敗時のリカバリー手順も明記されている。

なぜ注目されているか

推測 NVIDIAのコンシューマー向けGPUには複数GPUの同時使用を制限するUEFIレベルのロックが存在するとされており、このツールはそのロックをUEFIブートプロセスへの介入によって回避しようとするコミュニティプロジェクトとして注目されている。FP16テンソル演算で約1.9倍のパフォーマンス向上を報告するベンチマーク証跡が含まれており、AI・機械学習用途でのGPU活用拡大を目指す研究者や自作PCユーザーの関心を集めている。

どんな人に役立つか

特定のサポートされたNVIDIA RTX 30シリーズGPUと対応マザーボードを持ち、UEFIのブート設定変更に慣れた上級者向け。AI・機械学習用に自作PCのGPU性能を最大限引き出したい研究者・エンジニアにも向いているが、互換性は特定のカードとシステム構成に限定される。

技術的なポイント

  • PowerShellスクリプトとClang/LLDを使ってUEFIアプリケーションをビルドし、EFIシステムパーティションに配置してWindowsブートマネージャーより先に実行させる仕組み。
  • Pythonで実装されたオフライン互換性チェッカーがPCIデバイスのプローブキャプチャデータを解析し、GPU/PROM/PCI状態を検証する。
  • PCIブリッジチェーン探索とセグメント対応のLOCAL検出により、最大4台のNVIDIAディスプレイチャイルドデバイスをEDIDドライバーなしで認識できる。
  • GPUファミリー層（GA102/GA104/GA106共通）とカード固有の設定を分離した設計で、コミュニティ貢献による新機種プロファイル追加を容易にしている。

試し方

  1. Secure BootをBIOSで無効化し、BitLockerが無効なことを確認する。
  2. 少なくとも1GiBのGPT FAT32 EFIシステムパーティションをUEFIシステムパーティション（例: Uドライブ）として用意する。
  3. 管理者権限のPowerShellからリポジトリルートでConfigure.psとbuild-unlock.ps1を実行してビルドする。
  4. Headless.ps1 -Assets '.\assets' -Register でF8テストエントリを登録し、テスト成功後に-EnableAutomaticで自動ブートを有効にする。
.\internal-boot\Configure.ps1 -UnlockDriveLetter U -WindowsEspGuid 'YOUR-WINDOWS-ESP-GUID'
.\research\headless\build-unlock.ps1 -Clang 'C:\TOOLS\LLVM20\bin\clang.exe' -LldLink 'C:\TOOLS\LLVM20\bin\lld-link.exe'
.\internal-boot\Headless.ps1 -Assets '.\assets' -Register
.\internal-boot\Headless.ps1 -EnableAutomatic -ConfirmedSuccess
.\internal-boot\Headless.ps1 -RestoreWindowsFirst
python -I research/profile/check-compatibility.py "D:\RTX3090-UNLOCK"
