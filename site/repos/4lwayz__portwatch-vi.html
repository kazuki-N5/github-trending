GTA VIのPC移植進捗をリアルタイムで追跡するトラッカーサイト

何ができるか

  • コミュニティによるGTA VIの再コンパイル・エミュレーション・PC移植の取り組みを一覧・スコアリングして表示する。
  • スケジュールされたスカウト処理が3時間ごとに自動でデータを更新する。
  • 各プロジェクトの進捗をスコア付きリーダーボードカードで可視化する。
  • GitHub・GitLab・フォーラム・SNS・ニュースフィード・GitHubのDMCAログから新規候補を自動発見する。
  • スパムや偽ダウンロードリンクを検出・警告する機能を備える。
  • AnthropicのAPIキーを設定するとClaudeによるプロジェクト評価や記事自動生成が利用できる。

なぜ注目されているか

推測 GTA VIのPC版リリースを望むユーザーが多い中、移植進捗を一目で確認できる情報集約サイトとして注目を集めたと考えられる。自動更新・スコアリング・偽情報フィルタリングという実用性の高さも支持された要因だろう。

どんな人に役立つか

GTA VIのPC移植動向を継続的に追いたいゲームファンや、GitHubのコミュニティ活動を監視・分析したい開発者向け。

技術的なポイント

  • GitHub Pagesで静的サイトとしてホストし、GitHub Actionsのスケジュールワークフローでデータを自動更新する。
  • スコアリングロジックはassets/js/scoring.jsに集約されており、コード量・活動量などを評価する。
  • 全データはdata/tracker.jsonに集約されており、手動編集も容易な構成になっている。
  • オプションのClaude APIキー連携により、取り組みの定性評価や記事生成を自動化できる。

試し方

  1. リポジトリをGitHubにプッシュし、Pages設定でGitHub Actions経由のデプロイを有効にする。
  2. Scoutワークフローを手動で一度実行する。
  3. 以降はスケジュールに従い自動更新される。
node scripts/scout.mjs --dry-run
