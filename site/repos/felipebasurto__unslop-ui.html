felipebasurto/unslop-ui

HTML 初掲載 2026-11-20（Trendshift 17位） GitHub ↗

UIコピーとチャートからAI的な装飾・冗長表現を自動で除去するエージェントスキル

何ができるか

  • UIテキストからアイキャッチラベル、装飾的な番号付け、ステータスドット、絵文字など16種類のAIらしいパターンを検出・削除する。
  • オプションの--surfaceフラグを使うとグラデーション、過大なフォントウェイト、派手なアニメーションなど4つの視覚的な過剰装飾（U17〜U20）も修正できる。
  • 実行ごとにheavy・light・noneの3段階で評価し、変更した文字列・保持した項目・ユーザーへのタスクを含むレポートを出力する。
  • scripts/count_tells.pyでCIパイプラインに組み込み、--maxオプションで基準値を超えたらエラーを出すことができる。
  • ユニットテストとevals/ディレクトリに動作確認用フィクスチャが含まれており、エージェントCLIで実行可能。

なぜ注目されているか

推測 生成AIで作られたUIにはアイキャッチラベルや絵文字の多用など「AIらしい」冗長な装飾が混入しやすく、それを自動で取り除くツールへの需要が高まっていると考えられる。推測 AIコーディングアシスタントをプロダクション開発に使う開発者が増える中、UIの品質を保つための後処理・自動チェックツールとして注目されている。CIへの組み込みに対応している点も実用性を高めている。

どんな人に役立つか

AIコーディングアシスタントを使ってUIを開発するフロントエンドエンジニアに特に役立つ。AIが生成したダッシュボードやチャートの表示文字列を自動でクリーンアップしたいデザイナーやプロダクトマネージャーにも適している。

技術的なポイント

  • Python 3.9以上で動作し、追加パッケージ不要で軽量に利用できる。
  • Claude CodeのエージェントスキルおよびClaude Codeプラグインとして動作し、npx skills addコマンドでインストールできる。
  • 16のコピー・チャートルール（U1〜U16）と4つのオプション視覚ルール（U17〜U20）から構成されるルールセットで判定する。
  • scripts/count_tells.pyは正規表現ベースのカウンターで、CIへの組み込みに対応している。

試し方

  1. Node.jsがインストールされていることを確認する（npxを使用するため）。
  2. npx skills add felipebasurto/unslop-ui -gでグローバルインストールする。
  3. 対象のファイル・フォルダ・コンポーネントを指定してスキルを実行する。
npx skills add felipebasurto/unslop-ui -g
python3 -m unittest discover -s tests
