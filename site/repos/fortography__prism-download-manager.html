FortoGraphy/prism-download-manager

Rust 初掲載 2026-11-28（Trendshift 15位） GitHub ↗

最大32接続・クラッシュ耐性のあるOSSダウンロードマネージャー

何ができるか

  • 1ファイルを最大32並列接続に分割してダウンロードし、帯域制限があるサーバーで最大15倍高速化できる
  • クラッシュ・スリープ・ケーブル抜けが発生しても中断した箇所から正確に再開できる
  • Chrome・Edge・Firefox向けのブラウザ拡張でリンクを即座にPrismに渡せる
  • YouTube他1,800サイト超の動画をMP4（8K/HDR対応）またはMP3でダウンロードできる
  • Hugging FaceのAIモデルを名前・リンク・検索でダウンロードしSHA-256で検証できる

なぜ注目されているか

推測 IDM（Internet Download Manager）の有料代替品として無料・OSSで登場し、AIモデルのダウンロード機能やliquid-glassのUIデザインが注目を集めている。BitTorrent・HLS・DASHなど多プロトコル対応も差別化になっている。

どんな人に役立つか

大容量ファイルや動画を頻繁にダウンロードするユーザー、AIモデルをHugging Faceから取得したいエンジニア、IDMの無料代替を求めるWindows/macOS/Linuxユーザー向け。

技術的なポイント

  • Rustで実装されており、高速かつメモリ安全な並列ダウンロードエンジンを実現している
  • HTTP(S)・FTP/FTPS・HLS/DASHストリーム・BitTorrentとマグネットリンクに対応する多プロトコル設計になっている
  • yt-dlpを内部で活用して1,800サイト超の動画取得とSponsorBlockによるスキップを実現している
  • ブラウザ拡張がリンクを約0.25秒でPrismに渡すため、シームレスなダウンロード開始体験を提供する

試し方

  1. GitHubリリースページから自分のOSに合ったインストーラーをダウンロードする
  2. インストーラーを実行してPrismをセットアップする（署名なしの警告が出た場合は「詳細→実行」を選ぶ）
  3. Chrome Web StoreからPrismブラウザ拡張を追加し、アイコンにConnectedと表示されることを確認する
