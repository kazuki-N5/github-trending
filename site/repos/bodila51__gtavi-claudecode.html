GTA 6配信からショート動画を切り出して収益化するClaude Codeプラグイン

何ができるか

  • キャンペーンファインダーで報酬付きクリッピングキャンペーンの一覧と残予算・ルールを確認できる
  • トレンドレーダーでGTA 6動画の時間別再生数ランキングと配信者リストを取得できる
  • モーメントファインダーで配信の見どころとなる15〜40秒のシーンを自動抽出できる
  • クリップカッターで1080x1920の縦型動画にキャプションとクレジットを付けて書き出せる
  • ライブモードでチャットの急上昇を検知してライブ配信をリアルタイムにクリップできる
  • 多言語対応機能で1本の動画コンテンツを5言語向けに展開できる

なぜ注目されているか

推測 GTA 6配信の市場拡大に伴いショート動画収益化の需要が急増しており、その機会を素早く捉えたいクリエイターの注目を集めている。Claude Codeのプラグイン形式で16のスキルを提供し、キャンペーン探索から投稿確認まで一連の作業を補助できる点が特徴的である。推測 自動投稿を行わず全てのアクションを人間が承認する設計や、公式情報のみを使用するコンテンツ制限ルールを設けた点が信頼性を高め、収益化を始めたい初心者にも支持されていると考えられる。

どんな人に役立つか

GTA 6配信を活用してショート動画収益を得たいコンテンツクリエイターに向いている。動画編集の手間を減らしつつ複数の報酬付きクリッピングキャンペーンに参加したい人や、顔出しなしでGTA 6テーマのSNSページを育てたい人にも適している。

技術的なポイント

  • Python 3.10以上で動作し、NVIDIA GPUを利用すると音声文字起こし処理を高速化できる
  • Claude Codeのプラグイン機能を使い、/pluginコマンド2回だけでインストールできる設計になっている
  • 16種類のスキルモジュールに処理を分担し、キャンペーン探索・動画切り出し・多言語展開を個別に実行できる
  • 投稿前にrule-checkスキルでガイドライン違反やリーク・著作権侵害がないかを自動検証する仕組みを持つ

試し方

  1. Python 3.10以上の環境を用意する（NVIDIA GPUがあれば高速化できる）
  2. Claude Codeを起動し、/pluginコマンドを2回実行してプラグインをインストールする
  3. campaign-finderスキルで参加可能なクリッピングキャンペーンを確認する
  4. stream-finderで対象配信を見つけ、moment-finderで見どころシーンを抽出する
  5. clip-cutterで縦型動画に加工し、rule-checkで確認してから投稿を承認する
