MermaidとAIを内蔵したデスクトップMarkdownエディタ

何ができるか

  • WYSIWYGモードとコードビューを切り替えてMarkdownを編集できる
  • Mermaidのフローチャート・シーケンス図・クラス図など多様なダイアグラムをリアルタイムプレビュー付きで編集できる
  • Marpを使ってMarkdownでスライドプレゼンテーションを作成し、フルスクリーン発表ができる
  • Ollama・Claude・CodexなどのローカルまたはクラウドAIアシスタントと連携してドキュメントを直接編集できる
  • PDF・Markdown・DOCX形式でエクスポートできる
  • マルチルートサイドバー・クイックスイッチャー・全文検索などのワークスペース機能を備えている

なぜ注目されているか

Tauri 2.0を採用した軽量なデスクトップアプリでMarkdownとMermaidダイアグラムを統合して扱える点が特徴である。ローカルAIアシスタントとの統合により、AIによる自動スナップショットと一クリックでの元に戻す機能を備えたドキュメント編集が可能である。英語・日本語・中国語・ドイツ語・ポーランド語のUI多言語対応も行われている。

どんな人に役立つか

MarkdownとUMLダイアグラムを同じエディタで作業したい開発者や技術ライターに向いている。AIアシスタントをドキュメント編集に活用したいユーザーにも適している。

技術的なポイント

  • Tauri 2.0（RustバックエンドとWebViewフロントエンド）でクロスプラットフォームに動作する
  • Vue 3とTipTap・Viteを使ったフロントエンドで構成されている
  • Mermaid.jsを統合してダイアグラムのリアルタイムレンダリングを実現している
  • OpenAI互換APIに対応しているためOllamaなどのローカルサーバーにも接続できる
  • pnpm tauri devで開発起動し、pnpm tauri buildでビルドする

試し方

  1. Node.js 18以上とRustとpnpmをインストールする
  2. リポジトリをクローンしてpnpm installで依存関係をインストールする
  3. pnpm tauri devで開発モードで起動する
pnpm install
pnpm tauri dev
pnpm tauri build
