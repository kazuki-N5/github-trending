Shell 初掲載 2026-10-30（Trendshift 17位） GitHub ↗

Claude Codeをフルゲーム開発スタジオに変えるエージェント構成テンプレート

何ができるか

  • 49種類のAIエージェントがゲームスタジオの階層構造（ディレクター・部門リード・スペシャリスト）を再現し役割分担する
  • 74個のスラッシュコマンドスキルで設計からQAまでの開発ワークフロー全体をカバーする
  • Godot 4、Unity、Unreal Engine 5向けのエンジン固有エージェントセットを含む
  • コミット・プッシュ・アセット変更・設計書読み書きを監視する15個の自動フックで品質を保証する
  • GDD（ゲームデザインドキュメント）、UX仕様書、ADR（アーキテクチャ決定記録）等62種類のドキュメントテンプレートを提供する

なぜ注目されているか

推測 ゲーム開発は多職種の協業が必要な複雑なプロセスであり、それをAIエージェントで再現することへの関心から注目されている。4本のゲームをminimal・standard等の異なる厳密さレベルで開発した比較結果を公開しており、AIゲーム開発の実証データとして評価されている。

どんな人に役立つか

Claude Codeを使ってゲームを開発したい個人開発者や小規模チームに向いている。特にGodot 4、Unity、UE5でのゲーム開発経験がある人や、構造化された開発プロセスを求める開発者に有益である。Git、Python 3、Bashが利用できる環境が必要で、jqがあると便利である。

技術的なポイント

  • project.yamlの設定ファイルでリゴーレベル（厳密さ）をminimal・standard・fullの3段階から選択でき、デフォルトはminimalである
  • Gitフック（commit・push等のタイミングで自動実行されるスクリプト）で自動的にコード品質チェックを実施する
  • エージェント間の役割分担をスタジオ階層として定義し、何かを書く前に必ずエージェントの承認フローを経る仕組みを実装する
  • Python 3とBashを組み合わせた自動化スクリプトでワークフロー全体を管理する

試し方

  1. Git、Claude Code、Python 3、Bashをインストールする（jq推奨）
  2. リポジトリをクローンしてプロジェクトルートでClaude Codeを開く
  3. /startコマンドを実行してゲーム開発を開始する
git clone https://github.com/Donchitos/Claude-Code-Game-Studios
/start
