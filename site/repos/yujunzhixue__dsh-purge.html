DeepSeek Harness の制限を外し、独自のシステムプロンプトを注入するプラグイン

何ができるか

  • ローカルにインストールされた公式 DeepSeek Harness（AI エージェント実行環境）の @deepseek-ai パッケージにパッチを当て、既定の文言・権限ポリシー・ツール上限などを書き換えます。
  • 会話ごとにシステムプロンプト（モデルに最初に与える指示文）へ独自の文章を注入でき、モデルごとに別のプロンプトや AGENTS.md / CLAUDE.md の規則セットに切り替えられます。
  • 会話タイトル横のサイドバーから、パッチの適用・元に戻す（リバート）・アンインストール、プロンプトや規則セットの編集を行えます。
  • Skill（エージェントに追加する手順書）を圧縮ファイルやフォルダから Harness の公式ディレクトリへ取り込めます。
  • 許可同意後に使える「演習台」ページで、手元の資産・スキル・環境を確認できます（README では、自分が管理する端末やオフラインの標的、書面で許可された演習のみに使うよう求めています）。
  • CLI（dsh-purge --status など）とチャットコマンド（/purge、/rules、/skills、/rewind）でも操作できます。

なぜ注目されているか

README によると、Harness は実行時にプロンプト・承認ゲート・サンドボックスを加えるため、単に「モデルが答えるか」だけを見ると、ホスト側のブロックをモデル自身の拒否と取り違えてしまいます。このプラグインはその2層を分けて、ネットワークセキュリティのレッドチーム評価（攻撃側の視点で安全性を試す評価）に使うものとされています。推測 説明文で「どのモデルでもジェイルブレイク（安全制限の回避）できる」とうたっているため、関心と議論の両方を集めていると考えられます。

どんな人に役立つか

自分の PC に DeepSeek Harness を入れていて、LLM の安全対策がホスト側とモデル側のどちらで効いているかを評価・研究したい人向けです。README は、権限のない対象や公開中のシステムで使うことを禁止しており、ライセンスもオープンソースではなく商用ライセンスに変わっている点に注意が必要です。

技術的なポイント

  • Node.js（18 以上）で動く JavaScript 製の DSH プラグインで、web / desktop の profile ごとに別々にインストールします。
  • パッチを当てる前に対象ファイルを <ファイル>.dshpurge.bak としてバックアップし、リバート時にはそれを書き戻します。何度適用しても結果が同じになる（冪等な）設計です。
  • 注入するプロンプトは prompt-inject.md、作業フォルダの AGENTS.md / CLAUDE.md、プラグイン内の暗号化された既定値の順で選び、strict / fallback / always のポリシーで既定の workspace baseline 段落を残すか決めます。
  • DSH_HOME 環境変数、dsh 起動ファイル横の .dsh、~/.dsh の順に設定ディレクトリを探し、ドライブ名などのパスを決め打ちしません。
  • ネットワークの許可範囲を net-scope-allow.txt で管理し、登録していない中国本土・香港・マカオのアドレスへのアクセスを禁止する仕組みがあります。

試し方

  1. dsh plugin コマンドで、Web 版（profile web）と公式デスクトップ版（profile desktop）にそれぞれプラグインを追加します。
  2. 追加したホスト（dsh web やデスクトップ EXE）を完全に終了してから、もう一度起動します。
  3. 会話タイトル横の dsh-purge を開き、「清洗」ページで「応用（適用）」を押します。成功すると自動で再起動します。
  4. 新しい会話を始め、/purge status で DSH_HOME とパッチ一覧が表示されることを確認します。
  5. 元に戻すときは「卸载（アンインストール）」を押すか、dsh-purge --uninstall を実行します。
dsh plugin --profile web add https://github.com/YuJunZhiXue/dsh-purge/archive/refs/heads/master.tar.gz
dsh plugin --profile desktop add https://github.com/YuJunZhiXue/dsh-purge/archive/refs/heads/master.tar.gz
dsh-purge --status
dsh-purge --apply
dsh-purge --revert
dsh-purge --uninstall
