AI エディタ Cursor のプラグイン仕様と公式プラグイン集

何ができるか

  • 開発ツール、フレームワーク、SaaS 向けの Cursor 公式プラグインがまとめて公開されています。
  • Gmail、Google ドライブ、GitHub、Salesforce、Playwright など多数の外部サービスと連携するプラグインがあります。
  • 新しいプラグインの雛形作成と検証を行う create-plugin や、並列のクラウドエージェントに大きな作業を分担させる orchestrate など、エージェント作業を助けるプラグインもあります。
  • 大事な判断の前や行き詰まったときに、より強力なモデルへ相談させる advisor プラグインがあります。
  • ルートの marketplace.json が全プラグインを一覧にし、マーケットプレイスとして機能します。

なぜ注目されているか

AI エディタ Cursor の開発元が公式に公開しているプラグインの仕様と実装です。推測 Cursor の機能を広げる公式の仕組みであり、エージェントに外部サービスやワークフローを組み込む具体例が多数見られるため注目されていると考えられます。

どんな人に役立つか

Cursor を使っていて、外部サービス連携や作業の自動化を加えたい人に向いています。自分で Cursor 用のプラグインを作りたい人は、構成の見本として使えます。

技術的なポイント

  • 各プラグインはリポジトリ直下の独立したディレクトリで、それぞれ .cursor-plugin/plugin.json というマニフェスト（設定ファイル）を持ちます。
  • プラグインには skills（フロントマター付きの SKILL.md で書くエージェント用スキル）、rules（.mdc ファイルの Cursor ルール）、mcp.json（MCP サーバーの定義）を含められます。
  • MCP（Model Context Protocol、AI に外部ツールをつなぐための標準仕様）のサーバーを定義して外部サービスとつなぎます。
  • 一部のプラグインは hooks を持ち、エージェントの動作の区切りでスクリプトを実行します。
