AIエージェントの会話を監視・脅威検出するPythonフレームワーク

何ができるか

  • テキスト・正規表現・構造化フィールド・ツール使用チェックによるルール定義ができる。
  • 複数ターンにわたるフロールール・キャプチャ・カウント・型付きポリシーパラメータをサポートする。
  • ルールはYAMLで設定し、`.rule`形式のDSLで記述できる。
  • CLIから会話ログをスキャンし、JSON・CSV形式で結果を出力できる。
  • モデルスコアリング・分類・補完・トークンカウントなどの推論機能をオプションで追加できる。
  • 同期・非同期両方のPython APIを提供し、入力・コンパイル・時間・モデル呼び出しの制限が設定できる。

なぜ注目されているか

推測 AIエージェントの普及に伴い、エージェントの会話に仕込まれた脅威やプロンプトインジェクションを検出する需要が高まっている。CiscoのAIセキュリティチームが開発したという信頼性も注目度を後押ししていると考えられる。

どんな人に役立つか

AIエージェントをプロダクションで運用するセキュリティエンジニアやMLエンジニア向け。エージェントの会話ログに対してルールベースの脅威検知パイプラインを構築したい人に役立つ。

技術的なポイント

  • ルールはシンボリック有限オートマトン（FSA）にコンパイルされ、コンパイル失敗はロード時に即検知できる。
  • RE2正規表現エンジンを使用することで、安全で高速なパターンマッチングを実現している。
  • Python 3.11〜3.13に対応し、パッケージ管理にはuvを使用する。
  • モデルプロバイダアダプター経由でLLM（大規模言語モデル）を推論に組み込める設計になっている。

試し方

  1. Python 3.11〜3.13とuvをインストールする。
  2. リポジトリをクローンする。
  3. `uv sync --frozen` を実行して依存関係をインストールする（推論機能を使う場合は `--extra inference` を追加）。
  4. YAMLで設定ファイルを作成し、ルールディレクトリを指定する。
  5. CLIまたはPython API (`QuarryGuard(config).scan(conversation)`) でスキャンを実行する。
uv sync --frozen
uv sync --frozen --extra inference
