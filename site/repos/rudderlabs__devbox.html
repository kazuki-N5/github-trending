rudderlabs/devbox

初掲載 2026-11-07（はてなブックマーク 1位） GitHub ↗

チケットを渡すだけでコードを書きPRを作るセルフホスト型自律エンジニアリングハーネス

何ができるか

  • チケットを入力すると計画・実装・自己レビュー・ドラフトPR作成まで自動で行う
  • PRへのレビューコメントや失敗したCIの結果を受け取って自動修正を試みる
  • CLIまたはLinearからタスクを投入でき、GitHubでは自分が作ったPRへのフォローアップのみ対応する
  • タスクごとに独立したサンドボックスを用意し、実際の認証情報はサンドボックス内に入れない設計になっている
  • 学習内容をリポジトリへのコミットとして保存し、コードと同様にレビューできる

なぜ注目されているか

エンジニアリング作業の自動化ツールとして、自分のインフラ上で動かせるセキュアな設計が評価されている。RudderStack（データパイプライン企業）が公開したオープンソース実装という点でも注目を集めている。

どんな人に役立つか

繰り返し的なバグ修正や機能追加をAIに任せたいエンジニアチーム、またはセキュアな社内AIコーディングエージェントを試したい開発組織に向いている。

技術的なポイント

  • Docker ComposeまたはKubernetesで展開でき、タスクごとに独立したサンドボックスコンテナを使う
  • EgressプロキシでGitHubへの書き込みを許可リスト内リポジトリに限定し本物の認証情報が漏れない設計になっている
  • OpenAIまたはAnthropicのモデルを段階ごとに設定でき、bun run quickstartで約15分でセットアップできる
  • Langfuseトレーシングはオプションでデフォルトオフ、RudderStackへのテレメトリー送信はなし

試し方

  1. Docker・Bun・LLMのAPIキーを用意する
  2. bun run quickstartを実行してセットアップガイドに従う
bun run quickstart
