AIエージェントとスクレイピング向けの軽量ヘッドレスブラウザエンジン

何ができるか

  • V8 エンジンで JavaScript を実行し、Chrome DevTools Protocol (CDP) サーバーとして動作する
  • Puppeteer や Playwright がそのまま接続できるため既存の自動化スクリプトを流用できる
  • スクリーンショット撮影・ライブページのスクリーンキャスト・PDF 出力が Chromium なしで動作する
  • ステルスモードでフィンガープリントをランダム化し、数千のトラッカードメインをブロックする
  • MCP サーバーとして起動でき、AI エージェントから直接操作できる

なぜ注目されているか

ヘッドレスブラウザは従来 Chromium ベースが主流だったが、メモリ消費が大きく起動も遅いという課題があった。Obscura は Rust で書かれており、メモリ使用量・バイナリサイズ・起動速度の面で大幅な改善を主張している。AIエージェントからブラウザを操作するユースケースが増えたことも注目理由の一つと考えられる。

どんな人に役立つか

大量のウェブスクレイピングを高速・低コストで行いたい開発者や、AIエージェントにブラウザ操作を組み込みたいエンジニアに向いている。

技術的なポイント

  • Rust で実装され、V8 JavaScript エンジンを組み込んでいる
  • Chrome DevTools Protocol を実装し、既存の Puppeteer/Playwright と互換性がある
  • CDP サーバーまたは MCP サーバーとして起動できる二重モードを持つ
  • オプションのステルスビルドでフィンガープリントランダム化とトラッカーブロックを追加できる

試し方

  1. Linux・macOS・Windows 向けのプリビルドバイナリをリリースページからダウンロードする
  2. または Docker イメージを使って即座に起動する
  3. CLI でページ取得・リンク抽出・並列スクレイプを実行する
  4. Playwright/Puppeteer から CDP エンドポイントに接続して利用する
docker pull obscura/obscura
