LNPANDY/NX2Apple

Swift 初掲載 2026-11-08（Trendshift 9位） GitHub ↗

SwitchゲームをiPhone/iPadでネイティブ実行するmacOSランチャーアプリ

何ができるか

  • macOS（またはWindows）上でGUIを操作するだけでSwitchゲームをAppleデバイス向けにビルドでき、ターミナル操作が不要。
  • ゲームライブラリ管理とゲームごとの起動オプション設定ができる。
  • コントローラーとタッチコントロールの両方に対応している。
  • iCloud Driveを通じたクラウドセーブに対応している。
  • Switch 2のゲームファイル（.nupなど）にも対応している。
  • iPhoneとiPadで共通のシェルアプリを使い、同一ビルドで両デバイスをサポートする。

なぜ注目されているか

推測 SwitchゲームをiPhone/iPadで動かせるという注目度の高い機能と、GUIで一クリックでビルドできる手軽さがSNSやコミュニティで広まりトレンド入りしていると考えられる。nxnativeというプロジェクトのコミュニティフォークであり、より使いやすいフロントエンドを提供している点も評価されていると推測される。

どんな人に役立つか

自分で入手したSwitchゲームをiPhone/iPadで遊びたいユーザー。静的リコンパイルやAppleプラットフォーム向けゲームビルドの仕組みに興味のある開発者。

技術的なポイント

  • エミュレーターではなく静的リコンパイル（ゲームコードをネイティブバイナリに事前変換する手法）でゲームを実行するnxnativeを基盤としている。
  • iOS/iPadOS 26以上が対象で、NVNゲームのビルドにはXcode 27.2が必要。
  • iOSデバイスへのインストールには、Macとデバイスのペアリングが必要。
  • .NET SDK 10が必要な依存関係の一つとして挙げられている。
  • ランチャー自体は署名なし（Unsigned）のため、インストール方法に制限がある。

試し方

  1. macOS 13以上のAppleシリコンMacを用意し、Xcode 27.2と.NET SDK 10をインストールする。
  2. GitHubのReleasesページからランチャーアプリをダウンロードする。
  3. 自分のゲームダンプと`prod.keys`を用意してランチャーに登録する。
  4. ビルドを実行し、完成したアプリをiPhone/iPadにインストールする。
