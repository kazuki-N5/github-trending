AIネットワークのトラフィック監視とインターネット遮断をWebコンソールで操作するLinuxゲートウェイ

何ができるか

  • AIネットワークの通信セッションを地図・リスト・履歴で可視化する
  • ノードの死活監視と推定ドメイン・推定国・新規観測ドメインを表示する
  • 直近1時間・24時間のトラフィック量をランキング表示する
  • 確立済み接続とDNSを含めてAIネットワークのインターネットアクセスをワンクリックで遮断・許可できる
  • mTLS（相互TLS認証）とソースIPフィルタリングで管理コンソールへのアクセスをセキュアに制限する

なぜ注目されているか

推測 AIエージェントが外部に予期せぬ通信をするリスクを物理ネットワークレベルで管理したいニーズが高まっており、ソフトウェア的な制限よりも確実なゲートウェイでの遮断手段として注目されている。

どんな人に役立つか

AIシステムのネットワーク通信を監視・制御したいセキュリティエンジニアや研究者向け。AIホームラボや企業内のAI検証環境の管理者にも適している。

技術的なポイント

  • Linuxゲートウェイ上でiptables/nftablesとDNSサーバーを組み合わせてネットワークを制御する
  • CaddyをリバースプロキシとしてmTLS（クライアント証明書認証）を実装し、管理コンソールへの不正アクセスを防ぐ
  • Debian 13以降またはUbuntu 24.04のsystemdとNetworkManagerを前提として動作する
  • python3 setup.py demoでデモ環境を起動でき、実機なしでmacOSでも動作を確認できる

試し方

  1. Python 3.11以降をインストールする
  2. リポジトリをクローンする
  3. python3 setup.py demoでデモモードを起動する
  4. ブラウザでhttp://127.0.0.1:8766にアクセスして動作を確認する
