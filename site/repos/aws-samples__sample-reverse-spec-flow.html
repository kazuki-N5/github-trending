既存コードをAIエージェント向けMarkdown仕様書に自動変換するワークフロー

何ができるか

  • 既存のソースコードを解析し、各記述にコード上の証拠（path:line）を付きのMarkdown仕様書を生成する。
  • 別エージェント（ベリファイア）が各記述と引用箇所の整合性を検証し、未確認箇所はUNKNOWNとマークする。
  • モジュール・エントリポイント・外部接続をまとめたコードグラフを作成し、網羅性チェックリストとして使う。
  • gates.shスクリプトが正常終了するまで作業完了とみなさない品質ゲートを備える。
  • 並列処理と進捗のgit保存により、長いセッションを中断・再開できる。
  • Claude CodeとKiro IDEで動作確認済み。

なぜ注目されているか

推測 大規模なレガシーコードベースをAIで扱う際、仕様書の不在が大きな障壁となっており、その自動生成ニーズが高まっている。証拠付き仕様書という信頼性を高める設計が注目を集めていると考えられる。

どんな人に役立つか

ドキュメントが不足したレガシーシステムを保守・リプラットフォームしたいエンジニアや、AIコーディングエージェントを実務投入したいチームに役立つ。

技術的なポイント

  • AIコーディングエージェント（Claude Code / Kiro）をオーケストレーションして仕様書生成と検証を行う。
  • コードグラフで依存関係を把握し、ビジネス領域ごとに並列解析を実施する。
  • 仕様書はMarkdownファイルとして別リポジトリに出力し、安定したIDとインデックスで参照管理する。
  • Playbook（技術スタック別カウントルール）を差し込むことで異なるフレームワークに対応できる。

試し方

  1. 対象コードリポジトリの隣に仕様書リポジトリを作るため、init.shを実行する。
  2. AIエージェント（Claude Code等）にワークフロー指示を渡して解析を開始する。
  3. gates.shが0で終了するまで繰り返し実行し、仕様書の完成度を確認する。
bash init.sh
bash gates.sh
