azu/chizu

初掲載 2026-10-30（はてなブックマーク 2位） GitHub ↗

URLルールに基づいて特定ブラウザ・プロファイルへリンクを振り分けるmacOSデフォルトブラウザ

何ができるか

  • クリックしたリンクをルール設定に基づいてDia・Chrome・Firefoxの指定プロファイルへ自動転送する
  • JSONC形式の設定ファイルをリンク受信のたびに読み直し、再起動なしで設定変更を反映する
  • URLの文字列一致・正規表現・ホスト名・パスプレフィックス・送信元アプリのBundle IDで振り分け条件を指定できる
  • chizu check URLコマンドでブラウザを実際に開かずにルールの動作を確認できる
  • chizu-https:スキームを使うユーザースクリプトでページ内リンクも振り分けルールに通せる

なぜ注目されているか

推測 仕事用・プライベート用など複数のブラウザプロファイルを使い分けるエンジニアが、リンクを手動で振り分ける手間を省くために開発された。設定ファイルベースで動作し、GUIウィンドウが不要な点がCLIに慣れた開発者に受け入れられている。

どんな人に役立つか

複数のChromeプロファイルやブラウザを用途別に使い分けているmacOSユーザー向け。特にApple Siliconチップ搭載のMacを使う開発者に適している。

技術的なポイント

  • Apple Silicon Mac (macOS 14以降)専用のSwiftネイティブアプリとして実装されている
  • 設定ファイルにJSONC（コメント付きJSON）形式を採用し、起動のたびに再読込することでデーモン再起動を不要にしている
  • CaddyによるmTLS（相互TLS認証）でブラウザプロセスへのアクセスを制御できる設計になっている
  • 自己署名のため公証なし（notarized未対応）であり、初回起動時にmacOSのゲートキーパー警告が出る

試し方

  1. GitHubのReleasesページからZIPをダウンロードし、SHA-256チェックサムを確認する
  2. ~/Applications/Chizu.app に展開してインストールする
  3. chizu default setでChizuをmacOSのデフォルトブラウザに設定する
  4. chizu config initで設定ファイルの雛形を作成する
  5. ~/.config/chizu/config.jsoncを編集してルールを追加する
  6. chizu config checkで設定の構文を検証する
chizu default set
chizu config init
chizu config check
chizu check <URL>
chizu open <URL>
