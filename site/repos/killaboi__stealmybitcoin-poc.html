KillaBoi/StealMyBitcoin-PoC

初掲載 2026-10-27（はてなブックマーク 4位） GitHub ↗

PHPのメモリ枯渇脆弱性を悪用してBitcoinウォレットを奪取するCTFチャレンジのPoC

何ができるか

  • PHPのアップロード進捗パース処理のメモリ枯渇（OOM）条件を利用してメモリレイアウト情報をリーク（漏洩）する
  • 取得したメモリ配置情報をもとにワーカープロセスでコマンド実行（RCE）を実現する
  • PHP 8.4.26 Alpine環境を再現するDockerラボ環境でローカル検証が可能
  • 標準ライブラリのみを使用したPython 3.11+スクリプト一本で攻撃を実行できる
  • 成功率や失敗パターンなどの信頼性情報も文書化されており、学習に活用できる

なぜ注目されているか

PHP内部のメモリ管理に関わる低レイヤーな脆弱性を突く手法として、セキュリティ研究者やCTF参加者から注目を集めています。実際のBitcoinウォレットをターゲットにしたチャレンジ形式であるため、実践的な攻撃シナリオの学習素材として価値があります。また、外部ライブラリなしで実装されている点も技術的な参考になります。

どんな人に役立つか

CTF（Capture The Flag）やWebセキュリティを学んでいる学生やエンジニアに向いています。特にPHPの内部動作やメモリ安全性に興味があり、実際の脆弱性悪用手法（エクスプロイト）を手を動かして学びたい人に役立ちます。

技術的なポイント

  • PHPのアップロード進捗機能（upload_progress）におけるメモリ枯渇条件を悪用するメモリリーク手法
  • メモリレイアウト情報（ASLR回避に使うアドレス情報）の取得によるRCE（リモートコード実行）への橋渡し
  • PHP 8.4.26 Alpine + nginxをDockerで再現したローカルラボ環境の構築
  • Python 3.11+の標準ライブラリのみで実装されたシングルスクリプトの攻撃ツール設計

試し方

  1. DockerでPHP 8.4.26 Alpine + nginxのラボ環境を起動する
  2. Python 3.11以上がインストールされていることを確認する
  3. 攻撃スクリプトを --url フラグでラボのエンドポイントURLを指定して実行する
  4. 成功すると対象ホストでコマンド実行が可能になり、出力と証拠ファイルが生成される
python exploit.py --url http://localhost:<port>
