makecindy/cindy

TypeScript 初掲載 2026-10-25（Trendshift 17位） GitHub ↗

思いついたタスクをそのまま実行する、開箱即用（すぐ使える）オープンソースAIエージェント

何ができるか

  • ローカルマシン上の実際のファイルやログイン済みアプリに直接アクセスして作業を自動実行できる
  • ブラウザ・PC・スマートフォンを横断して操作し、幅広いタスクをこなすことができる
  • Claude CodeやCodexなど複数のAIハーネス（AIとツールをつなぐ実行環境）を選んで利用できる
  • 使用するモデルとハーネスを作業の途中でも自由に切り替えることができる
  • チャットアプリからのメッセージやスケジュールをトリガーに作業を自動実行できる

なぜ注目されているか

ローカルマシン上のファイルやログイン済みアプリに直接アクセスしながら動作する点が、既存のクラウド型AIエージェントとの差別化ポイントとなっている。推測 開箱即用（すぐ使える設計）でありながら複数AIモデル・ハーネスの切り替えをサポートし、デスクトップとモバイルを一つのクライアントで統合した包括的な対応範囲が開発者コミュニティから注目されていると考えられる。

どんな人に役立つか

AIエージェントを使って日常的な作業や繰り返し作業を自動化したいエンジニアや開発者に適している。自分のローカル環境でプライバシーを保ちながらAIエージェントを利用したいユーザーにも向いている。

技術的なポイント

  • pnpmモノレポ構成で、Electronを使ったデスクトップクライアントとExpo/React Nativeを使ったモバイルクライアントを同一リポジトリで管理している
  • Claude CodeやCodexなど複数のAIハーネスをサポートし、実行中にモデルとハーネスを動的に切り替えられる柔軟なアーキテクチャを採用している
  • バックエンドサービスは別リポジトリに分離されており、デフォルトでは公式クラウドサービスに接続する設計になっている
  • Git LFSで大きなバイナリを管理し、プラットフォームごとのツールバイナリをpnpm installで自動ダウンロードする仕組みを持つ

試し方

  1. Node.js 22.x と pnpm 10.x（v11は未サポート）、および Git LFS をインストールする
  2. リポジトリをクローンし、Git LFSのファイルを取得する
  3. pnpm install で依存パッケージをインストールする
  4. 中国本土以外のアカウントは --region=global オプション付きでデスクトップアプリを起動する
git clone https://github.com/makecindy/cindy.git
cd cindy
git lfs pull
pnpm install
pnpm restart:desktop:remote --region=global
