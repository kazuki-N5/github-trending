intel/intel-one-mono

初掲載 2026-11-27（Trendshift 18位） GitHub ↗

Intelが開発した視認性重視のオープンソース等幅フォント

何ができるか

  • ライト・レギュラー・ミディアム・ボールドの4ウェイト（各イタリック付き）を提供し、200以上の言語（ラテン文字系）に対応している。
  • 低視力・ロービジョンの開発者からのフィードバックを取り入れ、目の疲れとコーディングミスを減らすよう設計されている。
  • ss01（プログラミングリガチャー）・ss02（矢印形式の<=/>= ）・ss03（wwwリガチャー）などのOpenTypeフィーチャーを提供している。
  • Windows向けに手動でTrueTypeヒンティングが施されており、小さいサイズでも画面上での表示品質が高い。
  • デスクトップ用（.otf/.ttf）・モバイル用（.ttf）・Web用（.woff/.woff2）の各フォーマットを提供している。

なぜ注目されているか

コーディング専用に設計されたIntel公式のオープンソースフォントとして、開発者コミュニティで注目を集めている。低視力ユーザーへのアクセシビリティを考慮した設計思想と、主要エディタへの簡単な設定手順が評価されている。推測 Fira Code・JetBrains Monoなどプログラミング向けフォントへの関心が高い開発者層に響いたと考えられる。

どんな人に役立つか

コーディング時の視認性やフォントの美しさにこだわる開発者が主な対象。特に長時間のコーディングで目の疲れを軽減したい人や、ロービジョンの開発者にも配慮されたフォントを探しているユーザーに向いている。フォントのソースを編集・カスタマイズしたいフォントデザイナーにも対応している。

技術的なポイント

  • UFO（Unified Font Object）形式のソースファイルをRoboFont（バージョン4.4推奨）で管理しており、他のUFO対応エディタでも編集可能。
  • マスター（最軽量・最重量のローマン体・イタリック体）から.designspaceファイルを用いてインターポレーション（補間）でウェイトを生成する仕組みを採用している。
  • TrueType形式の手動ヒンティングソースはMicrosoft VTTで管理されており、Windows上でのピクセルレベルのレンダリング品質を最適化している。
  • OpenTypeのss11/ss12/saltフィーチャーでコロンの表示をコンテキスト依存または全体適用で制御できる。

試し方

  1. GitHubのリリースページからビルド済みフォントファイルをダウンロードする。
  2. OSのフォント管理機能を使ってフォントをインストールする。
  3. VSCodeの場合はsettings.jsonに"editor.fontFamily": "Intel One Mono"を追加する。
  4. プログラミングリガチャーを有効にするにはsettings.jsonに"editor.fontLigatures": "'ss01'"を追加する。
