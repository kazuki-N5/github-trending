mdiri-ai/SoduWork

JavaScript 初掲載 2026-11-18（Trendshift 18位） GitHub ↗

AIエージェントとチームが協働するセルフホスト型AIワークエンジン

何ができるか

  • 複数のAIエージェント実行環境（ハーネス）を切り替えながら作業を進められる
  • あるハーネスが作業し別のハーネスが検証するクロスハーネスレビュー機能で品質を担保できる
  • タスクは承認基準を持ち、担当者のサインオフ（承認）が得られるまで完了とならない
  • 実績あるワークフローをバージョン付きプラグインとして保存・共有・権限管理できる
  • ロール管理・コスト追跡・監査ログなどガバナンス機能を備えた組織向けのセルフホスト展開に対応している

なぜ注目されているか

推測 AIコーディングエージェントが普及するにつれ「AIが出力した成果物を誰がどう承認するか」という管理・ガバナンスの問題が顕在化しており、人間のサインオフを必須とするSoduWorkのアプローチが注目されている。セルフホストでデータを外部に出さずに使える点も評価されている。

どんな人に役立つか

AIエージェントの出力を組織的に管理・レビューしたい開発チームに向いている。AIの成果物に対して承認フローや監査記録を求める企業や、プロンプトのベストプラクティスをプラグインとして社内共有したいエンジニアリングマネージャーに役立つ。

技術的なポイント

  • バックエンドはPython 3.12+とFastAPI（Webフレームワーク）・SQLAlchemyで構築されPostgreSQLまたはSQLiteを使用する
  • デスクトップクライアントはNode.js 22.19+とElectron・Reactで実装されている
  • エージェントランナーはWebSocket経由でHubに接続し、各ハーネスは独立したサブプロセスとして動作する
  • ハーネスの追加にはACP（Agent Client Protocol）という標準インタフェースを使う

試し方

  1. リポジトリをクローンする
  2. デスクトップクライアント付きで起動するスクリプトを実行する（初回は依存パッケージも自動インストール）
  3. adminパスワードを設定し、管理画面のModel catalogでAIプロバイダーを追加する
  4. チャットを開始してAIエージェントにタスクを依頼する
