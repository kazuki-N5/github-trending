AIエージェント向けショートドラマ動画制作の全工程をカバーするルールセット（スキルパッケージ）

何ができるか

  • 企画・脚本・分鏡（絵コンテ）・動画モデルへのプロンプト生成・品質チェックまでの制作全工程をAIエージェントに指示できる。
  • 1つのルーターSKILL（short-drama-director）と10のサブスキルで構成され、工程ごとに役割分担している。
  • Seedance 2.5/2.0やMiniMax H3など複数の動画生成AIに直接投入できる七段式プロンプト組を出力する。
  • validate_prompt.pyやgate_check.pyなどの品質チェックスクリプトで納品前の自動検証ができる。
  • オフラインで使えるストーリーボードビューアーがあり、プロジェクトファイルを単一HTMLページに変換できる。

なぜ注目されているか

推測 Seedance・MiniMaxなど中国系動画生成AIの台頭により、AI動画制作のワークフロー自動化への需要が高まっている。エージェントに渡すだけでプロ水準の制作フローが走るルールセットとして、製作コストを大幅に下げる可能性がある点が注目されている。

どんな人に役立つか

AIを使ったショートドラマ・縦型動画コンテンツの制作者や、動画制作のパイプラインを自動化したいAIエンジニアに向く。OpenClaw・Coze・DifyなどAIエージェントプラットフォームの利用者が対象で、画像生成は外部サービスで行う前提のため画像素材自体は含まない。

技術的なポイント

  • AIエージェントへの指示をスキル（ルール文書）として記述し、工程ごとのルーターSKILLとサブスキルに分割する設計を採用している。
  • 制作開始前に出典・モデルバージョン・アスペクト比・納品形式・連結方式のロック確認を義務付け、未確定項目があれば作業を止める仕組みになっている。
  • 素材形態をM0（プロンプトのみ）・M1・M2に分類し、画像アセットの有無に応じてワークフローを切り替える。
  • validate_prompt.pyやgate_check.pyなどPython製のlintスクリプトで機械的な品質チェックを自動化している。

試し方

  1. OpenClaw・Coze・DifyなどAIエージェントプラットフォームを用意する。
  2. リポジトリからスキルファイルをダウンロードしてエージェントにインポートする。
  3. 制作開始前に要求される五つのロック項目（出典・モデル・比率・形式・連結方法）を確認・入力する。
  4. short-drama-directorスキルを呼び出し、企画情報を入力して制作フローを開始する。
python validate_prompt.py
python gate_check.py
