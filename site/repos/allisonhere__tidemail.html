キーボード操作中心のターミナルメールクライアント（IMAP/SMTP対応）

何ができるか

  • IMAP/SMtpをサポートし、複数アカウントを統合受信トレイで管理できる。
  • メールの既読・スター・アーカイブ・移動・削除がIMAP経由でサーバーに同期される。
  • 削除・送信などの操作をCtrl+Zで取り消せるアンドゥ機能を備える。
  • Vimキーバインド・検索/置換・テンプレート・オフラインスペルチェックを備えた作成エディタがある。
  • Kitty互換ターミナル（Ghostty、Kitty、Rioなど）ではメール内に画像をインライン表示できる。
  • 51種類・23ファミリーのテーマを搭載し、コントラスト自動チェック機能も持つ。

なぜ注目されているか

推測 GUIに依存しないキーボード駆動のメールクライアントとして、開発者やターミナルユーザーの間で注目を集めている。AIエージェント向けのヘッドレスCLIやスキルインストールコマンドを備える点が、AIツールとの連携を重視する層に受けていると考えられる。

どんな人に役立つか

ターミナル上で全作業を完結させたいエンジニアや、GUIメールクライアントの重さを嫌うユーザー向け。AIツールとの統合やプラグインによる拡張を必要とする上級ユーザーにも適している。

技術的なポイント

  • GoとBubble Tea（TUIフレームワーク）で実装されており、軽量かつ高速なターミナルUIを実現している。
  • メールのローカルキャッシュにSQLiteを使用しており、オフライン閲覧や高速検索が可能。
  • GmailはOAuth2（現在は一時的に利用不可でアプリパスワード推奨）、OutlookはOAuthによる認証をサポートする。
  • パスワード管理はlibsecret（Linux）またはKeychain（macOS）に委任し、安全に保管される。
  • PGP（GnuPG経由）やAI要約・校正などのプラグイン機構を持ち、機能を外部拡張できる。

試し方

  1. Homebrew、AUR（tidemail-bin）、Nix、またはcurlインストーラーでインストールする。
  2. ~/.config/tidemail/config.toml にアカウント情報を設定する。
  3. tidemail を実行してターミナルUIを起動する。
brew install tidemail
go build -o tidemail .
go test ./...
