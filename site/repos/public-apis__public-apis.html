Python 初掲載 2026-11-03（Trendshift 14位） GitHub ↗

無料で使えるパブリックAPIを50以上のカテゴリに分類してまとめた定番リスト

何ができるか

  • 動物・アニメから気象・仮想通貨まで50以上のカテゴリにわたるAPIをリスト化している
  • 各APIについて認証方式（なし・APIキー・OAuth）・HTTPS対応・CORS対応を一覧で確認できる
  • AIエージェントがAPIをツールとして呼び出せるMCPサーバーの一覧も収録されている
  • publicapis.lolでキーなしフィルタや稼働状況確認が可能な検索ディレクトリが提供されている
  • APILayerが提供する商用グレードのAPIも紹介されている

なぜ注目されているか

推測 開発者がプロトタイプや個人プロジェクトに使える無料APIを探す際の定番リポジトリとして長年参照され続けており、GitHubで非常に多くのスターを獲得している。学習用・ハッカソン・個人開発での需要が絶えないため、継続的に高い注目を集めている。

どんな人に役立つか

APIを活用したアプリを作りたい学生や個人開発者に最適。特に認証不要で手軽に試せるAPIを素早く探したい場合や、ハッカソンのアイデア出しにも役立つ。

技術的なポイント

  • リポジトリ自体はPythonで管理されており、APIリストの検証や自動化スクリプトに使用されている
  • MCPサーバーのリストも含まれており、AIエージェントからAPIをツールとして呼び出す用途にも対応している

試し方

  1. GitHubのREADMEまたはpublicapis.lolで目的のAPIをカテゴリから探す
  2. 各APIの公式ドキュメントにアクセスしてAPIキーを取得する（必要な場合）
  3. APIエンドポイントに対してHTTPリクエストを送信して利用する
